# 02-实时经营挑战 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
实时经营挑战是回合制策略商赛的**进阶形态**，从"回合暂停思考"转向"持续运转决策"。面向初中及以上学段，作为沙盒练习模式运行。界面设计核心目标是制造**多线程操作的认知负荷**，训练学生在信息过载环境下的快速判断能力。

### 1.2 与回合制的本质区别
| 维度 | 回合制策略商赛 | 实时经营挑战 |
|------|---------------|-------------|
| 时间结构 | 离散回合，轮间暂停 | 连续流动，24h=1游戏年 |
| 决策节奏 | 5-15分钟深思熟虑 | 5分钟应急决策时限 |
| 信息状态 | 静态快照 | 动态流式 |
| 失败模式 | 排名落后 | 现金流断裂 |
| 核心能力 | 战略预判 | 应急响应 |

### 1.3 设计目标
- **模拟真实经营压力**：公司24小时运转，决策即时生效
- **训练多线程注意力**：同时监控多个业务模块
- **制造可控危机**：随机事件在5分钟窗口内要求应急决策

## 三、各模块详细说明

### 3.1 Hero区域

**视觉特征**：
- 主题色：青色系（`#06b6d4`），传递"流动、实时、动态"的心理暗示
- 徽章标签："沙盒练习模式 · 24小时游戏年"
- 副标题强调"持续运转"与"随机事件"

**核心数据展示**：
| 数据项 | 值 | 教学意义 |
|--------|-----|----------|
| 决策生效 | 实时 | 决策与后果之间无缓冲 |
| 时间压缩 | 24h=1游戏年 | 在课堂时间内体验长期经营 |
| 应急时限 | 5分钟 | 制造适度紧迫感 |
| 参与形式 | 个人挑战 | 聚焦个体多任务能力 |

---

### 3.2 经营模式 · 三卡片概览

**持续运营** 🏭
- 公司24小时不间断运转
- 收入、支出、库存实时变化
- 需要随时关注现金流，避免断裂

**随机事件** 🎲
- 供应链断裂、竞品发布、舆情危机
- 事件随机发生，必须在5分钟内做出应急决策

**效率优化** 📊
- 同时管理多个业务线
- 在有限时间内做出最优资源配置

**供应链可视化**（下方大卡片）：
采用水平流程图展示四个节点：
```
🌾 原材料 → 🏭 生产制造 → 📦 仓储物流 → 🛒 销售渠道
库存充足    运转正常      配送中        热销中
```

每个节点包含：图标、名称、状态标签。箭头连接形成流动感。状态标签使用颜色编码（绿色=正常，黄色=警告，红色=危机）。

---

### 3.3 核心指标监控 · 四宫格仪表盘

| 指标 | 当前值 | 趋势 | 含义 |
|------|--------|------|------|
| 现金流 | ¥892万 | ▲ +12%/小时 | 生命线，归零即出局 |
| 客户满意度 | 94% | ▼ -2%/小时 | 影响复购率 |
| 产能利用率 | 68% | ▲ +5%/小时 | 资源浪费或不足 |
| 库存量 | 1,240 | ▼ -15%/小时 | 断货风险 |

**设计细节**：
- 数值使用大字号等宽字体，强化数据感
- 趋势箭头+颜色（绿=上升/好，红=下降/坏）
- 每个指标卡片hover时轻微上浮

**市场快讯滚动条**（下方）：
- 横向无限滚动动画（CSS `@keyframes ticker`）
- 内容重复两次以实现无缝循环
- 包含4条市场信息：竞品动态、原材料价格、客户反馈、供应商预警

---

### 3.4 经营指挥中心（核心交互区）

采用**mockup-frame**框架模拟真实软件界面：

**顶部状态栏**：
- 左侧：三个圆点（模拟窗口控制按钮）
- 中间："经营指挥中心 · 第47游戏日 · 运营中"
- 右侧：绿色脉冲指示灯 + "系统正常"

**突发事件卡片**（红色渐变背景）：
- 事件类型标签："🚨 突发事件"
- 事件标题："供应链断裂：主要供应商工厂停工"
- 事件描述：库存将在3小时后耗尽
- **决策倒计时**：大字号红色数字（04:32），制造紧迫感
- 右侧显示"若不行动，跑道将缩短至..."

**应急决策选项**（2×2网格）：

| 选项 | 图标 | 名称 | 代价 |
|------|------|------|------|
| A | 🔍 | 紧急寻找替代供应商 | 成本+20%，立即恢复 |
| B | 📉 | 降低产能消化库存 | 收入-30%，维持运营 |
| C | 🤝 | 向竞争对手采购 | 成本+35%，可能泄露信息 |
| D | ⏸️ | 暂停部分产品线 | 聚焦核心，损失最小化 |

**设计意图**：四个选项没有绝对正确答案，每个都有明确代价。学生必须在信息不完全和时间压力下做出权衡——这正是真实商业决策的特征。

### 3.5 事件日志流

**实时记录格式**：
```
[时间戳] [类型标签] 事件描述
```

**类型标签颜色编码**：
| 类型 | 颜色 | 示例 |
|------|------|------|
| [危机] | 红色 | 供应商工厂设备故障 |
| [市场] | 橙色 | 竞品发布新品 |
| [运营] | 绿色 | 仓库扩建完成 |
| [财务] | 蓝色 | Q3财报生成 |
| [舆情] | 橙色 | 社交媒体负面讨论 |
| [销售] | 绿色 | 预售订单突破 |
| [人事] | 蓝色 | 团队扩招完成 |
| [库存] | 橙色 | 库存降至警戒线 |

**设计细节**：
- 时间戳使用等宽字体，对齐形成视觉节奏
- 最新事件在顶部，向下滚动查看历史
- 最大高度300px，超出时内部滚动

## 四、视觉设计系统

### 4.1 色彩方案
- **主题色**：`#06b6d4`（青色）——传递流动、实时、动态
- **危险事件**：红色渐变背景（`rgba(239,68,68,0.15)`到`rgba(245,158,11,0.1)`）
- **状态指示**：绿色脉冲动画（`animation: pulse 2s infinite`）
- **日志类型**：四种颜色对应四种信息类型

### 4.2 动效设计
- **脉冲动画**：状态指示灯、危机卡片的呼吸效果
- **滚动动画**：市场快讯的无限横向滚动
- **hover效果**：指标卡片上浮、行动按钮边框变色

### 4.3 布局响应式
- 桌面端：四宫格指标、2×2决策网格、双栏日志
- 移动端：指标改为2×2、决策选项垂直堆叠、日志全宽

## 五、教学锚点与能力映射

### 5.1 直接训练能力
| 能力维度 | 界面元素 | 训练机制 |
|----------|----------|----------|
| 多线程操作 | 四指标+日志+快讯 | 同时关注多个信息源 |
| 应急响应 | 5分钟倒计时 | 时间压力下的快速决策 |
| 风险权衡 | 四选项各有利弊 | 没有标准答案的艰难选择 |
| 现金流意识 | 现金流仪表盘 | 持续关注核心指标 |

### 5.2 赛后可引出的理论概念
- **运营管理**：JIT（准时制生产）vs 安全库存
- **危机管理**：业务连续性计划（BCP）
- **决策理论**：满意性决策（satisficing）vs 最优化决策
- **系统动力学**：正反馈与负反馈回路

## 六、与回合制模式的对比教学价值

两种模式可以**配对使用**：
1. **先玩回合制**：在相对从容的环境中理解基本机制
2. **再玩实时模式**：在压力环境下检验和深化理解
3. **对比复盘**：
   - "回合制中你有10分钟思考，实时模式只有5分钟——哪些决策变得不同了？"
   - "实时模式的供应链断裂，如果在回合制中你会怎么处理？"

## 七、使用建议

### 7.1 适合场景
- 已熟悉回合制基本规则的学生进阶训练
- 强调"运营能力"而非"战略能力"的教学目标
- 个人技能评估（而非团队协作）

### 7.2 教师操作要点
1. **赛前**：明确"24小时=1游戏年"的时间压缩比例
2. **赛中**：观察学生的注意力分配——是否只顾现金流忽视客户满意度？
3. **赛后**：重点复盘"第一个危机出现时，你的第一反应是什么？"

### 7.3 常见学生误区
- **过度反应**：对每个事件都采取最激进的应对措施
- **忽视预警**：日志中的警告信息被忽略，直到危机爆发
- **单点聚焦**：只关注现金流，忽视客户满意度和库存的连锁影响
