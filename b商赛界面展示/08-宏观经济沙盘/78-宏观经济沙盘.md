# 08-宏观经济沙盘 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
宏观经济沙盘是商业模拟平台的**系统性思维训练模块**。引入通胀、紧缩、政策调控等宏观变量，所有队伍在同一经济周期中经营。面向大学及以上学段，理解宏观环境对微观决策的影响，训练系统性思维。

### 1.2 设计目标
- **理解经济周期**：体验繁荣→衰退→萧条→复苏的循环
- **感受政策影响**：作为"央行行长"选择政策组合
- **观察传导机制**：宏观政策如何通过产业链影响企业
- **训练系统思维**：理解"局部最优≠全局最优"

### 1.3 教学哲学
传统商业教育往往从微观入手（企业如何经营），此模式补充了宏观视角（企业在什么环境中经营）。学生发现：即使是最优秀的企业管理者，也无法对抗经济周期的力量——但可以通过预判周期来调整策略。

| 调控工具 | 政策 | 体验政府的经济调控角色 |

**SVG环形图**：

**季度宏观经济报告**（下方横幅）：
> "本季度经济持续复苏，GDP增长4.2%，但通胀率攀升至3.8%，接近央行警戒线。消费回暖带动零售增长，但原材料价格同步上涨，企业成本压力增大。央行维持宽松货币政策，但市场普遍预期下季度可能加息。"

### 3.4 政策工具箱

**四卡片网格**（2×2）：

**货币政策A：加息** 🏦
- 将基准利率上调0.5%
- 抑制通胀，但可能减缓经济增长
- **效果**：通胀▼-0.8% / GDP▼-0.5% / 融资成本▲+15% / 消费▼-8%

**货币政策B：维持现状** 💵（当前选中）
- 保持当前利率不变
- 观察经济数据变化
- **效果**：通胀▲+0.3% / GDP▲+0.2% / 融资成本→不变 / 消费→不变

**财政政策：基建刺激** 🏗️
- 增加政府基建支出
- 拉动内需，但可能推高通胀
- **效果**：GDP▲+1.0% / 就业▲+5% / 通胀▲+0.5% / 赤字▲+2%

**汇率政策：贬值促出口** 🛡️
- 允许本币适度贬值
- 提升出口竞争力
- **效果**：出口▲+12% / 进口成本▲+8% / 外资流入▼-5% / 通胀▲+0.3%

**设计细节**：
- 每个政策卡片有图标、名称、描述、效果列表
- 效果使用颜色编码（绿=正面，红=负面）
- 选中状态：边框高亮+背景变色
- hover时边框变色

- **宏观经济学**：IS-LM模型、AD-AS模型、菲利普斯曲线

- **国际经济学**：汇率决定理论、蒙代尔-弗莱明模型

## 六、使用建议

### 6.1 适合场景
- 宏观经济学课程的情境化教学
- 需要理解"宏观环境影响微观决策"
- 训练系统性思维和多因素权衡

### 6.2 教师操作要点
1. **赛前**：确保学生理解基本宏观指标的含义
2. **赛中**：引导学生关注"政策的副作用"
3. **赛后**：讨论"如果你是央行行长，你会如何选择？"

### 6.3 常见学生误区
- **单一目标思维**：只关注GDP增长，忽视通胀
- **线性外推**：认为当前趋势会永远持续
- **忽视时滞**：不理解政策效果有延迟
