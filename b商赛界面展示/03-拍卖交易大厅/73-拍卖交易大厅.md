# 03-拍卖交易大厅 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
拍卖交易大厅是商业模拟平台的**金融素养训练模块**，通过公开喊价与密封报价并存的拍卖机制，让学生直接体验价格发现、信息不对称利用与风险控制。面向高中及以上学段，每轮节奏1-2分钟，是十种模式中最接近真实金融市场交易体验的模式。

### 1.2 设计目标
- **体验价格发现机制**：通过实时竞价观察"价格如何形成"
- **理解信息不对称**：密封报价中独立判断vs受他人影响的张力
- **感受赢者诅咒**：高价中标后发现标的实际价值低于出价
- **训练风险控制**：设定最高出价上限并严格遵守

### 1.3 教学哲学
拍卖是经济学中最纯粹的市场机制之一。与回合制策略商赛的"复杂系统"不同，拍卖将商业决策简化为**单一维度（价格）的博弈**，让学生聚焦于"估值"这一核心商业能力。

## 三、各模块详细说明

### 3.1 Hero区域

**视觉特征**：
- 主题色：琥珀色系（`#f59e0b`），传递"财富、交易、紧张"的心理暗示
- 徽章标签："快节奏竞价 · 1-2分钟一轮"
- 图标使用拍卖锤（🔨），强化模式识别

**核心数据展示**：
| 数据项 | 值 | 教学意义 |
|--------|-----|----------|
| 每轮节奏 | 1-2分钟 | 快速迭代，高频决策训练 |
| 报价方式 | 密封/公开 | 体验不同信息环境下的策略 |
| 拍卖标的 | 多品类 | 不同标的的估值方法不同 |
| 价格发现 | 实时 | 观察市场如何形成共识价格 |

---

### 3.2 拍卖类型 · 三种核心机制

**城市广告位拍卖** 🏙️
- 每轮开始前，各城市置顶展示位公开竞价
- 价高者获得该城市品牌曝光加成
- 过高出价会挤压其他投资预算
- **经济学概念**：公开升价拍卖（English Auction）

**技术专利交易** 📜
- 队伍间可买卖Tech属性（一次性转移）
- 密封报价，双方议价
- **经济学概念**：双边议价、知识产权估值

**供应链竞标** 📦
- 上游原材料供应商由NPC或教师扮演
- 多轮密封报价，最低报价者获得供应合同
- **经济学概念**：采购拍卖、成本透明化

### 3.3 实时拍卖大厅（核心交互区）

采用**舞台式布局**，模拟真实拍卖会场：

**拍卖舞台**（顶部深色区域）：
- 背景：深棕色渐变（`#451a03`到`#78350f`）+ 金色图案纹理
- 标的名称：大字号金色文字（"🏙️ 杭州 · 黄金广告位"）
- 标的描述："获得杭州市场品牌展示加成50%，持续2轮"
- **当前最高出价**：超大字号（3.5rem）金色等宽数字（"¥45万"）
- 倒计时："00:47"，红色大字号

**出价者列表**（中部）：
- 按出价时间倒序排列
- 领先者（leading）边框高亮+背景变色
- 每行显示：头像、队伍名称、出价时间、出价金额
- 出价金额使用主题色等宽字体

**出价控制区**（底部）：
```
[+5万 (¥50万)]  [+10万 (¥55万)]  [+15万 (¥60万)]  [放弃]
```
- 三个加价按钮，梯度递增
- "放弃"按钮使用红色边框，视觉区分
- 主按钮（+15万）使用实心主题色+阴影

**即将开拍的标的**（下方三卡片）：
- LOT-002：南京品牌展示位（¥30万起）
- LOT-003：Tech专利包A（¥25万起）
- LOT-004：合肥原材料供应（¥20万起）
- 每个卡片显示：编号、状态标签、名称、描述、起拍价、出价次数

- 形成视觉上的价格趋势

### 3.5 拍卖策略指南

**四卡片网格**：

1. **公开拍卖策略** 🎯
   - 观察对手出价节奏，判断预算上限
   - 适时"狙击"——最后一秒出高价
   - 注意：过度竞价导致"赢者诅咒"

2. **密封报价策略** 🎭
   - 基于独立判断出价，不受他人影响
   - 最优策略：出价比预估价值略低
   - 保留安全边际

3. **风险控制原则** ⚖️
   - 设定最高出价上限并严格遵守
   - 拍卖的肾上腺素容易让人冲动
   - 记住：没有拍到不是损失，高价拍错才是

4. **信息价值** 💡
   - 拍卖前尽可能收集信息
   - 对手预算、历史出价风格、标的价值区间
   - 信息优势是超额收益的来源

## 五、经济学原理映射

### 5.1 拍卖理论
| 拍卖类型 | 界面体现 | 理论概念 |
|----------|----------|----------|
| 英式拍卖（公开升价） | 实时竞价大厅 | 价格发现、信号传递 |
| 荷式拍卖（公开降价） | 可扩展机制 | 时间压力、抢先出手 |
| 密封一价 | 技术专利交易 | 独立私有价值 |
| 密封二价（维克里） | 可扩展机制 | 真实报价激励 |

### 5.2 行为经济学
- **赢者诅咒**：中标者往往出价过高，因为最乐观的人赢得拍卖
- **锚定效应**：起拍价成为心理锚点
- **社会认同**：看到他人出价会提高自己的估值
- **禀赋效应**：一旦参与竞价，对标的的估值会上升

### 5.3 信息经济学
- **信息不对称**：密封报价中，每个人对标的的估值不同
- **信号传递**：公开拍卖中，出价行为本身传递信息
- **信息价值**：间谍情报（在其他模式中）在拍卖中体现为"观察对手"

## 六、使用建议

### 6.1 适合场景
- 经济学/金融课程的情境化教学
- 需要快速多次决策的训练场景
- 理解"市场如何形成价格"的教学目标

### 6.2 教师操作要点
1. **赛前**：简要讲解四种拍卖类型的区别（5分钟）
2. **赛中**：提醒学生注意"赢者诅咒"——中标不代表胜利
3. **赛后**：对比不同学生的出价策略，引出最优拍卖设计理论

### 6.3 常见学生误区
- **追涨杀跌**：看到他人出价就跟随加价
- **过度自信**：高估自己对标的价值的判断
- **沉没成本谬误**：已经投入很多出价，不愿放弃
- **忽视机会成本**：把所有预算投入一个标的，忽视其他机会

## 七、扩展可能性

### 7.1 可增加的拍卖机制
- **维克里拍卖**（密封二价）：最高出价者获胜，但支付第二高价——理论上会诱导真实报价
- **全支付拍卖**：所有出价者都要支付自己的出价——适合模拟政治游说、研发竞赛
- **组合拍卖**：同时拍卖多个标的，允许打包出价——更接近真实频谱拍卖

### 7.2 与其他模式的联动
- 回合制策略商赛中的"暗标拍卖"可复用此界面
- 产业链角色扮演中的"供应链竞标"可扩展为拍卖形式
- 投资人对决中的"估值谈判"与拍卖的出价逻辑相通
