## 使用建议

　　这些 PNG 是高质感补充资产，适合用在较大的卡片、空状态、教程提示、赛事介绍、拍卖资源卡和关键状态面板中。小尺寸按钮和密集表格仍优先使用 SVG / lucide 图标，以保证可读性和体积控制。

　　当前单图为从 4x3 图标板裁切得到的方形 PNG，带浅色背景，不是透明底。若后续要作为浮动 cutout 使用，建议单独生成透明版或进行本地抠图处理。
