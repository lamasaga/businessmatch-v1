# 01-回合制策略商赛 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
回合制策略商赛是整个商业模拟平台的**经典竞技模式**，采用4轮标准赛制，面向高中及以上学段。界面设计遵循"体验先行，概念后置"的教学原则——学生先沉浸在投资决策的紧张感中，赛后复盘时才接触到softmax效用函数、纳什均衡等理论概念。

### 1.2 设计目标
- **降低认知门槛**：用可视化滑块替代数字输入，用颜色编码替代文字说明
- **强化博弈感知**：通过间谍情报、联盟提示、实时排名预估，让"对手存在"成为决策的显性因素
- **制造时间压力**：倒计时器与提交按钮形成紧迫感，模拟真实商业决策的时效约束

## 三、各模块详细说明

### 3.1 Hero区域

**视觉特征**：
- 全宽背景图（cover.svg）+ 深色渐变遮罩，确保文字可读性
- 主题色：蓝紫色系（`#6366f1`），传递"科技+策略"的心理暗示
- 徽章标签："经典竞技模式 · 4轮标准赛制"

**核心数据展示**（四宫格）：
| 数据项 | 值 | 教学意义 |
|--------|-----|----------|
| 标准回合 | 4轮 | 有限博弈框架，训练短期策略优化 |
| 每轮决策 | 5-15分钟 | 制造适度时间压力，避免过度分析 |
| 同场竞技 | 4-10队 | 保证竞争密度，又不至于信息过载 |
| 班级联赛 | 16-40人 | 适配标准班级规模 |

**副标题文案**：
> "四轮回合制竞技，队伍选择路线并投资技术/用户匹配/品牌展示，基于复杂引擎结算排名。训练资源分配、战略预判与博弈推理能力。"

---

### 3.2 赛制流程（四轮回合时间线）

采用垂直时间线布局，四个节点依次展开：

**Round 1 · 开局布局**
- 选择经营路线（TECH/USER/BRAND/PATHFINDER）
- 确定首座城市，分配初始预算
- 建立战略基线

**Round 2 · 市场渗透**
- 根据首轮反馈调整策略
- 可选择扩展新城市或深耕已有市场
- 首次感受到竞争压力

**Round 3 · 战略博弈**
- 市场格局初现，需预判对手动作
- 可启用"间谍"机制查看对手上回合决策摘要
- 或发起临时联盟

**Round 4 · 终局冲刺**
- 最后一轮，所有预算必须投出
- 结算引擎基于softmax效用、排名竞争、BQI调节计算最终排名

**设计细节**：每个时间节点带有`animate-fadeInUp`动画和递增的delay，形成视觉上的递进感。

---

### 3.3 核心机制 · 四大路线与三维投资

**路线选择卡片**（2×2网格）：

| 路线 | 图标 | 核心加成 | 标签 | 适合人群 |
|------|------|----------|------|----------|
| TECH | 🔬 | 技术投入效率+30% | 高成长/长周期 | Geek群体占比高的城市 |
| USER | 🎯 | 用户匹配投入效率+30% | 精准/中周期 | Show群体活跃的市场 |
| BRAND | 📢 | 品牌展示投入效率+30% | 爆发/高风险 | 市场成熟、竞争激烈的城市 |
| PATHFINDER | 🚀 | 独占红利触发概率提升 | 博弈/灵活 | 敢于冒险、追求差异化 |

**交互设计**：
- 卡片hover时边框变色+背景微亮
- 选中状态（`.active`）显示右上角勾选标记
- 每个卡片底部带两个标签，快速传达路线特性

**城市市场参数**（3×2网格）：
- 展示6座城市的Geek/Show人群占比
- 选中状态（`.selected`）边框高亮
- 城市数据与路线加成形成策略组合空间

### 3.4 决策舱界面（核心交互区）

这是整个界面最复杂的部分，采用**三栏式布局**：

```
┌─────────────┬─────────────────────┬─────────────┐
│  左栏        │  中栏                │  右栏        │
│  我的状态    │  投资分配（核心）     │  实时情报    │
│             │                     │             │
│ · 当前路线   │ · 回合指示器         │ · 间谍情报   │
│ · 已开城市   │ · 5个投资滑块        │ · 市场动态   │
│ · 可用资金   │ · 预算使用进度       │ · 预计排名   │
│ · 当前排名   │ · 预览/提交按钮      │             │
└─────────────┴─────────────────────┴─────────────┘
```

**左栏 · 我的状态**：
- 当前路线（带路线图标和颜色）
- 已开通城市列表
- 可用资金（大字号等宽字体，强化数字感知）
- 当前排名

**中栏 · 投资分配**：
- **回合指示器**：4个圆点，已完成为绿色✓，当前为边框高亮，未开始为灰色
- **5个投资滑块**：
  - 技术投入（全局）
  - 用户匹配-杭州
  - 用户匹配-南京
  - 品牌展示-杭州
  - 品牌展示-南京
- 每个滑块包含：资源名称、当前数值、滑轨、填充条、拇指按钮
- 底部显示"预算已使用79% · 剩余¥27.5万"
- 两个按钮：预览效果（次要）/ 确认提交（主要）

**右栏 · 实时情报**：
- **间谍情报面板**（红色渐变背景，制造紧张感）：显示某队上回合决策摘要
- **市场动态**：3条bullet point快讯
- **预计排名**：基于当前投入的大字号预估排名

**设计意图**：三栏布局将"自我状态-决策操作-外部信息"分离，符合人类决策的认知模型（现状评估→行动选择→环境反馈）。

---

### 3.5 特色机制

**三卡片网格**：

1. **间谍机制** 🕵️
   - 投入预算查看某队上回合决策摘要
   - 信息即力量，但间谍行为本身消耗资源
   - 教学锚点：信息不对称、博弈论中的信息价值

2. **联盟系统** 🤝
   - 两队临时合作共享某城市Fit属性
   - 联盟可随时背叛
   - 教学锚点：重复博弈、信任建立与破坏

3. **暗标拍卖** 🔨
   - 各城市置顶展示位密封报价拍卖
   - 价高者得，但过高出价挤压其他投资
   - 教学锚点：拍卖理论、赢者诅咒

---

### 3.6 实时排行榜

**列表式设计**：
- 排名1-3名使用金银铜渐变背景+特殊颜色文字
- 第4名及以后使用标准卡片背景
- 每行显示：排名徽章、队伍名称、路线/城市标签、得分、涨跌幅
- 涨跌幅用▲▼箭头+颜色区分

**教学价值**：排行榜不仅是竞争工具，更是"社会比较"心理机制的载体——学生通过排名变化直观感受决策后果。

## 四、视觉设计系统

### 4.1 色彩方案
- **主题色**：`#6366f1`（靛蓝）——传递理性、策略、科技感
- **成功色**：`#22c55e`（绿）——正向反馈、完成状态
- **警告色**：`#f59e0b`（橙）——风险提示、需要注意
- **危险色**：`#ef4444`（红）——危机、出局、负面事件
- **背景层级**：primary(#0f172a) → secondary(#1e293b) → card(#1e293b带边框) → hover(#334155)

### 4.2 字体层级
- 标题：1.75-2rem，font-weight 700-800
- 数据：等宽字体（var(--font-mono)），强化数字的精确感
- 正文：1rem，line-height 1.7，保证长文本可读性
- 标签/辅助：0.75rem，color: text-muted

### 4.3 动效设计
- `fadeInUp`：内容区块进入视口时的上浮淡入
- `pulse`：状态指示灯、拍卖倒计时的呼吸效果
- `shimmer`：加载状态的骨架屏闪光
- 所有过渡使用`transition: all 0.3s ease`

## 五、教学锚点与能力映射

### 5.1 直接训练能力
| 能力维度 | 界面元素 | 训练机制 |
|----------|----------|----------|
| 资源分配 | 投资滑块 | 有限预算下的多目标优化 |
| 战略预判 | 预计排名 | 决策前预览可能后果 |
| 博弈推理 | 间谍/联盟 | 对手建模与信息不对称利用 |
| 风险权衡 | 路线标签 | 高成长vs长周期的选择 |

### 5.2 赛后可引出的理论概念
- **微观经济学**：边际效用递减（投资过载提示）
- **博弈论**：纳什均衡（多队竞争的最优策略）、囚徒困境（联盟背叛）
- **运筹学**：线性规划（预算约束下的最优分配）
- **行为经济学**：锚定效应（首轮决策对后续的影响）

## 六、技术实现要点

### 6.1 前端架构
- 纯HTML/CSS静态页面，无JavaScript框架依赖
- 使用CSS Grid和Flexbox实现响应式布局
- CSS自定义属性（变量）实现主题切换

### 6.2 响应式断点
- 桌面端（>1024px）：三栏决策舱、2×2路线网格
- 平板端（768-1024px）：双栏布局，决策舱改为上下堆叠
- 移动端（<768px）：单栏全宽，滑块垂直排列

### 6.3 性能优化
- 所有动画使用CSS transform和opacity（GPU加速）
- 背景图使用SVG格式，体积<50KB
- 无外部字体依赖，使用系统字体栈

## 八、使用建议

### 8.1 适合场景
- 初次接触商业模拟的学生（入门门槛最低）
- 班级联赛（4-10队规模适配标准教室）
- 需要明确胜负排名的竞技场景

### 8.2 教师操作要点
1. **赛前**：确保学生理解四条路线的差异（可用5分钟快速讲解）
2. **赛中**：关注倒计时，提醒学生注意时间分配
3. **赛后**：重点复盘"如果知道对手会怎么做，你的决策会改变吗？"

### 8.3 常见学生误区
- **过度集中**：把所有预算投入一个城市，忽视分散风险
- **忽视路线匹配**：选择与城市人群不匹配的投资方向
- **信息焦虑**：过度使用间谍，导致实际投资不足
