# 05 - 平台体验与交互设计

> 学生不易理解、教学意义不够——这两个痛点很大程度上是体验设计问题。本文件从用户旅程、信息架构、界面范式三个层面提供设计思路。

---

## 一、用户角色与旅程地图

### 1.1 核心角色

| 角色 | 核心目标 | 痛点 | 设计关键词 |
|------|----------|------|-----------|
| **学生（参赛者）** | 赢比赛、学到东西、获得认可 | 规则看不懂、决策没反馈、输了不知道为啥 | 清晰、即时、有成就感 |
| **教师（组织者）** | 顺利完成教学活动、看到学生成长 | 组织麻烦、数据难收集、控场困难 | 高效、可控、可分析 |
| **投资人/评委** | 准确评估队伍、参与感强 | 信息太多太杂、评分标准不透明 | 聚焦、对比、公正感 |
| **观摩者（家长/嘉宾）** | 看得懂、觉得有意思 | 完全看不懂在干嘛 | 直观、故事化 |

### 1.2 学生旅程（一次完整的课程体验）

```
课前 24h
├── 收到邀请（微信/班级群）
├── 点击链接 → 快速注册（手机号/微信授权）
├── 完成"新手引导"（3分钟互动教程）
└── 获得"预备创业者"称号，充满期待

课中
├── 0-5min：教师开场，大屏展示今日主题
├── 5-10min：学生进入"决策舱"（个人终端），查看本轮情境
├── 10-18min：决策时间（投资分配、宣言撰写）
│   └── 系统实时提示："你的预算还剩 30%，是否确认？"
├── 18-20min：提交截止，等待结算
├── 20-23min：动画结算（城市份额饼图展开、排名升降）
├── 23-28min：个人战报弹窗 + 教师点评窗口
└── 循环 4 轮

课后
├── 收到"个人商业复盘报告"（H5 页面，可分享）
├── 查看班级排行榜 + 获得的徽章
├── 解锁下一课程单元（若完成目标）
└── 朋友圈分享："我在商业模拟中获得了'逆势翻盘'徽章！"
```

## 二、信息架构：三层界面模型

### 2.1 战略层（Strategic View）—— 教师端 / 大屏端

**目标**：掌控全局、制造氛围

| 模块 | 内容 | 设计 |
|------|------|------|
| 进程控制 | 轮次状态、计时器、开始/结算按钮 | 醒目按钮，防误触二次确认 |
| 全场态势 | 各队预算、路线分布、城市覆盖 | 蜂巢图或矩阵图 |
| 实时提交 | 已提交 / 未提交队伍 | 进度条 + 队名亮灯 |
| 结算动画 | 排名变化、关键事件 | 3D 柱状图升降、新闻 ticker |
| 排行榜 | 累计加权分排名 | 始终置顶或侧栏 |

### 2.2 战术层（Tactical View）—— 学生决策端

**目标**：在有限时间内做出 informed decision

**当前 TechVenture 的问题**：学生面对空白的数字输入框，缺乏决策框架。

**改进方案**：

```
决策界面（每轮）
┌─────────────────────────────────────────┐
│  顶部：倒计时 + 本轮情境摘要              │
│  "R3 · 突发事件：技术突破浪潮 · 剩余 5:23" │
├─────────────────────────────────────────┤
│  左侧：我的状态                           │
│  ├─ 当前路线：技术驱动型 [切换? -5万]      │
│  ├─ 已开通城市：杭州 ★ 南京              │
│  └─ 可用资金：￥142.5 万                  │
├─────────────────────────────────────────┤
│  中部：投资分配（核心交互区）              │
│  ┌─────────────┐ ┌─────────────┐        │
│  │  技术投入    │ │  用户匹配    │        │
│  │  [====] 50  │ │  杭州 [==] 20│        │
│  │  预估增长：+0.8│  南京 [==] 15│        │
│  │  过载状态：正常│  预估增长...  │        │
│  └─────────────┘ └─────────────┘        │
│  ┌─────────────┐                        │
│  │  品牌展示    │                        │
│  │  杭州 [==] 20│                        │
│  │  南京 [==] 10│                        │
│  │  *提示：南京 Show 竞争激烈*           │
│  └─────────────┘                        │
├─────────────────────────────────────────┤
│  底部：宣言 + 提交                        │
│  "本回合我们将..." [________________]    │
│  [预览效果] [确认提交]                    │
└─────────────────────────────────────────┘
```

**关键改进点**：
1. **可视化滑块替代数字输入**：拖拽即可，实时显示预估效果
2. **智能提示**："你在南京的 Show 投入排名第 4，预计获得 15% 加成"
3. **一键预设**：保存常用配置，一键应用
4. **影响预览**：提交前显示"如果其他队不变，你的预计排名是..."

### 2.3 复盘层（Reflective View）—— 结算后

**目标**：让学习显性化

| 元素 | 设计 |
|------|------|
| **成绩卡片** | 可分享的精美卡片，显示排名、关键数据、一句系统评语 |
| **决策回放** | 时间轴展示每轮的投资分配变化，配以上升/下降箭头 |
| **对比分析** | 与冠军队的差距在哪？（雷达图对比 Tech/Fit/Show/Budget） |
| **概念锚定** | "你这次体验到了'边际效用递减'——看，第三轮追加 Tech 的收益明显下降了" |
| **教师批注区** | 教师可预先写好点评模板，系统自动匹配条件发送 |

## 三、降低认知负荷的具体策略

### 3.1 规则显性化

**不要**：给学生发一份 10 页的 PDF 规则书
**要**：
- **互动教程**：第一局强制进行 1 轮"沙盘演练"，NPC 手把手带
- **悬停提示**：每个专业术语旁有小问号，悬停显示一句话解释 + 动画演示
- **规则分层**：
  - L1 新手：只看到"投技术/投用户/投品牌"
  - L2 进阶：看到群体比例、城市差异
  - L3 高阶：看到完整公式、β 参数、softmax 机制

### 3.2 反馈即时化

| 场景 | 现有问题 | 改进 |
|------|----------|------|
| 输入投资金额 | 不知道这个数字意味着什么 | 实时显示"预估属性增长"和"在同类投入中的排名" |
| 选择路线 | 不清楚路线差异 | 对比卡片：TECH 路线 +30% 技术效率，但 Show 竞争更激烈 |
| 提交后 | 干等 | 显示"已提交，等待其他 X 队..."，同时可查看历史 |
| 结算后 | 只看得到排名 | 先看 30 秒动画故事，再看数据 |

### 3.3 叙事化包装

将冰冷的数字转化为故事：

- 不是"你的 Fit 属性为 5.2"，而是"南京的用户觉得你的产品'刚好够用'（匹配度 52%）"
- 不是"你排名第 3"，而是"你的《元宇宙》在合肥刷屏了，但南京用户还在观望"
- 事件新闻现有设计很好，但可以更视觉化：新闻卡片 + 城市地图闪烁

## 四、多端一致性策略

| 终端 | 核心场景 | 设计取舍 |
|------|----------|----------|
| **PC Web（教室）** | 主决策界面 | 完整功能、大屏适配 |
| **平板** | 移动教室、路演展示 | 简化布局、触控优化 |
| **手机** | 课后查看、社交分享、轻量决策 | 核心数据 + 社交功能，复杂决策引导到 PC |
| **大屏/投影** | 教师控场、观众观看 | 高对比度、大字、动画、无交互 |
| **小程序** | 微信生态传播、家长围观 | 极简注册、一键分享、成绩卡片 |

## 五、无障碍与包容性设计

| 群体 | 需求 | 方案 |
|------|------|------|
| 色盲/色弱 | 难以区分红绿 | 不用单纯颜色区分好坏，叠加图标/文字/纹理 |
| 阅读障碍 | 大量文字困难 | 关键信息图表化、语音播报选项 |
| 低年级学生 | 抽象概念难理解 | 具象比喻（技术=秘方、用户=口味、品牌=装修） |
| 网络不稳定 | 提交失败焦虑 | 本地草稿自动保存、断网重连恢复、操作队列 |
| 低性能设备 | 卡顿 | 提供"极速模式"（关闭动画、简化图表） |

## 六、情感化设计触点

| 触点 | 设计 | 情感目标 |
|------|------|----------|
| 首次登录 | 欢迎动画 + "欢迎加入创想星图，探险家" | 归属感 |
| 首次获胜 | 全屏特效 + 音乐 + "你的第一桶金！" | 成就感 |
| 连败安慰 | "差一点！合肥的用户其实很喜欢你，下轮试试加大投入？" | 坚持 |
| 好友超越 | "小明刚刚超过了你的排名！要再看看策略吗？" | 轻度竞争 |
| 赛季结束 | 个人年度视频回顾（类似支付宝年度账单） | 回顾与感动 |

---

> **核心建议**：好的教育科技产品，不是把"教"做得更花哨，而是让"学"的过程更**顺畅**、更**有反馈**、更**有尊严**。学生不是听不懂商业，而是被不好的界面拦在了商业门外。
