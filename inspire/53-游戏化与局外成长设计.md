# 03 - 游戏化与局外成长设计

> 如何将"一次性的商赛体验"转化为"持续的生涯成长旅程"。核心命题：学生为什么下个月还想登录这个平台？

---

## 一、现有 TechVenture 的体验断层分析

| 断层 | 表现 | 后果 |
|------|------|------|
| **无账号沉淀** | 每局用队伍码进入，局后即走 | 学生无归属感，无法累积 |
| **无纵向成长** | 4 轮结束即游戏结束 | 没有"变强"的反馈循环 |
| **无身份认同** | 只有队伍排名，无个人标签 | 社交分享动力弱 |
| **无探索动力** | 规则固定，多局重复体验一致 |  replay 价值低 |
| **无外部激励** | 仅有教师组织的比赛才使用 | 平台活跃完全依赖教师推动 |

---

## 二、局外成长（Meta-progression）系统架构

**核心理念**：把平台设计成"商业 RPG"——学生是主角，每局商赛是一次"副本"，副本奖励经验和资源，用于主角成长。

### 2.1 成长维度设计

```
StudentProfile (学生档案)
├── 等级系统 (Level)
│   └── 经验值 XP：来自完成对局、课程单元、每日任务
│   └── 等级称号：商业学徒 → 创业者 → 企业家 → 商业领袖
│
├── 技能树 (Skill Tree)
│   ├── 财务洞察：解锁更详细的 ROI 分析面板
│   ├── 市场直觉：对局中获得城市群体比例预览
│   ├── 谈判专家：组队时获得额外预算加成
│   ├── 危机处理：减少突发事件负面影响
│   └── 领导魅力：宣言 BQI 加成小幅提升
│   └── *技能点来自等级提升 + 特定成就*
│
├── 徽章/成就 (Achievements)
│   ├── 路线专精："技术宅"（TECH 路线赢 5 局）
│   ├── 行为标签："孤勇者"（PATHFINDER 路线独占红利触发）
│   ├── 社交类："金牌队友"（被队友点赞 10 次）
│   ├── 探索类："全图鉴"（体验过所有路线+所有城市开局）
│   └── 隐藏类："逆风翻盘"（R3 时排名末位，R4 夺冠）
│
├── 收藏品/图鉴 (Collection)
│   ├── 商业案例卡：每完成一个课程单元解锁真实企业案例
│   ├── 城市故事：解锁南京/合肥/杭州的本地商业故事
│   ├── 导师语录：解锁知名企业家/经济学家的短语录
│   └── 皮肤/主题：个人资料页装饰、队伍旗帜样式
│
└── 赛季/通行证 (Season Pass)
    ├── 免费轨道：基础奖励
    └── 付费轨道（可选）：高级皮肤、专属徽章、额外课程
```

### 2.2 经验值（XP）获取矩阵

| 行为 | XP 奖励 | 备注 |
|------|---------|------|
| 完成一局标准对局 | 100-300（依排名） | 鼓励参与 |
| 完成一个课程单元 | 50-150（依测验成绩） | 鼓励学习 |
| 提交决策并写理由 | +20 | 鼓励深度思考 |
| 首次尝试新路线 | +50 | 鼓励探索 |
| 获得对局前 3 名 | +100  bonus | 鼓励竞争 |
| 每日登录 | +10 | 保留存 |
| 邀请新同学注册 | +50 | 裂变增长 |
| 教师点评为"优秀" | +30 | 连接教学 |

**防沉迷设计**：每日 XP 获取有软上限，超出后收益递减，避免过度游戏化导致功利。

## 三、游戏化机制清单

### 3.1 核心循环（Core Loop）

```
登录 → 查看今日任务 → 选择课程/对局 → 决策与体验 → 结算与反馈 → 获得 XP/徽章 → 升级/解锁 → 分享成就 → 下线期待
```

### 3.2 具体机制

| 机制 | 设计 | 心理驱动 |
|------|------|----------|
| ** streak（连续打卡）** | 连续每日登录获得递增奖励，断签重置 | 损失厌恶 |
| **随机宝箱** | 每完成 3 局获得一次"商业洞察宝箱"，开出随机案例卡或 XP | 可变奖励 |
| **排行榜** | 班级榜（周重置）、全校榜（月重置）、全国榜（赛季） | 社会比较 |
| **师徒系统** | 高等级学生可带新手，双方都有奖励 | 互惠 + 责任 |
| **组队羁绊** | 固定队友多次合作解锁组合技能 | 社交纽带 |
| **剧情模式** | 单人的"从 0 到 1"创业故事线，有 NPC 对话和分支选择 | 叙事沉浸 |
| **挑战模式** | 特定约束下获胜（如：只用 BRAND 路线夺冠、零开城费夺冠） | 精通感 |

### 3.3 社交与协作

- **班级公会**：同一班级的学生自动加入，班级总 XP 解锁班级奖励（如：全班获得一次特殊对局机会）
- **队伍预设**：可保存常用"战略配置"（路线偏好、城市偏好），一键应用
- **观战与押注**：非参赛者可观战并"预测冠军"，预测正确获得小额 XP
- **弹幕/表情**：大屏端或观战模式发送预设表情，增加氛围

## 四、局外成长对对局设计的影响

**重要原则**：局外成长可以**丰富体验**，但不能**破坏公平**。

### 4.1 公平性分级

| 对局类型 | 成长影响 | 说明 |
|----------|----------|------|
| **教学对局**（课程单元） | 技能有效 | 偏向 PvE，允许技能提供辅助信息 |
| **班级练习赛** | 技能有效 | 半 PvP，以练习为主 |
| **正式排位赛** | 技能无效 / 仅 cosmetic | 纯竞技，所有玩家数值平等 |
| **锦标赛** | 强制平等 | 最高公平，局外成长仅影响外观 |

### 4.2 技能设计示例（仅影响信息/体验，不影响数值）

| 技能 | 效果 | 为什么公平 |
|------|------|-----------|
| 财务洞察 Lv.1 | 结算报告中多显示"每万元投入带来多少 attention" | 信息优势，不改变结果 |
| 市场直觉 Lv.2 | 对局前看到各城市群体比例的模糊区间（如：Geek 10%-20%） | 降低不确定性，不增加数值 |
| 历史回放 | 可查看自己过去 10 局的决策轨迹 | 纯工具 |
| 教练视角 | 观战时看到参赛者的实时决策（非公开信息） | 仅限观战 |

## 五、叙事包装与世界观

### 5.1 世界观建议："创想星图"

学生不是"参赛者"，而是"星际商业探险家"：
- 每座城市 = 一个星球/市场
- 每局对局 = 一次"市场开拓任务"
- 路线选择 = 飞船配置（科技舰 / 贸易舰 / 宣传舰 / 隐形舰）
- 属性增长 = 市场影响力指数
- 局外成长 = 探险家等级与装备

**好处**：
- 脱离枯燥的"比赛"语境，进入"冒险"语境
- 便于美术统一（科幻/卡通/国潮风格可选）
- 为未来的跨星球、跨时代扩展留空间

### 5.2 剧情模式框架

```
第一章：启航（小学难度）
  └── 任务 1-1：在 lemonade 星球卖出第一杯
  └── 任务 1-2：面对竞争对手该怎么办？
  └── Boss 战：星球集市大比拚

第二章：扩张（初中难度）
  └── 任务 2-1：选择你的第一站
  └── 任务 2-2：用户说你听不懂他们
  └── Boss 战：三星球同时作战

第三章：风云（高中难度）
  └── 任务 3-1：技术瓶颈
  └── 任务 3-2：政策突变
  └── Boss 战：年度商业峰会（16 队大乱斗）

第四章：巅峰（大学难度）
  └── 开放世界：自由创建对局、设计规则
```

## 六、激励系统的边界与伦理

| 风险 | 应对 |
|------|------|
| 过度竞争导致挫败感 | 确保 70% 的体验是"合作/成长"，30% 是"竞争"；提供"努力奖" |
| 付费影响公平（若引入付费） | 严格区分 cosmetic / convenience / power；power 绝不卖 |
| 数据隐私（未成年人） | 遵守《未成年人保护法》；不收集不必要的个人信息 |
| 游戏成瘾 | 单次对局控制在 30 分钟内；每日任务而非每日强迫；家长端可见时长 |
| 社交压力 | 排行榜可选匿名；允许隐藏等级 |

---

> **核心建议**：局外成长系统的灵魂不是"让学生玩更多"，而是"让学生在一次次的对局后，**感觉自己变得更懂商业了**"——这种"我成长了"的主观体验，是留存和口碑的根本。
