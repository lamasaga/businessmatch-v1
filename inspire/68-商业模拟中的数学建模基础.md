# 18 - 商业模拟中的数学建模基础

> 商业模拟不是"用数字装饰游戏"，而是用数学语言重构商业规律。理解这些模型，才能设计出既符合教学逻辑又运行稳定的模拟系统。

---

## 一、为什么商业模拟需要数学建模

### 1.1 模型化思维的价值

商业世界极其复杂——无数个决策者在不确定环境中互动，产生难以直接预测的结果。数学模型的作用不是"精确预测"，而是：

- **结构化混乱**：将模糊的商业直觉转化为可计算的变量关系
- **可重复验证**：相同的输入应该产生相同的输出，支持教学复盘
- **参数化调节**：通过调整参数，模拟不同行业、不同市场环境
- **认知脚手架**：让学生看到"如果改变 X，Y 会如何变化"的因果关系

### 1.2 模型复杂度的教育匹配

| 学段 | 模型复杂度 | 学生可理解的数学工具 |
|------|-----------|---------------------|
| 小学高段 | 线性关系、简单比例 | 加法、乘法、百分比 |
| 初中 | 单变量函数、简单反馈 | 一元函数、图表读取 |
| 高中 | 多变量交互、概率概念 | 函数、概率、基础统计 |
| 大学 | 动态系统、优化、博弈论 | 微积分、线性代数、概率论 |

**核心原则**：模型的复杂度必须与学生当前的数学能力匹配，否则模拟变成"黑箱"，失去教学意义。

## 二、基础市场模型

### 2.1 供需均衡模型（Supply & Demand）

最基础的经济学模型，也是商业模拟的底层逻辑之一。

```
需求函数：Q_d = a - b·P
供给函数：Q_s = c + d·P

均衡条件：Q_d = Q_s
均衡价格：P* = (a - c) / (b + d)
均衡数量：Q* = (ad + bc) / (b + d)
```

**在教育模拟中的应用**：
- 模拟"市场价格"如何由所有参与者的总供给和总需求决定
- 学生通过调整产量/价格，观察市场均衡点的移动
- 外生冲击（如原材料涨价 = c 增加）如何影响均衡

**教学锚点**：让学生先手动计算小规模案例（2-3 个参与者），再用系统模拟大规模市场，体会"个体理性 → 集体结果"的涌现。

### 2.2 弹性与敏感性分析

```
价格弹性：E_p = (ΔQ/Q) / (ΔP/P)
收入弹性：E_I = (ΔQ/Q) / (ΔI/I)
交叉弹性：E_xy = (ΔQ_x/Q_x) / (ΔP_y/P_y)
```

**应用示例**：
- 奢侈品（|E_p| > 1）：降价反而增加总收入——让学生体验不同品类的定价策略
- 必需品（|E_p| < 1）：涨价对销量影响小——体验民生品类的商业逻辑
- 替代品（E_xy > 0）：竞品降价直接冲击自家销量

### 2.3 消费者选择模型：效用最大化

消费者（或市场）在预算约束下最大化效用：

```
max U(x₁, x₂, ..., x_n)
s.t.  Σ p_i·x_i ≤ B
```

其中 U 是效用函数，常见形式：
- **线性效用**：U = a·x₁ + b·x₂（完全替代品）
- **柯布-道格拉斯**：U = x₁^α · x₂^β（偏好有比例）
- **CES 效用**：U = (α·x₁^ρ + β·x₂^ρ)^(1/ρ)（替代弹性可变）

**与 TechVenture 的连接**：
现有引擎中消费者群体（Geek/Pragmatic/Trendy）的效用函数就是线性加权的：
```
U = w_tech · Tech + w_fit · Fit + w_show · Show
```
这实际上是线性效用函数的简化版。

## 三、市场竞争模型

### 3.1 完全竞争 vs 垄断 vs 寡头

| 市场结构 | 参与者数量 | 定价权 | 模拟实现难度 |
|----------|-----------|--------|-------------|
| **完全竞争** | 无数 | 无（价格接受者） | 低（系统定价） |
| **垄断竞争** | 很多 | 有限（差异化） | 中（引入产品差异化） |
| **寡头** | 少数 | 显著（相互依存） | 高（需要博弈论） |
| **垄断** | 1 | 完全 | 低（单参与者定价） |

**现有 TechVenture 的定位**：介于**寡头**和**垄断竞争**之间——参与者数量中等（4-16 队），产品通过 Tech/Fit/Show 差异化，存在明显的策略互动。

### 3.2 古诺模型（Cournot Model）—— 产量竞争

两个（或多个）企业同时选择产量，市场价格由总产量决定。

```
市场反需求函数：P = a - b·(q₁ + q₂)
企业 1 利润：π₁ = (P - c)·q₁ = [a - b·(q₁+q₂) - c]·q₁

纳什均衡产量：
q₁* = q₂* = (a - c) / (3b)
均衡价格：P* = (a + 2c) / 3
```

**教学价值**：
- 让学生体验"如果我和竞争对手都理性，最终产量会高于垄断但低于完全竞争"
- 引入"囚徒困境"在商业中的应用：个体理性导致集体次优

### 3.3 伯特兰模型（Bertrand Model）—— 价格竞争

企业选择价格而非产量，消费者选择价格最低的产品。

```
均衡结果：P₁* = P₂* = c（边际成本）
```

**悖论**：只要有两家企业，价格就被压到成本——这与现实不符，因为现实中产品有差异化。

**改进**：引入 Hotelling 空间竞争模型——消费者不仅看价格，还看"距离/匹配度"。

```
消费者效用：U = v - p - t·|x - x_i|
```
其中 x 是消费者偏好位置，x_i 是企业产品位置，t 是 mismatch 成本。

**与 TechVenture 的连接**：
现有引擎中的 "Fit" 属性本质上就是 Hotelling 模型中的匹配度概念——产品与消费者偏好的距离越近，效用越高。

## 四、消费者行为的高级模型

### 4.1 离散选择模型（Discrete Choice Model）

当消费者面临多个选项时，如何选择？Logit 模型是最经典的方法：

```
P(消费者选择选项 i) = exp(U_i) / Σ_j exp(U_j)
```

其中 U_i 是选项 i 的效用。

**与 TechVenture 的连接**：
现有引擎中的 softmax 函数本质就是 Logit 选择模型：
```
share_i = exp(β·U_i) / Σ_j exp(β·U_j)
```
β 是"选择锐度"参数——β 越大，消费者越挑剔，效用稍低的产品市场份额急剧下降。

**教学价值**：
- 让学生理解"为什么第二名和第一名的差距远大于第十名和第九名"
- 理解"差异化"的战略价值——在拥挤市场中，微小差异带来巨大份额差异

### 4.2 嵌套 Logit 模型（Nested Logit）

当选项存在层次结构时使用。例如消费者先选"城市"，再在该城市内选"品牌"。

```
P(选城市 c) = [Σ_{i∈c} exp(U_i/λ)]^λ / Σ_{c'} [Σ_{j∈c'} exp(U_j/λ)]^λ
P(选品牌 i | 城市 c) = exp(U_i/λ) / Σ_{j∈c} exp(U_j/λ)
```

λ ∈ (0,1] 是"相似度参数"——λ 越小，同一 nests 内的产品替代性越强。

**应用**：模拟"消费者先决定在哪座城市消费，再决定买哪个品牌"的两阶段决策。

### 4.3 消费者学习模型

消费者不是全知的，而是通过体验逐步学习产品质量：

```
E_t[quality] = (1-α)·E_{t-1}[quality] + α·observed_quality_t
```

α 是学习速率。α 高 = 消费者很快更新认知；α 低 = 品牌声誉粘性大。

**教学价值**：让学生理解"首因效应"和"品牌重建的困难"。

## 五、动态与反馈模型

### 5.1 存量-流量模型（Stock & Flow）

系统动力学的核心语言，适合模拟累积效应。

```
存量(t) = 存量(t-1) + 流入(t) - 流出(t)
```

**商业模拟中的应用**：

| 存量 | 流入 | 流出 |
|------|------|------|
| 品牌认知度 | 广告投入、口碑传播 | 遗忘、竞品干扰 |
| 技术积累 | 研发投入 | 技术过时 |
| 客户基础 | 新用户获取 | 用户流失 |
| 现金储备 | 收入、融资 | 成本、投资 |

**与 TechVenture 的连接**：
现有引擎中的 Tech/Fit/Show 属性本质上就是存量——每轮投资是流入，自然衰减（如果有的话）是流出。

### 5.2 S 曲线增长（Sigmoid Growth）

大多数商业增长不是线性的，而是 S 形的：

```
dN/dt = r·N·(1 - N/K)

解析解：N(t) = K / (1 + ((K-N₀)/N₀)·exp(-rt))
```

- K = 市场容量（ carrying capacity ）
- r = 增长率
- N₀ = 初始值

**教学价值**：让学生理解"为什么早期增长慢（认知不足）、中期爆发（口碑效应）、后期放缓（市场饱和）"。

### 5.3 巴斯扩散模型（Bass Diffusion Model）

新产品在市场中扩散的经典模型：

```
dF/dt = (p + q·F)·(1 - F)
```

- F(t) = t 时刻的采用者比例
- p = 创新系数（外部影响，如广告）
- q = 模仿系数（内部影响，如口碑）

**峰值采用时间**：t* = ln(q/p) / (p + q)

**教学价值**：理解"为什么有些产品靠广告就能火，有些必须靠口碑"

## 六、随机性与不确定性建模

### 6.1 蒙特卡洛模拟（Monte Carlo Simulation）

当模型包含多个不确定变量时，通过大量随机抽样估计结果分布。

```
for i = 1 to N:
    随机抽取 demand_shock ~ N(0, σ_d)
    随机抽取 cost_shock ~ N(0, σ_c)
    计算 outcome_i = model(demand_shock, cost_shock)

分析 outcome_1 ... outcome_N 的分布
```

**在教育模拟中的应用**：
- 让学生理解"确定性决策 → 不确定性结果"
- 展示"期望值相同，但风险不同的策略如何选择"

### 6.2 马尔可夫链（Markov Chain）

系统状态只依赖于前一个状态，与更早的历史无关。

```
P(X_{t+1} = s_j | X_t = s_i) = P_{ij}
```

**应用**：模拟市场状态的转换（繁荣 → 衰退 → 复苏）、消费者品牌转换行为。

### 6.3 随机游走与市场有效性

```
P_t = P_{t-1} + ε_t,  ε_t ~ N(0, σ²)
```

**教学价值**：让学生体验"试图预测纯随机过程是徒劳的"，从而理解市场有效性的概念。

## 七、优化与决策模型

### 7.1 线性规划（Linear Programming）

在约束条件下最大化目标函数：

```
max c₁·x₁ + c₂·x₂ + ... + c_n·x_n
s.t.  a₁₁·x₁ + ... + a₁_n·x_n ≤ b₁
      ...
      x_i ≥ 0
```

**应用**：最优预算分配（在 Tech、Fit、Show 之间分配有限预算以最大化期望效用）。

### 7.2 动态规划（Dynamic Programming）

多阶段决策问题，每阶段的决策影响后续状态。

```
V_t(s) = max_a [R(s,a) + γ·E[V_{t+1}(s')]]
```

**应用**：多轮商业模拟中的最优策略——当前轮的投资不仅是为了本轮收益，还为了建立后续轮次的竞争优势。

## 八、模型选择的决策树

```
你想模拟什么？
├── 市场价格如何形成？
│   └── → 供需均衡模型
├── 消费者如何在多个品牌间选择？
│   └── → Logit / Softmax 模型
├── 竞争对手如何互动？
│   ├── 价格竞争 → 伯特兰模型
│   └── 产量竞争 → 古诺模型
├── 品牌认知如何随时间累积？
│   └── → 存量-流量模型 / S曲线
├── 新产品如何扩散？
│   └── → Bass 扩散模型
├── 结果受多少随机因素影响？
│   └── → 蒙特卡洛模拟
└── 多阶段最优策略？
    └── → 动态规划
```

## 九、与现有 TechVenture 引擎的数学对照

| 引擎组件 | 使用的数学 | 可扩展的方向 |
|----------|-----------|-------------|
| 消费者选择 | Softmax (Logit) | 引入 Nested Logit、考虑消费者学习 |
| 市场份额 | 效用加权 + 排名加成 | 引入更复杂的价格敏感函数 |
| 属性增长 | 递减增长函数 | 引入 S 曲线饱和效应 |

| BQI 调节 | 规则触发线性修正 | 引入连续非线性反馈 |
|  ceiling | 平均质量函数 | 引入网络外部性（市场越大， ceiling 越高） |

## 十、设计原则：模型复杂度 vs 教学清晰度

| 原则 | 说明 |
|------|------|
| **奥卡姆剃刀** | 在满足教学目标的前提下，使用最简单的模型 |
| **可见性** | 学生应该能直觉理解模型的核心逻辑，即使不懂数学 |
| **可调节** | 同一模型应可通过参数调节适配不同难度 |
| **可拆解** | 复杂模型应能拆解为简单模块，逐步教学 |
| **可验证** | 模型的行为应与现实商业常识一致 |

---

> **核心洞见**：数学模型不是商业模拟的"发动机"，而是"翻译器"——它将模糊的商业直觉翻译成精确的结构化语言。一个好的商业模拟平台，应该让学生在不知不觉中与这些模型互动，然后在复盘时教师才指出："你刚才体验到的，就是经济学家所说的____。"
