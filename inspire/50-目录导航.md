# Inspire —— 商业模拟教学平台构想文档库

> **链接纪律**：本库**内部目录**由本文维护；**从仓库其它位置进入 inspire 的外链**仅由 [agent.md](../agent.md)、[README.md](../README.md)、根目录 [00～09](../00-项目全景与目录结构.md#14-inspire-专题索引权威外链维护点) 维护。`inspire/` 文内**禁止**专题之间相互 Markdown 链接（见 [doc-linking.mdc](../.cursor/rules/doc-linking.mdc)）。
>
> "Inspire" 取"启发、灵感"之意。这里存放的是从现有 TechVenture 项目出发，建设一套全新商业理解教学体系的支持性思考与建议。
> 
> 这些文档不是最终的产品设计文档（PRD），而是**方向性、框架性、启发性**的知识库。旨在帮助团队在技术选型、课程设计、游戏化策略、平台运营等方面拥有更广阔的视野和更系统的思考基础。
>
> **根目录权威文档**（`00～09`）引用本库时，内容资产路径以 **`inspire/a/`** 及保留子目录为准；已归档内容见 `docs/archive/`。见 [00-项目全景与目录结构](../00-项目全景与目录结构.md) §二。

## 核心设计主张（贯穿所有文档的共识）

| 主张 | 含义 |
|------|------|
| **从比赛到课程** | 不只做一年几次的竞赛工具，而是融入日常教学的常态化平台 |
| **从工具到 RPG** | 学生不是临时参赛者，而是持续成长的"商业探索者" |
| **从复杂到分层** | 同一套引擎通过参数模板，服务小学到大学不同年龄 |
| **从封闭到开放** | 规则可配置、课程可扩展、数据可分析 |
| **从一次到一生** | 局外成长系统让每次参与都有长期价值 |
| **从模拟到真实** | 平台是桥梁，连接课堂学习与真实商业世界 |
| **从本土到全球** | 中国深度是优势，全球视野是目标 |
| **从盈利到向善** | 商业成功与教育使命不是零和，而是相互增强 |
