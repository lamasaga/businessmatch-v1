# Inspire —— 商业模拟教学平台构想文档库

> "Inspire" 取"启发、灵感"之意。这里存放的是从现有 TechVenture 项目出发，建设一套全新商业理解教学体系的支持性思考与建议。
> 
> 这些文档不是最终的产品设计文档（PRD），而是**方向性、框架性、启发性**的知识库。旨在帮助团队在技术选型、课程设计、游戏化策略、平台运营等方面拥有更广阔的视野和更系统的思考基础。
>
> **根目录权威文档**（`00～09`）引用本库时，内容资产路径以 **`inspire/a～f/`** 为准；见 [00-项目全景与目录结构](../00-项目全景与目录结构.md) §二。

## 现有项目速览

**TechVenture v6.0**（位于 `../TechVenture`）
- 技术：TypeScript + Express + 文件持久化
- 机制：4 轮回合制商赛，队伍选择路线（TECH/USER/BRAND/PATHFINDER）并投资技术/用户匹配/品牌展示
- 结算：基于 softmax 效用、排名竞争、BQI 调节、随机噪声的复杂引擎
- 角色：管理员（控场）、参赛队（决策）、投资人（观察）
- 现状：功能完整但无在线前端、无用户系统、无成长积累、规则理解门槛高

## 如何使用这些文档

### 按场景查阅

1. **做技术方案时**：先看 01（架构），再按需查阅 06（安全）、08（AI 技术）
2. **设计课程时**：先看 02（内容体系），再查阅 04（玩法类型）、13（跨文化）寻找合适的模拟形式
3. **讨论产品方向时**：03（游戏化）、05（体验）、11（学习科学）结合看，确认"好玩"与"好懂"并重
4. **制定计划时**：以 07（路线）为框架，将各文档中的建议映射到具体迭代
5. **思考商业模式时**：10（真实世界连接）和 12（商业模式）对照看，找到可持续路径
6. **探索未来形态时**：08（AI）和 09（XR）提供技术前瞻视野

## 核心设计主张（贯穿所有文档的共识）

| 主张 | 含义 |
|------|------|
| **从比赛到课程** | 不只做一年几次的竞赛工具，而是融入日常教学的常态化平台 |
| **从工具到 RPG** | 学生不是临时参赛者，而是持续成长的"商业探索者" |
| **从复杂到分层** | 同一套引擎通过参数模板，服务小学到大学不同年龄 |
| **从封闭到开放** | 规则可配置、课程可扩展、数据可分析 |
| **从一次到一生** | 局外成长系统让每次参与都有长期价值 |
| **从模拟到真实** | 平台是桥梁，连接课堂学习与真实商业世界 |
| **从本土到全球** | 中国深度是优势，全球视野是目标 |
| **从盈利到向善** | 商业成功与教育使命不是零和，而是相互增强 |
