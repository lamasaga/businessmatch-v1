## 一、投资摘要：AI 的战略定位

　　**商域（BizSim Edu）** 不是「给课堂加一个 ChatGPT 窗口」，而是把 AI 嵌入**三层价值**：

| 层级 | AI 做什么 | 对投资人的意义 |
|------|-----------|----------------|
| **工程层** | AI 辅助编程 + 文档约束体系（蓝图编程、`docs/decisions` ADR） | 小团队可高速迭代多赛制、双端产品；**研发效率即壁垒** |
| **教学产品层** | 规则引擎陪练（零 Token）+ 渐进式 LLM 教练（Athena 等） | **边际成本可控**：练习规模化不烧 API，高价值场景才用大模型 |
| **终局能力层** | OPC 一人公司（AI 员工 + Gateway 评审）+ 拟真城市 World | 从「会玩商赛」到「能交付项目 / 理解区域系统」，**差异化与续费故事** |

　　产品主线见 [01-](./01-平台愿景与产品架构.md) §1.1：商赛引擎 → 智能体财商教练 → 生涯大循环 → 知识图谱 / 课程 → **OPC** / **拟真城市**。AI 贯穿全程，但遵循 [03-](./03-技术架构与实现现状.md) §8.1：**规则层优先 → RAG 增强 → 完整 Agent**，避免全站 LLM 导致成本与幻觉失控。

　　与 [58-](./58-AI赋能的商业教育革命.md) 一致：**AI 扩展教师、不替代教师**；平台设计原则为「智能性：Athena + 教师园丁」。

## 三、AI 作用的七个方面

### 3.1 商赛练习：规则型 AI 对手（已规模化，零 Token）

　　当前**最强、最可规模化**的 AI 能力。

| 赛制 | 实现位置 | 学生获得什么 |
|------|----------|----------------|
| **浮生记 RTS v2** | `games/trading/rts_ai_levels.py`（`chaotic` / `advanced`） | 单人 5s tick 开练，无需凑局 |
| **浮生记回合 v1** | `ai_trader.py` + `practice_flow.py` | 供需套利 + AI 随回合决策 |
| **创想大赢家 TechVenture** | `games/techventure/ai_team.py` | 1 真人队 + 5 AI 队，满 4 轮策略练习 |

　　对齐 58 §2.1 的难度梯度与可复盘排名；尚未达到「自然语言解释对手策略」——属 Phase D。

　　**投资亮点**：[04-](./04-实施路线与里程碑.md) §4.4：练习 AI **零 LLM Token**；千级 DAU 练习主要由算力承担，**单位经济学友好**。

**演示路径**（详见 [08-](./08-工程现状与webapp实现详表.md) §2.3）：路径 B（RTS 练习）、B′（回合练习）、C′（TechVenture 练习）。

## 四、商业价值与壁垒

### 4.1 今日可演示、可谈试点的场景

| 场景 | AI 价值一句话 | 状态 |
|------|----------------|------|
| 学校/机构办正式商赛 | 降组织者控场成本；即时对局反馈 | ✅ |
| 学生课后自主练习 | 无师在旁，规则 AI 陪练 | ✅ |
| 普惠财商日常 | 生涯 + 教练 + Quest | 🟡 壳在，Phase B 打通 |
| 高阶创业孵化 | OPC + Gateway | 🔴 Phase E |

### 4.2 成本结构（可放入财务模型）

　　逻辑摘自 [04-](./04-实施路线与里程碑.md) §4.4～4.5：

- **练习 / 对局 AI**：规则引擎 → **≈ 0 Token**  
- **复盘 / 答疑 / OPC Agent**：按次计费；文档含 100～1000 DAU 量级参考（国产模型假设）  
- **策略**：规则承担规模，LLM 只做高价值节点  

### 4.3 竞争壁垒（AI 相关）

1. **CyberCore** 声明式赛制 + 多引擎（trading / techventure）  
2. **双前端 + 单库单 API** 已跑通练习/正式/组织者  
3. **Pedagogy OS** 统一编排（Athena 与 OPC 共用 LangGraph 基建）  
4. **拟真城市 World** + Demia POP（长周期内容与科研合作）  
5. **蓝图文档 + ADR** 体系（AI 原生团队复制成本高）

## 五、阶段路线与验收指标

| 阶段 | AI 相关交付 | 业务含义 |
|------|-------------|----------|
| **A（当前）** | 规则练习 AI + 三赛制 + XP 账本 + 组织者端 | 可试点、可演示 |

| **E** | OPC Cortex / Gateway / MCP | 高阶付费与品牌故事 |
| **F** | 多租户、教师看板、LLM 配额精细化 | 机构规模化 |

## 六、伦理与风险（对齐 58 §五）

| 风险 | 平台对策 |
|------|----------|
| 依赖 AI 给标准答案 | 练习规则博弈；Athena 追问式引导；无「自动替决策」 |
| 幻觉 | RAG 锚定知识卡片与规则文档；Gateway / 教师介入高 stakes |
| 隐私 | 多租户隔离与匿名化（Phase F 规划） |
| 成本失控 | 规则优先；OPC 配额；国产模型（04- 风险表） |
