# ADR-012: 三层资源经济体系设计 — XP / 金币 / 水晶

**日期**：2026-06-01  
**状态**：草案（供产品/工程评审）  
**触发**：长线运营视角下，单一 XP 无法支撑「日常活跃 + 营团激励 + 稀缺荣誉」的复合诉求  
**对齐**：ADR-009（赛季演进）· ADR-011（夏令营PRD）· 84-（营团P1缺口）

---

## 一、设计目标

　　当前平台仅有 **XP（经验值）** 一条经济线，存在三个结构性问题：

| 问题 | 表现 | 根因 |
|------|------|------|
| **激励颗粒度粗** | 学生参赛获得XP，但日常的「小行为」（签到、分享、阅读）难以量化激励 | XP 发放成本高（需幂等记录），不适合高频小额度 |
| **营团内无流通货币** | 夏令营的营币是孤立的，结营即清零，缺乏长线价值感 | 无平台级软货币承接营团价值 |
| **高价值行为无区分** | 参加日常练习和参加正式营团决赛，获得的都是XP | 无稀缺资源区分「普通参与」与「卓越成就」 |

　　引入 **XP / 金币 / 水晶** 三层资源，分别对应：
- **成长线**（XP）：只增不减，记录一切
- **日常线**（金币）：可增可减，高频流通
- **荣誉线**（水晶）：稀缺控制，高价值锚定

---

## 二、三层资源定义

### 2.1 XP（经验值 / Experience）—— 成长线

| 维度 | 定义 |
|------|------|
| **性质** | 只增不减的终身累积值 |
| **隐喻** | 就像人的「阅历」——做过的事都算数 |
| **来源** | **任意活动**：比赛、任务、学习、阅读、营团活动、每日签到、分享 |
| **消耗** | ❌ 不可消费、不可转让 |
| **作用** | ① 等级计算 ② 解锁内容与功能 ③ 五维雷达图 ④ 生涯叙事 |
| **通胀策略** | 无通胀，线性累积。但升级曲线可设计为「前快后慢」 |

**与现有系统的关系**：
- 复用现有 `xp_events` 表 + `User.experience` 字段
- 扩展 `source` 枚举，覆盖更多行为类型
- 升级公式从线性改为「前快后慢」：见 §6.2

---

### 2.2 金币（Gold / 基础货币）—— 日常线

| 维度 | 定义 |
|------|------|
| **性质** | 可增可减的平台级流通货币 |
| **隐喻** | 就像「工资」——日常劳动所得，日常消费所用 |
| **来源** | **日常活动**：每日任务、日常练习、营团日常活动、签到、分享、阅读知识卡片 |
| **消耗** | 营团内消费、基础道具购买、普通外观解锁、基础抽卡 |
| **作用** | ① 营团内「商城」消费 ② 解锁基础内容 ③ 日常游戏化激励 |
| **通胀策略** | 运营主要调控点。可通过「消耗品设计」（如限时道具）和「回收机制」（如 taxes）控制 |

**与夏令营的关系**：
- 夏令营内的 **营币 = 金币在营团内的「本地视图」**
- 学生入营时获得「营团金币钱包」，与平台金币余额分离显示
- 结营时，营团金币可按比例 **转化** 为平台金币（见 §4.3）

---

### 2.3 水晶（Crystal / 高级货币）—— 荣誉线

| 维度 | 定义 |
|------|------|
| **性质** | 严格控制产出的稀缺货币 |
| **隐喻** | 就像「勋章」或「奖杯」——不是努力就有，而是卓越才有 |
| **来源** | **高价值行为**：正式营团大赛排名奖励、赛季卓越表现、特殊成就、限时活动、付费充值（远期） |
| **消耗** | 高级道具、稀有外观/皮肤、重置机会、跳过等待、抽卡（高级池） |
| **作用** | ① 区分「普通参与者」与「卓越成就者」② 付费转化基础（远期） ③ 社交炫耀资本 |
| **通胀策略** | 严格控制。产出口径由产品团队管理，季度评估总量 |

**与夏令营的关系**：
- 夏令营 **Day 7 终极路演** 的获奖团队获得水晶奖励
- 夏令营内 **不做水晶消费**，水晶仅在平台级商城使用
- 水晶是跨营团、跨赛季的「终身荣誉资产」

## 三、三层资源对比总表

| 维度 | XP（经验值） | 金币（Gold） | 水晶（Crystal） |
|------|-------------|-------------|----------------|
| **定位** | 成长线 | 日常线 | 荣誉线 |
| **增减性** | 只增不减 | 可增可减 | 可增可减 |
| **获取难度** | 极易（几乎所有行为） | 容易（日常活动） | 困难（卓越表现） |
| **获取频率** | 高频 | 高频 | 低频 |
| **消耗场景** | 不可消耗 | 营团商城/基础内容 | 平台商城/高级内容 |
| **跨营团** | ✅ 全局 | ✅ 全局（营团内为本地视图） | ✅ 全局 |
| **结营处理** | 继续累积 | 营团余额→按比例转化 | 继续保留 |
| **运营调控** | 不调控（公式固定） | 主要调控杠杆 | 严格控制，季度审批 |
| **付费相关** | ❌ 绝不 | ❌ 暂不 | ✅ 远期开放充值 |

- XP：全部累积到生涯，无损失

> 💡 设计意图：让每个学生结营时带走「看得见的成长」（XP）+ 「用得上的财富」（金币）+ 「难得的荣誉」（水晶），三线都有获得感。

## 五、消耗途径矩阵

### 5.1 金币消耗途径

| 消耗场景 | 金币成本 | 说明 |
|----------|----------|------|
| **营团商城 — 情报卡** | 30 | 偷看其他组进度/作品（限1次/天） |
| **营团商城 — 复活机会** | 50 | 重新提交一次已截止任务 |
| **营团商城 — 加时卡** | 20 | 任务截止延长30分钟 |
| **营团商城 — 广告位** | 价高者得 | Day 5 广告竞拍 |
| **营团商城 — 公司皮肤** | 100-500 | Logo框、主题色、气泡效果 |
| **平台商城 — 基础外观** | 200-1000 | 头像框、称号、主页背景 |
| **平台商城 — 基础抽卡** | 100/抽 | 知识卡片包、表情包、普通道具 |
| **知识图谱 — 解锁高级内容** | 500 | 某些深度文章/案例 |
| **OPC — 雇佣基础AI员工** | 300 | 普通品质员工 |
| **金币→少量水晶（高溢价）** | 10000:1 | 极不划算，仅兜底 |

**金币回收设计原则**：
1. **消耗 > 产出 × 0.7**：确保金币有稀缺感，不是无限花
2. **社交消耗优先**：情报卡、广告位竞拍等「人对人」的消耗最自然
3. **外观消耗长线**：皮肤、头像框等无实际功能但展示价值高的消耗品是长期回收主力

---

### 5.2 水晶消耗途径

| 消耗场景 | 水晶成本 | 说明 |
|----------|----------|------|
| **平台商城 — 稀有外观** | 50-200 | 限定头像框、动态称号、特效 |
| **平台商城 — 高级抽卡** | 50/抽 | 稀有道具池、限定皮肤 |
| **比赛 — 重置机会** | 30 | 重新开始一场已结束练习赛（重新计分） |
| **比赛 — 跳过等待** | 10 | 立即开始下一场练习（跳过冷却） |
| **OPC — 雇佣高级AI员工** | 50 | 稀有品质员工，特殊技能 |
| **营团 — 特殊道具（远期）** | 视道具 | 不影响公平性的纯展示道具 |
| **生涯 — 雷达图重置** | 100 | 重新分配五维属性点（远期） |

**水晶设计原则**：
1. **绝不卖数值**：水晶只买外观、便利、收藏，不影响比赛公平
2. **炫耀价值 > 实用价值**：水晶物品的核心价值是「别人知道你有」
3. **限时限定**：大部分水晶物品限时上架，制造稀缺感

### 5.3 XP 的「准消耗」—— 解锁机制

　　XP 本身不可消耗，但可用于「解锁」：

| 解锁内容 | 所需等级（XP） | 说明 |
|----------|---------------|------|
| 基础商赛 | Lv.1（0 XP） | 默认开放 |
| 正式营团赛报名 | Lv.3（~500 XP） | 防小号/刷号 |
| 高级赛制 | Lv.5（~2000 XP） | 复杂规则需要基础 |
| OPC一人公司 | Lv.4（~1000 XP） | 有一定理解后再开公司 |
| 创建营团（教师） | Lv.8（~8000 XP） | 老玩家才有资格带新人 |
| 知识图谱高级节点 | Lv.6（~3500 XP） | 循序渐进学习 |

### 6.2 XP 升级公式（从线性改为前快后慢）

```python
def xp_for_level(level: int) -> int:
    """升到第 N 级所需总 XP"""
    if level <= 1:
        return 0
    # 前10级快速，之后放缓
    if level <= 10:
        return int(100 * (level - 1) ** 1.5)
    else:
        base = xp_for_level(10)  # ~2856
        return int(base + 500 * (level - 10) ** 1.8)

# 示例：
# Lv.1 → 0 XP      Lv.6 → ~1122 XP   Lv.11 → ~5356 XP
# Lv.2 → 100 XP    Lv.7 → ~1581 XP   Lv.15 → ~14656 XP
# Lv.3 → ~283 XP   Lv.8 → ~2121 XP   Lv.20 → ~33156 XP
# Lv.4 → ~566 XP   Lv.9 → ~2754 XP   Lv.30 → ~83156 XP
# Lv.5 → ~894 XP   Lv.10 → ~3486 XP  Lv.50 → ~208156 XP

def calculate_level(experience: int) -> int:
    """根据 XP 反推等级"""
    level = 1
    while xp_for_level(level + 1) <= experience:
        level += 1
    return level
```

    """营团内金币的每一笔变动 — 与平台 gold_transactions 分离"""
    __tablename__ = "camp_coin_transactions"

    id = Column(Integer, primary_key=True)
    teaching_group_id = Column(Integer, ForeignKey("teaching_groups.id"), nullable=False, index=True)
    entity_type = Column(String(16), nullable=False)   # "user" | "group"
    entity_id = Column(Integer, nullable=False)

    amount = Column(Integer, nullable=False)
    balance_after = Column(Integer, nullable=False)

    source_type = Column(String(32), nullable=False)   # task_reward / match_reward / shop_purchase / rule_auto / teacher_grant / teacher_deduct / fate_card / camp_convert
    source_id = Column(Integer, nullable=True)

    description = Column(String(256), nullable=True)
    granted_by = Column(Integer, ForeignKey("users.id"), nullable=True)  # 教师手动发放时记录

    created_at = Column(DateTime(timezone=True), server_default=func.now())

| 资源 | 日均净产出 | 月产出 | 调控手段 |

| 基础抽卡 | 100/抽 | — |
| 高级抽卡 | — | 50/抽 |
