## 二、同步策略

### 2.1 实时同步（事件驱动）

```yaml
real_time_sync:
  direction: 双向
  trigger: 事件总线
  latency: <100ms
  
  mappings:
    - OPC: OPC.xp.awarded
      platform: career.xp.add
      fields:
        career_id: career_id
        amount: xp_amount
        source: source_name
    
    - OPC: OPC.ability.updated
      platform: career.ability.update
      fields:
        career_id: career_id
        dimension: ability_name
        score: new_score
```

### 2.2 准实时同步（消息队列）

```yaml
near_real_time_sync:
  direction: 双向
  trigger: 变更数据捕获（CDC）
  latency: <5s
  
  tables:
    - OPC_table: one_companies
      platform_table: ventures
      sync_fields: [status, stage, revenue_total]
    
    - OPC_table: ai_employees
      platform_table: ai_agents
      sync_fields: [level, tasks_completed, avg_rating]
```

### 2.3 定时批量同步

```yaml
scheduled_sync:
  frequency: 每日凌晨2点
  direction: OPC → 现有平台（单向）
  
  jobs:
    - name: daily_stats_sync
      source: OPC.analytics.daily_stats
      target: platform.analytics.OPC_stats
      
    - name: weekly_report_sync
      source: OPC.reports.weekly
      target: platform.reports.OPC_weekly
```

## 三、冲突解决

### 3.1 冲突场景

| 场景 | 示例 | 解决策略 |
|------|------|----------|
| 同时更新同一字段 | 两边同时修改XP值 | 以OPC为准（业务发生地优先） |
| 数据类型不匹配 | OPC用decimal，平台用int | 转换规则映射 |
| 关联数据缺失 | OPC引用了一个平台不存在的user | 跳过并记录日志 |
| 删除冲突 | OPC删除了记录，平台还在引用 | 软删除，标记为archived |

### 3.2 冲突解决实现

```python
async def sync_with_conflict_resolution(OPC_record, platform_record):
    conflicts = detect_conflicts(OPC_record, platform_record)
    
    for conflict in conflicts:
        if conflict.field in ['xp', 'ability_score']:
            # OPC优先
            platform_record[conflict.field] = OPC_record[conflict.field]
        elif conflict.field in ['name', 'description']:
            # 时间戳优先
            if OPC_record.updated_at > platform_record.updated_at:
                platform_record[conflict.field] = OPC_record[conflict.field]
        else:
            # 记录冲突，人工处理
            log_conflict(conflict)
    
    await save(platform_record)
```

## 四、迁移脚本

### 4.1 初始化迁移

```python
# 将现有平台用户数据同步到OPC

async def migrate_existing_users():
    """为符合条件的用户创建OPC入口"""
    
    # 查询符合条件的用户（能力分>70）
    eligible_users = await platform_db.query("""
        SELECT career_id, user_id, ability_scores
        FROM career_profiles
        WHERE (ability_scores->>'financial')::int +
              (ability_scores->>'strategic')::int +
              (ability_scores->>'market')::int / 3 > 70
    """)
    
    for user in eligible_users:
        # 在OPC创建初始记录
        await OPC_db.execute("""
            INSERT INTO OPC_access (career_id, user_id, status, unlocked_at)
            VALUES (:career_id, :user_id, 'unlocked', NOW())
            ON CONFLICT (career_id) DO NOTHING
        """, user)
```
