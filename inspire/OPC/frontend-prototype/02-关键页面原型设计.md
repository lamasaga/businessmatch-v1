## A. AI员工局主页面 (`/opc/agency`)

### 页面概述

AI员工局是学生管理 AI 数字员工团队的核心页面。页面采用「组织架构图 + 员工卡片列表」的双视图模式，顶部为 React Flow 渲染的组织架构可视化区域，下方为网格化员工卡片。页面提供雇佣、解雇、查看详情、分配任务等核心操作入口。

### 组件清单与字段定义

#### 1. 页面头部 (`AgencyHeader`)

| 元素 | 类型 | 说明 |
|------|------|------|
| 页面标题 | `h1` | "AI员工局" |
| 副标题 | `p` | 动态显示"管理你的AI数字员工团队 — 共{N}人活跃中" |
| 招聘按钮 | `Button` | 主按钮，图标 `UserPlus`，跳转 `/opc/agency/hire` |
| 一键派活按钮 | `Button` | 次按钮，图标 `Zap`，打开批量任务分配弹窗 |

#### 2. 组织架构图 (`OrgChartFlow`)

基于 **React Flow** 实现，节点数据类型：

```typescript
interface OrgNodeData {
  id: string;
  codename: string;
  role: string;
  avatar: string;
  level: 1 | 2 | 3 | 4 | 5;
  status: 'idle' | 'working' | 'review' | 'offline';
  currentTask?: string;
  onView: (id: string) => void;
  onAssign: (id: string) => void;
}

interface OrgEdgeData {
  id: string;
  source: string;
  target: string;
  type: 'reports_to' | 'collaborates';
}
```

节点自定义样式（暗色主题适配）：
- 背景色：`var(--background-card)` (#141416)
- 边框：1px solid `var(--border-subtle)`
- 激活节点：左边框 2px solid `var(--primary)`
- 状态指示灯：8px 圆点（🟢#2dd4a0 / 🟡#f59e0b / 🔴#f87171 / ⚪#8a8a92）

#### 3. 员工卡片 (`EmployeeCard`)

```typescript
interface EmployeeCardProps {
  employee: {
    id: string;
    codename: string;
    role: string;
    avatar: string;
    level: number;
    levelName: string;
    experience: number;
    experienceToNext: number;
    status: 'idle' | 'working' | 'review' | 'offline';
    currentTask?: {
      id: string;
      title: string;
      progress: number;
    };
    skills: string[];
    isHired: boolean;
  };
  onView: () => void;
  onAssign: () => void;
  onHire?: () => void;
  onFire?: () => void;
}
```

卡片字段布局（从上到下）：
1. **头部行**：Avatar（32px）+ Codename + 角色名 + 右侧菜单按钮（`MoreVertical`）
2. **等级区**：等级名称（如"L3 资深"）+ 经验条（`width: ${exp/expToNext*100}%`）
3. **状态区**：状态指示灯 + 状态文本 + 当前任务标题（如果有）+ 进度条
4. **技能区**：技能标签（最多3个，超出显示 `+N`）
5. **操作区**：
   - 已雇佣：`[查看详情]` `[派活]` `[🔥 解雇]`（解雇为危险操作，需二次确认）
   - 未雇佣：`[立即雇佣]` 按钮（主按钮样式）

#### 4. 团队能力雷达图 (`TeamRadarChart`)

复用现有 `AbilityRadar` 组件，数据源改为聚合所有 AI 员工的能力值：

```typescript
interface TeamAbilityMap {
  strategic: number;   // 战略能力（Cortex + Advisor加权）
  technical: number;   // 技术能力（DEV类加权）
  marketing: number;   // 市场能力（GRW + Scout加权）
  creative: number;    // 创意能力（CP + DES加权）
  operational: number; // 运营能力（OPS + FIN + LEG加权）
}
```

#### 5. 本周KPI概览 (`WeeklyKpiPanel`)

| 指标 | 字段 | 类型 |
|------|------|------|
| 任务完成率 | `taskCompletionRate` | `number` (百分比) |
| 交付物验收率 | `deliverableAcceptanceRate` | `number` (百分比) |
| 平均响应时间 | `avgResponseTime` | `number` (小时) |
| 人机成本比 | `hacrRatio` | `string` (如 "1:72") |

雇佣确认对话框字段：
- 员工名称与头像
- 雇佣周期（周数选择器，默认4周）
- 周薪（固定，根据等级计算）
- 总成本（自动计算）
- 当前余额与支付能力提示
- `[取消]` `[确认雇佣]` 按钮

解雇确认对话框字段：
- 警告文本："解雇 {codename} 后，其正在执行的任务将被暂停。已产生的费用不予退还。"
- 解雇原因选择（下拉框）：战略调整 / 预算限制 / 绩效不达标 / 其他
- 详细原因输入框（多行文本，可选）
- `[取消]` `[确认解雇]` 按钮（确认按钮为 danger 样式）

## B. 任务管理面板 (`/opc/tasks`)

### 页面概述

任务管理面板采用 Kanban 看板视图，展示任务从创建到完成的完整生命周期。支持拖拽排序、快速筛选、批量操作。任务详情通过右侧抽屉（Drawer）展开，不打断当前看板上下文。

- `ratio`: 计算后的比值
- `tier`: 比值区间评级（`low:<10` / `medium:10-50` / `high:50-100` / `excellent:>100`）

#### 2. 品牌配置 (`BrandConfig`)

```typescript
interface BrandConfigData {
  logoUrl?: string;           // 上传后的Logo URL
  primaryColor: string;       // 默认 #d4a853
  accentColor: string;        // 默认 #2dd4a0
  textColor: string;          // 默认 #f2f0eb
  darkMode: boolean;          // 默认true（跟随系统）
}
```

Logo 上传组件：
- 支持拖拽上传
- 文件类型：SVG、PNG、JPG
- 最大 2MB
- 预览区实时显示 Logo + 公司名称组合效果

#### 3. 模式切换 (`ModeSwitch`)

```typescript
type OperationMode = 'simulation' | 'real';

interface ModeSwitchProps {
  currentMode: OperationMode;
  onSwitch: (mode: OperationMode) => void;
  realModeRequirements: {
    ageVerified: boolean;
    stripeConnected: boolean;
    identityVerified: boolean;
  };
}
```

切换真实模式时的确认流程：
1. 显示风险提示弹窗（真实资金、法律责任）
2. 勾选「我已了解真实模式的风险与责任」
3. 验证年龄（≥18岁）
4. 引导完成 Stripe 连接
5. 切换成功，财务看板数据重新加载

type IntegrationStatus = 'connected' | 'disconnected' | 'connecting' | 'error';
