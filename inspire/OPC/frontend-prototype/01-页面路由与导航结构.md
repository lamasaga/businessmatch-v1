## 一、路由体系总体设计

### 1.1 路由命名空间隔离

OPC 作为现有平台的「生涯终极阶段」模块，采用 `/opc/*` 的独立命名空间，避免与现有路由冲突：

```
现有平台路由              OPC 模块路由
─────────────────────────────────────────────
/                         /opc
/career                   /opc/career（OPC生涯概览）
/courses                  /opc/courses（创业课程）
/games                    /opc/challenges（创业挑战赛）
/wiki                     /opc/wiki（创业知识库）
                          /opc/agency（AI员工局）
                          /opc/tasks（任务管理）
                          /opc/pipeline（创业流水线）
                          /opc/bmc（商业模式画布）
                          /opc/finance（财务看板）
                          /opc/company/settings（公司设置）
```

### 2.2 OPCGuard 组件设计

```typescript
// src/components/opc/OPCGuard.tsx
import { Navigate, useLocation } from 'react-router-dom';
import { useAuthStore } from '../../stores/authStore';
import { useOPCStore } from '../../stores/opcStore';
import { Loader2 } from 'lucide-react';

interface OPCGuardProps {
  children: React.ReactNode;
}

export default function OPCGuard({ children }: OPCGuardProps) {
  const { isAuthenticated, isInitialized } = useAuthStore();
  const { isOhbUnlocked, isOhbLoading } = useOPCStore();
  const location = useLocation();

  // 等待所有状态初始化
  if (!isInitialized || isOhbLoading) {
    return (
      <div className="min-h-screen flex items-center justify-center bg-background">
        <div className="flex flex-col items-center gap-3">
          <Loader2 className="w-8 h-8 text-primary animate-spin" />
          <p className="text-sm text-foreground-muted">加载OPC工作空间...</p>
        </div>
      </div>
    );
  }

  // 未登录 → 跳转登录页，记录返回路径
  if (!isAuthenticated) {
    return <Navigate to="/login" replace state={{ from: location.pathname }} />;
  }

  // 已登录但未解锁OPC → 跳转OPC介绍/解锁页
  if (!isOhbUnlocked) {
    return <Navigate to="/opc" replace />;
  }

  return <>{children}</>;
}
```

### 2.3 OPC 解锁条件校验

OPC 解锁由后端 `CareerProfile` 中的 `OPC_unlocked` 字段控制，前端通过 `useOPCStore` 在初始化时拉取：

```typescript
// src/stores/opcStore.ts（权限相关部分）
interface OPCState {
  isOhbUnlocked: boolean;
  isOhbLoading: boolean;
  company: Company | null;
  currentStage: PipelineStage | null;

  // 权限Actions
  checkOhbAccess: () => Promise<void>;
  unlockOhb: () => Promise<void>;
}

export const useOPCStore = create<OPCState>((set, get) => ({
  isOhbUnlocked: false,
  isOhbLoading: true,
  company: null,
  currentStage: null,

  checkOhbAccess: async () => {
    try {
      const res = await api.get('/api/v1/opc/status');
      set({
        isOhbUnlocked: res.data.data.unlocked,
        company: res.data.data.company,
        currentStage: res.data.data.current_stage,
        isOhbLoading: false,
      });
    } catch {
      set({ isOhbLoading: false, isOhbUnlocked: false });
    }
  },

  unlockOhb: async () => {
    const res = await api.post('/api/v1/opc/unlock');
    set({ isOhbUnlocked: true, company: res.data.data.company });
  },
}));
```

### 3.2 面包屑组件实现

```typescript
// src/components/opc/BreadcrumbNav.tsx
import { Link, useLocation } from 'react-router-dom';
import { ChevronRight, Home } from 'lucide-react';
import { OPC_BREADCRUMBS } from '../../types/opc';

export default function BreadcrumbNav() {
  const location = useLocation();
  const items = OPC_BREADCRUMBS[location.pathname] || [
    { label: 'OPC首页', path: '/opc', icon: Home },
  ];

  return (
    <nav className="flex items-center gap-2 text-sm text-foreground-muted mb-6">
      {items.map((item, index) => {
        const Icon = item.icon || Home;
        const isLast = index === items.length - 1;
        return (
          <div key={item.label} className="flex items-center gap-2">
            {index > 0 && <ChevronRight className="w-4 h-4 text-foreground-muted/50" />}
            {isLast || !item.path ? (
              <span className="flex items-center gap-1.5 text-foreground font-medium">
                <Icon className="w-4 h-4" />
                {item.label}
              </span>
            ) : (
              <Link
                to={item.path}
                className="flex items-center gap-1.5 hover:text-primary transition-colors"
              >
                <Icon className="w-4 h-4" />
                {item.label}
              </Link>
            )}
          </div>
        );
      })}
    </nav>
  );
}
```

### 5.3 带状态保留的跳转

任务详情页（`/opc/tasks/:taskId`）返回任务看板时保留筛选状态：

```typescript
// TaskBoardPage → TaskDetailPage 跳转时
navigate(`/opc/tasks/${taskId}`, {
  state: { fromBoard: true, filters: currentFilters }
});

// TaskDetailPage 返回时
const location = useLocation();
const navigateBack = () => {
  if (location.state?.fromBoard) {
    navigate('/opc/tasks', { state: { preserveFilters: location.state.filters } });
  } else {
    navigate('/opc/tasks');
  }
};
```
