## 一、RBAC 模型

### 1.1 角色定义

```yaml
roles:
  student:
    description: "学生创始人"
    permissions:
      - company: [create, read, update, delete_own]
      - employee: [hire, dismiss, train_own]
      - task: [create, review, cancel_own]
      - finance: [read_own, record]
      - report: [generate_own]
    restrictions:
      - "最多创建3家公司"
      - "最多雇佣10个AI员工"
      - "只能操作自己的公司数据"
  
  teacher:
    description: "教师/导师"
    permissions:
      - company: [read_students]
      - gateway: [review]
      - report: [read_students]
      - student: [view_progress]
    restrictions:
      - "只能查看自己班级学生的数据"
      - "不能修改学生公司数据"
  
  parent:
    description: "家长"
    permissions:
      - company: [read_child]
      - finance: [read_child, approve_transaction]
      - notification: [receive]
    restrictions:
      - "只能查看自己孩子的数据"
      - "不能操作任何功能"
  
  platform_admin:
    description: "平台管理员"
    permissions:
      - all: [read]
      - system: [manage]
      - user: [manage]
      - content: [moderate]
    restrictions:
      - "不能修改用户公司数据（除非违规处理）"
      - "所有操作记录审计日志"
  
  ai_employee:
    description: "AI数字员工"
    permissions:
      - task: [read_assigned, update_status, submit_deliverable]
      - mcp_tools: [use_authorized]
      - memory: [read_own, write_own]
    restrictions:
      - "只能访问被授权的工具"
      - "只能读写自己的记忆"
      - "不能访问其他员工的数据"
```

## 二、API 速率限制

### 2.1 限制策略

```yaml
rate_limits:
  default:
    window: 60          # 秒
    max_requests: 100   # 每窗口最大请求数
  
  auth:
    login: { window: 300, max: 5 }      # 5分钟5次登录尝试
    register: { window: 3600, max: 3 }  # 1小时3次注册
  
  ai_tasks:
    create: { window: 60, max: 5 }      # 1分钟创建5个任务
    execute: { window: 60, max: 3 }     # 1分钟执行3个任务
  
  mcp_calls:
    default: { window: 60, max: 20 }    # 1分钟20次工具调用
    expensive: { window: 60, max: 5 }   # 昂贵工具1分钟5次
  
  reports:
    generate: { window: 300, max: 3 }   # 5分钟生成3个报告
```

### 2.2 实现方式

```python
# 使用Redis实现滑动窗口限流

import redis
from functools import wraps

r = redis.Redis()

def rate_limit(key_prefix: str, window: int, max_requests: int):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            # 获取用户标识
            user_id = get_current_user_id()
            key = f"ratelimit:{key_prefix}:{user_id}"
            
            # 获取当前计数
            current = r.get(key)
            if current and int(current) >= max_requests:
                raise RateLimitExceeded(
                    f"请求过于频繁，请{window}秒后再试"
                )
            
            # 增加计数
            pipe = r.pipeline()
            pipe.incr(key)
            pipe.expire(key, window)
            pipe.execute()
            
            return await func(*args, **kwargs)
        return wrapper
    return decorator

# 使用示例
@app.post("/api/v1/opc/tasks")
@rate_limit("ai_tasks:create", window=60, max_requests=5)
async def create_task(...):
    ...
```
