## 二、阶段一：IDEATE · 创意孵化

### 2.1 目标
在2周内，将模糊的兴趣/痛点转化为**结构化的商业创意**，输出完整的商业模式画布（BMC）和品牌方案。

### 2.2 学生动作

**第1周：发现与定义**
1. **兴趣审计**：平台根据学生在现有商赛/课程中的表现数据，推荐「高匹配度创业方向」
2. **痛点扫描**：使用 Scout AI 探查社交媒体、论坛、评论中的真实用户痛点
3. **创意碰撞**：与 CP-01（创意策划师）进行3轮头脑风暴，生成10+创意点子
4. **初步筛选**：用 BMC 轻量模板快速评估每个点子的可行性

**第2周：深化与定型**
1. **竞品深潜**：BA-01（商业分析师）输出竞品功能矩阵与差异化空间分析
2. **用户画像**：基于 Scout 数据，构建3个典型用户 persona
3. **价值主张**：与 CP-01 打磨核心价值主张（一句话说清楚「为谁解决什么问题」）
4. **品牌初稿**：命名、Slogan、视觉方向（3套方案）

### 2.4 里程碑评审（Gateway 1）

学生提交「创意包」后，触发 **AI 评审委员会 + 导师终审**：

| 评审维度 | AI评审 | 导师评审 | 通过标准 |
|----------|--------|----------|----------|
| BMC完整性 | ✅ 自动检查9宫格 | — | 无空白项 |
| 差异化程度 | ✅ 与竞品矩阵比对 | ✅ 行业经验判断 | 差异化指数>60 |
| 技术可行性 | ✅ 技术栈评估 | — | L1-L2难度 |
| 市场真实性 | ✅ 搜索量/趋势验证 | ✅ 直觉判断 | 非伪需求 |
| 学生匹配度 | ✅ 与Persona对齐 | ✅ 面谈确认 | 热情度>4/5 |

**评审结果**：
- 🟢 **通过**：进入 VALIDATE 阶段
- 🟡 **有条件通过**：修改指定问题后进入
- 🔴 **不通过**：返回 IDEATE，保留 Legacy（已完成的竞品分析可复用）

## 三、阶段二：VALIDATE · 市场验证

### 3.1 目标
在2-4周内，用**最小成本**验证核心假设：「目标用户真的愿意为我的解决方案付费/使用吗？」

### 3.2 学生动作

**核心方法论：冒烟测试（Smoke Test）**

不开发产品，先用「假装有产品」的方式测试需求：

1. **着陆页测试**
   - COPY-01 撰写着陆页文案
   - DES-01 设计单页视觉（可用 Carrd/Webflow 快速搭建）
   - GRW-01 设置简单的「预约/等待列表」表单
   - 投放少量广告或自然流量，看转化率

2. **假门测试（Fake Door）**
   - 在着陆页上放置「立即购买/订阅」按钮
   - 点击后显示「产品即将上线，留下邮箱第一时间获取」
   - 统计点击率 = 真实付费意愿的先行指标

3. **人工 concierge MVP**
   - 如果产品是服务类，先用纯人工方式服务5-10个客户
   - 验证服务流程、定价敏感度、客户满意度
   - 所有沟通记录录入平台，作为后续AI训练的语料

4. **众筹/预售**
   - 如果适合，在平台内建「预售页面」
   - 设置目标金额，达标后才进入 BUILD 阶段
   - 不达标则退款或转型（低成本试错）

### 3.4 里程碑评审（Gateway 2）

**验证指标矩阵**：

| 指标 | 最低门槛 | 理想值 | 数据来源 |
|------|----------|--------|----------|
| 着陆页访问-预约转化率 | >5% | >15% | Analytics |
| 假门点击率 | >2% | >8% | 热力图 |
| 邮件列表增长 | >50人 | >200人 | 邮件平台 |
| 用户访谈完成数 | >10人 | >30人 | 访谈记录 |
| NPS/满意度 | >30 | >50 | 问卷 |
| 预售金额（如适用） | >目标50% | >目标100% | 支付平台 |

**评审结果**：
- 🟢 **通过**：需求验证成功，进入 BUILD
- 🟡 ** pivot 建议**：数据有信号但方向需调整，进入「微转型」子流程
- 🔴 **不通过**：假设被证伪，鼓励学生归档经验，返回 IDEATE 或选择新方向

## 四、阶段三：BUILD · MVP构建

### 4.1 目标
在4-8周内，基于验证通过的需求，构建并上线**最小可用产品**。

### 4.2 产品类型与技术路径

根据学生能力和创意类型，平台推荐不同的技术路径：

| 产品类型 | 推荐技术栈 | AI员工主力 | 预估工时 |
|----------|-----------|-----------|----------|
| 信息类网站/博客 | Webflow/Notion + 自定义域名 | COPY-01, DES-01 | 1-2周 |
| 落地页+付费墙 | Carrd/Framer + Stripe | COPY-01, DES-01 | 2-3周 |
| 简单Web应用 | Next.js + Supabase + Vercel | DEV-01, DES-01 | 4-6周 |
| 小程序/轻应用 | 微信小程序/抖音小程序 | DEV-01, DES-01 | 4-6周 |
| Newsletter/付费社群 | Beehiiv/Circle + 支付集成 | COPY-01, GRW-01 | 1-2周 |
| 数字产品模板 | Figma/Canva + Gumroad | DES-01, COPY-01 | 2-4周 |
| AI工具/Agent | Python + FastAPI + 前端 | DEV-01, DATA-01 | 6-8周 |
| 电商/代发货 | Shopify/有赞 + 供应链对接 | GRW-01, OPS-01 | 3-4周 |

### 4.3 开发流程：AI 驱动的敏捷迭代

```
Sprint 周期: 1周
每个Sprint:
  Day 1: 学生与Cortex规划本周目标 → 拆解为AI员工任务
  Day 2-4: AI员工并行开发（代码/设计/文案）
  Day 5: 集成测试（OPC-sandbox自动测试 + 学生手动测试）
  Day 6: 评审会议（学生验收 + AI自评报告）
  Day 7: 部署 + 数据收集 + 复盘记录
```

## 五、阶段四：LAUNCH · 市场发射

### 5.1 目标
在2-4周内，将MVP推向目标用户，获取首批真实用户并完成首笔交易。

### 5.2 发射矩阵

平台提供多种「发射策略模板」，学生根据产品类型选择：

| 策略 | 适用产品 | 核心动作 | 目标 |
|------|----------|----------|------|
| **Product Hunt 发射** | 工具类/SaaS | 制作介绍页、收集早鸟反馈、争取榜单 | 500+ upvotes |
| **社媒病毒式** | 内容类/娱乐类 | KOL合作、话题挑战、UGC激励 | 10万+曝光 |
| **社群渗透** | 垂直工具/服务 | 精准社群贡献价值、软植入 | 100+种子用户 |
| **SEO长尾** | 信息类/工具类 | 批量长尾内容、自然排名 | 1000+月 organic |
| **付费冷启动** | 高客单价/本地服务 | 小规模精准广告投放 | 10+付费客户 |
| **平台寄生** | 模板/插件类 | 在已有平台（Notion/Figma/微信）上架 | 100+下载/使用 |
