# 15 - 什么是游戏：从本体论到内在结构

> 在讨论"如何设计一个游戏化的商业教学平台"之前，我们需要先回答一个更根本的问题：游戏究竟是什么？不是列举特征，而是理解其存在的结构方式。

---

## 一、问题的提出：为什么定义游戏很难

维特根斯坦在《哲学研究》中提出一个著名观点："游戏"之间不存在共同的本质，只有"家族相似性"。国际象棋、跳绳、角色扮演、赌博——它们共享某些特征，但没有哪一个特征是所有游戏都具备的。

然而，如果我们放弃追问"什么是游戏"，设计就会失去根基。一个好的游戏设计师不是模仿热门游戏的表面，而是理解使游戏成为游戏的**结构条件**。本文件尝试从游戏学（Ludology）的经典理论出发，构建一个关于游戏内在结构的认知框架。

---

## 二、游戏的本体论：游戏是一种"意义发生的领域"

### 2.1 赫伊津哈的魔圈（Magic Circle）

荷兰历史学家约翰·赫伊津哈（Johan Huizinga）在《游戏的人》（*Homo Ludens*, 1938）中提出的"魔圈"概念，是游戏本体论的基石：

> "游戏是在特定时空范围内、按照固定规则进行的自由活动，它在意识上自觉地站在'平常'生活之外，但同时又让玩家全身心投入。"

魔圈不是比喻，而是一种**存在论的空间**：
- 当你踏入篮球场，走路变成了运球，阻挡变成了犯规，这些行为的意义被完全改写
- 当你打开《王者荣耀》，点击屏幕不再是"触摸玻璃"，而是"释放技能"
- 魔圈内外的同一行为具有截然不同的意义维度

**核心洞察**：游戏的第一个结构性特征——**意义转换机制**。游戏创造了一个临时的意义系统，在这个系统中，日常行为被重新编码。

### 2.2 凯卢瓦的六要素与四原型

法国社会学家罗杰·凯卢瓦（Roger Caillois）在《人、游戏与竞技》（*Man, Play and Games*, 1958）中，将游戏（更准确地说是"游玩"play）定义为具有以下六个性质的活动：

| 要素 | 含义 | 设计启示 |
|------|------|----------|
| **自由（Free）** | 非强迫，自愿参与 | 教育游戏中的强制性会消解游戏性 |
| **分离（Separate）** | 在时空上与日常生活区隔 | 需要明确的"开始"与"结束"仪式 |
| **不确定（Uncertain）** | 结果不可预先知道 | 如果结果确定，游戏失去意义 |
| **非功利（Unproductive）** | 不直接产生物质财富 | 游戏创造的是内在价值，而非外在效用 |
| **规则约束（Governed by Rules）** | 受特定规则体系约束 | 规则是意义转换的语法 |
| **假装（Make-believe）** | 暂时接受虚构情境 | 玩家自愿"假装"这是真的 |

凯卢瓦进一步提出**四种游戏原型**，这四种力量可以按不同比例混合构成任何游戏：

- **竞争（Agôn）**：在人为平定的竞技场上验证优越性。象棋、体育、排名系统。
- **机遇（Alea）**：放弃控制，拥抱随机。掷骰子、抽卡、彩票。
- **模仿（Mimicry）**：扮演另一个存在。角色扮演、模拟经营、换装。
- **眩晕（Ilinx）**：追求感官的暂时失控。旋转木马、过山车、极限运动。

### 2.2.1 补充：从机制行为视角的游戏分类

在凯卢瓦的本体论框架基础上，我们可以从**玩家行为机制**的角度提出一个更贴近现代游戏设计的分类体系，这与凯卢瓦的"体验本质"视角形成互补：

| 类型 | 核心特征 | 本质 | 典型游戏 |
|------|----------|------|----------|
| **强迫对齐** | 成套收集、拼图、模式匹配 | 完整性追求与秩序建立 | 宝可梦收集、成就系统、拼图游戏 |
| **确定积累** | 成长、升级、经济行为 | 资源增长与长期规划 | RPG等级系统、经营模拟、经济策略 |
| **风险偏好** | 下注、投票、信息博弈 | 不确定性下的决策权衡 | 狼人杀、德州扑克、投票系统 |
| **攻击行为** | 直接对抗、破坏、支配 | 冲突与征服 | PVP对战、塔防、竞技格斗 |

#### 两套分类体系的范畴差异

凯卢瓦的分类是**体验本质导向**，回答"玩家获得什么体验"；上述分类是**行为机制导向**，回答"玩家在游戏中做什么"。二者存在以下对应关系：

| 机制分类 | 对应凯卢瓦原型 | 独特贡献 |
|----------|----------------|----------|
| 强迫对齐 | 模仿（部分）+ 竞争（部分） | 捕捉"完整性强迫症"和完美主义驱动 |
| 确定积累 | 竞争（成就驱动） | 强调经济系统和复利增长机制 |
| 风险偏好 | 机遇（随机）+ 竞争（策略） | 凸显信息不对称下的决策博弈 |
| 攻击行为 | 竞争（对抗）+ 眩晕（破坏快感） | 独立提炼直接冲突行为 |

#### 新增维度：社交协作

**社交协作**作为第五个维度，其核心特征是**共同目标下的互动与配合**，如MMO团队副本、合作解谜、多人建造。这一维度在凯卢瓦体系中被部分包含在"竞争"的反面（合作竞争），但值得单独强调。

**社交协作是否是一种游戏行为？** 是的，它具备游戏的核心要素：
- 自由参与：玩家自愿加入团队
- 规则约束：团队有分工和协作规则
- 不确定结果：协作效果影响胜负
- 非功利性：追求内在的团队成就

#### 性别差异的观察与思考

一个有趣的观察是：这五个维度从**强迫对齐 → 确定积累 → 社交协作 → 风险偏好 → 攻击行为**，可能存在明显的性别差异趋势——越接近"对齐"端，女性玩家偏好度越高；越接近"攻击"端，男性玩家偏好度越高。

**设计启示**：了解这种趋势有助于设计更具包容性的游戏系统。商业模拟游戏可以通过调整各维度的配比，满足不同玩家群体的偏好。

**核心洞察**：游戏的第二个结构性特征——**原型混合机制**。任何游戏都是这四种力量的独特配比。商业模拟游戏主要是 Agôn（竞争排名）+ Mimicry（扮演企业家）+ Alea（随机事件），几乎不含 Ilinx。

### 2.3 凯卢瓦的另一条轴：Paidia 与 Ludus

凯卢瓦还提出了一条从"无序"到"秩序"的光谱：

- **Paidia（派迪亚）**：自发的、无结构的、嬉闹的游玩。孩子的追逐打闹、沙坑里的自由建构。
- **Ludus（路德斯）**：受规则约束的、有目标的、需要技巧的游戏。国际象棋、围棋、电子竞技。

所有游戏都位于这条光谱的某一点上。

**对教育平台的启示**：
- 低年级学生需要更多 Paidia 元素（自由探索、无惩罚试错）
- 高年级学生可以承受更多 Ludus 元素（严格规则、排名竞争、策略深度）
- 最优秀的设计能够在 Paidia 的自由感与 Ludus 的成就感之间流动

## 三、游戏的内在结构：一个形式系统

### 3.1 Jesper Juul 的经典游戏模型

丹麦游戏学者耶斯珀·尤尔（Jesper Juul）在《半真实》（*Half-Real*, 2005）中，综合前人理论提出了被学界广泛引用的"经典游戏模型"，包含六个相互关联的特征：

```
┌─────────────────────────────────────────────────────────────┐
│                    经典游戏模型的三层结构                      │
├─────────────────┬─────────────────┬─────────────────────────┤
│  游戏作为形式系统  │  玩家与游戏的关系  │    游戏与外部世界的关系   │
├─────────────────┼─────────────────┼─────────────────────────┤
│ 1. 规则（Rules） │                 │                         │
│ 2. 可变、可量化的 │                 │                         │
│    结果          │                 │                         │
│ 4. 玩家努力      │ 3. 结果的价值赋值 │                         │
│                │ 4. 玩家努力      │                         │
│                │ 5. 玩家对结果的   │                         │
│                │    情感依附      │                         │
│                │                 │ 6. 可协商的后果           │
└─────────────────┴─────────────────┴─────────────────────────┘
```

尤尔的完整定义：
> "游戏是一个基于规则的正式系统，具有可变且可量化的结果，不同结果被赋予不同价值，玩家付出努力以影响结果，玩家对结果产生情感依附，且活动的后果是可选和可协商的。"

### 3.2 逐层解析六特征

#### 特征一：规则（Rules）—— 游戏的语法

规则不是"限制"，而是**意义的生成器**。
- 没有"不能用手触球"的规则，足球就不是足球，用手触球的行为也没有"犯规"的意义
- 规则创造了**内源性价值系统**（Endogenous Value）：在游戏内部，某些状态和行为的 valu 完全由规则赋予，与外部世界无关

规则可以分为三层：
| 规则层级 | 说明 | 示例 |
|----------|------|------|
| **构成性规则** | 决定游戏逻辑运行的底层规则 | 结算引擎的数学公式 |
| **操作性规则** | 玩家直接面对的操作指令 | "每轮可以投资三个方向" |
| **隐性规则/游戏精神** | 未明文规定但被共同遵守 | "不偷看对手的决策" |

#### 特征二：可变、可量化的结果（Variable, Quantifiable Outcome）—— 游戏的不确定性引擎

如果结果总是相同，就不是游戏，而是**仪式**或**程序**。

- **可变性**：不同结果必须可能产生。如果一方必胜，游戏崩塌为"表演"
- **可量化**：结果必须能被比较。"赢/输"、"得分高低"、"排名先后"

**关键设计问题**：如何管理不确定性？
- 纯 Agôn（如象棋）：不确定性来自对手的策略不可预测
- 纯 Alea（如彩票）：不确定性来自随机机制
- 混合（如商业模拟）：不确定性来自对手策略 + 随机事件 + 信息不完全

#### 特征三：结果的价值赋值（Valorization）—— 游戏的方向性

规则不仅产生结果，还为结果分配**价值**。

- 在商业模拟中，"排名第一"被赋予正价值，"排名最后"被赋予负价值
- 这种赋值是**人为的**、**内源性的**——在现实世界中，排名本身没有任何固有价值
- 但正因为这种赋值，玩家才有了**方向**和**动力**

**教育游戏的特殊张力**：
- 如果排名是唯一价值来源，学习变成了零和竞争
- 需要设计**多元价值系统**："探索新路线"有价值，"完成课程"有价值，"帮助队友"也有价值

#### 特征四：玩家努力（Player Effort）—— 游戏的能动性条件

玩家必须相信自己的努力可以影响结果。

- 纯随机游戏（如彩票）之所以是"边缘案例"，正是因为玩家努力与结果之间没有因果关系
- 努力不等于"操作难度"——策略思考、资源分配、风险评估都是努力的形式
- **努力的可见性**：玩家需要感知到"因为我的某个决策，结果发生了某种变化"

#### 特征五：玩家对结果的依附（Attachment）—— 游戏的心理粘合剂

玩家必须**在乎**结果。这是游戏区别于"解数学题"的关键。

- 依附产生**情绪**：赢的喜悦、输的失落、不确定时的紧张
- 依附使游戏具有** stakes（赌注感）**：有东西在风险中，才有投入的必要
- **教育设计的风险**：如果学生不在乎排名，整个游戏结构就失效了。需要设计让学生"在乎"的机制——不是强迫，而是让他们认同目标

#### 特征六：可协商的后果（Negotiable Consequences）—— 游戏的边界弹性

游戏的后果可以是"只是游戏"，也可以延伸到现实世界。

- 你可以"只是为了好玩"下象棋，也可以赌钱
- 同一套规则，后果可轻可重
- 这意味着游戏是一个**有边界的系统**，但这个边界是**可渗透的**

**教育平台的后果设计**：
- 完全无后果 → 学生不在乎（Attachment 缺失）
- 后果过重（如与升学直接挂钩）→ 焦虑压倒乐趣，游戏性消解
- 理想状态：后果足够让学生在乎，但不足以造成真正的伤害——这正是"魔圈"的保护功能

## 四、Salen & Zimmerman 的三层图式：规则、游戏、文化

凯蒂·萨伦（Katie Salen）和埃里克·齐默尔曼（Eric Zimmerman）在《游戏规则》（*Rules of Play*, 2004）中提出了理解游戏的三个互补图式：

### 4.1 规则图式（Rules）—— 游戏作为逻辑系统

从形式逻辑角度分析游戏：
- 状态空间：游戏可能处于的所有状态（如商业模拟中所有可能的预算分配组合）
- 合法操作：从一个状态到另一个状态的允许变换（如"投入 Tech 10 万"）
- 终止条件：游戏结束的判断（如"4 轮结束"）
- 胜负函数：给终止状态赋值（如"按加权总分排名"）

### 4.2 游戏图式（Play）—— 游戏作为体验过程

从玩家体验角度分析游戏：
- 有意义的游戏（Meaningful Play）：行动与结果之间的关系既**可辨识**（discernable）又**被整合**（integrated）到更大的游戏语境中
- 例：如果你的预算分配在结算中完全看不出影响，那就是"无意义的游戏"

### 4.3 文化图式（Culture）—— 游戏作为文化实践

从社会语境角度分析游戏：
- 游戏不是封闭系统，它与外部文化持续交换意义
- 商业模拟之所以有效，是因为学生已经在文化中学到了"竞争""投资""创业"等概念
- 游戏可以反过来影响文化（如《大富翁》塑造了人们对资本主义的理解）

**核心启示**：设计游戏时，三个图式必须同时考虑。只优化规则图式会得到"数学正确但体验冰冷"的系统；只优化游戏图式会得到"感觉不错但缺乏深度"的花瓶；忽视文化图式会得到"学生看不懂在做什么"的失败产品。

## 五、Raph Koster 的视角：游戏是"好吃的模式"

游戏设计师拉夫·科斯特（Raph Koster）在《乐趣理论》（*A Theory of Fun for Game Design*, 2005）中提出了一个更贴近认知科学的定义：

> "游戏是以可被大脑吸收的方式呈现的模式（patterns）。"

科斯特认为，游戏的乐趣本质上来自**模式识别和学习**：
- 大脑是模式识别机器，发现模式时释放多巴胺
- 游戏提供了一个**安全的学习环境**：失败成本低，反馈即时，模式清晰
- 当玩家"掌握"了一个模式，乐趣消退，需要新的模式来维持兴趣

**这与教育的天然连接**：
- 商业模拟的本质，就是让学生在安全环境中识别商业决策的模式
- "供需关系"是一个模式，"边际效用递减"是一个模式，"蓝海战略"是一个模式
- 好的商业模拟游戏，就是将这些模式以"可被大脑吸收的方式"呈现出来

## 六、游戏的内在结构：一个整合模型

综合以上理论，我们可以提出一个关于游戏内在结构的整合模型：

```
                    ┌──────────────┐
                    │   魔圈边界    │  ← 游戏与日常的区隔
                    │  (Magic Circle)│
                    └──────┬───────┘
                           │
    ┌──────────────────────┼──────────────────────┐
    │                      │                      │
    ▼                      ▼                      ▼
┌─────────┐        ┌─────────────┐        ┌─────────────┐
│  规则系统  │◄────►│   冲突空间   │◄────►│  意义生成器  │
│(Rules)  │        │  (Conflict)  │        │ (Meaning)   │
└────┬────┘        └──────┬──────┘        └──────┬──────┘
     │                    │                      │
     │    ┌───────────────┘                      │
     │    │                                      │
     ▼    ▼                                      ▼
┌─────────────────────────────────────────────────────────┐
│                      玩家 (Player)                       │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐   │
│  │  努力   │  │  决策   │  │  情感   │  │  学习   │   │
│  │(Effort) │  │(Agency) │  │(Attach) │  │(Mastery)│   │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘   │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │  可变结果    │
                    │ (Variable    │
                    │  Outcome)    │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              ▼            ▼            ▼
         ┌────────┐  ┌────────┐  ┌────────┐
         │  正价值  │  │  负价值  │  │  零价值  │
         │ (Win)  │  │ (Lose) │  │ (Draw) │
         └────────┘  └────────┘  └────────┘
```

### 这个模型的运作逻辑：

1. **魔圈**划定了一个临时意义领域，日常行为在这里被重新编码
2. **规则系统**定义了状态空间和合法操作
3. **冲突空间**提供了挑战和不确定性（可以是竞争、运气、或与环境对抗）
4. **玩家**在其中付出努力、做出决策、产生情感、进行学习
5. **可变结果**通过价值赋值产生意义——赢之所以让人快乐，不是因为赢本身，而是因为整个结构使其有意义
6. **意义生成器**将结果反馈给玩家，形成闭环，驱动下一轮参与

## 七、从理论到设计：游戏的七条结构律

基于上述分析，提炼出设计任何游戏化系统时应遵循的七条"结构律"：

| 定律 | 内容 | 反例（当定律被破坏时） |
|------|------|----------------------|
| **魔圈律** | 必须有明确的时空边界和意义转换 | 学生分不清"这是模拟"还是"这是考试" |
| **不确定律** | 结果必须具有真正的不可预测性 | 策略完全被破解，最优解唯一且已知 |
| **努力律** | 玩家必须能感知到自己的决策影响结果 | 结算公式过于复杂，学生看不懂为什么输 |
| **依附律** | 玩家必须在情感上在乎结果 | "反正只是游戏"，完全不在意排名 |
| **价值律** | 必须有清晰的内源性价值系统 | 不知道"赢"意味着什么 |
| **模式律** | 必须提供可被学习、掌握、再超越的模式 | 纯随机，没有可学习的规律 |
| **后果律** | 后果必须"足够真实以让人在乎，足够安全以让人冒险" | 后果太轻（无所谓）或太重（不敢尝试） |

## 八、对教育模拟设计的终极追问

当你设计一个商业模拟教学平台时，以下问题可以检验你是否真正理解了游戏的结构：

1. **魔圈问题**：学生踏入这个平台时，他们进入的是一个"学习空间"还是一个"游戏空间"？这两个身份如何共存？
2. **规则问题**：你的结算引擎是一套"评分标准"还是一套"物理定律"？前者让学生感到被评判，后者让学生感到在探索一个世界。
3. **不确定问题**：如果一名高手每次都能赢，这是设计成功还是设计失败？
4. **努力问题**：学生能否在结算后清晰地回答"我因为这轮做了什么具体决策，导致了什么具体结果"？
5. **依附问题**：学生输的时候，是感到"学到了东西"还是"被否定了能力"？
6. **价值问题**：平台传递的价值观是什么？竞争至上？合作共赢？探索未知？
7. **模式问题**：学生离开平台后，能否在现实中识别出"这就是我在模拟中学到的那个模式"？

> **最终洞见**：游戏不是"加了分数的学习"，也不是"包装成娱乐的考试"。游戏是一种**独特的意义生成结构**，它通过规则创造一个临时世界，在这个世界中，努力与结果之间的关系被精心设计得既清晰又充满悬念。理解了这个结构，你就不需要模仿任何游戏的外观——你可以将任何值得学习的领域，转化为一个让学生自愿投入、全身心参与、并在过程中自然成长的**游戏空间**。
