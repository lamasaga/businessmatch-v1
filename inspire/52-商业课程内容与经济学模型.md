# 02 - 商业课程内容与经济学模型

> 面向不同年龄层学生（小学高段、初中、高中、大学/职校），设计模块化、可嵌套的商学知识体系，并讨论如何将其转化为可运行的模拟参数。

---

## 一、年龄分层与认知锚点

| 学段 | 年龄 | 认知特点 | 教学重心 | 模拟复杂度 |
|------|------|----------|----------|-----------|
| **小学高段** | 10-12 | 具象思维、喜欢故事与角色 | 基础财商、交换与分工、简单供需 | ⭐ 极简 |
| **初中** | 13-15 | 抽象思维萌芽、竞争意识强 | 成本意识、市场定位、团队协作 | ⭐⭐ 轻量 |
| **高中** | 16-18 | 逻辑推理成熟、关注自我发展 | 战略决策、财务分析、博弈论入门 | ⭐⭐⭐ 标准 |
| **大学/职校** | 18+ | 系统思维、职业导向 | 全栈经营、投融资、宏观政策、产业链 | ⭐⭐⭐⭐ 完整 |

**设计原则**：同一平台通过**规则模板**实现分层，而非开发多个平台。

## 二、核心经济学概念的可游戏化映射

### 2.1 微观经济学

| 经济学概念 | 现实含义 | 游戏化映射（模拟参数） | 适用学段 |
|-----------|----------|---------------------|----------|
| **供需关系** | 价格由供需决定 | 城市市场规模 `scale`、竞争队伍数 `kCity`、Ceiling 上限 | 全学段 |
| **边际效用递减** | 投入越多单份收益越低 | Tech 过载系数 `kappa`、增长衰减曲线 `growthRate` | 高中+ |
| **机会成本** | 选择 A 意味着放弃 B | 路线切换成本、开城费、有限预算约束 | 初中+ |
| **市场细分** | 不同人群偏好不同 | Geek/Pragmatic/Trendy 群体权重、城市群体差异 | 初中+ |
| **差异化竞争** | 避开红海找蓝海 | PATHFINDER 路线独占红利、 crowdTax 机制 | 高中+ |
| **信号理论** | 用行为传递信息 | 宣言-投入一致性（BQI R5）、品牌溢价 | 高中+ |
| **网络外部性** | 用户越多价值越大 | Halo 效应、Show 属性的跨城溢出 | 大学 |

### 2.2 财务管理

| 概念 | 模拟映射 | 备注 |
|------|----------|------|
| 启动资金/种子轮 | `SEED = 100` 万 | 可随学段调整规模感 |
| 现金流管理 | 每轮预算 = 上期剩余 + 利息 + 追加 | 引入"断裂"机制可教学风险 |
| 投资回报率 (ROI) | 属性增长 / 资金投入 | 可在前端展示 ROI 雷达图 |
| 负债与利息 | 可引入"借贷"模块（未来扩展） | 适合高中+ |
| 股权稀释 | 多轮追加投资对应股权让渡 | 大学进阶模块 |

### 2.3 战略管理

| 概念 | 模拟映射 | 教学时机 |
|------|----------|----------|
| SWOT 分析 | 对局前后的城市-路线选择界面嵌入 SWOT 模板 | 回合开始前 |
| 波特五力 | 竞争者数量、替代品（事件）、买方/卖方议价 | 复盘分析 |
| 蓝海战略 | PATHFINDER 路线设计、独家红利 | R2-R3 战略转折 |
| 安索夫矩阵 | 市场渗透（深耕一城）vs 市场开发（开新城） | 全局决策 |

## 三、模块化课程单元设计

### 3.1 单元结构（每个单元 = 微课 + 模拟关卡 + 复盘）

```
单元名称：[主题]
├── 微课视频（5-8分钟）
├── 概念测验（3-5题）
├── 模拟关卡（1-3轮简化对局）
│   ├── 情境设定（角色、目标、约束）
│   ├── 决策轮次（通常 2-3 轮）
│   ├── 实时反馈（每轮结算后解释"为什么"）
│   └── 成就解锁（完成即获得经验/徽章）
└── 复盘报告（系统自动生成 + 教师点评模板）
```

### 3.2 课程单元库（示例）

#### 模块 A：财商启蒙（小学高段 - 初中）

| 单元 | 核心概念 | 模拟简化 |
|------|----------|----------|
| A1  lemonade stand | 成本、售价、利润 | 单城市、单属性（展示）、无事件 |
| A2  小镇集市 | 供需、竞争 | 2-3 队伍、固定预算、看谁的摊位人气高 |
| A3  开一家小店 | 选址、简单投入 | 选择城市（规模不同）、投入钱换人气 |

#### 模块 B：创业入门（初中 - 高中）

| 单元 | 核心概念 | 对应现有机制 |
|------|----------|-------------|
| B1  产品还是营销？ | 路线选择 | TECH vs BRAND 路线体验 |
| B2  听懂用户 | 需求匹配 | Fit 属性、用户群体偏好 |
| B3  城市攻略 | 市场进入策略 | 开城费、城市规模差异、多城竞争 |
| B4  突发事件 | 风险管理 | R3 事件机制、应对策略 |

#### 模块 C：商战策略（高中 - 大学）

| 单元 | 核心概念 | 对应现有机制 |
|------|----------|-------------|
| C1  技术壁垒 | 研发投入与回报曲线 | Tech 过载、增长衰减 |
| C2  差异化生存 | 蓝海战略 | PATHFINDER 路线、独占红利 |
| C3  资本游戏 | 融资与估值 | Follow_on、投资人视角 |
| C4  全媒体时代 | 品牌与口碑管理 | Show 属性、Halo、Hot Pulse |
| C5  政策与合规 | 外部性与监管 | Compliance 事件、营销过度惩罚 |

#### 模块 D：进阶专题（大学 / 竞赛预备）

| 单元 | 核心概念 | 设计方向 |
|------|----------|----------|
| D1  产业链模拟 | 上下游博弈 | 多角色（供应商-制造商-渠道-消费者） |
| D2  宏观经济周期 | 通胀、紧缩、政策 | 全局事件影响所有队伍成本与收入 |
| D3  跨国经营 | 汇率、文化差异 | 多国家地图、汇率波动 |
| D4  ESG 与企业社会责任 | 可持续发展 | 引入环保/社会指标，影响长期估值 |

## 四、从知识点到模拟参数的转化方法

现有 TechVenture 的参数体系已经非常参数化，这是巨大优势。课程设计应与参数体系双向映射：

### 4.1 参数分层

```
全局常量（Global）
  └── 决定游戏"年代感"与难度基调
  例：SEED 资金规模、ROUNDS 轮数、SIGMA 随机性强度

城市参数（City）
  └── 决定地理经济特征
  例：scale 市场规模、群体比例、etaFit/etaShow 效率系数

路线参数（Route）
  └── 决定战略风格差异
  例：rTech/rFit/rShow 增长率、techInvestBoost、fitT1/T2

事件参数（Event）
  └── 决定外部冲击
  例：群体比例偏移、市场规模跳变、罚则倍率

消费者参数（Consumer）
  └── 决定需求侧结构
  例：tech/fit/show 权重（geek 重技术，pragmatic 重匹配）
```

### 4.2 课程-参数配置表示例

```json
{
  "template_id": "lemonade_stand_v1",
  "target_age": "11-13",
  "simplified_from": "techventure_v6",
  "params": {
    "SEED": 50,
    "ROUNDS": 3,
    "CITIES": ["杭州"],
    "ROUTES": ["TECH", "BRAND"],
    "CONSUMER_WEIGHTS": {
      "pragmatic": { "tech": 0.3, "fit": 0.5, "show": 0.2 }
    },
    "GROWTHRATE": "线性简化版",
    "EVENTS": [],
    "BQI_RULES": "关闭复杂规则，仅保留基础排名"
  },
  "ui_hints": {
    "tech_label": "秘方研发",
    "fit_label": "口味调试",
    "show_label": "摊位装修"
  }
}
```

**价值**：教师可在后台选择"课程模板"，一键生成对应规则的对局，无需理解底层参数。

## 五、教学闭环设计

### 5.1 课前：激活先验知识
- 3分钟微课 + 1个生活案例（如：为什么校门口的奶茶店总在换？）

### 5.2 课中：沉浸式决策
- 每轮 5-8 分钟（与现有设计一致）
- 强制"决策笔记"：学生必须写下 1 句话理由才能提交（数据用于课后分析）

### 5.3 课后：智能复盘
系统自动生成报告：
- **个人维度**：你的资金花在哪了？ROI 最高的投入是哪笔？
- **团队维度**：你们队的战略一致性如何？（宣言 vs 投入匹配度）
- **班级维度**：全班选择了什么路线分布？是否符合博弈论预测？

### 5.4 跨课程关联
局外成长系统将各单元获得的经验/徽章串联：
- 完成 A1-A3 → 解锁"小店主"称号 → B 模块开放
- B 模块获得"战略家"徽章 → C 模块可选更复杂事件

## 六、可引入的外部经济学资源

| 资源类型 | 示例 | 使用方式 |
|----------|------|----------|
| 经典案例 | 可口可乐 vs 百事、苹果产品周期 | 微课素材 |
| 数据平台 | 国家统计局青少年版、世界银行公开数据 | 城市参数真实化 |
| 行为经济学实验 | 囚徒困境、信任博弈、拍卖实验 | 设计为独立小游戏 |
| 商业纪录片 | 《美国工厂》《走进比尔》 | 课后拓展 |
| 经典游戏参考 | 《过山车大亨》《模拟城市》《Steam 上的 Startup Company》 | 玩法借鉴 |

---

> **核心建议**：不要让模拟器去"教"经济学，而是让学生在做决策时**自然遭遇**经济学原理，然后在复盘时**命名和解释**这些原理。模拟是土壤，教师的引导是阳光。
