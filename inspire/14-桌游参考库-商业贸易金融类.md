## 一、经典入门（现象级普及作品）

### 1. 大富翁 · Monopoly

| 项目 | 内容 |
|------|------|
| 设计师 | Charles Darrow（基于 Elizabeth Magie 的「地主游戏」） |
| 首发 | 1935 年（Parker Brothers） |
| 人数 | 2–8 人 |
| 时长 | 60–180 分钟 |
| 核心机制 | 掷骰移动、地产购买、收取租金、房屋升级、玩家破产淘汰 |

**简介**：玩家通过掷骰子在棋盘上移动，购买地块、建造房屋与酒店，向其他落脚的玩家收取租金。游戏目标是让其他所有玩家破产，成为唯一的垄断者。

**核心亮点**：
- 极简规则带来的极低学习门槛
- 「位置决定收入」模拟了地段价值差异
- 随机事件（机会卡、公益金）制造戏剧转折
- 交易谈判是唯一的玩家互动出口

**对商域的参考价值**：
- ** beginners-friendly 的资产配置直觉**：地产→升级→收租的链条直观展示了资产增值逻辑
- **谈判系统的必要性**：纯随机无法支撑长期趣味，玩家间交易创造了社交深度
- **死亡螺旋问题**：落后玩家难以翻盘，现代设计多用「软淘汰」或「追赶机制」修正

---

### 2. 卡坦岛 · Catan（原名 The Settlers of Catan）

| 项目 | 内容 |
|------|------|
| 设计师 | Klaus Teuber |
| 首发 | 1995 年（Kosmos） |
| 人数 | 3–4 人（扩展支持 6 人） |
| 时长 | 60–120 分钟 |
| 核心机制 | 资源产出、自由交易、建设投资、 longest road / largest army 计分 |

**简介**：玩家在随机生成的岛屿上建立定居点与道路，通过掷骰产出五种资源（木、砖、羊、麦、矿），用于扩张建设。率先达到 10 分的玩家获胜。

**核心亮点**：
- **开放市场**：任何玩家可在任何时候向任何玩家提议资源交换
- **产量与概率绑定**：2d6 的分布让玩家 intuitively 理解「期望值」与「风险」
- **卡人策略**：故意不交易、封锁道路位置等间接竞争

**对商域的参考价值**：
- **自由市场的课堂**：卡坦岛的谈判桌本身就是供需关系的微观经济学实验室
- **资源稀缺性的动态平衡**：某种资源在某局可能极缺，玩家必须调整策略
- **概率教育的天然载体**：2d6 的概率分布可通过可视化呈现，非常适合教学场景

## 二、资源交易与建设

### 3. 电力公司 · Power Grid（原名 Funkenschlag）

| 项目 | 内容 |
|------|------|
| 设计师 | Friedemann Friese |
| 首发 | 2004 年（Rio Grande Games） |
| 人数 | 2–6 人 |
| 时长 | 90–120 分钟 |
| 核心机制 | 拍卖竞价、资源采购、城市网络建设、收益再投资 |

**简介**：玩家经营电力公司，通过拍卖获得发电厂，购买煤、石油、垃圾或铀等燃料，向城市供电获得收入，再用收入扩张网络。游戏分为三个阶段，地图逐步解锁。

**核心亮点**：
- **拍卖机制是价格发现的核心**：电厂的价值随游戏进程动态变化
- **资源市场的供需波动**：燃料是共享池，买的人多价格就涨
- **步速控制（Turn Order Catch-up）**：领先玩家后行动，形成天然平衡

**对商域的参考价值**：
- **「领先者劣势」的优雅设计**：不需要人工平衡，规则本身让落后者有追赶空间
- **多市场并行**：拍卖市场 + 资源市场 + 地产市场，三个子系统互相影响
- **阶段性解锁**：Phase 1→2→3 的难度递进，非常适合课程模块化设计

### 4. 工业革命：伯明翰 · Brass: Birmingham

| 项目 | 内容 |
|------|------|
| 设计师 | Martin Wallace |
| 首发 | 2018 年（Roxley Games，重制版） |
| 人数 | 2–4 人 |
| 时长 | 60–120 分钟 |
| 核心机制 | 手牌管理、网络建设、资源转化、贷款、市场消费 |

**简介**：玩家在工业革命时期的英国建设运河与铁路网络，开设煤矿、棉花厂、炼铁厂、啤酒厂等，生产货物满足市场需求，赚取收入与声望。

**核心亮点**：
- **贷款是双刃剑**：可提前借债扩张，但利息侵蚀利润
- **产业链上下游**：煤→铁→制造品， location 决定物流成本
- **市场饱和**：某个等级的货物一旦被消费完，相关产业立即贬值

**对商域的参考价值**：
- **供应链思维的可视化**：玩家必须理解「上游资源→中游生产→下游消费」的完整链条
- **资金时间价值的体验**：借债扩张 vs 保守经营的两种哲学直接对决
- **产业升级的历史感**：运河时代→铁路时代的切换，隐喻技术革命

## 三、股票、金融与市场投机

### 5. 并购 · Acquire

| 项目 | 内容 |
|------|------|
| 设计师 | Sid Sackson |
| 首发 | 1962 年（3M Bookshelf Games） |
| 人数 | 2–6 人 |
| 时长 | 60–90 分钟 |
| 核心机制 | 板块放置、公司创立、股票发行、并购套利、 majority / minority 股东分红 |

**简介**：玩家在 12×9 的网格上放置酒店板块，相邻板块合并成连锁酒店。玩家可以购买各连锁酒店的股票，当两家连锁合并时，持有被合并方股票的玩家获得分红。

**核心亮点**：
- **公司价值的动态形成**：公司大小由实际板块数量决定，非固定估值
- **并购套利的核心张力**：做大自己持股的公司，同时试图促成他人持股的公司被吞并
- ** majority / minority 分红差异**：大股东获得数倍于小股东的溢价

**对商域的参考价值**：
- **股票市场最纯粹的抽象模型**：没有复杂规则，只保留「投资→公司成长→并购→分红」的核心循环
- **信息不对称的简化版**：每位玩家知道自己的手牌（即将放置的板块），可预判合并时机
- **教学场景极佳**：可在 30 分钟内讲解完规则，让学生体验「股东权益」与「并购溢价」

### 6. 1830：铁路与资本大鳄 · 1830: Railways & Robber Barons

| 项目 | 内容 |
|------|------|
| 设计师 | Francis Tresham |
| 首发 | 1986 年（Avalon Hill） |
| 人数 | 2–7 人 |
| 时长 | 180–360 分钟 |
| 核心机制 | 股票发行、公司运营、分红/保留决策、铁路网络建设、市场做空 |

**简介**：18XX 系列的开山之作。玩家既是个人投资者，也是铁路公司的总裁。通过买卖股票、运营公司、决定分红或保留利润再投资，最终拥有最高净资产者获胜。

**核心亮点**：
- **双重角色**：个人投资者 vs 公司总裁，利益并不总一致
- **分红 vs 再投资的永恒 tension**：分红让股价上涨（个人获利），保留资金让公司扩张（长期价值）
- **股票破发与做空**：公司股价可跌至 0，市场机制允许真实的投机行为

**对商域的参考价值**：
- **公司治理的沙盘**：总裁由最大股东担任，小股东可以联手换帅
- **资本市场的完整闭环**：IPO→交易→分红→并购→破产，全部涵盖
- **长周期决策训练**：一局 4–6 小时，迫使玩家思考「三年后这家公司会在哪里」

### 7. 期货 · Pit

| 项目 | 内容 |
|------|------|
| 设计师 | Edgar Cayce |
| 首发 | 1903 年（Parker Brothers） |
| 人数 | 3–8 人 |
| 时长 | 30–60 分钟 |
| 核心机制 | 实时喊价、集合交易、 corner the market（垄断一种商品） |

**简介**：玩家手持 commodity 卡牌，通过大声喊价进行实时交易，目标是集齐同一种商品的 9 张卡牌（corner the market），或凑齐每种商品各 1 张（变体规则）。

**核心亮点**：
- **实时竞价的速度感**：没有回合制，所有人同时喊价
- **信息噪音**：市场上充满了假报价和试探性喊价
- **corner 的爽感**：集齐一手牌的瞬间类似于垄断市场

**对商域的参考价值**：
- **交易 floor 的极致简化**：可用于模拟期货交易大厅的混乱与机会
- **信息处理的训练**：在噪音中识别真实意图
- **可作为赛事暖场环节**：规则简单，5 分钟上手，气氛热烈

### 8. 股票囤积 · Stockpile

| 项目 | 内容 |
|------|------|
| 设计师 | Brett Sobol, Seth Van Orden |
| 首发 | 2015 年（Nauvoo Games） |
| 人数 | 2–5 人 |
| 时长 | 45–60 分钟 |
| 核心机制 | 封闭拍卖、不对称信息、内幕消息、股票涨跌 |

**简介**：玩家经营自己的股票投资组合。每回合会揭示一些「公开信息」和「内幕消息」影响股价，玩家通过拍卖获得股票卡牌，同时可以用行动卡操纵市场。

**核心亮点**：
- **信息不对称是核心乐趣**：部分玩家提前知道某只股票会涨/跌
- **拍卖中的博弈**：你知道内幕，但别人不知道你知道什么
- **简化的金融市场**：去掉了 18XX 的复杂度，保留了投机的快感

**对商域的参考价值**：
- **信息不对称的教学工具**：可设计为「部分玩家知道季度财报，部分不知道」
- **拍卖机制的多种变体**：盲拍、公开竞价、一口价等可混合使用
- **短时长高重玩**：45 分钟一局，非常适合课堂场景

## 四、企业经营与产业竞争

### 9. 快餐连锁大亨 · Food Chain Magnate

| 项目 | 内容 |
|------|------|
| 设计师 | Splotter Spellen（Jeroen Doumen, Joris Wiersinga） |
| 首发 | 2015 年 |
| 人数 | 2–5 人 |
| 时长 | 120–240 分钟 |
| 核心机制 | 招聘树、市场营销、供应链、价格竞争、需求地图 |

**简介**：玩家在 1950 年代的美国经营快餐连锁店。需要招聘员工（从CEO到物流员形成一个树状结构），生产食物，投放广告创造需求，设定价格，将食物送达有需求的居民区。

**核心亮点**：
- **招聘树是组织的抽象**：每个员工提供一项能力，位置决定汇报链
- **营销创造需求**：广告投入把「需求 token」放在地图上，没有需求就没有销售
- **价格战的零和博弈**：两家店覆盖同一个居民区时，低价者通吃

**对商域的参考价值**：
- **组织架构的可视化**：招聘树直接映射为公司的部门与职能
- **营销预算 vs 生产能力的平衡**：广告打太多供不上货 = 浪费；生产太多没广告 = 滞销
- **地段的极致重要性**：店铺位置几乎决定成败，与大富翁的「地段即价值」呼应

### 10. 看板：电动车 · Kanban EV

| 项目 | 内容 |
|------|------|
| 设计师 | Vital Lacerda |
| 首发 | 2020 年（Eagle-Gryphon Games） |
| 人数 | 2–4 人 |
| 时长 | 90–120 分钟 |
| 核心机制 | 工人放置、生产排程、需求满足、效率优化、老板检查 |

**简介**：玩家在丰田风格的汽车工厂中扮演生产线工程师，管理从设计到装配的完整流程，满足不断变化的市场订单，同时优化效率指标。

**核心亮点**：
- **「看板」机制**：生产线上的半成品必须按顺序流动，不能跳步
- **老板检查的压力**：桑德斯主席会定期检查各部门，表现不佳者扣绩效
- **需求卡的不确定性**：市场订单随机出现，玩家必须灵活调整生产计划

**对商域的参考价值**：
- **精益生产的游戏体验**： kanban、just-in-time、瓶颈管理全部融入机制
- **多目标优化的训练**：速度、质量、成本、库存，四者不可兼得
- **制造业管理的入门**：比纯理论课程更直观地理解运营管理

### 11. 奥地利大饭店 · Grand Austria Hotel

| 项目 | 内容 |
|------|------|
| 设计师 | Simone Luciani, Virginio Giglio |
| 首发 | 2015 年（Lookout Games） |
| 人数 | 2–4 人 |
| 时长 | 60–120 分钟 |
| 核心机制 | 骰子工放、客人入住、资源管理、声誉建设 |

**简介**：玩家在 20 世纪初的维也纳经营豪华酒店。通过骰子决定每回合可用的行动，接待皇帝、贵族、艺术家等客人，准备客房与餐饮，赚取金钱与声望。

**核心亮点**：
- **骰子即市场条件**：每回合的骰子分布决定了「哪些行动成本低」，模拟市场环境波动
- **客人需求的差异化**：不同客人需要不同的客房等级与配套服务
- **声誉的滚雪球**：高声誉吸引更多高端客人，形成正反馈

**对商域的参考价值**：
- **服务业的体验设计**：客人的「满意度」由多个触点共同决定
- **动态定价的雏形**：同一行动在不同骰子数量下成本不同，类似供需波动
- **品牌建设的游戏化**：声誉系统可直接映射为「品牌忠诚度」教学模块

## 五、物流、贸易与供应链

### 12. 集装箱 · Container

| 项目 | 内容 |
|------|------|
| 设计师 | Franz-Benno Delonge, Thomas Ewert |
| 首发 | 2007 年（Valley Games） |
| 人数 | 3–5 人 |
| 时长 | 60–90 分钟 |
| 核心机制 | 封闭经济、自我定价、生产-运输-消费闭环、无外部银行 |

**简介**：玩家在同一经济体中分别扮演生产者、运输商、消费者。所有交易在玩家之间进行，没有外部银行或无限货币。价格完全由玩家自行协商决定。

**核心亮点**：
- **封闭经济**：系统内的总金额恒定，一人之得必为另一人之失
- **自我定价**：同一批货，卖方开价多少完全自由，市场是否接受是另一回事
- **角色的互相依赖**：没有运输商，生产者的货无法到达消费者

**对商域的参考价值**：
- **供应链三方博弈的最简模型**：生产者、物流、零售的关系一目了然
- **价格由谁决定**：没有「正确价格」，只有「成交价格」
- **封闭经济系统的设计挑战**：非常适合用于理解 GDP 的循环流动

### 13. 巴拿马运河 · Panamax

| 项目 | 内容 |
|------|------|
| 设计师 | Gil d'Orey, Paulo Soledade |
| 首发 | 2014 年（Stronghold Games） |
| 人数 | 1–4 人 |
| 时长 | 90–120 分钟 |
| 核心机制 | 船运调度、股份公司、货运合同、运河通行费、物流优化 |

**简介**：玩家经营航运公司，通过巴拿马运河运输货物。需要管理船队、签订货运合同、安排通过运河的时序（运河容量有限），同时可以投资运河本身的股份获取分红。

**核心亮点**：
- **基础设施的公共品属性**：运河是所有玩家共享的瓶颈资源
- **调度 puzzle**：如何安排船只顺序以最大化自己的货运效率
- **公司运营 + 基础设施投资的双重身份**：与 18XX 类似，但更简单

**对商域的参考价值**：
- **瓶颈资源的管理**：运河容量限制是「约束理论」的完美隐喻
- **公地悲剧的游戏化**：每个人都想让船先过，但顺序需要协商
- **多式联运的简化版**：海运 + 陆运 + 仓储的组合优化

## 六、拍卖与价格发现

### 14. 现代艺术 · Modern Art

| 项目 | 内容 |
|------|------|
| 设计师 | Reiner Knizia |
| 首发 | 1992 年（Hans im Glück） |
| 人数 | 3–5 人 |
| 时长 | 45–60 分钟 |
| 核心机制 | 多种拍卖形式、价格信号、市场操纵、艺术品投机 |

**简介**：玩家扮演画廊老板，通过五种不同的拍卖机制（公开增价、密封出价、一口价等）买卖画作。每轮结束时，在当轮售出最多的画家作品会升值，其他的贬值。

**核心亮点**：
- **五种拍卖机制合一**：规则书即拍卖理论入门教材
- **价格即信号**：你以高价买入某位画家，就是在向市场释放「这个画家值得投资」的信号
- **自我实现的泡沫**：如果所有人都相信某画家会涨，集体买入确实会让他涨

**对商域的参考价值**：
- **拍卖机制的百科全书**：公开拍卖、盲拍、Vickrey 拍卖等一网打尽
- **市场心理的可视化**：泡沫的形成与破裂可在 45 分钟内完整体验
- **信号传递理论**：价格不只是交易结果，更是信息载体

### 15. 太阳神 · Ra

| 项目 | 内容 |
|------|------|
| 设计师 | Reiner Knizia |
| 首发 | 1999 年（Hans im Glück） |
| 人数 | 2–5 人 |
| 时长 | 45–60 分钟 |
| 核心机制 | 瓷砖抽取、 Sun tile 拍卖、风险累积、时机抉择 |

**简介**：玩家通过消耗 Sun tiles（有限的竞价货币）拍卖各种埃及主题瓷砖。中央市场不断累积瓷砖，何时触发拍卖、花多少 Sun tile 出价，是核心决策。

**核心亮点**：
- **货币总量固定且递减**：花掉的 Sun tile 会进入拍卖所得，货币供应严格受限
- **风险累积**：市场瓷砖越积越多，但触发拍卖的时机由玩家控制
- **评估能力的差异**：同一批瓷砖对不同玩家的价值完全不同

**对商域的参考价值**：
- **固定货币供应的通缩体验**：Sun tile 越用越少，必须精算每一手的价值
- **拍卖时机的策略深度**：「现在拍」还是「再等等」是永恒的 tension
- **异质估值的教学工具**：同样的资源，因玩家的组合目标不同而有不同价值

## 七、财商教育专用

### 16. 现金流 · Cashflow（富爸爸系列）

| 项目 | 内容 |
|------|------|
| 设计师 | Robert Kiyosaki, Sharon Lechter |
| 首发 | 1996 年（Rich Dad Co.） |
| 人数 | 2–6 人 |
| 时长 | 60–180 分钟 |
| 核心机制 | 收支循环、资产负债表、被动收入、 rat race / fast track 两阶段 |

**简介**：玩家从「老鼠赛跑」（rat race）开始——工资收入减去支出，剩余投入资产。当被动收入超过总支出时，进入「快车道」（fast track），追求财务自由目标。

**核心亮点**：
- **财务报表即手牌**：每位玩家的收入和支出明细就是一张简化资产负债表
- **资产 vs 负债的重新定义**：Kiyosaki 式的定义（让钱流入口袋的是资产，流出的是负债）
- **两阶段目标清晰**：先逃离 rat race，再在 fast track 完成梦想

**对商域的参考价值**：
- **个人财务管理的游戏化标杆**：资产负债表、现金流、投资回报率全部融入
- **教育属性强于竞技属性**：胜负不是核心，理解财务概念才是
- **可直接作为教学模块**：rat race 的循环机制非常适合做成数字化模拟

## 八、设计启示汇总

### 8.1 经济模型维度

| 维度 | 代表作品 | 教学应用 |
|------|----------|----------|
| **供需关系** | Catan、Power Grid、Container | 自由市场定价、资源稀缺性 |
| **资产配置** | Monopoly、Acquire | 地段价值、投资组合、股东权益 |
| **公司治理** | 1830、Brass | 分红政策、总裁选举、利益冲突 |
| **供应链管理** | Brass、Kanban EV、Container | 上下游依赖、库存管理、瓶颈理论 |
| **金融市场** | 1830、Stockpile、Pit | 股票交易、信息不对称、投机行为 |
| **拍卖理论** | Modern Art、Ra、Power Grid | 价格发现、竞价策略、市场信号 |
| **财务素养** | Cashflow、Monopoly | 收支平衡、资产增值、被动收入 |

### 8.2 机制设计模式

| 模式 | 说明 | 来源 |
|------|------|------|
| **开放市场** | 玩家之间自由议价交易 | Catan、Container、Pit |
| **封闭经济** | 系统内货币/资源总量恒定 | Container、Ra |
| **步速平衡** | 领先者获得劣势（后行动、高成本） | Power Grid |
| **多市场并行** | 拍卖市场 + 商品市场 + 股票市场同时运行 | 1830、Power Grid |
| **双重角色** | 玩家同时是个人和公司决策者 | 1830、Brass |
| **信息层级** | 公开 / 半公开 / 私密信息分层 | Stockpile、Acquire |
| **阶段解锁** | 游戏分阶段开放新规则/新地图 | Power Grid、Brass |
| **软淘汰** | 落后者仍可参与直至终局 | 现代 Eurogame 通用 |

### 8.3 对商域平台的直接建议

1. **谈判系统必须存在**：Catan 和 Container 证明，纯 AI 计算无法替代玩家间的人际交易
2. **概率可视化**：2d6 的产出分布、股票价格走势图，应将「隐性概率」转为「显性信息」
3. **多重子市场**：同时运行 2–3 个市场（如资源市场 + 股票市场），比单一市场更有深度
4. **领先者制衡**：参考 Power Grid 的「步速平衡」，避免马太效应摧毁落后者体验
5. **短时长优先**：课堂场景下，45–60 分钟的完整体验优于 4 小时的深度模拟
6. **财务报表透明**：Cashflow 的做法——每位玩家的资产/负债/现金流实时可见——是财商教育的核心
7. **角色差异化**：不同玩家获得不同信息或能力，创造博弈空间（参考 Stockpile 的内幕消息）
