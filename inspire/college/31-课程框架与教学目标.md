# 01 - 课程框架与教学目标

> 搭建课程体系的地基。定义"我们要培养什么样的人"，然后推导出"我们要设计什么样的课程"。

---

## 一、总体定位

### 1.1 课程性质

本课程体系是**面向基础教育与职业教育的商业素养通识课程**，以商业模拟平台为核心教学工具，采用"体验先行、概念锚定、迁移应用"的教学模式。

**不是**：
- 不是商学院专业课（不需要高等数学基础）
- 不是创业培训课（不教注册公司、写BP）
- 不是游戏课（不以娱乐为首要目标）

**是**：
- 是面向未来公民的**商业思维启蒙**
- 是连接抽象概念与具体决策的**体验桥梁**
- 是培养理性决策、协作沟通、风险意识的**素养课程**

### 1.2 适用对象

| 学段 | 年级 | 课程定位 | 每学段课时 |
|------|------|----------|-----------|
| 小学高段 | 五-六年级 | 兴趣启蒙课 / 社团课 | 16-20课时 |
| 初中 | 七-九年级 | 综合实践课 / 选修课 | 24-32课时 |
| 高中 | 高一-高三 | 选修课 / 社团课 / 竞赛预备 | 32-48课时 |
| 大学/职校 | 大一-大三 / 职校全段 | 通识课 / 商科基础课 / 创业教育 | 32-64课时 |

## 二、核心素养模型（5维20项）

```
商业素养
│
├── 财务素养
│   ├── FL-1 成本意识：理解"做任何事都有代价"
│   ├── FL-2 收入逻辑：理解"价值创造是收入的前提"
│   ├── FL-3 利润思维：理解"收入-成本=利润"及其局限性
│   ├── FL-4 时间价值：理解"今天的钱比明天的钱更有价值"
│   └── FL-5 风险回报：理解"高收益通常伴随高风险"
│
├── 市场素养
│   ├── ML-1 供需直觉：理解"价格由供需关系决定"
│   ├── ML-2 消费者视角：理解"产品价值由消费者定义"
│   ├── ML-3 竞争意识：理解"差异化是应对竞争的手段"
│   ├── ML-4 定价逻辑：理解"定价不是成本加利润"
│   └── ML-5 市场细分：理解"不同人群有不同需求"
│
├── 战略素养
│   ├── SL-1 目标导向：理解"战略是选择不做什么"
│   ├── SL-2 资源配置：理解"有限资源下的优先级排序"
│   ├── SL-3 长期思维：理解"短期牺牲可能换来长期收益"
│   ├── SL-4 信息决策：理解"决策质量取决于信息质量"
│   └── SL-5 适应变化：理解"计划需要随环境调整"
│
├── 协作素养
│   ├── CL-1 角色认知：理解"团队中不同角色的价值"
│   ├── CL-2 沟通协商：理解"有效沟通需要倾听和表达"
│   ├── CL-3 共同决策：理解"集体决策的利弊"
│   └── CL-4 冲突处理：理解"冲突可以是建设性的"
│
└── 伦理素养
    ├── EL-1 公平竞争：理解"规则意识是商业的基石"
    ├── EL-2 利益相关者：理解"决策影响多方利益"
    ├── EL-3 社会责任：理解"企业是社会的一部分"
    └── EL-4 可持续思维：理解"长期生存需要环境友好"
```

## 三、四阶递进框架

### 3.1 进阶逻辑

```
认知复杂度
    ▲
    │                         第四阶
    │                    系统思维 / 宏观视角
    │                    多变量交互 / 长期战略
    │               第三阶
    │          策略思维 / 竞争意识
    │          多轮博弈 / 风险权衡
    │     第二阶
    │  抽象思维 / 概念连接
    │  简单模型 / 团队协作
    │第一阶
    │具象思维 / 生活连接
    │简单规则 / 个人操作
    └────────────────────────────────►
         小学高段    初中      高中      大学
```

### 3.2 每阶核心能力目标

| 维度 | 第一阶（小学高段） | 第二阶（初中） | 第三阶（高中） | 第四阶（大学/职校） |
|------|-------------------|---------------|---------------|-------------------|
| **财务素养** | 认识钱的来源与去向 | 理解成本结构和利润计算 | 分析财务报表，计算ROI | 理解估值、融资、现金流管理 |
| **市场素养** | 感受"有人买才有人卖" | 分析供需变化和价格弹性 | 运用市场细分和定位策略 | 设计市场进入策略，分析竞争格局 |
| **战略素养** | 体验"选择"的意义 | 制定简单计划并执行 | 多轮战略调整，应对不确定性 | 系统战略规划，资源优化配置 |
| **协作素养** | 在引导下完成团队任务 | 主动分工协商 | 处理团队冲突，领导与跟随 | 跨团队协作，利益相关者管理 |
| **伦理素养** | 认识公平与规则 | 讨论诚信与后果 | 分析商业伦理两难 | 评估企业社会责任策略 |

## 四、评估体系

### 4.1 三维评估模型

不唯分数，而是从**知识、能力、态度**三个维度评估：

```
评估维度
├── 知识维度（30%）
│   ├── 概念理解：能否正确解释商业概念
│   └── 知识迁移：能否在新情境中识别概念
│
├── 能力维度（50%）
│   ├── 决策质量：模拟中的策略是否合理
│   ├── 数据分析：能否从数据中提取洞察
│   ├── 沟通表达：能否清晰阐述决策理由
│   └── 团队协作：团队角色履行情况
│
└── 态度维度（20%）
    ├── 参与度：投入时间和精力的程度
    ├── 开放性：是否愿意尝试新策略
    ├── 反思性：是否能从失败中学习
    └── 规则意识：是否遵守游戏规则
```

### 4.2 评估工具箱

| 工具 | 用途 | 数据来源 |
|------|------|----------|
| **平台自动报告** | 决策轨迹、排名变化、属性成长 | 模拟引擎结算数据 |
| **决策理由评分** | 评估逻辑思维和概念应用 | 学生提交的回合宣言 |
| **同伴互评** | 团队协作、贡献度评估 | 组员互评问卷 |
| **概念测验** | 知识掌握度 | 课后5题快速测验 |
| **反思日志** | 态度和学习深度 | 学生书面/语音反思 |
| **教师观察表** | 参与度、沟通能力 | 课堂观察记录 |

### 4.3 徽章与等级对应

| 等级 | 获得条件 | 对应素养水平 |
|------|----------|-------------|
| **铜章** | 完成单元全部环节 | 基础参与，初步体验 |
| **银章** | 测验得分≥70% + 决策理由合格 | 概念理解，能解释自己的行为 |
| **金章** | 测验得分≥85% + 对局前30% + 优秀反思 | 概念应用，能策略性思考 |
| **钻石章** | 全部金章 + 帮助其他学生学习 + 创新策略 | 概念精通，能教别人 |

## 六、课程实施的关键原则

### 6.1 "70-20-10"时间分配

```
每课时（45分钟）的推荐分配：

70% 学生主导（体验、讨论、决策）
    ├── 平台模拟体验
    ├── 小组讨论
    └── 决策与操作

20% 师生互动（引导、反馈、讲解）
    ├── 教师点评
    ├── 概念命名
    └── 问答澄清

10% 知识传递（微课、阅读）
    ├── 概念微课
    └── 案例阅读
```

### 6.2 最小可行课堂（MVC）

如果条件受限，一个**最简有效**的商业模拟课堂需要：

| 条件 | 最低要求 |
|------|----------|
| 时间 | 40分钟 × 4次（完成一个基础单元） |
| 设备 | 学生每人一部手机/平板 + 教室投影 |
| 网络 | 教室WiFi |
| 教师 | 完成平台基础培训（2小时） |
| 学生 | 2人一组（最低可单人） |

### 6.3 差异化教学策略

| 学生类型 | 支持策略 |
|----------|----------|
| **学习困难者** | 提供更多提示、简化规则模板、允许观看示范 |
| **能力超前者** | 挑战模式、导师角色、帮助其他同学 |
| **内向学生** | 书面决策理由权重增加、可选非发言角色 |
| **竞争焦虑者** | 默认显示"进步排名"、强调合作目标 |
| **数学恐惧者** | 隐藏公式、强调直觉和图形化呈现 |

## 七、课程质量保障

### 7.1 内容审查清单

每个新单元上线前必须通过：

- [ ] 概念准确性：经济学/商业概念经专业教师审核
- [ ] 年龄适配性：语言、案例、复杂度符合目标学段
- [ ] 平台可实现性：有对应的规则模板和功能支持
- [ ] 教学完整性：有明确的教学目标、活动流程、评估方式
- [ ] 价值观审查：传递积极、包容、负责任的商业观
- [ ] 文化敏感性：案例和情境尊重多元文化背景

### 7.2 迭代机制

```
每学期
├── 收集反馈（教师问卷 + 学生问卷 + 平台行为数据）
├── 分析数据（完成率、测验正确率、NPS）
├── 识别问题（哪些单元太难？哪些概念没讲清？）
├── 优化内容（修订微课、调整规则参数、补充案例）
└── 更新版本（单元版本号 + 更新日志）
```

---

> **核心原则**：课程设计的终点不是"学生知道了什么"，而是"学生能做什么、愿意做什么、相信自己能做成什么"。
