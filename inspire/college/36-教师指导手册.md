# 06 - 教师指导手册

> 技术平台和课程内容只是工具。最终决定教学效果的，是站在教室里的那位教师。本手册不是"使用说明书"，而是"课堂教练指南"。

---

## 一、教师角色定位

### 1.1 你不是"讲解员"，而是"教练"

| 讲解员 | 教练 |
|--------|------|
| 告诉学生正确答案 | 帮助学生发现自己答案中的逻辑 |
| 评判对错 | 引导反思 |
| 控制课堂节奏 | 根据学生状态灵活调整 |
| 知识传递者 | 学习体验设计者 |

**核心转变**：从"我教了什么"转变为"学生体验了什么、发现了什么"。

### 1.2 三种教师类型

| 类型 | 特征 | 适合场景 |
|------|------|----------|
| **引导型** | 善于提问、营造讨论氛围 | 概念探索、复盘环节 |
| **技术型** | 熟悉平台操作、数据分析 | 模拟体验、报告解读 |
| **故事型** | 善于案例讲述、情境构建 | 导入环节、概念锚定 |

**建议**：根据单元类型选择主导风格，但三种能力都应具备。

## 二、课前准备清单

### 2.1 技术准备（课前24小时）

- [ ] 测试平台登录（教师端 + 学生端）
- [ ] 创建班级/房间，设置正确的规则模板
- [ ] 导入学生名单或确认班级码有效
- [ ] 测试大屏投影 / 屏幕共享
- [ ] 准备备用方案（如网络故障时的纸质版）

### 2.2 教学准备（课前1小时）

- [ ] 复习本单元教学目标和关键概念
- [ ] 准备 2-3 个"追问问题"（用于学生回答后的深度引导）
- [ ] 预判学生可能的困惑点，准备解释话术
- [ ] 确认时间分配（建议用计时器）

### 2.3 心态准备

- [ ] 接受"不确定性"：模拟结果不可预测，正是教学价值所在
- [ ] 接受"沉默"：学生思考时需要时间，不要急于填补沉默
- [ ] 接受"错误"：学生的错误决策是最佳教学素材

## 三、课堂流程控制

### 3.1 标准课堂时间轴（45分钟）

```
00:00-00:05  导入（5分钟）
  └── 用一个案例/问题/视频抓住注意力
  └── 明确本节课的学习目标

00:05-00:10  规则说明（5分钟）
  └── 简要说明本轮模拟的特殊规则
  └── 强调：规则不是限制，是游戏的一部分

00:10-00:30  模拟体验（20分钟）
  └── 学生操作平台，教师巡视
  └── 观察：谁在主导？谁在沉默？谁有困惑？

00:30-00:38  结算与初步反馈（8分钟）
  └── 执行结算，展示结果
  └── 先不给结论，让学生自己观察

00:38-00:45  复盘与概念锚定（7分钟）
  └── 提问："你们发现了什么？"
  └── 将学生发现与商业概念连接
```

### 3.2 控场技巧

#### 当学生过于兴奋时
- **现象**：大声争论、试图偷看对手屏幕
- **应对**："我注意到大家很投入——这正是商业决策时的压力。让我们把这种能量转化为更清晰的思考。"
- **技术**：倒计时最后 30 秒播放轻柔提示音

#### 当学生过于沉默时
- **现象**：无人讨论、等待别人决策
- **应对**："每个角色都有独特的信息，不说话团队就会失去你的视角。CEO，你特别想听听 CFO 的意见。"
- **技术**：设置"每个人必须在聊天框输入一个想法才能提交"

#### 当学生抱怨"不公平"时
- **现象**："他们运气好""规则对我不利"
- **应对**："商业世界本来就不公平。但长期看，运气平均化，策略浮现。让我们看看 3 轮后的结果。"
- **教学转化**：这正是教授"风险"和"样本量"概念的机会

#### 当学生连续失败时
- **现象**：情绪低落、想放弃
- **应对**：私下鼓励 + 公开寻找其决策中的亮点
- **话术**："你这一轮虽然在排名上落后，但你的 Fit 投入策略让南京用户满意度最高——这是很多队伍忽略的。"

## 四、复盘引导话术库

### 4.1 通用复盘问题

| 时机 | 问题 | 目标 |
|------|------|------|
| 结算后 | "第一名的队伍，你们做对了什么？" | 让胜者反思成功因素 |
| 结算后 | "排名靠后的队伍，如果重来你们会改变哪个决策？" | 将失败转化为学习 |
| 结算后 | "有没有哪个结果出乎你们的预料？为什么？" | 挑战认知偏差 |
| 概念讲解前 | "你们刚才的行为，经济学家会给它起什么名字？" | 让学生主动建构概念 |
| 概念讲解后 | "这个概念在你们刚才的模拟中体现在哪里？" | 连接体验与理论 |

### 4.2 针对不同单元的引导重点

| 单元类型 | 引导重点 | 典型问题 |
|----------|----------|----------|
| 财商启蒙 | 成本意识 | "你们的钱花在了哪里？哪些钱花得值，哪些不值？" |
| 供需关系 | 市场响应 | "如果天气变了，你们为什么没有调整产量？" |
| 团队协作 | 决策过程 | "你们团队的意见一开始一致吗？最后怎么达成一致的？" |
| 博弈论 | 策略互动 | "你们考虑了对手会怎么做吗？对手实际怎么做的？" |
| 风险管理 | 不确定性 | "你们的选择是在赌运气，还是在管理风险？" |
| 伦理决策 | 价值冲突 | "短期利润和长期信任，你们怎么权衡的？" |

## 五、常见技术问题处理

### 5.1 平台问题

| 问题 | 快速解决 | 备用方案 |
|------|----------|----------|
| 学生无法登录 | 检查班级码、网络连接 | 让同组同学共享屏幕操作 |
| 结算卡住 | 刷新页面，教师端重新执行结算 | 口述结果，手动更新数据 |
| 提交失败 | 检查是否超时，允许补提交 | 用纸质表单收集决策 |
| 大屏不显示 | 检查投影连接、浏览器缩放 | 教师口述关键数据 |

### 5.2 课堂突发状况

| 状况 | 应对策略 |
|------|----------|
| 网络全校中断 | 切换到"桌面推演"模式：用纸笔模拟一轮 |
| 学生设备不足 | 2-3人共用一台，强化讨论 |
| 学生因排名争吵 | 暂停模拟，进行5分钟"情绪冷却"讨论 |
| 有学生完全不懂 | 安排该学生担任"观察员"，记录团队决策过程 |

## 六、评价与反馈

### 6.1 如何写有效的学生评语

**避免**："表现不错""需要努力"（过于笼统）

**建议**：
- 描述具体行为："你在 R3 选择从 TECH 切换到 USER 路线，这个决策体现了对事件变化的敏感"
- 连接商业概念："你的预算分配接近'成本领先'战略"
- 提出成长方向："下一步可以尝试关注对手的路线选择，提前预判"

### 6.2 如何组织同伴互评

```
互评流程：
1. 每个团队向另一团队展示复盘（3分钟）
2. 听评团队提出 1 个问题和 1 个赞赏（2分钟）
3. 被评团队回应（1分钟）
4. 轮换
```

**互评问题模板**：
- "你们团队最聪明的决策是什么？"
- "如果你们有额外 10 万预算，会投在哪里？"
- "你们认为对手最可能改进什么？"

## 七、教师成长路径

### 7.1 新手教师（第1学期）

- 目标：熟练操作平台，完成标准课堂流程
- 支持：平台培训视频、标准化教案、在线答疑群
- 建议：先从小班（20人以下）开始

### 7.2 熟练教师（第2-3学期）

- 目标：灵活调整规则，根据学生状态即兴发挥
- 支持：进阶培训（博弈论、系统动力学基础）、教师社区
- 建议：开始尝试自定义规则模板

### 7.3 专家教师（第4学期+）

- 目标：设计原创课程单元，指导其他教师
- 支持：课程设计认证、全国教师社群、年度教师大会
- 建议：投稿分享自己的教学案例
