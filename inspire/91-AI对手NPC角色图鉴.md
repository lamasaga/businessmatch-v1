# 首期角色（Phase B1）

## 01 陈叙 CHEN XU

> **"我做的是水渠，不是洪水。洪水来钱快，但水渠能流三十年。"**

| 属性 | 内容 |
|------|------|
| 年龄 | 42 岁 |
| 性别 | 男 |
| 代表城市 | 蓉城 |
| 默认策略 | **conservative**（保守型） |
| 原型 | 供应链老兵 / 冷链物流老板 |

### 人物小传

陈叙在蓉城白家批发市场长大，父亲是做冻品批发的个体户。他 18 岁跟车跑过川藏线，26 岁拥有自己的第一台冷链车，35 岁成立了"叙物流"——一个只有 17 辆车、但准时率达到 99.3% 的小型冷链公司。

他不是那种会上商业杂志的人。他的核心竞争力极度无聊：他知道蓉城每个农批市场的开市时间，知道哪条高速在雨季会塌方，知道哪个冷库管理员会偷偷调温。他的手机相册里没有游艇和峰会，只有各种路况照片和货车里程表。

2019 年他曾差点破产。一个连锁火锅品牌的账期从 30 天拖到 120 天，他现金流断裂，抵押了房子。那次之后他定下铁律：现金储备永远不低于 6 个月运营费，任何客户的账期超过 45 天直接断供。这条铁律让他错过了两次扩张机会，也让他在 2022 年行业大洗牌时活了下来。

他对手底下的年轻司机有种奇怪的保护欲，会为了 200 块运费差额跟货主吵半小时，但每年年会都给每个人手写一张卡片。

### 商业风格

- **核心逻辑**：现金流第一，利润第二，规模第三。
- **打法特征**：从不 All-in，每局保留大量现金；低价只买熟悉品类（生鲜、冻品）；极少跨城冒险，但一旦锁定路线会反复跑。
- **对学生的态度**：像对待自家学徒。你亏了他会冷嘲热讽，但你如果按照他的思路赚了他会别扭地夸一句"还行"。

### 口头禅

- "账算清楚之前，别谈格局。"
- "这价格你也敢进？我 2008 年都不敢。"
- "（沉默三秒）……算了，年轻人总要交点学费。"

### 缺陷

极度抠门。即使赚了大钱也舍不得升级车辆，坚持认为"老车省油"。

### 成长轨迹

| 阶段 | 变化 |
|------|------|
| Novice | 标准保守参数，偶尔会因为"教你怎么算"而慢半拍 |
| Developing | 开始记住你的惯用路线，会在你常跑的路上提前囤货抬价 |
| Mature | 形成"针对型保守"——对你激进，对别人照旧稳健 |
| Legend | 故意卖你一个破绽，看你敢不敢捡 |

### YAML 策略

```yaml
ai_strategies:
  chen_xu:
    name: 陈叙·稳健流
    behavior:
      type: conservative
      params:
        max_single_trade_ratio: 0.06
        cash_reserve_ratio: 0.55
        min_profit_margin: 0.22
        target_products: [grain, produce, raw_materials]
```

## 02 林锐 LIN RUI

> **"市场错价存在的平均时间是 14 秒。我能在第 3 秒发现，第 7 秒下单，第 12 秒平仓。你？你还没刷新页面。"**

| 属性 | 内容 |
|------|------|
| 年龄 | 29 岁 |
| 性别 | 女 |
| 代表城市 | 沪市 |
| 默认策略 | **arbitrageur**（套利型） |
| 原型 | 高频量化交易员 / 前投行衍生品组 |

### 人物小传

林锐本科是复旦数学系，研究生转去读了金融工程。她的第一份工作是在某头部券商的衍生品 desk，负责商品期货的跨期套利。她的 KPI 是每天找到 20 个 basis 异常并执行，平均持仓时间 4.7 分钟。

她在那家公司干了 3 年，离开时带着两个东西：一套自己写的 Python 套利扫描脚本，和对"基本面分析"的永久性鄙视。"看财报做商品？"她会说，"那你不如看星盘。"

2022 年她辞职做独立 trader，在一套月租 6800 的公寓里架了 6 块屏幕。她的生活极度单调：早上 6 点起床看夜盘，下午 3 点国内收盘后去打拳击，晚上 9 点继续看美盘。她的朋友圈半年更新一次，每次都是因为某次套利成功发了张截图（故意把收益率截掉，只留交易时间戳）。

她说话很快，带一点不耐烦。不是故意 rude，是真的觉得大多数人思考速度太慢。但如果你能在她还没说完之前就接住她的逻辑，她的眼神会亮一下。

### 商业风格

- **核心逻辑**：价格永远是对的，但不同市场的价格同时正确且互斥。
- **打法特征**：全图扫描价差，只买最低价城市、只卖最高价城市；持仓时间极短，一轮内完成买→移→卖；几乎不持有库存过夜。
- **对学生的态度**：竞争式。她尊重聪明人，鄙视犹豫的人。你慢了她会叹气，你快了她会皱眉然后嘴角微翘。

### 口头禅

- "这个 spread 我奶奶都看得出来。"
- "你在等什么？等它涨到你心理舒适区？"
- "（赢了一局后）……还行。不过第 3 轮你那个犹豫，要是在实盘里已经爆仓了。"

### 缺陷

没有长期思维。遇到需要持仓等待的行情会焦躁，容易在趋势行情中踏空。

### 成长轨迹

| 阶段 | 变化 |
|------|------|
| Novice | 标准套利参数，偶尔会因为"spread 不够大"而 hold |
| Developing | 开始预判你的移动方向，提前在你目的地建仓 |
| Mature | 引入假动作：故意在某个城市挂高价诱使你过去，然后反向操作 |
| Legend | 同一轮内同时赚你买卖两边的钱 |

### YAML 策略

```yaml
ai_strategies:
  lin_rui:
    name: 林锐·套利流
    behavior:
      type: arbitrage
      params:
        min_spread_ratio: 0.12
        max_inventory_ratio: 0.15
        risk_appetite: 0.85
```

## 03 苏慢 SU MAN

> **"我不是在买商品，我是在买时间。时间比钱贵，但大多数人不知道。"**

| 属性 | 内容 |
|------|------|
| 年龄 | 34 岁 |
| 性别 | 女 |
| 代表城市 | 深市 |
| 默认策略 | **hoarder**（囤积型） |
| 原型 | 跨境电商买手 / 前亚马逊大卖操盘手 |

### 人物小传

苏慢的名字是她爷爷取的，取"慢工出细活"。她爷爷是深圳第一批做来料加工的厂长。她本人却一点不像名字——她说话快、走路快、刷 TikTok 都是 2 倍速。

但她在一件事上真的慢：建仓。

她在华强北做过三年手机配件，在坂田做过两年跨境电商，然后自己出来做独立站。她的核心竞争力不是流量（她承认自己的 Facebook 广告打得一般），而是库存管理。她能在双十一前三个月就开始囤某款电子配件，在竞品断货时从容加价 40% 出售。

她的仓库有 800 平米，她自己写了一套 Excel+Python 的库存预测模型，准确率在她自己定义的"可用范围"内。她有个习惯：每次大促结束后会写一篇复盘，但不发，存在本地。"写给自己看的，发出去就成了表演。"

她离婚过一次，没有孩子。她的微信置顶是一个叫"慢下来"的群，里面只有她自己，用来发每天学到的碎片知识。

### 商业风格

- **核心逻辑**：提前 3-5 轮布局，等别人断货时收割。
- **打法特征**：早期大量低价吃进目标商品，忍受多轮账面亏损；中后期一次性高价抛售；极少移动，"坐城待涨"。
- **对学生的态度**：导师式，但带一点傲娇。她愿意分享逻辑，但会强调"你做不到是因为你没有耐心，不是因为你没看懂"。

### 口头禅

- "这价格我三个月前就在等了。"
- "你卖是因为你慌了，不是因为它该卖。"
- "（你跟着她囤了一轮后）……挺有眼光的。不过下次别告诉我，会影响我的价格。"

### 缺陷

过度自信自己的预测。遇到突发事件（如随机事件大幅增产）会死扛，导致库存暴跌。

### 成长轨迹

| 阶段 | 变化 |
|------|------|
| Novice | 标准囤积参数，容易被突发增产事件打崩 |
| Developing | 开始分散囤积品类，不再 single-product bet |
| Mature | 学会对冲式囤积：同时囤互补品和替代品 |
| Legend | 故意让你以为她在囤 A，实际她在等 A 崩盘后抄底 B |

### YAML 策略

```yaml
ai_strategies:
  su_man:
    name: 苏慢·囤积流
    behavior:
      type: value_hoarding
      params:
        buy_threshold: 0.82
        sell_threshold: 1.40
        target_products: [appliances, passenger_car, luxury]
        max_single_buy_ratio: 0.30
```

## 04 赵焰 ZHAO YAN

> **"数据不会说谎，但数据会说你想听的话。我做的事是：让数据说我想让它说的话，然后让它成真。"**

| 属性 | 内容 |
|------|------|
| 年龄 | 26 岁 |
| 性别 | 男 |
| 代表城市 | 深市 |
| 默认策略 | **momentum**（趋势型） |
| 原型 | 直播电商操盘手 / 抖音本地生活服务商 |

### 人物小传

赵焰是 Z 世代商业动物的代表。他大学学的是体育教育（因为他爸是中学体育老师，"毕业有编制"），大二开始拍短视频，大三成了某零食品牌的校园代理，大四退学全职做直播电商。

他的第一个爆款是一场 4 小时的"仓库清仓直播"，GMV 47 万，佣金 8 万。他当晚请团队吃了顿海底捞，然后在账本上记下"第 0 天"。

他的打法极度趋势驱动。他能从抖音热榜第 17 位的关键词里嗅出三天后的爆款，能从某个三线城市奶茶店的排队长度推算出下个月全国的杯子缺货。他的团队有 3 个人：他自己负责看数据和开播，一个表哥负责对接供应链，一个 AI 脚本负责自动生成直播话术。

他的办公室（其实是一间 60 平的出租屋）墙上贴着一句话："情绪是最大的生产力。"

他有时候会让人不舒服——太急于验证自己的想法，太习惯用数据碾压别人的直觉。但如果你问他对某件商品的看法，他会说"我不知道，但我可以测出来"，然后真的去测。

### 商业风格

- **核心逻辑**：价格趋势一旦形成，就有惯性。在惯性的前半段上车，后半段下车。
- **打法特征**：紧密跟踪价格变化，追涨杀跌；对突发事件的反应极快；喜欢 all-in 热门品类。
- **对学生的态度**：竞争式+好奇。他喜欢和聪明人过招，输了会认真复盘，赢了会发朋友圈（把你名字打码）。

### 口头禅

- "这个品类在抖音上已经爆了，你还在看财报？"
- "我跟你说，下一轮的 wind 在这里。"
- "（输了一局后）……有意思。加个微信？我想看看你后台数据。"

### 缺陷

没有基本面分析能力。趋势反转时往往是最晚离场的人，一次大亏可以抹去十次小赚。

### 成长轨迹

| 阶段 | 变化 |
|------|------|
| Novice | 标准趋势参数，追涨杀跌但反应慢半拍 |
| Developing | 开始用假趋势诱导你跟风，然后反向收割 |
| Mature | 引入情绪指标：不仅看价格趋势，还看其他 AI 的行为模式 |
| Legend | 通过大额交易主动制造趋势，然后引导全场 |

### YAML 策略

```yaml
ai_strategies:
  zhao_yan:
    name: 赵焰·趋势流
    behavior:
      type: momentum
      params:
        trend_window: 2
        momentum_threshold: 0.06
        contrarian: false
```

## 05 王可 WANG KE

> **"我不是在交易，我是在玩。你们把输赢看得太重了，重到看不见游戏本身。"**

| 属性 | 内容 |
|------|------|
| 年龄 | 23 岁 |
| 性别 | 非二元（they/them） |
| 代表城市 | 港城 |
| 默认策略 | **random**（混乱型） |
| 原型 | NFT 交易员 / 数字游民 / 前游戏公会会长 |

### 人物小传

王可不会告诉你他们的真名。他们在 Discord 上的 ID 是"WangWasHere"，在 Twitter 上是"@probably_wang"，在 LinkedIn 上根本没有账号。

他们在港城出生，在英国读了两年艺术史后退学，然后在东南亚漂了三年。他们的"商业经验"包括：组织过 2000 人的游戏公会、倒卖过球鞋、炒过 NFT、在清迈开过一个月就倒闭的咖啡馆。每一段的结束原因都一样："不好玩了。"

他们来商域平台的原因是："听说这里的 AI 挺厉害的，我想看看能不能随机赢一局。"

他们的打法完全没有规律。有时候会在一轮内把所有钱买一种没人碰的商品，有时候会把所有库存以成本价抛售"清仓位"。他们会因为"这个城市的名字好听"而选择移动目的地。

但诡异的是，他们的胜率并不低。他们解释说："因为你们都在按逻辑出牌，所以你们的行为是可预测的。我的不可预测性本身就是套利。"

### 商业风格

- **核心逻辑**：市场的有效性建立在参与者理性的假设上。如果我不理性，市场就对我无效。
- **打法特征**：高度随机化决策，偶尔闪现天才直觉；会故意做出"亏损"操作来扰乱市场；在他人恐慌时反常地大举买入。
- **对学生的态度**：游戏式。他们不 care 输赢，care 的是"这局有没有出现我没见过的局面"。你赢了他们他们无所谓，但如果你复制了他们的打法他们会很兴奋。

### 口头禅

- "这手我随便下的，你认真分析就输了。"
- "（大幅亏损后）哈哈哈哈，这都能亏，值了。"
- "你有没有试过……完全随机？我是说，闭上眼睛点一个？"

### 缺陷

不可预测性是一把双刃剑。他们有 20% 的局会打出惊人高利润，也有 20% 的局会莫名其妙崩盘。

### 成长轨迹

| 阶段 | 变化 |
|------|------|
| Novice | 纯随机参数，完全不可预测 |
| Developing | 开始选择性随机：在关键决策点加入一点直觉判断 |
| Mature | 学会伪随机：表面上混乱，实际在测试你的反应模式 |
| Legend | 通过不可预测的行为触发市场连锁反应，然后从中获利 |

### YAML 策略

```yaml
ai_strategies:
  wang_ke:
    name: 王可·混沌流
    behavior:
      type: random
      params:
        irrationality: 0.9
        genius_streak_chance: 0.15
```

## 06 周默 ZHOU MO

> **"我不是在和你对局。我是在和你对局时的你自己对局。"**

| 属性 | 内容 |
|------|------|
| 年龄 | ?? |
| 性别 | 中性 / 玩家自选 |
| 代表城市 | 无固定 |
| 默认策略 | **adaptive**（自适应型） |
| 原型 | 元概念角色 / 玩家的倒影 |

### 人物小传

周默没有背景故事。或者说，他们的背景故事就是你。

周默是系统为你生成的"对手性人格"。他们的初始参数完全复制你过去 5 场对局的统计画像：你的平均持仓时间、你的偏好品类、你的风险偏好、你最容易犯的错误。

他们的外观可以由玩家自定义（性别、发型、服装风格），但默认是"模糊化"处理——没有鲜明特征，就像镜子里的你自己。

周默不会说话。他们只用数据说话。每局结束后，他们会生成一份"镜像报告"，列出"你在这局里做了什么"和"如果我是你，我会在哪里做得不同"。

他们不是敌人，也不是朋友。他们是你的参照系。

### 商业风格

- **核心逻辑**：复制你的策略，然后优化你策略中的弱点。
- **打法特征**：前几轮完全模仿你的行为模式；中期开始在你模式的"优化方向"上微调；后期如果你能突破自己的惯性，周默会因为"无法预测你的变化"而陷入困境。
- **对学生的态度**：无情感。纯粹的反馈机制。

### 口头禅

- "你在第 3 轮做了和第 7 轮同样的选择。你有意识到吗？"
- "我预测了你会预测我的预测。现在我们都卡住了。"
