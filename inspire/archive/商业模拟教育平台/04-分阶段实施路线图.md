## Phase 1：地基与生涯 MVP（0–6 个月）

### 1.1 目标

　　验证假设：**生涯模式 + 日常 Quest + 一门课 + 一种商赛** 能否提升周留存与教师复用率。

### 1.2 产品范围

| 模块 | 范围 | 不做 |
|------|------|------|
| Identity | 注册登录、班级邀请码 | 多租户计费 |
| Career | 开启生涯、XP、等级、班级 XP 榜 | 全国榜、通行证付费 |
| Atlas | 导入 ≥24 张 L1 卡片、Wiki 浏览、mastery 测验 | 全 48 张、3D 可视化 |
| Academy | 2 个学段各 3 个演示单元（YAML 导入） | 全 college 单元 |
| Quest | 每日 3 任务 + streak | 公会战 |
| Arena | **1 种** CyberCore 可玩（回合制策略）+ 房间 | 16 赛制 |
| Credenti | 20 个基础成就 | 区块链证书 |
| Persona | 简版测评 + 赛制推荐 Top3 | 完整 15- 框架 |
| Athena | 生涯周计划 + **模板化商赛复盘** + Quest 轻反思 | 实时陪跑、全对话 |
| Demia | 回合制 **2 个 POP** 规则层 | LLM 舆情叙事 |
| Rival | — | 产业链 3 轮谈判 MVP |
| Ethos | 决策日志 + `dialogue_logs` | 空头承诺检测 |

### 1.3 技术任务

| 周次 | 任务 | 负责 |
|------|------|------|
| W1–2 | SQLite→PostgreSQL、Alembic、`career_profiles` / `xp_events` | 后端 |
| W3–4 | 生涯主页、Quest 页、XP 动画 | 前端 |
| W5–8 | `import_knowledge_cards.py`、mastery API | 后端+教研 |
| W9–12 | CyberCore v1：回合制 YAML + 结算 Worker | 后端 |
| W13–16 | WebSocket 房间、决策提交、局末结算 | 全栈 |
| W17–20 | 3 单元 content bundle 导入、教学对局打通 | 教研+后端 |
| W21–24 | 10 校试点、NPS 调研、迭代 | 产品 |

### 1.4 验收标准

- [ ] 新用户 5 分钟内完成：注册 → 开生涯 → 完成 1 每日任务 → 进入 1 局教学赛
- [ ] XP 账本幂等、日软上限生效
- [ ] 教师可查看班级 XP 榜与对局参与率
- [ ] NPS ≥ 35（试点校）

## Phase 2：五域贯通与 AI v1（6–12 个月）

### 2.1 目标

　　完成 **Atlas ↔ Academy ↔ Quest ↔ Arena ↔ Credenti** 事件闭环；上线 **5 种核心赛制** 与 **Athena 赛后复盘**。

### 2.2 产品范围

| 模块 | 增量 |
|------|------|
| Atlas | 全 48 节点；图谱可视化；推荐路径 |
| Academy | 初中+高中各 1 个模块（约 20 单元） |
| Arena | 5 赛制：回合制、产业链、拍卖、案例推演、ESG |
| Quest | 每周挑战、班级公会进度 |
| Credenti | 微证书 3 种；成就 60+ |
| Persona | 完整测评报告；Mercury 路径推荐 |
| Athena | 商赛+Quest+单元**统一复盘**；生涯双周回顾；战报分享 |
| Demia | 叙事层上线；宏观/ESG/贸易 **POP** |
| Rival | Easy/Normal；产业链+拍卖+融资谈判 |
| Apollo | 学生雷达图、教师班级热力图 v1 |
| 移动端 | PWA 离线缓存课件摘要 |

### 2.3 技术任务

- ClickHouse 或 PG 分区：决策日志分析
- pgvector：知识卡片 RAG
- 排行榜服务：赛季 XP + 竞技 ELO 分离
- 内容 CMS：教师上传 Bundle 草稿（审核流）

### 2.4 验收标准

- [ ] 单用户 7 日留存较 P1 提升 ≥15%
- [ ] 赛后 24h 内 ≥60% 用户打开复盘
- [ ] 100 所学校账号、10,000 MAU

---

## Phase 3：赛季生态与认证（12–18 个月）

### 3.1 目标

　　赛季制、跨校联赛、认证体系与家长端；**10 种内置赛制** 全部可配置上线。

### 3.2 产品范围

| 模块 | 增量 |
|------|------|
| Arena | 10 赛制齐套；联赛模板；大屏端 |
| Career | Season Pass；Legacy 跨赛季 |
| Credenti | 能力认证考试；证书 PDF + 验证码 |
| 家长端 | 小程序成长报告、时长管理 |
| Ethos | 举报、诚信分、伦理维度评分 |
| 企业端 | 案例植入位、赞助联赛（只读 MVP） |
| Narrative | 成长叙事引擎 v1 |

### 3.3 里程碑事件

| 月份 | 事件 |
|------|------|
| M13 | 首届校级联赛工具内测 |
| M15 | 首张「商业基础」微证书颁发 |
| M16 | 新增 6 种赛制（对齐 `12-` 扩展赛制） |
| M18 | 跨校联赛第一届 |

### 3.4 验收标准

- [ ] 500 校、50,000 MAU
- [ ] 教师学期留存 ≥70%
- [ ] 月收入 ≥50 万（B2B 订阅为主）

---

## Phase 4：规模与开放（18–24 个月）

### 4.1 目标

　　规则市场（教师自创赛制）、开放 API、国际化内容包；对齐 v2.0 Phase 4 愿景。

### 4.2 产品与技术

- 规则市场上线：审核 + 沙箱模拟
- 公开 API：对局创建、成绩回写（学校 LMS 对接）
- 剩余 6 种扩展赛制 + 难度分级
- XR/沉浸式：选 1 个赛制 POC（可选）
- 自研教育微调模型评估（与 API 混合）

### 4.3 验收标准

- [ ] 2,000 校、200,000 MAU
- [ ] 年收入 ≥2,000 万
- [ ] 发布《中学生商业素养平台白皮书》

## 四、风险登记册

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| CyberCore 工期超预期 | 高 | 高 | 先 1 赛制跑通；规则 DSL 最小集 |
| 内容产能不足 | 中 | 高 | AI 辅助 + `13-` 模板；先初中段 |
| 教师不愿改用 | 中 | 高 | 与现有课堂流程对齐；1 键开课 |
| 学生功利刷分 | 中 | 中 | XP 软上限 + Ethos |
| 竞品复制 | 高 | 中 | 数据与内容壁垒、性格适配专利布局 |
