## 一、ESG核心框架

### 1.1 三重底线（Triple Bottom Line）

| 维度 | 关注对象 | 关键议题 | 量化指标示例 |
|------|----------|----------|-------------|
| **利润（Profit）** | 股东/投资者 | 盈利能力、增长、回报 | ROE、EPS、股价 |
| **人（People）** | 员工/社区/客户 | 劳工权益、社区关系、客户隐私 | 员工满意度、社区投资、NPS |
| **地球（Planet）** | 环境/生态系统 | 碳排放、资源利用、废物管理 | 碳足迹、水循环率、可再生比例 |

### 1.2 ESG评分体系

| 支柱 | 关键指标 | 评分权重 |
|------|----------|----------|
| **环境（E）** | 碳排放量、可再生能源占比、水资源循环率、废物回收率 | 35% |
| **社会（S）** | 员工培训时长、多元化占比、社区投资、供应链伦理 | 35% |
| **治理（G）** | 信息披露透明度、独立董事占比、反腐败政策、股东权利 | 30% |

### 1.3 SDGs贡献地图

17个联合国可持续发展目标与商业议题的映射：

| SDG | 目标 | 商业关联议题 |
|-----|------|-------------|
| SDG 7 | 清洁能源 | 可再生能源投资、能效提升 |
| SDG 8 | 体面工作 | 员工培训、公平薪酬、工会权利 |
| SDG 12 | 负责任消费 | 循环经济、零废弃设计、延长产品寿命 |
| SDG 13 | 气候行动 | 碳中和承诺、碳交易、绿色金融 |

## 二、伦理困境题库

### 困境A：环保投入决策

**情境**：
> 你的工厂每天排放500吨工业废水。当前处理系统只能达到国家最低标准。环保组织正在调查你所在的行业，如果被发现"仅达标"，可能引发公关危机。升级处理系统需要一次性投入200万，但可将排放降至行业领先水平。
> 
> 当前财务状况：
> - 现金：450万
> - 月利润：80万
> - 环境评分：72分

**四个选项**：

**选项1：维持现状**
- "我们已经在合法范围内，不需要额外投入。"
- 影响：利润+200万 / 环境-15分 / 50%概率公关危机

**选项2：全面升级**
- "投资未来，成为行业环保标杆。"
- 影响：利润-200万 / 环境+25分 / 获得绿色认证

**选项3：渐进升级**
- "分阶段投入，平衡财务与环保。"
- 影响：利润-80万/季度 / 环境+10分/季度 / 6个月完成

**选项4：联合行动**
- "联合同行共建处理中心，分摊成本。"
- 影响：利润-60万 / 环境+20分 / 依赖合作伙伴

**博弈论分析**：
- 囚徒困境结构：若所有企业都不投资，集体声誉受损；若某企业单独投资，承担成本但获得竞争优势
- 公地悲剧：清洁环境是公共品，个体理性导致集体投资不足

### 困境B：员工福利 vs 成本控制

**情境**：
> 你的公司面临激烈的市场竞争，利润率从15%降至5%。
> 竞争对手已将生产转移至东南亚，人工成本降低40%。
> 
> 当前员工状况：
> - 平均薪资高于行业20%
> - 提供完善的培训和福利
> - 员工满意度高，流失率仅5%

**四个选项**：

**选项1：维持现有薪酬福利**
- 影响：利润率持续承压 / 保持高员工满意度 / 长期竞争力存疑

**选项2：适度降薪+增加股权激励**
- 影响：短期节省成本 / 员工可能不满 / 绑定长期利益

**选项3：裁员20%+保留核心人才**
- 影响：立即改善利润 / 士气受损 / 知识流失

**选项4：迁移部分业务至低成本地区**
- 影响：大幅降低成本 / 本土员工失业 / 品牌形象受损

### 困境C：供应链伦理

**情境**：
> 你的主要供应商被曝光使用童工。该供应商提供你30%的原材料，且替代供应商价格高出25%。
> 
> 调查确认：
> - 供应商确实存在童工问题
> - 立即终止合作将导致生产中断3个月
> - 媒体已联系你寻求评论

**四个选项**：

**选项1：立即终止合作并公开谴责**
- 影响：树立道德标杆 / 生产中断 / 成本上升

**选项2：私下施压整改并设定期限**
- 影响：维持供应链 / 被批评为"虚伪" / 整改效果不确定

**选项3：帮助供应商改善并投资教育项目**
- 影响：成本最高 / 真正解决问题 / 长期品牌收益

**选项4：低调更换供应商，不公开评论**
- 影响：避免舆论 / 未解决根本问题 / 若被曝光后果严重

## 三、多目标优化

### 3.1 帕累托前沿

ESG决策是多目标优化问题：

```
最大化 [Profit, E_score, S_score, G_score]
约束条件：Profit >= Profit_min
```

**帕累托前沿**：不存在一个解同时在所有维度上最优——必须在利润和ESG之间权衡。

**图示**：
```
利润
 上
  │    ● 帕累托前沿
  │   / 
  │  /  
  │ /    
  │/______→ ESG评分
```

### 3.2 ESG投资策略

| 策略 | 定义 | 示例 | 回报特征 |
|------|------|------|----------|
| **负面筛选** | 排除不符合标准的公司 | 不投资烟草、武器、煤炭 | 风险降低 |
| **正面筛选** | 选择ESG表现优异的公司 | 投资ESG评级A+的公司 | 长期 alpha |
| **主题投资** | 聚焦特定ESG主题 | 清洁能源基金、水基金 | 主题 beta |
| **影响力投资** | 主动创造社会/环境影响 | 扶贫微金融、可持续农业 | 影响力+财务回报 |
| **股东参与** | 通过股东权利推动改变 | 代理投票、与管理层对话 | 治理改善 |

## 四、ESG报告标准

### 4.1 主要报告框架

| 框架 | 发起机构 | 侧重点 | 适用范围 |
|------|----------|--------|----------|
| **GRI标准** | 全球报告倡议组织 | 全面可持续性披露 | 全球通用 |
| **SASB** | 可持续发展会计准则委员会 | 行业特定、投资者导向 | 美国市场 |
| **TCFD** | 气候相关财务披露工作组 | 气候风险 | 金融监管机构推荐 |
| **CDP** | 碳披露项目 | 碳排放和水资源 | 投资者要求 |
| **中国ESG披露指引** | 证监会/交易所 | 本土化要求 | A股上市公司 |

### 4.2 ESG报告核心内容

```
1. 治理结构
   - ESG委员会设置
   - 高管薪酬与ESG挂钩机制
   - 利益相关者沟通机制

2. 环境绩效
   - 温室气体排放（Scope 1/2/3）
   - 能源使用与可再生能源比例
   - 水资源管理
   - 废物处理与循环经济

3. 社会绩效
   - 员工结构（性别、年龄、民族）
   - 培训与发展投入
   - 健康与安全记录
   - 社区投资

4. 治理绩效
   - 董事会独立性
   - 反腐败政策与培训
   - 信息披露质量
   - 股东权利保护
```

## 五、教学锚点

| 学生体验 | 教师锚定问题 | 对应理论 |
|----------|-------------|----------|
| "环保投入减少了当期利润" | "这就是短期vs长期的冲突。ESG是成本还是投资？" | 外部性内部化、三重底线 |
| "如果我不投资环保，竞争对手也不投，大家一起受益" | "这就是囚徒困境。如何解决集体行动的失败？" | 公地悲剧、囚徒困境 |
| "我发现做ESG好的公司长期股价更高" | "ESG与财务绩效的关系：是相关还是因果？" | ESG alpha、长期价值 |
| "利益相关者太多，无法让所有人都满意" | "利益相关者理论vs股东至上：企业的目的是什么？" | 利益相关者理论、企业目的 |
| "我的ESG评分提高了，但客户并不关心" | "ESG的价值如何实现？通过消费者溢价还是降低融资成本？" | ESG价值传导机制 |
