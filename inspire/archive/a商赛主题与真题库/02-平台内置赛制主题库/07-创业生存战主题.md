## 二、危机决策题库

### 2.1 危机A：最大客户流失

**危机横幅**：
> 重大危机：最大客户流失
> 占收入40%的核心客户终止合作，月收入将从8万骤降至4.8万
> 若不行动，跑道将缩短至1.2个月

**四选项网格**：

**方案A：紧急裁员50%**
- 裁掉6名员工，支出从8.5万降至5.5万
- 需支付N+1补偿金约6万（一次性）
- 影响：+1.1月跑道 / -6人 / -30%产能

**方案B：紧急融资**
- 以极低估值（稀释40%股权）借款30万
- 影响：+10月跑道 / -40%股权 / 高风险

**方案C：全力挽回客户**
- 创始人亲自拜访，承诺降价20%
- 50%概率挽回
- 影响：50%挽回率 / -20%利润率 / 不确定

**方案D：Pivot转型**
- 放弃B端业务，All in C端产品
- 3个月开发期，期间零收入
- 影响：3月零收 / 10x潜在市场 / 70%失败率

**最优策略分析**：
- 若对现有业务仍有信心 → 方案A或C
- 若判断业务模式有问题 → 方案D（高风险高回报）
- 若有外部资源 → 方案B

### 2.2 危机B：竞品低价冲击

**危机横幅**：
> 竞品冲击：主要竞争对手降价40%
> 你的核心产品定价100元，竞品推出功能相似的替代品定价60元
> 过去一周新客户签约量下降70%

**四选项网格**：

**方案A：跟随降价**
- 将价格降至65元
- 影响：利润率从30%降至5%，但维持市场份额

**方案B：差异化强化**
- 维持价格，增加增值服务
- 推出"尊享版"定价150元
- 影响：短期销量下滑，但建立高端定位

**方案C：成本革命**
- 重构供应链，将成本从70元降至45元
- 影响：需6个月，期间面临持续压力

**方案D：细分市场**
- 放弃价格敏感客户，专注高端市场
- 影响：市场规模缩小，但利润率和客户质量提升

### 2.3 危机C：核心团队分裂

**危机横幅**：
> 团队危机：CTO和2名核心工程师提出离职
> 他们正在筹备竞品公司
> 带走将意味着技术壁垒消失

**四选项网格**：

**方案A：高薪挽留**
- 给予CTO股权激励+薪资翻倍
- 影响：-50万现金 / 士气提振 / 其他员工可能效仿

**方案B：法律手段**
- 启动竞业禁止诉讼
- 影响：-20万法律费用 / 舆论风险 / 不一定能阻止

**方案C：快速替代**
- 紧急招聘+外包过渡
- 影响：-3个月技术停滞 / 代码交接风险

**方案D：战略转型**
- 承认技术优势丧失，转向模式创新
- 影响：重新定义公司价值主张

## 三、财务生存指标

### 3.1 跑道计算（Runway）

**公式**：
> Runway（月）= 当前现金余额 / 月度净消耗
> 
> 月度净消耗 = 月度总支出 - 月度总收入

**安全阈值**：
| 跑道长度 | 状态 | 建议行动 |
|----------|------|----------|
| 大于12个月 | 安全 | 专注增长 |
| 6-12个月 | 注意 | 控制支出，探索收入增长 |
| 3-6个月 | 警告 | 紧急融资或削减成本 |
| 小于3个月 | 危险 | 立即采取生存措施 |

### 3.2 盈亏平衡分析

**题目**：
> 你的公司固定成本每月8万，产品售价200元，变动成本120元。
> 1. 盈亏平衡销量是多少？
> 2. 如果降价至180元，新的盈亏平衡销量是多少？
> 3. 如果要实现月利润2万，需要销售多少件？

**解答**：
1. 盈亏平衡 = 80,000 / (200-120) = 1,000件
2. 新盈亏平衡 = 80,000 / (180-120) = 1,333件（风险上升）
3. 目标销量 = (80,000+20,000) / 80 = 1,250件

### 3.3 Altman Z-Score（破产预测）

**公式**：
> Z = 1.2X1 + 1.4X2 + 3.3X3 + 0.6X4 + 1.0X5
> 
> X1 = 营运资金 / 总资产
> X2 = 留存收益 / 总资产
> X3 = EBIT / 总资产
> X4 = 市值 / 负债账面值
> X5 = 销售额 / 总资产

**判断标准**：
- Z < 1.81：破产风险高
- 1.81 < Z < 2.99：灰色地带
- Z > 2.99：财务状况良好

## 四、系统动力学：死亡螺旋

```
现金流紧张 → 削减研发投入 → 产品质量下降 → 客户流失 → 收入下降 → 现金流更紧张
         上                                                            下
          下__________________________________________________________上
```

**教学点**：
- 增强回路反向运行——"坏的越坏"
- 为什么"节流"有时比"开源"更紧迫
- 避免削减核心能力（研发、关键人才）

## 五、生存策略框架

### 5.1 现金流管理优先级

```
优先级1：生存必需（不可削减）
├── 核心团队工资（保留最低必需人员）
├── 服务器/云服务（维持产品运行）
└── 关键供应商付款（维持供应链）

优先级2： strategically重要（谨慎削减）
├── 市场营销（保留最有效的渠道）
├── 产品迭代（保留核心功能开发）
└── 客户服务（保留关键客户）

优先级3：可延迟/削减（立即削减）
├── 办公室租金（考虑远程办公）
├── 非核心人员（行政、实习生）
├── 差旅和招待
└── 非必要软件订阅
```

### 5.2 紧急融资途径

| 途径 | 速度 | 成本 | 风险 | 适用场景 |
|------|------|------|------|----------|
| 创始人个人借款 | 立即 | 低 | 个人财务风险 | 早期阶段 |
| 亲友借款 | 1-2周 | 低 | 关系风险 | 任何阶段 |
| 过桥贷款 | 2-4周 | 高（利率15-25%） | 高杠杆 | 有明确回款预期 |
| 股权融资 | 1-3月 | 稀释 | 控制权稀释 | 有增长故事 |
| 政府补贴/ grants | 2-6月 | 极低 | 竞争激烈 | 符合条件 |
| 应收账款融资 | 1-2周 | 中等 | 依赖客户信用 | B2B业务 |

## 六、教学锚点

| 学生体验 | 教师锚定问题 | 对应理论 |
|----------|-------------|----------|
| "现金流一断，什么都没了" | "这就是财务杠杆的双刃剑——放大收益也放大风险" | 经营杠杆、财务杠杆 |

| "我活到了最后，但公司面目全非" | "生存是否是唯一目标？'活着但失去灵魂'值得吗？" | 战略一致性、核心价值观 |
| "我发现固定成本是致命的" | "为什么初创公司应该尽可能将成本变为变动成本？" | 成本结构、经营杠杆 |
