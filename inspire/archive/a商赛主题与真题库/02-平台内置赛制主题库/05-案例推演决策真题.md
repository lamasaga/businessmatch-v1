# 案例推演决策 · 主题与真题库

> **赛制编号**：Mode 05
> **核心机制**：叙事驱动、10个关键决策点、分支结局、伦理困境
> **适用学段**：大学及以上
> **核心能力**：伦理判断、长期思维、利益相关者分析
> **节奏**：1-2天一个决策点，异步在线体验

---

## 一、案例结构标准模板

每个案例推演包含10个决策节点，覆盖企业生命周期的关键阶段：

```
节点1：创业初心          → 选择创业方向
节点2：首轮融资          → 接受谁的投资
节点3：产品定位          → 高端vs大众
节点4：危机应对          → 当前决策点（如供应链丑闻）
节点5：扩张策略          →  organic vs 并购
节点6：竞争博弈          → 价格战/差异化/蓝海
节点7：伦理困境          → 利润vs责任
节点8：上市抉择          → IPO时机与定价
节点9：全球化            → 进入新市场
节点10：终局             →  legacy与传承
```

## 二、经典案例题库

### 案例A：绿源科技——供应链丑闻

**案例背景**：
> "绿源科技"发展三年，主打环保智能家居，刚完成B轮融资，估值5亿元。核心供应商"宏达制造"占采购量60%。媒体报道宏达存在严重环保违规，投资人要求"尽快处理"。

**决策点4：供应链丑闻曝光**

**当前公司状况**：
| 指标 | 数值 |
|------|------|
| 公司估值 | ¥5亿 |
| 宏达采购占比 | 60% |
| 现金储备 | ¥8,000万 |
| 今日股价波动 | -12% |
| 投资人态度 | 施压要求切割 |

**四个选项**：

**选项A · 立即终止合作**
- 发布公开声明，立即停止所有合作
- 承担短期供应链断裂风险
- 树立负责任的企业形象
- **3年后结局**：公司成功上市，市值30亿。宏达破产，200名工人失业——未预料到的代价

**选项B · 限期整改+备选方案**
- 给宏达90天整改期限
- 秘密寻找替代供应商
- 对外表示"正在调查中"
- **3年后结局**：公司稳健发展，估值15亿。没有成为英雄，也没有成为反派

**选项C · 公开辩护**
- 召开新闻发布会，质疑媒体报道
- 表示宏达是"被竞争对手恶意中伤"
- 宣布法律诉讼
- **3年后结局（两种可能）**：
  - 若赢：市值50亿，成为"对抗虚假新闻"的英雄
  - 若输：公司倒闭，成为商学院"伦理反面教材"

**选项D · 主动披露+第三方审计**
- 超越媒体爆料，主动公开合作细节
- 邀请环保NGO参与监督
- 将危机转化为透明度展示
- **3年后结局**：写了《透明经营》畅销书，公司估值20亿。但"过度透明"让竞争对手获得太多情报

**教学锚点**：
- 利益相关者理论（股东、员工、供应商、社区、环境）
- 危机管理（危机生命周期、声誉修复策略）
- 囚徒困境（若行业其他公司也面临同样问题，集体沉默vs集体行动）

### 案例B：数据隐私风暴

**案例背景**：
> "未来视界"是一家AI驱动的个性化教育平台，服务10万学生。公司收集了大量学生的学习行为数据以优化推荐算法。某黑客组织声称获取了平台数据库，包含学生姓名、学校、成绩和学习障碍诊断信息。

**决策点：数据泄露应对**

**当前状况**：
| 指标 | 数值 |
|------|------|
| 用户数 | 10万学生 |
| 泄露数据量 | 疑似全部用户数据 |
| 现金储备 | ¥3,000万 |
| 监管环境 | GDPR合规压力 |
| 竞争对手 | 2家同类产品正在快速获客 |

**四个选项**：

**选项A · 立即通知所有用户并报警**
- 公开透明，符合监管要求
- 面临集体诉讼风险
- 用户信任可能崩塌
- **长期影响**：成为行业数据安全的标杆，但短期用户流失50%

**选项B · 先内部调查，确认后再通知**
- 争取时间评估影响范围
- 违反GDPR"72小时通知"要求
- 若被媒体提前曝光，后果加倍
- **长期影响**：避免了恐慌性流失，但被罚款¥2,000万，品牌受损

**选项C · 私下与黑客谈判**
- 支付赎金删除数据
- 不公开事件，保护品牌
- 违法且可能遭遇重复勒索
- **长期影响**：事件最终被曝光，创始人面临刑事责任

**选项D · 将危机转化为产品升级**
- 公开事件，宣布全面安全升级
- 为受影响用户提供终身免费服务
- 邀请白帽黑客参与安全测试
- **长期影响**：短期成本高昂，但建立了最强安全口碑

**教学锚点**：
- 数据伦理与隐私权
- GDPR等法规的合规要求
- 声誉风险的量化与管理
- 囚徒困境（若与黑客谈判被发现 vs 若公开透明）

### 案例C：反垄断风暴

**案例背景**：
> "云购天下"是中国最大的电商平台，市场份额65%。平台要求商家"二选一"（只能在云购天下或竞争对手平台开店）。监管部门启动反垄断调查，舆论压力巨大。公司年收入¥5,000亿，现金储备¥2,000亿。

**决策点：监管压力应对**

**四个选项**：

**选项A · 全面配合整改**
- 立即停止"二选一"政策
- 开放数据接口给竞争对手
- 接受¥50亿罚款
- **长期影响**：短期股价暴跌30%，但3年后成为行业开放生态的领导者

**选项B · 法律抗辩**
- 聘请顶级律师团队
- 声称"二选一"是保护消费者权益
- 与监管长期对抗
- **长期影响**：罚款增至¥200亿，创始人被限制出境，公司被拆分风险

**选项C · 主动拆分**
-  preemptively 将业务拆分为多个独立公司
- 将云服务和电商分离
- **长期影响**：各业务线独立上市，总市值反而上升40%

**选项D · 政治游说+公众关系**
- 投入巨资进行政府关系和媒体公关
- 强调公司对就业和税收的贡献
- **长期影响**：短期内缓解了压力，但公众形象受损，长期仍面临整改

**教学锚点**：
- 反垄断经济学（市场势力、消费者福利、创新激励）
- 博弈论（与监管部门的动态博弈）
- 路径依赖（早期战略选择如何锁定未来）

### 案例D：全球化文化冲突

**案例背景**：
> "美味快餐"是一家中国连锁餐饮品牌，在国内拥有500家门店，计划进入印度市场。印度市场潜力巨大（14亿人口），但面临以下挑战：
> - 40%人口素食，牛肉和猪肉禁忌
> - 各地口味差异极大（南vs北）
> - 已有强大本土竞争对手
> - 复杂的特许经营法规

**决策点：印度市场进入策略**

**四个选项**：

**选项A · 完全本土化**
- 开发全素食菜单
- 与当地企业成立合资公司
- 聘请印度籍CEO
- **结果**：获得了消费者认同，但品牌中国特色消失，母公司控制力下降

**选项B · 全球标准化**
- 维持中国菜单，仅做最小调整
- 直营模式，保持总部控制
- 强调"正宗中国味"
- **结果**：在印华人社区受欢迎，但大众市场接受度低，3年亏损¥5亿

**选项C · "Glocal"混合策略**
- 核心产品标准化（如品牌视觉、服务流程）
- 菜单50%本土化+50%中国特色
- 特许经营模式快速扩张
- **结果**：平衡了效率与适应，成为印度快餐市场前5名

**选项D · 收购本土品牌**
- 收购印度本土快餐连锁
- 保留原品牌，逐步注入中国元素
- **结果**：快速获得渠道和品牌认知，但文化整合困难，最终亏损出售

**教学锚点**：
- 国际市场进入模式（出口/合资/全资子公司/并购）
- Hofstede文化维度理论
- "全球思考，本地行动"（Think Global, Act Local）

### 案例E：AI伦理困境

**案例背景**：
> "智慧医疗"公司开发了一款AI诊断系统，能够通过分析X光片检测早期肺癌，准确率达95%（高于普通医生的85%）。但系统存在以下问题：
> - 训练数据主要来自白人患者，对少数族裔准确率下降至75%
> - 系统偶尔给出"无法判断"的结果，但医生倾向于信任AI而不再仔细检查
> - 保险公司希望使用AI结果决定是否赔付

**决策点：算法偏见的处理**

**四个选项**：

**选项A · 立即暂停推广，补充训练数据**
- 投入¥5,000万收集多样化数据
- 推迟上市12个月
- 竞争对手可能在此期间推出同类产品

**选项B · 标注局限性，限制使用场景**
- 明确告知系统对少数族裔准确率较低
- 仅在准确率≥90%的人群中推广
- 要求AI结果必须经医生二次确认

**选项C · 推出"人类+AI"混合模式**
- AI提供初步筛查
- 高危病例必须人工复核
- 建立反馈循环持续改进算法

**选项D · 优先推向高价值市场**
- 先在准确率高的地区推广
- 用收入资助少数族裔数据收集
- **伦理争议**：是否构成系统性歧视？

**教学锚点**：
- 算法公平性（Fairness in Machine Learning）
- 伦理框架（功利主义vs义务论vs美德伦理）
- 责任归属（AI出错时，谁承担责任？）

## 三、决策陷阱与行为经济学

每个案例都设计为触发特定的认知偏差：

| 决策陷阱 | 行为经济学概念 | 案例体现 |
|----------|--------------|----------|
| 短期利润vs长期品牌 | 双曲贴现 | 案例A中选择C（辩护）追求短期股价 |
| 跟风决策 | 信息级联 | 案例B中若选择B（拖延），因为"其他公司也这样" |
| 沉没成本 | 禀赋效应 | 案例D中因已投入¥2亿而坚持错误策略 |
| 极端选项 | 框架效应 | 案例E中选项D的表述方式影响选择 |
| 权威服从 | 米尔格拉姆效应 | 案例C中因创始人权威而抗拒拆分 |
| 道德推脱 | 认知失调 | 案例A中为继续使用违规供应商找借口 |

## 四、教学使用指南

### 4.1 课前准备

1. **案例选择**：根据课程主题选择匹配的决策节点
   - 商业伦理课：案例A、B、E
   - 战略管理课：案例C、D
   - 创业管理课：案例A（节点1-5）

2. **学生分组**：4-6人一组，每组扮演"董事会"
   - 指定CEO、CFO、CMO、COO等角色
   - 每人有不同信息（信息不对称）

### 4.2 课中流程

```
Step 1（5分钟）：阅读案例背景
Step 2（10分钟）：小组讨论，各角色陈述观点
Step 3（5分钟）：投票决策
Step 4（5分钟）：系统揭示不同选择的后果
Step 5（15分钟）：全班讨论，教师锚定理论概念
```

### 4.3 课后复盘问题

1. "如果回到决策前，你会改变选择吗？为什么？"
2. "你的决策主要考虑了哪些利益相关者？遗漏了谁？"
3. "这个案例中的决策陷阱是什么？你中招了吗？"
4. "在现实中，你会如何收集更多信息来降低不确定性？"
