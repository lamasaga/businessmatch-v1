# 21 - 随机性、不确定性与风险建模

> 商业世界不是确定性的机器。需求波动、政策变化、竞争对手的意外举动——这些不确定性不是干扰项，而是商业决策的核心挑战。如何在模拟中合理引入随机性，既保持教学的真实性，又不让学生感觉"被随机支配"？

---

## 一、不确定性的三种类型

经济学家弗兰克·奈特（Frank Knight）的经典区分：

| 类型 | 定义 | 可处理性 | 商业例子 |
|------|------|----------|----------|
| **风险（Risk）** | 结果未知，但概率分布已知 | 可量化、可保险 | 已知历史销量的产品，需求波动 |
| **不确定性（Uncertainty）** | 结果未知，概率分布也未知 | 难以量化，需情景分析 | 全新市场、颠覆性技术 |
| **模糊性（Ambiguity）** | 连可能的结果集合都不清楚 | 需探索和适应 | 黑天鹅事件、前所未有的危机 |

**教学启示**：
- 低年级：主要面对**风险**（已知概率的随机事件）
- 中年级：引入**不确定性**（需要收集信息才能判断）
- 高年级：面对**模糊性**（规则本身可能被颠覆）

## 二、随机变量的建模方法

### 2.1 均匀分布 vs 正态分布

**均匀分布**（所有结果等可能）：
```
X ~ U(a, b)
P(X ∈ [c,d]) = (d-c) / (b-a)
```

适用场景：掷骰子、抽卡、简单随机事件。缺点：不符合大多数自然现象。

**正态分布**（钟形曲线）：
```
X ~ N(μ, σ²)
f(x) = (1/√(2πσ²)) · exp(-(x-μ)²/(2σ²))
```

适用场景：需求波动、测量误差、多因素叠加的结果。

**关键参数**：
- μ（均值）：期望水平
- σ（标准差）：波动幅度
- σ/μ（变异系数）：相对波动性

**TechVenture 中的噪声**：现有引擎使用 `noise ~ U(-σ, +σ)`，即均匀分布。可扩展为混合分布（主体正态 + 偶尔大偏差）。

### 2.2 肥尾分布：黑天鹅的数学

正态分布假设极端事件极不可能。但现实中：

```
正态分布：P(|X-μ| > 3σ) ≈ 0.27%
肥尾分布（如幂律）：P(|X-μ| > 3σ) 可能是 5% 甚至更高
```

**常用肥尾分布**：

| 分布 | 特征 | 适用场景 |
|------|------|----------|
| **对数正态** | 右偏，乘性过程 | 股价、销售额、城市规模 |
| **幂律（Power Law）** | 极端事件概率高于正态 | 地震、金融危机、爆款产品 |
| **泊松分布** | 计数事件，稀有发生 | 客户投诉、设备故障 |
| **指数分布** | 无记忆性 | 设备寿命、客户等待时间 |

**教学价值**：让学生体验"为什么 10 个标准差的'不可能事件'在现实中会发生"。

### 2.3 随机游走与均值回归

**随机游走**（Random Walk）：
```
X_t = X_{t-1} + ε_t,  ε_t ~ N(0, σ²)
```

特征：无记忆性，过去无法预测未来。

**均值回归**（Mean Reversion）：
```
X_t = μ + ρ·(X_{t-1} - μ) + ε_t,  |ρ| < 1
```

特征：偏离均值后会趋向回归。

**商业含义**：
- 股票价格更接近随机游走（难以预测）
- 利润率更接近均值回归（竞争会拉平超额利润）

## 三、不确定性下的决策理论

### 3.1 期望值准则

```
EV(策略) = Σ P(结果_i) × 收益(结果_i)
选择 EV 最大的策略
```

**局限**：只考虑平均，忽略风险。

**案例**：
```
策略 A：50% 赚 100，50% 赚 0 → EV = 50
策略 B：100% 赚 40 → EV = 40

期望值说选 A，但如果本金只有 50 且不能承担损失呢？
```

### 3.2 期望效用理论

```
EU(策略) = Σ P(结果_i) × U(收益(结果_i))
```

U 是效用函数，通常假设风险厌恶（凹函数）：
```
U(x) = x^α,  0 < α < 1
```

**含义**：损失 100 的痛苦 > 获得 100 的快乐。

**应用**：在模拟中引入"风险调整收益"——高风险策略即使期望收益高，也可能因效用损失而不被选择。

### 3.3 前景理论（Prospect Theory）

卡尼曼和特沃斯基的发现：人类决策不是理性的。

| 偏离理性的行为 | 数学表达 | 商业含义 |
|-------------|----------|----------|
| **损失厌恶** | U(-x) < -U(x) | 损失的痛苦是收益快乐的 2-2.5 倍 |
| **参照点依赖** | 评价相对于参照点，而非绝对值 | 盈利 100 万，但目标是 150 万 → 感觉亏损 |
| **概率加权** | 小概率被高估，中概率被低估 | 彩票、保险、极端风险管理 |
| **禀赋效应** | 拥有后估值上升 | 已投入的项目难以放弃（沉没成本谬误） |

**教学价值**：让学生在模拟中体验"为什么我不理性"，然后教师引入前景理论解释。

## 四、信息的价值：从不确定到确定

### 4.1 完全信息期望值（EVPI）

```
EVPI = EV(有完美信息) - EV(当前最优策略)
```

含义：你愿意付多少钱来消除不确定性？

**教学应用**：
- 设置"市场调研"选项：花费 5 万预算，可以获知下轮事件的部分信息
- 让学生计算：在何种情况下，买信息是值得的？

### 4.2 贝叶斯更新

随着新信息到达，不断更新对世界的信念：

```
P(假设|数据) = P(数据|假设) × P(假设) / P(数据)
```

**商业应用**：
- 初始信念：某城市 Geek 群体占 20%
- 市场调研结果：样本显示 30%
- 贝叶斯更新后：后验信念约为 24%（取决于先验强度和样本量）

**教学价值**：让学生理解"为什么第一次调研结果不应该完全相信"。

## 五、蒙特卡洛模拟

### 5.1 基本方法

当解析解难以求得时，通过大量随机抽样估计结果分布。

```
for i = 1 to N:
    随机生成所有不确定变量的取值
    计算该情境下的结果
    记录结果

分析 N 个结果的统计分布
```

### 5.2 在商业模拟中的应用

**场景**：学生制定了某策略，想知道"最坏情况会怎样？"

```
策略：All-in TECH 路线，投入全部预算于技术

模拟 1000 次：
    - 随机生成竞争对手策略（假设服从某分布）
    - 随机生成事件（按已知概率）
    - 运行结算引擎
    
结果分布：
    - 均值排名：3.2
    - 中位数排名：3
    - 第 10 百分位：1（最好情况）
    - 第 90 百分位：7（最坏情况）
    - P(排名 ≤ 3) = 60%
```

**教学价值**：让学生从"点估计思维"（我会排第几？）转向"分布思维"（我的风险敞口有多大？）。

## 六、风险管理策略的模拟

### 6.1 对冲（Hedging）

通过持有负相关资产降低风险：

```
组合方差：σ_p² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρσ₁σ₂

当 ρ < 0 时，组合风险低于单独持有
```

**商业模拟应用**：
- 同时开拓多个市场（南京/合肥/杭州），利用城市间的低相关性分散风险
- 同时投资 Tech 和 Show，对冲单一策略失败的风险

### 6.2 实物期权（Real Options）

将投资决策视为期权：

| 期权类型 | 商业决策 | 价值来源 |
|----------|----------|----------|
| **延迟期权** | 先观察市场，再决定进入 | 避免不确定性下的错误投资 |
| **扩张期权** | 小规模试点，成功后扩张 | 控制下行风险，保留上行空间 |
| **放弃期权** | 项目不佳时及时止损 | 沉没成本不是继续的理由 |
| **转换期权** | 根据市场变化切换策略 | 灵活性本身有价值 |

**TechVenture 中的应用**：
- R1 只开 1 个城市 = 延迟期权（保留未来扩展的灵活性）
- 路线切换成本 = 转换期权的执行成本
- 多轮结构本身就是"序列决策"，天然适合实物期权思维

## 七、设计原则：随机性的教育化

### 7.1 好的随机性设计

| 原则 | 说明 |
|------|------|
| **可解释** | 学生应该能理解"为什么这轮结果波动这么大" |
| **可学习** | 随机中应存在模式，让学生通过经验改善预测 |
| **有边界** | 极端结果应被限制，避免完全破坏体验 |
| **透明化** | 让学生知道随机因素的存在和范围 |
| **归因清晰** | 学生能区分"我的决策贡献了多少，随机贡献了多少" |

### 7.2 随机性的可见性分级

| 可见级别 | 设计 | 适用场景 |
|----------|------|----------|
| **完全隐藏** | 学生不知道结果中有随机成分 | 不推荐（破坏信任） |
| **暗示存在** | "市场存在不确定性" | 初学者 |
| **量化范围** | "本次结算包含 ±5% 的市场波动" | 进阶者 |
| **完全透明** | 显示随机抽样过程和分布 | 高阶者/教学演示 |

## 八、检验清单

- [ ] 模拟中的随机性是否服务于教学目标，而非单纯增加难度？
- [ ] 学生能否区分"我的决策结果"和"随机扰动"？
- [ ] 极端负面结果是否有安全网（不让学生因运气而完全出局）？
- [ ] 是否提供了降低不确定性的信息工具（如市场调研）？
- [ ] 随机性的分布在现实中有对应物（如真实市场波动率）？
- [ ] 多轮模拟后，随机性是否被部分"平均掉"，让策略质量显现？

---

> **核心洞见**：不确定性不是商业模拟的"噪音"，而是其核心教学内容之一。一个好的商业模拟平台，应该让学生在安全环境中体验"在不确定中决策"的焦虑与兴奋，理解风险与收益的权衡，并学会用概率思维替代确定思维。最终目标不是消灭不确定性，而是学会与之共舞。
