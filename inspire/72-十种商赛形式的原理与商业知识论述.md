### 2.1 Mode 01：回合制策略商赛

#### 经济学原理

**核心：供需均衡与边际效用递减**

回合制策略商赛的底层是**多市场供需模型**。每座城市可视为一个独立的市场，拥有固定的市场规模（`scale`）和消费者群体结构（Geek/Pragmatic/Trendy 的比例）。各队伍的投资决策（Tech/Fit/Show）构成市场供给，而消费者偏好构成需求。

**关键经济学概念：**

- **边际效用递减**：Tech 属性的增长遵循递减曲线——`growthRate` 随投入增加而下降，`kappa`（过载系数）进一步惩罚过度集中。这直接对应经济学中的**边际产出递减规律**。
- **机会成本**：路线切换成本（-5万）和开城费的存在，迫使学生在"深耕现有市场"与"开拓新市场"之间权衡——这正是**机会成本**的具象化。
- **市场细分**：不同城市的群体比例差异（如合肥 Geek 45%、南京 Show 50%）对应**市场细分理论**。TECH 路线在 Geek 占比高的城市效率更高，体现了**比较优势**原理。
- **信号理论**：宣言-投入一致性（BQI）机制模拟了**信号传递**——企业通过行为（而非言语）向市场传递信息。高 BQI 获得加成，意味着"言行一致"本身就是一种竞争优势。

#### 博弈论结构

**核心：不完全信息的静态非合作博弈**

```
类型：多参与者、同时行动、不完全信息、变和非合作博弈
策略空间：路线 {TECH, USER, BRAND, PATHFINDER} × 城市子集 × 预算分配
信息结构：同时决策（不知道对手本轮选择），但知道对手历史表现
重复性：4 轮重复博弈
```

**纳什均衡分析：**

| 路线 | 均衡条件 | 博弈论解释 |
|------|----------|-----------|
| PATHFINDER | 选择者 ≤ 2 | 差异化博弈（Hotelling 模型）——过度拥挤消除差异化红利 |
| TECH | 多数对手选 BRAND | 最佳反应策略——避开红海，寻找蓝海 |
| BRAND | 市场事件 favor Show | 外部冲击改变收益矩阵，原有均衡被打破 |

**间谍机制**引入了**不完全信息博弈**的海萨尼转换——通过投入预算获取对手历史决策信息，降低信息不确定性，但间谍行为本身也消耗资源，形成**信息价值的权衡**。

**联盟机制**引入了**合作博弈**的元素。两队临时合作共享 Fit 属性，但联盟可随时背叛——这模拟了真实商业中**战略联盟的不稳定性**（如卡特尔困境）。

#### 数学模型

**核心：Softmax 选择模型 + 排名竞争**

消费者选择使用 **Logit 模型**（Softmax 函数）：

```
share_i = exp(β·U_i) / Σ_j exp(β·U_j)
```

其中 `U_i = w_tech·Tech + w_fit·Fit + w_show·Show`，β 是"选择锐度"参数。

**教学价值**：
- 理解"为什么第二名和第一名的差距远大于第十名和第九名"
- 微小差异在拥挤市场中被指数级放大

**排名竞争**引入了**锦标赛理论**——奖励不仅取决于绝对表现，还取决于相对排名。这解释了为什么学生有时会做出"非理性"的冒险决策（为了超越特定对手）。

#### 系统动力学

**增强回路 R1**：投资 → 属性提升 → 市场份额 → 追加投资能力
**增强回路 R2**：排名靠前 → Follow_on 资金 → 更多投资 → 维持优势
**调节回路 B1**：投资增加 → 过载系数下降 → 投资效率降低
**调节回路 B2**：某城市拥挤 → 竞争加剧 → 单队份额下降

**时间延迟**：投资决策在本轮提交，但效果在结算后才完全显现——学生体验"决策→结果"的时滞，理解为什么商业决策需要耐心。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 路线选择 | 战略定位（成本领先 vs 差异化 vs 聚焦） |
| 城市选择 | 市场进入决策（TAM/SAM/SOM 分析） |
| 预算分配 | 资源配置（CAPEX vs OPEX 权衡） |
| BQI 机制 | 品牌一致性管理 |
| 间谍机制 | 竞争情报（CI）系统 |
| 联盟机制 | 战略联盟与合资企业 |

### 2.2 Mode 02：实时经营挑战

#### 经济学原理

**核心：生产理论与成本曲线**

实时经营模拟的底层是**生产函数**和**成本结构**。学生经营的虚拟公司持续运转，收入、支出、库存实时变化。

**关键经济学概念：**

- **固定成本 vs 可变成本**：办公租金、人员工资是固定成本（无论产量如何都需支付），原材料是可变成本（随产量变化）。这对应**短期成本理论**中的 FC/VC/TC 结构。
- **产能利用率**：68% 的产能利用率意味着存在闲置产能——对应**规模经济**的反面：产量不足时，单位成本偏高。
- **库存管理**：库存降至警戒线以下触发供应链危机——对应**经济订货量（EOQ）模型**和**JIT（准时制）生产**的风险。

#### 博弈论结构

**核心：单人决策 vs 环境不确定性**

实时经营模式本质上是**人与环境的博弈**，而非人与人之间的博弈。对手是"时间"和"随机事件"——这是一种**随机博弈**（Stochastic Game）。

```
类型：单参与者、连续时间、完全信息（但未来事件随机）、与自然的博弈
策略空间：实时资源调配 + 应急决策
信息结构：当前状态完全可见，未来事件概率分布已知
```

**决策理论应用**：
- 每个突发事件需要在 5 分钟内做出应急决策——对应**实时决策理论**（Real-Time Decision Theory）
- 多线程操作训练**注意力分配**和**认知负荷管理**

#### 数学模型

**核心：排队论 + 马尔可夫决策过程**

事件随机发生可建模为**泊松过程**：
```
P(k 个事件在时间 t 内发生) = (λt)^k · exp(-λt) / k!
```

其中 λ 是事件发生率。

**库存管理**使用**（s, S）策略**：
- 当库存降至 s（再订货点）时，订货至 S（目标库存水平）
- 学生需要在没有明确公式的情况下，凭直觉找到合适的 s 和 S

**马尔可夫决策过程（MDP）**：
```
V(s) = max_a [R(s,a) + γ · Σ P(s'|s,a) · V(s')]
```
每个状态 s（公司当前状况）下选择最优行动 a，考虑即时奖励和未来的期望价值。

#### 系统动力学

**核心：延迟效应与牛鞭效应**

实时经营中最关键的系统动力学概念是**延迟**：

- **感知延迟**：问题发生后，学生需要时间才能注意到
- **反应延迟**：做出决策后，执行需要时间
- **物理延迟**：供应链的物理过程无法加速

这些延迟叠加产生**牛鞭效应**——需求端的微小波动，沿供应链向上游放大。学生在多轮应急中体验"为什么我总是矫枉过正"。

**系统基模：舍本逐末**
```
问题出现 → 快速治标（紧急采购）→ 问题暂时缓解
                     ↓
              削弱治本能力（建立长期供应商关系）→ 问题更严重
```

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 现金流监控 | 营运资金管理 |
| 应急决策 | 危机管理（Crisis Management） |
| 供应链断裂 | 业务连续性计划（BCP） |
| 随机事件 | 风险管理与情景规划 |
| 多线程操作 | 运营管理与效率优化 |

### 2.3 Mode 03：拍卖交易大厅

#### 经济学原理

**核心：价格发现与信息不对称**

拍卖是**市场机制设计**的经典场景。不同拍卖形式对应不同的价格发现逻辑：

| 拍卖类型 | 经济学原理 | 价格发现机制 |
|----------|-----------|-------------|
| 英式拍卖（公开竞价）| 信息披露动态 | 价格逐步上升，揭示买方估值分布 |
| 荷式拍卖（降价拍卖）| 时间压力 | 第一个接受者暴露其最低可接受价格 |
| 密封一价 | 策略性出价 | 买方有动力隐瞒真实估值（shade bid） |
| 密封二价（Vickrey）| 激励相容 | 说真话是占优策略 |

**收入等价定理**：在一定条件下，四种标准拍卖给卖家的期望收入相同。这解释了为什么平台可以灵活选择拍卖形式而不影响公平性。

**赢者诅咒**（Winner's Curse）：在共同价值拍卖中，最高出价者往往是对价值最乐观的人——如果所有人都理性出价，赢家反而可能亏损。这是拍卖教学中的核心概念。

#### 博弈论结构

**核心：不完全信息博弈 + 贝叶斯纳什均衡**

拍卖是典型的**不完全信息博弈**——每个买方知道自己的估值，但不知道他人的估值。

**贝叶斯纳什均衡**：
```
对每个参与者 i，策略 s_i*(v_i) 是对手策略 s_{-i}* 的最优反应：
s_i*(v_i) = argmax E[u_i(s_i, s_{-i}*(v_{-i})) | v_i]
```

**教学价值**：
- 密封一价拍卖中，最优出价 = 真实估值 × (n-1)/n（n 为竞争者数量）
- 学生通过实践体验"为什么不应该按真实估值出价"

#### 数学模型

**核心：订单簿模型 + 市场微观结构**

交易市场的**深度图**（Depth Chart）模拟了真实金融市场的订单簿：

```
买盘（Bids）：按价格从高到低排列的买入订单
卖盘（Asks）：按价格从低到高排列的卖出订单
价差（Spread）：最低卖价 - 最高买价
```

**价格影响函数**：大额订单会"推动"市场价格——买入量大时，需要接受更高的卖价。这对应**市场冲击成本**（Market Impact Cost）。

#### 系统动力学

拍卖本身是**瞬时均衡**（单轮即出清），但多轮拍卖之间存在**动态关联**：
- 上轮拍卖结果影响本轮预算约束
- 历史成交价格形成**价格锚定**（Anchoring Effect）
- 连胜/连败影响**风险偏好**（前景理论中的参照点依赖）

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 城市广告位拍卖 | 媒体采购（RTB 实时竞价） |
| 技术专利交易 | 知识产权交易与许可 |
| 供应链竞标 | 政府采购、B2B 招标 |
| 订单簿交易 | 股票市场、外汇市场 |

### 2.4 Mode 04：产业链角色扮演

#### 经济学原理

**核心：纵向关系理论与双重边际化**

产业链模拟的底层是**纵向市场结构**。当上游供应商和下游零售商各自拥有市场势力时，会产生**双重边际化**（Double Marginalization）——每层都加价，导致最终价格过高、总利润低于纵向一体化。

**关键经济学概念：**

- **纵向一体化 vs 外包**：学生体验"自己做"vs"买"的权衡
- **转移定价**：供应链内部的定价影响利润分配和税收
- **套牢问题**（Hold-up）：关系专用性投资后，一方可能被另一方要挟

#### 博弈论结构

**核心：多阶段讨价还价博弈 + 合作博弈**

产业链中的谈判对应**纳什讨价还价解**：
```
max (π₁ - d₁) · (π₂ - d₂)
```
其中 d₁, d₂ 是谈判破裂时的外部选项（威胁点）。

**合作博弈中的 Shapley 值**：
当多方可形成联盟时，如何公平分配合作收益？Shapley 值根据每个参与者的**边际贡献**分配：
```
φ_i = Σ_{S⊆N\{i}} [|S|!(|N|-|S|-1)! / |N|!] · [v(S∪{i}) - v(S)]
```

**教学价值**：让学生理解"公平"有多种定义，谈判不仅是分钱，还是分"公平感"。

#### 数学模型

**核心：线性规划（最优合同设计）**

供应链合同可以建模为**约束优化问题**：
```
max 总供应链利润
s.t. 各方参与约束（IR）：各方利润 ≥ 外部选项
     激励相容约束（IC）：各方如实报告信息
```

**合同类型比较**：
| 合同类型 | 数学结构 | 风险分配 |
|----------|----------|----------|
| 批发价合同 | 固定单价 | 零售商承担全部需求风险 |
| 回购合同 | 批发价 + 回购价 | 供应商分担部分库存风险 |
| 收益共享 | 批发价 + 收入分成 | 双方共担风险 |

#### 系统动力学

**核心：供应链牛鞭效应**

```
终端需求波动 → 零售商订单波动 → 批发商订单波动 → 制造商生产波动
        ↑                                                          │
        └──────────────── 信息扭曲逐级放大 ────────────────────────┘
```

学生在产业链中亲身体验：为什么"我只是多订了一点安全库存"，却导致上游工厂产能过剩。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 供应商-制造商谈判 | 采购管理、SRM |
| 合同系统 | 法务与合规 |
| 产业链利润分配 | 价值链分析（Porter） |
| 信息不对称 | 委托-代理问题 |

### 3.1 Mode 05：案例推演决策

#### 经济学原理

**核心：行为经济学与决策理论**

案例推演决策的底层是**行为经济学**——人类不是完全理性的决策者。每个决策点都设计为触发特定的认知偏差：

| 决策陷阱 | 行为经济学概念 | 教学点 |
|----------|--------------|--------|
| 短期利润 vs 长期品牌 | 双曲贴现 | 人们过度低估未来收益 |
| 跟风决策 | 信息级联 | 看到别人的选择后放弃独立思考 |
| 沉没成本 | 禀赋效应 | 已投入的越多，越难放弃 |
| 极端选项 | 框架效应 | 同一问题的不同表述改变选择 |

#### 博弈论结构

**核心：单人决策树 + 道德风险**

案例推演本质上是**扩展式博弈**（Extensive Form Game）——决策有先后顺序，每个决策点引出不同的分支。

```
决策 1
├── 选择 A → 决策 2A
│            ├── 选择 A1 → 结局 X
│            └── 选择 A2 → 结局 Y
└── 选择 B → 决策 2B
             ├── 选择 B1 → 结局 Z
             └── 选择 B2 → 结局 W
```

**逆向归纳**（Backward Induction）：从最终结局倒推，找出最优策略路径。但现实中人们很少这样做——这正是**有限理性**的体现。

#### 数学模型

**核心：决策树 + 期望效用**

每个决策节点计算**期望效用**：
```
EU(选择) = Σ P(结果_i | 选择) × U(结果_i)
```

**信息价值**：
```
EVPI = EU(有完美信息) - EU(当前最优)
```
学生体验"如果我知道未来的确切结果，现在的选择会不同"。

#### 系统动力学

**核心：路径依赖**

```
早期决策 → 锁定效应 → 后续选择空间缩小 → 最终结局被早期决策"锁定"
```

案例推演让学生体验**路径依赖**——"如果当初选 A，3 年后会怎样"的对比，直观展示初始条件的长期影响。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 决策树 | 战略选择分析 |
| 道德两难 | 商业伦理（Business Ethics） |
| 分支结局 | 情景规划（Scenario Planning） |
| 概念锚定 | 复盘与知识内化 |

### 3.2 Mode 06：投资人对决

#### 经济学原理

**核心：金融市场理论与资产定价**

投资人对决的底层是**资本市场理论**。创业者需要理解估值，投资人需要理解风险-收益权衡。

**关键经济学概念：**

- **估值方法**：
  - P/S（市销率）：估值 = 年收入 × 行业倍数
  - DCF（现金流折现）：估值 = Σ 未来现金流 / (1+r)^t
  - 可比公司法：参考同类公司的交易估值
- **风险-收益权衡**：高风险要求高回报（风险溢价）
- **信息不对称**：创业者比投资人更了解公司真实状况——产生**逆向选择**和**道德风险**

#### 博弈论结构

**核心：双边不对称信息博弈 + 拍卖理论**

创业者与投资人的互动是**双边市场**中的匹配博弈：

```
创业者（质量未知）→ 信号传递（路演、数据）→ 投资人推断质量 → 出价
```

**信号传递均衡**：高质量创业者有动力发送"高质量信号"（如投入更多自有资金），因为低质量创业者无法模仿（**分离均衡**）。

**Term Sheet 谈判**是**多议题谈判**——同时谈判估值、股权比例、董事会席位、反稀释条款等。各议题之间存在**权衡空间**（logrolling），为创造性协议提供可能。

#### 数学模型

**核心：CAPM + 期权定价思想**

投资组合理论使用**均值-方差优化**：
```
min σ_p² = Σ w_i²σ_i² + ΣΣ w_iw_jσ_iσ_jρ_ij
s.t. E[R_p] = R_target
```

**实物期权思维**：
- 投资早期项目 = 购买看涨期权
- 分期投资（里程碑式）= 复合期权
- 放弃权 = 看跌期权

#### 系统动力学

**核心：融资轮次的累积效应**

```
种子轮 → 天使轮 → A轮 → B轮 → IPO
   ↓        ↓       ↓      ↓      ↓
估值上升  股权稀释  对赌压力  增长要求  退出预期
```

每轮融资改变公司的资本结构、治理结构和战略自由度——早期决策对后期产生路径依赖。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 路演评分 | Pitch Deck 设计 |
| 估值计算 | VC/PE 投资分析 |
| Term Sheet | 投资协议条款 |
| 组合管理 | 基金管理（Portfolio Management） |

### 3.3 Mode 07：创业生存战

#### 经济学原理

**核心：现金流理论与破产成本**

创业生存战的底层是**财务困境理论**。现金流断裂即出局，对应**破产清算**的现实逻辑。

**关键经济学概念：**

- **经营杠杆**：固定成本占比高 → 销量波动对利润影响大
- **财务杠杆**：负债经营 → 利息压力加速现金流消耗
- **破产成本**：直接成本（法律费用）+ 间接成本（客户流失、供应商收紧信用）
- **跑道计算**：Runway = 现金余额 / 月度净消耗

#### 博弈论结构

**核心：生存博弈（War of Attrition）**

创业生存战是**消耗战**——不是比谁更强，而是比谁更能坚持。

```
类型：多参与者、连续时间、不完全信息、零和（生存名额有限）
策略空间：成本控制、融资、收入提升、战略转型
信息结构：知道自己的现金流，只能观察对手的外在表现
```

**关键洞察**：在消耗战中，**承诺的可信度**至关重要。如果对手相信你会坚持到最后，他们可能提前退出。

#### 数学模型

**核心：破产预测模型（Altman Z-Score）**

```
Z = 1.2X₁ + 1.4X₂ + 3.3X₃ + 0.6X₄ + 1.0X₅

X₁ = 营运资金 / 总资产
X₂ = 留存收益 / 总资产
X₃ = EBIT / 总资产
X₄ = 市值 / 负债账面值
X₅ = 销售额 / 总资产
```

Z < 1.81：破产风险高
Z > 2.99：财务状况良好

#### 系统动力学

**核心：死亡螺旋**

```
现金流紧张 → 削减投入 → 产品质量下降 → 客户流失 → 收入下降 → 现金流更紧张
         ↑___________________________________________________________|
```

这是典型的**增强回路往反方向运行**——"坏的越坏"。学生体验为什么"节流"有时比"开源"更紧迫。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 现金流监控 | 财务规划与分析（FP&A） |
| 裁员决策 | 组织重构（Restructuring） |
| 紧急融资 | 过桥贷款（Bridge Loan） |
| Pivot 转型 | 战略转型（Strategic Pivot） |

### 3.4 Mode 08：宏观经济沙盘

#### 经济学原理

**核心：宏观经济学与政策传导机制**

宏观经济沙盘的底层是**IS-LM 模型**和**AD-AS 模型**的简化版。

**关键经济学概念：**

- **货币政策传导**：央行利率 → 银行贷款利率 → 企业投资 → GDP
- **财政政策乘数**：政府支出增加 → 收入增加 → 消费增加 → 进一步收入增加
- **菲利普斯曲线**：失业率与通胀率的短期权衡
- **汇率决定**：利率平价、购买力平价、国际收支

#### 博弈论结构

**核心：政策博弈（Policy Game）**

央行（或政府）与企业之间的互动是**斯塔克尔伯格博弈**（Stackelberg Game）——央行先行动（宣布政策），企业后行动（调整经营策略）。

```
央行选择政策 → 企业观察政策 → 企业选择产量/价格
     ↑___________________________________|
              （央行预期企业反应，选择最优政策）
```

**时间不一致性问题**：央行今天承诺低通胀，但明天有动力制造意外通胀来刺激就业——这解释了为什么**央行独立性**如此重要。

#### 数学模型

**核心：动态随机一般均衡（DSGE）的简化版**

宏观经济沙盘使用**差分方程**模拟经济周期：
```
GDP_t = c + α·GDP_{t-1} + β·Policy_t + γ·Shock_t + ε_t
```

**政策冲击的滞后效应**：
- 货币政策：6-18 个月传导至实体经济
- 财政政策：3-12 个月传导
- 汇率政策：即时影响进出口，但 J 曲线效应（先恶化后改善）

#### 系统动力学

**核心：经济周期的内生产生**

```
繁荣 → 通胀上升 → 央行加息 → 投资下降 → 衰退
  ↑                                              ↓
  └──────── 央行降息 → 投资回升 → 复苏 ──────────┘
```

经济周期不需要外部冲击就能产生——这是系统内部反馈回路的结果。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 利率调控 | 央行货币政策 |
| 财政刺激 | 政府预算与基建投资 |
| 汇率政策 | 国际贸易与资本流动 |
| 经济周期 | 行业周期分析 |

### 4.1 Mode 09：ESG可持续经营

#### 经济学原理

**核心：外部性理论与公共品**

ESG 的底层是**市场失灵**——企业污染环境、损害员工权益时，成本由社会承担（负外部性），但企业不承担。ESG 机制试图**内部化外部性**。

**关键经济学概念：**

- **外部性内部化**：通过碳税、排放权交易，让污染者承担成本
- **公共品问题**：清洁空气、社会信任是**非排他性**的——市场供给不足
- **三重底线（TBL）**：利润（Profit）、人（People）、地球（Planet）
- **利益相关者理论**：企业应对所有利益相关者负责，而非仅对股东

#### 博弈论结构

**核心：公地悲剧与自愿贡献博弈**

ESG 投资是**公共品供给**——一家企业投入环保，所有企业都受益（行业声誉提升），但投入者单独承担成本。

```
        企业 B
    投资 ESG    不投资
   ┌─────────┬─────────┐
投 │ (8, 8)  │ (3, 10) │
资 ├─────────┼─────────┤
不 │ (10, 3) │ (5, 5)  │
投 └─────────┴─────────┘
```

**（不投资，不投资）是纳什均衡**，但（投资，投资）对双方都更好——这正是**囚徒困境**的结构。

**解决机制**：
- **监管**：政府强制要求 ESG 披露
- **声誉**：ESG 表现好的企业获得消费者溢价
- **金融**：ESG 基金只投资高评分企业，降低其融资成本

#### 数学模型

**核心：多目标优化**

ESG 决策是**多目标优化问题**：
```
max [Profit, E_score, S_score, G_score]
s.t. Profit ≥ Profit_min
```

**帕累托前沿**：不存在一个解同时在所有维度上最优——必须在利润和 ESG 之间权衡。

#### 系统动力学

**核心：长期 vs 短期的冲突**

```
短期压力（股东要求回报）→ 削减 ESG 投入 → 短期利润上升
                                    ↓
                              长期声誉受损 → 客户流失 → 长期利润下降
```

这是**成长上限**基模的变体——短期优化削弱长期竞争力。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| ESG 评分 | MSCI ESG 评级、Sustainalytics |
| 伦理困境 | 企业社会责任（CSR）决策 |
| 可持续报告 | GRI 标准、SASB 标准 |
| SDGs 映射 | 联合国可持续发展目标 |

### 4.2 Mode 10：跨国贸易博弈

#### 经济学原理

**核心：国际贸易理论与汇率经济学**

跨国贸易的底层是**比较优势理论**和**汇率决定理论**。

**关键经济学概念：**

- **比较优势**：即使一国在所有产品上都比另一国强，双方仍可通过专业化分工获益
- **赫克歇尔-俄林模型**：各国出口密集使用其丰裕要素的产品
- **汇率决定**：
  - 购买力平价（PPP）：长期汇率趋向于使相同商品在不同国家价格相同
  - 利率平价：高利率货币远期贬值
  - 国际收支：贸易顺差 → 本币升值压力
- **关税与贸易壁垒**：关税提高进口品价格，保护国内产业但损害消费者福利

#### 博弈论结构

**核心：贸易战博弈 + 协调博弈**

国家之间的贸易政策是**重复博弈**：
```
        国家 B
    自由贸易   保护主义
   ┌─────────┬─────────┐
自 │ (10,10) │ (2, 12) │
由 ├─────────┼─────────┤
保 │ (12, 2) │ (5, 5)  │
护 └─────────┴─────────┘
```

**（保护主义，保护主义）是纳什均衡**，但（自由贸易，自由贸易）对双方都更好——这是**囚徒困境**在国际贸易中的应用。

**WTO 的作用**：通过规则将博弈从一次性变为重复博弈，使**以牙还牙策略**（合作直到对方背叛）成为均衡。

#### 数学模型

**核心：汇率风险管理**

**远期汇率**（Covered Interest Parity）：
```
F = S × (1 + r_d) / (1 + r_f)
```
其中 F 是远期汇率，S 是即期汇率，r_d 是本币利率，r_f 是外币利率。

**风险敞口计算**：
```
外汇风险 = 外币资产 - 外币负债
对冲比率 = 远期合约金额 / 外汇风险
```

#### 系统动力学

**核心：J 曲线效应**

```
本币贬值 → 进口品本币价格上升 → 贸易逆差扩大（短期）
                                    ↓
                              出口竞争力提升 → 出口增加
                                    ↓
                              进口需求下降 → 贸易逆差缩小（长期）
```

贬值对贸易收支的影响先恶化后改善，形成"J"形曲线。

#### 商业知识映射

| 模拟机制 | 真实商业场景 |
|----------|-------------|
| 汇率波动 | 外汇风险管理（Hedging） |
| 关税计算 | 国际贸易合规 |
| 文化维度 | 跨文化管理（Hofstede） |
| 贸易谈判 | 国际商务谈判 |

## 六、教学转化建议

### 6.1 原理揭示的时机

遵循"**体验先行，概念锚定**"的原则：

```
课前：不告知原理，让学生直接体验
  ↓
课中：学生在模拟中自然遭遇经济学现象
  ↓
课后复盘：教师指出"你刚才体验到的，就是____"
  ↓
概念深化：给出公式/模型，让学生用数学语言重新理解自己的决策
  ↓
迁移应用：讨论现实中哪些场景存在同样的结构
```

### 6.2 跨模式学习路径

建议学生按以下路径体验，逐步提升原理复杂度：

```
入门路径（初中+）：
  02 实时经营 → 01 回合制策略 → 03 拍卖交易
  体验：供需、成本、价格发现

进阶路径（高中+）：
  04 角色扮演 → 07 创业生存 → 05 案例推演
  体验：博弈、风险、伦理决策

高阶路径（大学+）：
  06 投资人对决 → 08 宏观经济 → 09 ESG经营 → 10 跨国贸易
  体验：估值、周期、可持续性、全球化
```

### 6.3 教师引导话术模板

| 学生体验 | 教师锚定话术 |
|----------|-------------|
| "我投了技术但效果越来越差" | "你体验到了边际效用递减——这是经济学最核心的规律之一" |
| "我和对手都降价，结果都亏了" | "这就是囚徒困境——个体理性导致集体非理性" |
| "我的广告效果总是延迟出现" | "这是系统动力学的时间延迟——商业世界不是即时的" |
| "我不知道对手会怎么做，很难决策" | "你面对的就是不完全信息博弈——信息本身具有战略价值" |
| "现金流一断，什么都没了" | "这就是财务杠杆的双刃剑——放大收益也放大风险" |

## 七、结语

十种商赛形式不是孤立的"游戏"，而是一个**层次递进、原理贯通**的商业素养训练体系：

- **基础层**（01-04）：训练微观经济学直觉——供需、成本、价格、博弈
- **进阶层**（05-08）：训练决策科学——不确定性、风险、周期、估值
- **高阶层**（09-10）：训练系统思维——可持续性、全球化、长期价值

每一种形式的底层都扎根于严谨的经济学理论和数学模型，但学生不需要先学会这些理论才能参与。恰恰相反，**模拟是土壤，理论是阳光**——学生在模拟中自发成长，教师在复盘时提供阳光，让经验升华为理解。

> **最终目标**：不是让学生记住"什么是纳什均衡"，而是让他们在真实商业决策中，本能地问出"如果对手也这么想，均衡在哪里？"
