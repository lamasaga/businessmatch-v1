# 02 - 小学高段（10-12岁）：财商启蒙模块

> 孩子不是"小大人"。他们对抽象概念的理解有限，但对故事、角色、具体情境的代入感极强。本模块将商业概念嵌入生活故事，让孩子在"玩商店"的过程中自然建立财商直觉。

---

## 一、模块总览

| 项目 | 内容 |
|------|------|
| **目标学段** | 小学五-六年级 |
| **总课时** | 16课时（每课时40分钟） |
| **单元数** | 8个单元 |
| **核心理念** | "商业就在生活中" |
| **教学风格** | 故事驱动、角色扮演、具象操作 |
| **平台模式** | 剧情模式（PVE）为主，2-3轮简化对局 |
| **数学工具** | 加减乘除、简单百分比、图表读取 |

## 二、8个单元设计

### 单元1： lemonade 小镇的开业日

**主题**：成本意识（FL-1）

**故事情境**：
> 你和小明在暑假开了一家柠檬水摊。妈妈给了你们 50 元启动资金。你们需要买柠檬、糖、纸杯。一杯柠檬水卖 3 元。第一天结束了，你们数了数：卖了 20 杯，收入 60 元。赚了吗？

**模拟体验（平台）**：
- 规则模板：`lemonade_stand_v1`
- 单城市（杭州）、单属性（Show/摊位装修）
- 2轮：第一轮采购定价，第二轮销售结算
- 核心操作：选择原料品质（高/中/低）→ 设定价格 → 选择摊位位置

**概念锚定**：
- 成本 = 原料钱 + 时间精力
- 收入 = 价格 × 销量
- 利润 = 收入 - 成本

**教学活动**：
1. 情境导入（5分钟）： lemonade 摊位视频
2. 模拟体验（15分钟）：平台操作 2 轮
3. 概念讲解（10分钟）：用真实账本演示成本收入利润
4. 小组讨论（10分钟）："为什么小明卖 5 元一杯反而赚得少？"

**评估**：
- 能否正确计算自己摊位的利润？
- 能否说出"卖得贵不等于赚得多"？

---

### 单元2：小镇集市大比拼

**主题**：供需关系（ML-1）

**故事情境**：
> 今天是小镇集市日。有 5 家 lemonade 摊位。天气特别热，大家都想喝 lemonade。但如果突然下雨呢？如果隔壁来了卖奶茶的呢？

**模拟体验**：
- 规则模板：`market_fair_v1`
- 引入"天气"事件（晴天/阴天/雨天）
- 引入"竞争对手数量"变化
- 核心操作：根据天气预测调整产量和价格

**概念锚定**：
- 晴天 → 需求高 → 可以涨价、多备货
- 雨天 → 需求低 → 需要降价或减少产量
- 竞争者多 → 需要差异化（更甜？更冰？）

**教学活动**：
1. 情境导入（5分钟）：讨论"为什么暑假冰淇淋涨价？"
2. 模拟体验（15分钟）：经历晴天→雨天→竞争对手进入
3. 概念讲解（10分钟）：供需曲线（用跷跷板比喻）
4. 应用练习（10分钟）：预测下周天气，制定策略

---

### 单元3：分工合作效率高

**主题**：交换与分工（CL-1）

**故事情境**：
> 你们小组 4 个人。有人擅长切柠檬（快），有人擅长招呼客人（嘴甜），有人擅长算账（细心），有人擅长装饰摊位（有创意）。如果每个人都做所有事，和分工合作，哪个更好？

**模拟体验**：
- 规则模板：`division_of_labor_v1`
- 4人一队，每人选一个角色：采购员/制作员/销售员/财务员
- 不同角色看到不同信息，必须交流才能做决策
- 第一轮：不分角色，每人独立做全部决策
- 第二轮：分角色，协作决策
- 对比两轮结果

**概念锚定**：
- 比较优势：哪怕你什么都比别人强，分工仍然让你更富
- 交易成本：分工需要沟通，沟通也有成本

---

### 单元4：储蓄还是消费？

**主题**：时间价值（FL-4）

**故事情境**：
> 你赚了 100 元。妈妈说你可以选择：现在花掉买玩具，或者存起来明年夏天买更贵的游戏机。怎么选？

**模拟体验**：
- 规则模板：`save_or_spend_v1`
- 每轮获得收入，选择消费（立即获得 happiness 点数）或储蓄（获得利息）
- 第 4 轮有一个"大机会"（买设备），需要足够储蓄
- 纯消费的学生错过机会；纯储蓄的学生前期 happiness 低

**概念锚定**：
- 现在的满足 vs 未来的更大满足
- 利息是"等待的奖励"
- 平衡：不是完全不消费，也不是完全不享受

---

### 单元5：我的顾客是谁？

**主题**：消费者视角（ML-2）

**故事情境**：
> 小镇上有三种人：小朋友（喜欢甜甜的）、大人（喜欢健康的）、老人（喜欢便宜的）。你的 lemonade 只能主打一种，还是都能满足？

**模拟体验**：
- 规则模板：`customer_types_v1`
- 引入三种消费者群体（对应 Geek/Pragmatic/Trendy 的简化版）
- 学生通过"市场调研"（投入少量预算）了解各群体偏好
- 决策：产品定位（甜/健康/便宜）→ 定价 → 宣传

**概念锚定**：
- 不是"我觉得好"，而是"顾客觉得好"
- 不同人群需求不同，不能讨好所有人
- 市场调研的价值：花小钱避免大错误

---

### 单元6：小镇上的竞争

**主题**：竞争意识（ML-3）

**故事情境**：
> 你的 lemonade 很受欢迎。但隔壁新开了一家，他们的杯子上有卡通图案，还放音乐。你怎么办？也放音乐？还是做别的不一样？

**模拟体验**：
- 规则模板：`competition_v1`
- 学生可以选择：模仿对手 / 差异化（做更健康的 lemonade） / 降价
- 不同选择有不同的风险和回报
- 引入"蓝海"概念：找到没人做的空白点

**概念锚定**：
- 模仿：安全但平庸
- 差异化：有风险但可能有高回报
- 降价：简单但伤害利润

---

### 单元7：公平交易

**主题**：公平竞争（EL-1）

**故事情境**：
> 有人建议你在 lemonade 里多加香精，让它闻起来更香，但标签不写。这样能卖得更好。你会做吗？

**模拟体验**：
- 规则模板：`fair_play_v1`
- 引入"诚信选择"：可以虚假宣传获得短期销量，但有概率被"曝光"
- 曝光后品牌信誉归零，多轮才能恢复
- 对比：诚信经营 vs 投机经营的长短期结果

**概念锚定**：
- 短期欺骗可能赚钱，长期信任才有生意
- 规则的意义：保护诚实的人
- 商业伦理不是"高尚"，而是"可持续"

---

### 单元8：我的商业计划书

**主题**：综合应用

**故事情境**：
> 学期结束了。你要向"小镇商业协会"（班级）展示你的商业故事：你做了什么决策？学到了什么？如果再来一次你会怎么做不同？

**活动设计**：
- 学生用平台"个人编年史"功能回顾整个学期的决策轨迹
- 制作 3 分钟"我的商业故事"演讲
- 同学投票：最佳创意 / 最佳策略 / 最佳团队 / 最佳进步

**评估**：
- 能否用简单语言解释一个商业概念？
- 能否从自己的失败中提取教训？
- 能否给新同学一条建议？

## 四、教师注意事项

### 4.1 语言转换

| 专业术语 | 课堂用语 |
|----------|----------|
| 供需关系 | "东西多便宜，东西少贵" |
| 边际效用 | "第一杯最好喝，第五杯不想喝" |
| 机会成本 | "选了 A 就不能选 B，B 就是你放弃的东西" |
| 沉没成本 | "电影票买了不好看，要不要走？" |

### 4.2 情绪管理

- 小学生对"输"的耐受度低，强调"体验"而非"排名"
- 每轮结束先问"你发现了什么？"而非"你排第几？"
- 允许"反悔"：第二轮可以调整策略，体验"学习"的价值

---

> **核心目标**：让孩子带着"商业很有趣，而且我能理解"的感觉离开课堂，而不是"商业很难，我学不懂"的挫败感。
