# 商业模拟教育平台 · 生涯模式与激励闭环

> **文档定位**：定义注册用户在**生涯模式**下如何通过五域活动获得**积分（XP）、排名、成就与奖励**，并构成与学习、竞赛、反馈相连的有机机制。

         ┌──────────┬───────────┼───────────┬──────────┐
         ▼          ▼           ▼           ▼          ▼
    ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐

    └────────┘ └────────┘ └────────┘ └────────┘ └────────┘
         ▲          ▲           ▲           ▲          ▲
         └──────────┴───────────┴───────────┴──────────┘

              Atlas │ Academy │ Quest │ Arena │ Credenti

### 1.1 四类激励的定位

| 类型 | 作用 | 心理驱动 | 重置周期 |
|------|------|----------|----------|
| **XP / 等级** | 纵向成长、解锁技能（信息类） | 进步感、精通感 | 永久累积 |
| **排名** | 横向比较、赛季荣誉 | 社会比较、竞技 | 周/月/赛季 |
| **成就** | 行为标签、探索收集 | 完成感、身份认同 | 永久 |
| **奖励** | 物质/权益（皮肤、通行证、证书） | 外在激励 | 活动/赛季 |

　　**叙事（第五维）**不直接兑换，但驱动长期留存：AI 将上述数据合成「商业探索故事」章节。

## 二、生涯开启流程

### 2.1 注册 → 生涯仪式

| 步骤 | 系统行为 | 用户感知 |
|------|----------|----------|
| 1 | `POST /auth/register` 创建 User | 账号创建 |
| 2 | 选择学段、昵称、头像 | 基础资料 |
| 3 | （可选）Persona 简测 8～12 题 | 「发现你的商业风格」 |
| 4 | `POST /career/start` 创建 CareerProfile | 动画：开启「第 1 赛季」 |
| 5 | **Athena** 生成 `career_plan_week1` 并对话确认 | AI 教师首次见面 |
| 6 | 发放新手包：100 XP + 徽章「启程者」+ 3 日 Quest 引导 | 明确下一步 |

### 2.2 生涯主页信息架构

| 区块 | 数据 |
|------|------|
| 头部 | 等级称号、赛季剩余天数、总 XP |
| 今日 | Quest 进度条、推荐 1 课 + 1 局 |
| 能力 | 五维雷达（财务/市场/战略/协作/伦理） |
| 图谱 | 已点亮节点数 / 48 |
| 社交 | 班级排名、公会贡献 |
| 故事 | 最新叙事摘要 + 「查看全章」 |

## 三、XP（积分）经济

### 3.1 XPEvent 数据结构

```yaml
xp_event:
  id: uuid
  career_id: string
  source_type: enum  # graph | academy | quest | arena | credenti | admin | social
  source_id: string   # 幂等键，如 match_id + user_id
  amount: int
  multiplier: float   # 活动加成，默认 1.0
  metadata:
    knowledge_nodes: []
    competency_tags: []
  created_at: datetime
```

### 3.2 XP 获取矩阵（默认权重，可配置）

| 行为 | 域 | XP | 备注 |
|------|-----|-----|------|
| 掌握知识节点（测验≥70%） | Atlas | 30–80 | 按 L1/L2/L3 递增 |
| 完成课程单元 | Academy | 50–150 | 依测验成绩线性 |
| 完成每日 Quest | Quest | 20–40 | 含 streak 加成 |
| 完成每周挑战 | Quest | 100 | 班级协作类更高 |
| 完成标准商赛对局 | Arena | 100–300 | 参与即有基础分 |
| 对局前三名 | Arena | +100 | 叠加 |
| 提交决策并附理由 | Arena | +20 | 鼓励 metacognition |
| 首次体验新赛制 | Arena | +50 | 探索奖励 |
| 教师评优 | Academy | +30 | 需教师端触发 |
| 解锁成就 | Credenti | 10–50 | 视稀有度 |
| 连续登录 streak | Quest | 10×天数 | 上限 7 日封顶加成 |

### 3.3 防沉迷与反刷

| 规则 | 说明 |
|------|------|
| 日软上限 | 超过 800 XP 后收益 ×0.5，超过 1200 后 ×0.25 |
| 幂等 | 同一 `source_id` 仅记账一次 |
| 异常检测 | 短时重复对局、脚本决策 → Ethos 标记 |
| 家长控制 | 可选每日游戏时长提醒（小程序） |

### 3.4 等级曲线（示例）

| 等级 | 累计 XP | 称号 |
|------|---------|------|
| 1–5 | 0–500 | 商业学徒 |
| 6–15 | 500–3000 | 市场行者 |
| 16–30 | 3000–12000 | 策略分析师 |
| 31–50 | 12000–40000 | 商业策划师 |
| 51+ | 40000+ | 商业领袖（赛季 Legacy 可继承前缀） |

## 四、排名体系

### 4.1 多榜并存（避免单一「分数至上」）

| 榜单 | 范围 | 排序依据 | 重置 |
|------|------|----------|------|
| **赛季 XP 榜** | 班级 / 校 / 国 | 当季 XP 增量 | 每学期 |
| **竞技榜** | 班级 / 校 | 排位赛 ELO 或积分 | 每月 |
| **协作榜** | 班级 | 公会 Quest 贡献、队友点赞 | 每周 |
| **探索榜** | 校 | 图谱覆盖率、新赛制体验数 | 赛季 |
| **成长榜** | 班级 | 五维能力「相对提升」而非绝对值 | 每月 |

　　**成长榜**对齐 `12-`「评价革命」：奖励「比昨天的自己进步」，缓解失败者挫败感。

### 4.2 排名与公平性分级

| 对局类型 | 局外技能/加成 | 上榜 |
|----------|---------------|------|
| 教学对局（课程内） | 允许信息类技能 | 不计入竞技榜 |
| 班级练习 | 允许 | 仅班级娱乐榜 |
| 排位赛 | 仅 cosmetic | 竞技榜 |
| 校际联赛 | 强制平等 | 全国榜 |

## 五、成就系统（Credenti 子集）

### 5.1 成就分类

| 类别 | 示例 | 触发 |
|------|------|------|
| 路线专精 | 「产业链老手」 | 某赛制获胜 N 次 |
| 行为标签 | 「逆风翻盘」 | 末位回合后夺冠 |
| 学习 | 「图谱开拓者」 | 点亮 L3 节点 5 个 |
| 社交 | 「金牌队友」 | 队友点赞 ≥10 |
| 伦理 | 「诚信先锋」 | Ethos 分持续优秀 |
| 隐藏 | 「深渊凝视者」 | 静默策略室特殊条件 |

### 5.2 成就与图谱/课程联动

　　成就条件可引用 `81-素养-赛制-知识映射表`：

- 完成「供需关系」节点 + 回合制商赛盈利 → 解锁「价格机制实践者」
- 完成 NEC 真题训练包 → 解锁「经济学挑战者」

## 七、五域 → 激励的具体闭环

### 7.1 Atlas（知识图谱）

```
学习节点 → 测验 → mastery 更新 → xp_event(graph)
    → 若 mastery≥80% → 推荐 Academy 单元（Mercury）
    → 若关联赛制已解锁 → Arena 练习赛推荐
```

### 7.2 Academy（课程）

```
选课 → 微课/模拟/测验 → unit_progress.completed
    → xp_event(academy) + 素养维度更新
    → 触发 Credenti 微证书进度
    → 单元绑定的 game_mode_id → 自动创建教学对局
```

### 7.3 Quest（日常）

```
每日 0:00 生成 QuestInstance → 用户完成 → claim
    → xp_event(quest) + streak 更新
    → 班级公会进度 → 全班奖励（可选）
```

### 7.4 Arena（商赛）

```
匹配/建房 → 多轮决策 → CyberCore 结算
    → decision_logs 入库 → xp_event(arena) + ELO
    → 异步：Athena debrief 任务
    → Apollo 更新能力雷达
    → 推送薄弱 knowledge_nodes（Atlas）
```

### 7.5 Credenti（认证）

```
条件满足 → badge.earned 事件 → xp_event(credenti)
    → 生涯主页展示 → 分享卡片（裂变）
    → 高阶认证需 L4 项目 + EX 考试（13- L5）
```

## 八、反馈机制（闭环的「馈」）

| 反馈层 | 时机 | 内容 | 负责 |
|--------|------|------|------|
| 生涯层 | 开启生涯 / 每 2 周 | 周计划、目标调整、鼓励语 | **Athena** |
| Quest 后 | 每日任务完成 | 2 问轻反思 + 与图谱关联 | **Athena** |
| 即时 | 决策提交后 | 规则提示、Ethos 提醒；排位局**无**策略陪跑 | Arena + Ethos |
| 局内环境 | POP 反应回合 | 人群满意度变化 + 舆情短讯 | **Demia** |
| 练习中 | 谈判轮次 | Rival 对话与成交条款 | **Rival** |
| 局末 | 结算完成 | 排名、维度得分、POP/对手摘要 | CyberCore |
| 赛后 24h 内 | 异步 | 商赛结构化复盘 + 可选导师对话 | **Athena** |
| 周期 | 每周 | 成长叙事段落 | Athena + Narrative |
| 学期 | 教师 | Rubric 评价、家长报告 | Apollo + 教师端 |

### 8.1 复盘 Prompt 原则（Athena）

- 引用学生**自己的决策理由**与 **Rival 谈判记录**（如有），不对抗
- 关联 1～2 个**图谱节点**复习链接
- 对 Demia 事件解释「哪类 POP 被哪项决策影响」
- **禁止**给出下一轮最优数值答案

　　完整 AI 能力定义见 [05-AI深度融合设计.md](./05-AI深度融合设计.md)。

## 九、Legacy（跨赛季遗产）

　　解决 `12-`「孤岛效应」：赛季结束不「清零人格」，而是：

| 遗产项 | 规则 |
|--------|------|
| 叙事章节 | 永久保留，可导出 PDF |
| 称号前缀 | 上赛季最高称号显示为「S1 策略分析师 · 」 |
| 成就 | 永久 |
| 等级 | 软重置：保留 70% XP 折算为新赛季起点 |
| 竞技 ELO | 软重置：向均值回归 30% |

## 十、与性格、伦理的交叉

| 系统 | 激励侧集成 |
|------|------------|
| **Persona** | 推荐赛制完成 → 成就「性格探索者」；不匹配赛制无惩罚，仅低 XP 加成 |
| **Ethos** | 作弊扣 XP、禁榜；诚信分高 → 伦理徽章与协作榜加权 |
| **16- 道德规则** | 特定赛制（ESG、案例推演）伦理维度占评分 20%+ |
