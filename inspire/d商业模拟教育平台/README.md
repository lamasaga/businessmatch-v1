## 三、30 秒电梯陈述

　　一位注册学生在平台上**开启生涯模式**后，由 **Athena** 规划每周路径；在**知识图谱、课程、日常 Quest、商赛** 五域中积累 XP 与资源；五域汇入 **Career Hub**（大循环见根目录 **[06-生涯模式](../../06-生涯模式-大循环家园与资源经济.md)**），形成「学 → 练 → 赛 → 证 → 馈」闭环。
