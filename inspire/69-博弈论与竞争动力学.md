# 19 - 博弈论与竞争动力学

> 商业不是一个人在战斗。你的最优策略取决于对手做什么，对手的最优策略取决于你做什么。博弈论就是研究这种"策略互动"的数学语言。

---

## 一、博弈论的基本结构

### 1.1 任何博弈都包含四个要素

```
┌─────────────────────────────────────────┐
│  参与者（Players）                       │
│  └── 谁在做决策？                         │
├─────────────────────────────────────────┤
│  策略空间（Strategy Space）               │
│  └── 每个人能选择什么？                    │
├─────────────────────────────────────────┤
│  收益函数（Payoff Function）              │
│  └── 每种策略组合下，每个人得到什么？       │
├─────────────────────────────────────────┤
│  信息结构（Information Structure）        │
│  └── 每个人知道什么？什么时候知道？         │
└─────────────────────────────────────────┘
```

**与 TechVenture 的映射**：
| 博弈要素 | TechVenture 对应 |
|----------|-----------------|
| 参与者 | 各参赛队伍 |
| 策略空间 | 路线选择 × 城市选择 × 预算分配 |
| 收益函数 | 结算引擎（Attention / 排名） |
| 信息结构 | 同时决策（sealed bid），部分信息公开 |

### 1.2 博弈的分类

```
博弈
├── 按参与者利益关系
│   ├── 零和博弈（一方所得 = 另一方所失）
│   ├── 常和博弈（总收益固定）
│   └── 变和博弈（总收益可变，可合作做大蛋糕）
│
├── 按决策时序
│   ├── 静态博弈（同时决策）
│   └── 动态博弈（轮流决策，后决策者观察到先决策者的行动）
│
├── 按信息完全度
│   ├── 完全信息（所有人知道所有规则和他人的收益）
│   ├── 不完全信息（存在私有信息）
│   └── 不完美信息（行动历史不完全可观察）
│
└── 按合作可能性
    ├── 非合作博弈（无法达成有约束力的协议）
    └── 合作博弈（可以结盟、分配收益）
```

**TechVenture 的定位**：不完全信息的静态非合作博弈（变和）。这是最接近真实商业竞争的类型，也是理论上最难分析和教学的。

## 二、核心概念：纳什均衡

### 2.1 定义

在纳什均衡中，每个参与者的策略都是对其他参与者策略的**最优反应**。

```
策略组合 (s₁*, s₂*, ..., s_n*) 是纳什均衡，当且仅当：
对于每个参与者 i：
    u_i(s_i*, s_{-i}*) ≥ u_i(s_i, s_{-i}*)   对所有 s_i 成立
```

通俗地说：**没有人有动力单独改变策略**。

### 2.2 经典案例：囚徒困境

```
                玩家 B
            合作        背叛
        ┌─────────┬─────────┐
  合作  │ (-1,-1) │ (-3, 0) │
玩家 A  ├─────────┼─────────┤
  背叛  │ (0, -3) │ (-2,-2) │
        └─────────┴─────────┘
```

**分析**：
- 对 A 来说，无论 B 选什么，"背叛"都比"合作"好（0 > -1，-2 > -3）
- 对 B 来说，同样
- 所以（背叛，背叛）是唯一的纳什均衡
- 但（合作，合作）对双方都更好——**个体理性导致集体非理性**

**教学价值**：
- 价格战：两家公司都降价 → 利润都受损
- 广告军备竞赛：都增加广告投入 → 市场份额不变，成本上升
- 让学生理解：为什么"理性"的个体行为会产生"非理性"的集体结果

### 2.3 协调博弈

```
                玩家 B
            策略 X    策略 Y
        ┌─────────┬─────────┐
  策略 X │ (2, 2)  │ (0, 0)  │
玩家 A   ├─────────┼─────────┤
  策略 Y │ (0, 0)  │ (1, 1)  │
        └─────────┴─────────┘
```

两个纳什均衡：（X,X）和（Y,Y）。前者对双方都更好，但如果没有协调机制，可能陷入（Y,Y）。

**教学价值**：标准制定、平台竞争（如 VHS vs Betamax）、为什么"先行者优势"重要。

## 三、商业竞争中的博弈模型

### 3.1 价格竞争：伯特兰悖论

两家企业生产同质产品，同时定价。

```
需求规则：消费者买价格最低的产品
均衡：P₁ = P₂ = c（边际成本）
```

**悖论**：只要有两家企业，利润就为零——这与现实不符。

**解释与现实修正**：
- **产品差异化**（Hotelling 模型）：消费者不仅看价格，还看产品匹配度
- **产能约束**（Edgeworth 模型）：低价者无法满足全部需求
- **重复博弈**：今天降价引发明天报复，维持高价成为均衡

### 3.2 产量竞争：古诺模型

企业选择产量，市场出清价格由总产量决定。

```
双寡头均衡：q₁* = q₂* = (a - c) / 3b
总产量：Q* = 2(a-c)/3b
均衡价格：P* = (a + 2c) / 3
每家利润：π* = (a-c)² / 9b
```

与垄断比较（产量 (a-c)/2b，价格 (a+c)/2）：
- 寡头总产量更高，价格更低
- 但高于完全竞争（产量 (a-c)/b，价格 c）

**教学价值**：让学生计算"如果只有我们两家合作限制产量，利润会增加多少"——体验卡特尔的不稳定性。

### 3.3 差异化竞争：Hotelling 线性城市

消费者均匀分布在 [0,1] 线段上，两家企业分别位于 a 和 b。

```
无差异消费者位置 x：
p₁ + t·|x - a| = p₂ + t·|x - b|

市场份额：
D₁ = x,  D₂ = 1 - x
```

**均衡结果**：如果企业可以自由选址，它们会选择线段两端（最大差异化）。

**与 TechVenture 的连接**：
- PATHFINDER 路线的"独占红利"本质上是 Hotelling 差异化的收益
- 当太多队伍挤入同一路线（差异化消失），利润被竞争侵蚀

## 四、不完全信息博弈

### 4.1 海萨尼转换（Harsanyi Transformation）

将不完全信息转化为"自然先行动，决定参与者的类型"。

```
自然以概率 p 赋予玩家 A "高成本"类型，概率 (1-p) "低成本"类型
玩家 A 知道自己的类型，玩家 B 不知道，但知道概率分布
```

**商业应用**：进入威慑博弈
-  incumbent（在位者）可能是"强硬型"（高成本也要反击）或"软弱型"
-  entrant（进入者）不知道类型，必须根据观察到的行为推断
-  这就产生了**信号传递**和**声誉**的价值

### 4.2 拍卖理论

拍卖是不完全信息博弈的经典场景。

| 拍卖类型 | 规则 | 策略考量 |
|----------|------|----------|
| **英式拍卖** | 公开竞价，价高者得 | 何时退出？信息披露 |
| **荷式拍卖** | 价格从高往下降，第一个接受者得 | 对估值的自信程度 |
| **密封一价** | 同时出价，最高者支付自己的出价 | 出价低于真实估值（shade） |
| **密封二价**（Vickrey） | 同时出价，最高者支付第二高出价 | **说真话是占优策略** |

**收入等价定理**：在一定条件下，四种拍卖给卖家的期望收入相同。

**教学应用**：城市广告位拍卖、技术专利拍卖。

## 五、重复博弈与声誉

### 5.1 有限重复 vs 无限重复

**有限重复囚徒困境**（已知只玩 N 轮）：
- 逆向归纳：第 N 轮必背叛，第 N-1 轮也背叛……第一轮就背叛
- **合作无法维持**

**无限重复囚徒困境**（或以概率 δ 继续下一轮）：
- 触发策略（Trigger Strategy）：开始合作，一旦对方背叛就永远背叛
- 合作条件：当期背叛收益 < 未来合作收益的现值

```
背叛的诱惑 ≤ 维持合作的长期收益
T ≤ R/(1-δ)   →   δ ≥ (T - R) / (T - P)
```

**商业含义**：
- 为什么"百年老店"更值得信赖？因为声誉的现值极高
- 为什么互联网平台初期疯狂补贴？建立用户基础后进入重复博弈
- 为什么旅游景点的商家容易宰客？一次性博弈，没有未来

### 5.2 冷酷触发 vs 以牙还牙

| 策略 | 规则 | 特点 |
|------|------|------|
| **冷酷触发**（Grim Trigger） | 合作直到对方背叛，然后永远背叛 | 极端惩罚，恢复合作极难 |
| **以牙还牙**（Tit for Tat） | 第一轮合作，之后模仿对方上轮行动 | 简单、宽容、可恢复 |
| **宽宏以牙还牙**（Generous TFT） | 偶尔原谅背叛 | 对抗噪声更有效 |

**阿克塞尔罗德竞赛**（Axelrod's Tournament）：以牙还牙在重复囚徒困境中表现最优。

**教学价值**：让学生在多轮模拟中体验"建立信任 → 试探 → 报复 → 和解"的动态。

## 六、演化博弈论

### 6.1 基本思想

不是理性计算最优策略，而是**适应性学习**：成功的策略被更多人模仿。

```
种群中策略 i 的比例变化：
dx_i/dt = x_i · (u_i - ū)

其中 u_i 是策略 i 的平均收益，ū 是种群平均收益
```

**演化稳定策略（ESS）**：如果整个种群都采用该策略，任何小规模突变策略都无法入侵。

### 6.2 鹰鸽博弈（Hawk-Dove Game）

```
        鹰        鸽
    ┌─────────┬─────────┐
 鹰 │(V-C)/2  │  V      │
    ├─────────┼─────────┤
 鸽 │  0       │ V/2     │
    └─────────┴─────────┘
```

- V = 资源价值
- C = 冲突成本
- 如果 C > V：ESS 是混合策略，种群中一部分鹰、一部分鸽

**商业含义**：市场中需要既有"激进竞争者"（鹰）也有"合作者"（鸽），纯粹鹰的世界成本太高。

## 七、博弈论在商业模拟中的教学设计

### 7.1 渐进式引入

| 阶段 | 博弈概念 | 模拟设计 |
|------|----------|----------|
| 入门 | 占优策略 | 明显存在一个"无论如何都更好"的选择 |
| 基础 | 纳什均衡 | 让学生找出"没人想单独改变"的状态 |
| 进阶 | 囚徒困境 | 设计需要合作但个体理性导致背叛的场景 |
| 高级 | 信号博弈 | 通过行动传递私有信息（如"我是强硬型"） |
| 专家 | 重复博弈声誉 | 多轮模拟中建立和维护信任 |

### 7.2 可设计的博弈情境

| 情境 | 博弈结构 | 教学点 |
|------|----------|--------|
| 价格战 | 伯特兰 + 重复博弈 | 短期收益 vs 长期关系 |
| 技术联盟 | 合作博弈（Shapley 值） | 公平分配合作收益 |
| 市场进入 | 信号博弈 | 在位者如何通过定价威慑进入者 |
| 广告战 | 公共品博弈 | 个体广告 → 全行业需求上升（正外部性） |
| 供应链谈判 | 讨价还价博弈（Nash Bargaining） | 分配谈判剩余 |

## 八、TechVenture 的博弈结构分析

### 8.1 当前引擎的博弈特征

```
类型：多参与者、同时行动、不完全信息、变和非合作博弈
策略空间：路线 {TECH, USER, BRAND, PATHFINDER} × 城市子集 × 预算分配
信息结构：同时决策（不知道对手本轮选择），但知道对手历史表现
重复性：4 轮重复博弈
```

### 8.2 潜在的纳什均衡分析

**路线选择的博弈**：

| 路线 | 特征 | 均衡条件 |
|------|------|----------|
| PATHFINDER | 独占时高收益，拥挤时低收益 | 选择者 ≤ 2 时可能是均衡 |
| TECH | 高投入、长回报 | 当多数对手选 BRAND 时可能占优 |
| BRAND | 快回报、高风险（营销过度） | 当市场事件 favor Show 时 |
| USER | 稳健、依赖 Fit | 当 Geek 比例不高时 |

**关键洞见**：当前引擎没有显式的博弈均衡解算器，但通过参数设计（如 PATHFINDER 的拥挤惩罚），设计者已经在引导某些策略组合成为"自然均衡"。

### 8.3 可扩展的博弈机制

| 扩展 | 博弈论概念 | 实现方式 |
|------|-----------|----------|
| 信息揭示 | 信号传递 | 高 Tech 队伍可以"专利公示"，威慑对手 |
| 联盟形成 | 合作博弈 | 允许临时联盟，共享某城市收益 |
| 报复机制 | 重复博弈声誉 | 上轮被"背叛"的队伍本轮获得信息优势 |
| 进入威慑 | 信号博弈 | 在位者通过高 Show 投入传递"我会反击"的信号 |

## 九、关键洞见与教学转化

| 博弈论洞察 | 教学转化 |
|-----------|----------|
| 纳什均衡不一定是帕累托最优 | "你和对手都理性，不代表结果对大家都好" |
| 重复博弈中合作可以维持 | "长期关系比一锤子买卖更有价值" |
| 信息有战略价值 | "知道对手不知道的东西，本身就是一种优势" |
| 承诺的力量 | "破釜沉舟有时比灵活应对更有效" |
| 混合策略的必要性 | "总是可预测的对手是最弱的对手" |

---

> **核心洞见**：博弈论不是教你"怎么赢"，而是教你"如何在别人的策略存在下思考"。这正是商业思维的核心——你的决策质量不仅取决于你对市场的理解，还取决于你对竞争对手反应的预判。一个好的商业模拟平台，应该让学生在互动中自发体验到这些博弈逻辑，然后在复盘时用博弈论的语言命名它们。
