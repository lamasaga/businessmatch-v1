## 1. 范式定义

　　**基于主体的模型（Agent-Based Model, ABM）** 与 **主体计算经济学（Agent-Based Computational Economics, ACE）** 用大量异质主体在离散时间步上的 **局部规则 + 交互** 生成宏观时间序列。宏观变量（价格、失业率、不平等）是 **涌现（emergence）** 结果，而非写入代表性行为人效用函数后再解析求解。

| 特征 | 说明 |
|------|------|
| **本体** | 主体（agent）、环境、交互拓扑 |
| **动力学** | 离散 tick / 事件驱动 |
| **均衡** | 可能无闭式解；以仿真轨迹为准 |
| **验证** | stylized facts（ fat tail、波动聚集等）+ 情景对比 |

## 3. 实现方法（学术界常见套路）

### 3.1 模型构建步骤

1. **定义主体类型**（不必一开始命名「中产」——可先 `cohort_0..n`）  
2. **写行为原语**（预算、搜索、模仿、库存目标）  
3. **定义交互拓扑**（网格、网络、城市节点+边）  
4. **设定初始条件**（财富、库存、位置）  
5. **跑仿真** → 记录宏观与微观时间序列  
6. **对比** 基线情景 vs 政策/冲击情景  

### 3.2 与本平台 POP 的对应

| ABM 要素 | 本平台实现位 |
|----------|--------------|
| Agent | POP cohort / 匿名主体状态机 |
| Environment | 城市节点 + 商品池 + 路网 |
| Schedule | RTS `tick_interval_sec` + scheduler 单写者 |
| Interaction | 同城买卖、跨城物流、玩家流 Φ |
| Emergence | ask/bid、池压力、趋势指标 τ |

## 4. 数据是如何做出来的？

| 数据类型 | 典型来源 | 本平台用法 |
|----------|----------|------------|
| **行为规则参数** | 文献默认、实验经济学、专家访谈 | `behavior_pack.yaml` |
| **初始分布** | 人口普查份额、收入分位 | L3 `share`、`income_index` |
| **网络结构** | 地理邻接、引力模型 | L1 `regions/*.yaml` 边权 |
| **验证目标** | 真实时间序列矩（波动率、自相关） | 07- §4 矩匹配（方向性） |
| **标定数据** | 往往 **没有** 微观逐笔 → 用 **宏观矩 + 专家判断** | 教学级 `confidence: teaching_grade` |

　　ABM 的核心：**数据不是「估一个需求表」**，而是 **(规则, 初始条件) → 仿真输出 → 与目标矩对比 → 调参** 的循环（见本目录 **07-** §3）。

### 4.1 常用估计/校准技术

| 方法 | 做法 | 适用 |
|------|------|------|
| **校准（Calibration）** | 调参使仿真均值/方差接近目标 | Phase B 首选 |
| **间接推断（Indirect Inference）** | 仿真矩 vs 真实矩，最小距离 | 研究级、样本量大时 |
| **敏感性分析** | 单参数扫掠、Sobol | 防「过拟合一个故事」 |
| **模式导向建模（POM）** | 先定要复现的宏观模式，再反推规则 | 与「行为还原定义」一致 |

## 5. 可参考的开源实现片段

| 思路 | 伪代码级描述 | 备注 |

　　工程上：`PopEngine.tick(agents, cities, products, player_flows) -> prices, states` 保持 **纯函数 + 确定性**，便于单测与复盘。

## 6. 优点、局限与平台纪律

| 优点 | 局限 | 纪律 |
|------|------|------|
| 易讲故事、易做政策情景 | 参数多、可识别性弱 | 原语 ≤12 条，须敏感性表 |
| 自然支持「定义后置」 | 计算量随主体数增 | 每城 3～5 cohort，非百万 agent |
| 与游戏 tick 同构 | 难声称预测 GDP | 对外仅 **教学模拟** |
