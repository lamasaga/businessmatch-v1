## 1. 范式定义

　　**系统动力学（System Dynamics, SD）** 用 **存量（stock）、流量（flow）、反馈环** 描述系统随时间的变化，擅长表现 **延迟、饱和、振荡**（如库存积压、政策时滞、猪周期）。**复杂系统** 强调非线性、多重均衡、路径依赖——与 ABM 有交集，但 SD 通常 **方程连续、聚合到城市/产业层**，不强调每个消费者主体。

| 概念 | SD 语言 | 本平台映射 |
|------|---------|------------|
| Stock | 库存、债务、满意度 | `Pool`、`satisfaction` |
| Flow | 生产、消费、贸易 | `S_base`、`D_eff`、`Φ` |
| Loop |  reinforcing / balancing | 涨价→需求降→池升→价降 |
| Delay | 运输、政策、工资谈判 | `income_lag`、`travel_ticks` |

## 2. 实现方法

### 2.1 学术/工业 SD 流程

1. **因果回路图（CLD）** 与利益相关方画环  
2. 转为 **存量流量图（SFD）**  
3. 写微分/差分方程（常 Euler 积分）  
4. **历史拟合** 或 **专家估参**（Delphi）  
5. 情景模拟（policy run）

### 2.2 工具

| 工具 | 说明 |
|------|------|
| Stella / Vensim / AnyLogic SD 模块 | 经典 SD 软件 |
| Python `pysd` | 读 Vensim 模型 |
| 自写差分 | 与 tick 引擎合并 |

### 2.3 与 POP/ABM 并联（推荐架构）

```
ABM 层：cohort 订单流 → 短期 ask/bid（每 tick）
SD 层：产业产能利用率、基建库存（每 N tick 更新一次）
```

　　避免同一变量两套方程；用 **ABM 输出流量 → SD 存量** 单向耦合。

## 3. 数据是如何做出来的？

| 方法 | 数据从哪来 | 平台适用 |
|------|------------|----------|
| **历史拟合** | 时间序列回归（猪周期、PPI） | 验证振荡幅度量级 |

| **文献默认** | 经典 SD 模型参数表 | 冷启动 |
| **ABM 生成** | 见 05- 合成面板 | 联合验收 |

### 3.1 教学情景示例（因果链数据无关、结构有关）

| 情景 | 环 | 参数来源 |
|------|-----|----------|
