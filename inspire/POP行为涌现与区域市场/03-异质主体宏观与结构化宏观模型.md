## 1. 范式定义

　　传统 **代表性代理人（RBC/DSGE）** 用一个家庭概括全社会。 **异质主体宏观（Heterogeneous-Agent Macro）** 保留宏观一致性（市场出清、政策规则），但家庭在 **财富、收入、约束** 上呈分布，使货币政策、财政、工资等冲击产生 **分位数差异** 的消费与价格响应。

| 分支 | 特点 | 与 POP 关系 |
|------|------|-------------|
| **HANK** | 名义刚性 + 异质家庭 + 有时失业风险 | 「工资↑→部分 POP 需求↑→池↑→ask↑」链条 |
| **Bewley / Aiyagari** | 借贷约束、财富累积 | 远期沙盘：储蓄率原语 |
| **Krusell–Smith** | 异质 + 聚合律近似 | 启发「聚合律」：少变量代表分布 |

## 2. 实现方法（学术）

### 2.1 理论模型路径

1. 写家庭最优化（或规则 of thumb）+ 企业 + 政策规则  
2. 求稳态或线性化（一阶扰动）  
3. 用 **冲击响应函数（IRF）** 展示传导  

　　实现依赖：Dynare、Julia（HANKlit 等）、Python（Sequence Space Jacobian 生态）。

### 2.2 与本平台的关系

| HANK 概念 | 教学仿真映射 |
|-----------|--------------|
| 边际消费倾向异质 | 不同 `income_index` + `budget_hard` 原语 |
| 名义工资粘性 | `income_lag` tick 延迟 |
| 货币政策冲击 | 教师事件：利率/信贷旋钮（远期） |
| 消费对收入弹性 | `β_w · Δwage`（主 PRD §4.2） |

　　**不**在 Phase B 引入完整 DSGE 求解器；只 **借用传导叙事与 1～2 个可估参数**。

## 3. 数据是如何做出来的？

| 数据 | 来源 | 用于 |
|------|------|------|
| **微观家庭调查** | PSID（美）、CHFS/CFPS（中）、消费支出调查 | 收入弹性、储蓄率区间 |
| **宏观矩** | GDP、CPI、工资总额 | 稳态缩放 `α`、tick 尺度 |
| **校准目标** | 消费对收入 0.3～0.6 等文献区间 | 约束 `β_w` |
| **结构估计** | SMM、GMM 对异质模型 | 研究级；平台用 **方向性** 即可 |

### 3.1 简化校准流程（平台可用）

```
1. 选 2 个 POP，设 Δwage = +10%
2. 跑 20 tick 无玩家仿真
3. 记录 D_eff 变化方向 per 商品
4. 若与教研预期不符 → 调 β_w 或 demand_vector 初值
5. 记录 provenance（07- meta）
```

## 4. 可参考的「实现方法」摘要

| 方法 | 描述 | 平台采纳度 |
|------|------|------------|
| **稳态 + 扰动** | 先定长期均值，再加冲击 | 高（母本 L2） |
| **序列空间 Jacobian** | 快速算政策导数 | 低（工程重） |
| **规则 of thumb 消费** | 固定 MPC，易解释 | **高（行为原语）** |
