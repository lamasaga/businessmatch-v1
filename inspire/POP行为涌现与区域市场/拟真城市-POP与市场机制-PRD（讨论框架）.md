## 1.1 设计哲学：行为原语与「涌现定义」

　　**核心立场**：POP 类型（中产、工人、高端）不应作为仿真的**起点**，而应作为对一组 **行为原语（behavior primitives）** 在时间与网络中运行后，所呈现出的宏观订单流的 **事后标签**。少写「这类人天生偏好奢侈品 1.5」，多写「在预算、参考价、缺货恐慌、收入滞后下，主体如何下单」——宏观曲线与趋势从互动中 **涌现**。

　　这与「用深度模型从市场数据挖掘 latent factor」在认识论上相近：都不假设一个先验完备的 representative agent；差别在于本平台优先 **可复盘、可手算、可课堂讲授**，故采用 **可解释行为规则 + 可选统计校准**，而非端到端黑箱。

### 三层结构（目标架构）

```
L0 行为原语（8～12 条，跨 POP 共用）
      ↓ 每主体携带状态（现金感知、记忆价、满意度、收入滞后）
L1 订单流（每 tick 各主体对各城各品产生买/卖意愿）
      ↓ 聚合
L2 宏观市场（D_eff、Pool、ask/bid、趋势指标）
      ↓ 复盘 / 聚类 / 教研命名
L3 叙事标签（pop_id、教学话术）← 定义后置，非仿真输入必需
```

| 原则 | 含义 |
|------|------|
| **定义后置** | `pop_id` 用于复盘与 UI；仿真可先跑「匿名主体 cohort」再聚类 |
| **趋势可解释** | 深层趋势 = 多条反馈环叠加（工资→消费→池→价→满意度→就业意愿） |
| **与 V3 差异** | Victoria 3 偏先验需求向量；本方案偏 **ACE 式自下而上** + 教育向命名 |
| **工程分期** | v0 可用静态 `demand_vector` 过渡；v1 起逐步替换为行为原语 |

### 行为原语草案（讨论用，非穷举）

| 原语 id | 行为摘要 | 影响的宏观现象 |
|---------|----------|----------------|
| `budget_hard` | 本月可花 ≤ 收入×储蓄率 | 收入冲击传导滞后 |
| `reference_price` | 仅当现价偏离记忆价 X% 时买/卖 | 价差套利窗口、粘性 |
| `scarcity_panic` | 连续缺货 tick → 加大抢购 | 需求被「制造」、脉冲涨价 |
| `habit_stock` | 必需品有最低消费量 | 刚需曲线相对无弹性 |
| `social_contagion` | 邻城/同 cohort 满意度上升 → 跟风 | 区域消费升级波浪 |
| `income_lag` | 工资/policy 变化 N tick 后才改消费 | 政策时滞、工资传导 |
| `supplier_response` | 长期 bid 过低 → 产出意愿降 | 供给曲线左移、去工业化叙事 |
| `luxury_veblen` | 价高且他人购买时需求↑（可选） | 炫耀性消费，**待决是否启用** |

## 1.2 与「深度学习挖因子」的范式对照

| 维度 | 表征学习 / 因子模型 | 本 POP（行为涌现） |
|------|---------------------|-------------------|
| 输入 | 海量历史收益、基本面 | 规则 + 城市母本 + 局内玩家流 |
| 产出 | latent factor（常后验命名） | 价格/池时间序列 → 再命名 POP |
| 可解释 | 弱（需专门 interpretability） | 强（每条原语对应教学句） |
| 拟合现实 | 强（若有数据） | 方向性校准 + 情景，非 GDP 预测 |
| 适用阶段 | Phase C+ 辅助校准 | Phase B 规则层主路径 |

　　**可结合**：用仿真日志做 **事后因子分析**（哪类订单流主成分=「刚需/可选/奢侈」），给涌现模式起名，而不是事先写死向量。

## 2. 概念模型

```
城市 City
 └── 主体 cohort[]           # 实现可带 pop_id，但核心驱动是行为状态机
      └── 行为原语 → 订单流 O_i(c,p,t)
产业 Ind(p)
物流 λ(city, p)
玩家流 Φ_player(p,t)
────────────────────────────────────────
D_eff = Σ_i O_i  （或由 O_i 与静态向量混合过渡）
S_eff = Ind(p) + imports(p) − constraint
Pool_{t+1} = Pool_t + S_eff − D_eff − Φ_buy + Φ_sell
ask/bid = g(mid(Pool), elasticity, min_spread)
趋势指标 τ = EMA(pressure), 分 POP 满意度均值, 等（供复盘）
```

## 4. 需求曲线（单城单品）

### 4.1 基线需求（无玩家时）

```
D_base(c,p) = α · Population(c) · Σ_i share_i · demand_vector_i[p] · demand_profile_city[c,p]
```

　　**v1 替换为**：`D_base = Σ_i O_i(c,p,t)`，其中 `O_i` 由行为原语生成。

| 符号 | 来源 |
|------|------|
| `Population` | L2 城市母本 |
| `demand_profile_city` | 城市结构性偏好（过渡字段） |
| `α` | tick 尺度换算（见 §13 待决 #1） |

### 4.2 POP 动态需求（核心）

```
D_i_t = D_i_base · (1 + β_w · Δwage_i) · (1 + β_s · (satisfaction_i - 0.5)) · Π_k shock_k
```

| 机制 | 含义 | 教学用途 |
|------|------|----------|
| `Δwage_i` | 人均收入相对开局变化 | 工资上涨拉动消费 |
| `satisfaction` | 缺货/涨价 → 需求萎缩或迁移 | 通胀抑制需求 |
| `shock_k` | 车展、丰收、补贴 | 需求被制造 |

### 4.3 供给曲线

```
S_base(c,p) = production[c,p] · capacity_utilization(c,p)
```

### 4.4 玩家冲击（与现行 pool 衔接）

```
Φ_net = buy_volume − sell_volume
Pool_{t+1} = Pool_t + S_base − D_eff − Φ_buy + Φ_sell
pressure = h(Pool / Pool_target, Φ_net / Pool_target)
mid = mid_structural(c,p) · (1 + pressure · elasticity)
ask, bid = spread(mid, min_spread)
```

**`Pool_target`**：由 `D_eff` 与 `S_base` 推导，非常数。

## 5. 玩家行为 → POP 反馈（浮生记 v1 必做 subset）

| 玩家现象 | POP / 原语规则（草案） | 可见反馈 |
|----------|------------------------|----------|
| 连续大量买入日用品 | `scarcity_panic` + satisfaction↑ | ask 持续偏高 |
| 奢侈品被扫货 | `luxury_veblen` 或 satisfaction↓ | 波动加剧 |
| 长期压低粮食 bid | `supplier_response` → 供给左移 | 产出城 bid 结构变化 |
| 跨城运货致 B 城缺货 | B 城 `satisfaction`↓ | 事件条 + 复盘 |

**纪律**：单局内仅写 **snapshot**；不回写 L2 母本。

## 14. 成功指标

| 指标 | 目标 |
