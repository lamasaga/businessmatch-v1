## 1. 范式定义

　　与 ABM **先规则后轨迹** 相反，**因子模型与机器学习** 常从 **高维观测** 中估计 **低维 latent 结构**，再事后解释（因子 1 = 「价值」？）。与你们「**少定义、多行为，事后命名 POP**」在 **认识论** 上相近，在 **工程** 上应作为 **校准与聚类层**，而非替代 `pop_engine` 规则层。

| 路线 | 代表 | 输出 |
|------|------|------|
| 线性因子 | Fama–French 三/五因子 | 风险溢价暴露 |
| 工具变量 / IPCA | 时变载荷 | 动态因子 |
| ML | PCA、自编码器、神经网络因子（Gu–Kelly–Xiu 等） | 非线性 latent |
| 因果 ML | 异质处理效应（CATE） | 政策对谁有效 |

## 2. 实现方法（学术与工业）

### 2.1 典型流水线

```
面板数据 (资产收益 / 消费品类 / 城市–品类价格)
    → 预处理（对齐、去极值、标准化）
    → 降维 / 正则化回归 / 深度学习
    → 因子序列或嵌入向量
    → 经济含义命名（往往事后）
    → 样本外检验（OOS R²、夏普等）
```

### 2.2 映射到本平台（**仿真日志 → 因子**）

| 步骤 | 平台做法 |
|------|----------|
| 输入 | 一局 RTS 日志：每 tick 每城每品 `(pool, ask, bid, Φ_net, satisfaction…)` |
| 降维 | PCA / NMF 得 2～3 个主成分 |
| 命名 | 教研命名：`PC1≈刚需压力`、`PC2≈奢侈需求` → 映射 `pop_id` 话术 |
| 用途 | 复盘卡、难度调节；**不**在 tick 中调用神经网络 forward |

## 3. 数据是如何做出来的？

| 类型 | 真实市场 | 本平台 |
|------|----------|--------|
| **收益面板** | CRSP、Wind 行情 | 无；用 **模拟价格变化** |
| **基本面** | 财报、宏观 | L2 产业标签 + 手工 YAML |
| **标签** | 行业、市值 | `pop_id`、cohort（事后） |
| **训练集** | 数十年日频 | 批量跑仿真生成 **合成面板** |

### 3.1 合成数据（推荐）

　　故意用 ABM 生成上万局短仿真 → 得到「城市–品类–tick」面板 → 练聚类/因子 → 检查是否能 **恢复已知原语参数**。这是 ABM 文献中验证结构的有效套路（**间接推断**的简化版）。

### 3.2 真实数据的角色

| 用途 | 做法 |
|------|------|
| **方向校准** | 真实城市批发价 index 上升/下降方向 vs 仿真 |
| **不参与 tick** | 避免黑箱拟合逐 tick 价格（不可审计） |

## 5. 优点、局限与纪律

| 优点 | 局限 | 纪律 |
|------|------|------|
| 发现未知模式 | 可解释性差 | **规则层定价**；ML 只离线 |
| 合成数据可控 | 与真实市场 gap | 须标注 `confidence: teaching_grade` |
| 适合「定义后置」 | 过拟合噪声 | 样本外情景检验 |
