## 为什么单独成库

　　POP 用于解释 **深层市场趋势**（工资传导、需求制造、冲击衰减），路线为 **少静态定义、多行为原语、宏观涌现**。本目录集中存放 **学术范式调研、实现套路、数据如何做**，与单赛制 PRD（inspire/赛事设计）分离。
