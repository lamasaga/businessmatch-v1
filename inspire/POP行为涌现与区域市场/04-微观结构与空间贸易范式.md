## 1. 范式定义

### 1.1 微观市场结构（Microstructure）

　　研究 **订单流、买卖价差、库存、市场深度** 如何形成短期价格。金融高频数据中最成熟；商品贸易游戏可 **抽象** 为：池存量 = 深度，净买入 = 订单流冲击。

| 概念 | 学术含义 | 本平台 `trading-v2-rts` |
|------|----------|-------------------------|
| Bid–ask spread | 流动性成本 | `min_spread` |
| Market depth | 大单对价影响 | `reference_pool`、`absorption_cap_per_tick` |
| Inventory risk | 做市商库存风险 | 城市 `pool` 动态 |
| Price impact | 净订单流推动价格 | `pool_pressure` + `Φ_net` |

### 1.2 空间贸易与城市体系（Spatial / Trade）

　　**空间均衡**、**引力模型**、**Armington 替代弹性**：解释为何货从 A 城运到 B 城有利可图。与浮生记 **路网 + 价差套利** 直接同构。

| 模型 | 核心方程直觉 | 数据需求 |
|------|--------------|----------|
| **引力模型** | 贸易流 ∝ 经济质量 / 距离^β | GDP/人口、运距 |
| **Armington** | 多源产品不完全替代 | 替代弹性 σ |
| **区位论 / 产业集群** | 供给在空间集聚 | 产业普查、园区统计 |

## 2. 实现方法

### 2.1 池–价差机制（本平台已有，可升格）

```
mid = f(结构性中枢, 本地产消)
pressure = h(Pool / Pool_target, Φ_net)
ask, bid = mid ± spread(pressure, elasticity)
Pool_{t+1} = Pool_t + S - D - buys + sells
```

　　学术上接近 **简化做市商模型** 或 **存量–流量市场**（非完整 Kyle 模型）。

### 2.2 空间层实现

| 步骤 | 做法 |
|------|------|
| 节点 | 城市 `city_id`，坐标用于 UI |
| 边 | `routes`：`base_travel_ticks`、`move_cost` |
| 价差 | 各节点 ask/bid 差驱动套利 AI / 玩家 |
| 均衡 | 不要求闭式解；tick 仿真至 `total_ticks` |

## 3. 数据是如何做出来的？

| 层级 | 数据来源 | 加工 |
|------|----------|------|
| **运价/时效** | 公路运价指数、港口吞吐、高德距离（合规使用） | 归一化为 `travel_ticks` |
| **产业结构** | 统计年鉴分行业产值、进出口 | 映射 10 品类 `production/consumption` |
| **价差 stylized** | 历史批发价差（若有）或专家设定 | 验证套利方向是否合理 |
| **深度参数** | 文献 spread 0.5%～5% 或调参 | `min_spread`、`absorption_cap` |

### 3.1 引力模型校准示例（教学级）

```
T_ij = K · (GDP_i · GDP_j) / dist_ij^β
→ 得到相对「贸易势能」→ 设定边权或初始 pool 分配
β, K 用已知城市对贸易额做数量级对齐（不必精确拟合）
```
