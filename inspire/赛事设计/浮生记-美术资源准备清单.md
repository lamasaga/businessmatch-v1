## 2. 风格与规格总则

### 2.1 视觉方向（讨论稿默认）

| 项 | 建议 |
|----|------|
| **整体** | 2D **教学向 stylized**，非卫星写实；长三角水乡 + 现代产业并存 |
| **色调** | 暗色 UI 底（对齐学生端 Tailwind 暗色主题）；地图层略降饱和，避免抢侧栏数据 |
| **线宽** | SVG 描边 1.5～2px @1x；缩放时保持矢量 |
| **可读性** | 16:9 下 1366×768 仍可辨认城名、商品 32px 图标 |
| **无障碍** | 价差/涨跌除颜色外，配 **箭头/图标**（↑↓） |

### 2.2 技术格式

| 用途 | 格式 | 规格要点 |
|------|------|----------|
| **M0/M1 矢量** | SVG | 无内嵌 raster；`viewBox` 明确；可 CSS 改色 |
| **M2 精灵** | PNG + 可选 WebP | 透明底；**@1x + @2x**；Power-of-two 图集可选 |
| **大地图底图** | WebP 主 + SVG 降级 | 16:9；宽 **1920px**（@1x）；单张 **≤800KB**（PRD 弱网目标） |
| **事件头图** | WebP | 宽 640～960px；16:9 或 3:2 |
| **音效** | OGG/MP3 | P2；单文件 ≤100KB |

### 2.3 命名与 ID 纪律

```
art-assets/fushengji/
├── maps/                    # 全图、示意、底图
├── maps/geo/                # 与 content/world/geo/yangtze_6/ 视觉对齐（BDD M1+）
├── maps/cities/             # 城徽 / 节点（非 GeoJSON 边界）
├── items/                   # product_id 同名
├── vehicles/                # van | truck
├── fleet/                   # 商队精灵（M1 SVG / M2 精灵表）
├── routes/                  # 边样式、箭头、拥堵叠加（可选）
├── events/                  # event_types.type 同名或映射表
├── ui/                      # HUD、面板装饰
├── fx/                      # 脉冲、热点、tick 相关
├── characters/              # 交易者/AI 占位
└── manifest.yaml            # 与工程 manifest 同步
```

| 键 | 必须一致 |
|----|----------|
| 城市 | `nanjing` `suzhou` `shanghai` `nantong` `wuxi` `changzhou` |
| 商品 | `grain` `produce` `raw_materials` `energy` `furniture` `textile` `daily_goods` `appliances` `passenger_car` `luxury` |
| 车辆 | `van` `truck` |
| 事件 | 见 §6.7，与 `fstrading.yaml` → `event_types[].type` 对齐 |

## 3. 里程碑与优先级总览

| 里程碑 | BDD/PRD 对应 | 美术交付目标 | 优先级 |
|--------|--------------|--------------|--------|
| **M0** | 示意底图 + 圆点锚点；降级场景 | 可玩 **示意包** 统一风格；清单 P0 除 geo 底图外齐套 | 开赛前必须 |
| **M1** | GeoJSON 轮廓 + SVG 地图层 + 折线边 + 精灵插值 | **真实地理感** stylized 底图 + 城界 **视觉填充/描边** + **商队 SVG** | 设计完善主目标 |
| **M2** | Pixi 精灵 + 缩放平移 + manifest 预加载 | PNG 精灵表、@2x、相机友好尺寸 | 性能/动效增强 |
| **M3** | 可选 OSM 底图、六城 bbox 校准 | G2 底图或高精细 stylized 第二套 | 可选 |

**P0** = M0/M1 阻塞 · **P1** = M1 完整体验 · **P2** = M2/M3 或组织者端

## 7. 交付自检（交稿前）

| 检查项 | 标准 |
|--------|------|
| ID 对齐 | 文件名与 `product_id` / `city_id` / `event type` 一致 |
