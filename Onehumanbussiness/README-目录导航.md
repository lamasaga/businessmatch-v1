## 核心概念速查

### 什么是一人公司（OPC）？
以个体为核心，借助AI等技术工具，独立或主导完成从价值创造到价值获取全商业闭环的新型创业实体。2025年36%的新创企业由单人创立。

### 什么是AI员工？
OHB中可执行真实任务的数字协作者，有岗位、KPI、交付物、记忆和升级机制。学生是AI员工的「管理者」，而非「对话者」。

### 什么是MCP？
Model Context Protocol，Anthropic开源的AI Agent与外部工具通信标准。类比为「AI的USB-C」，让不同AI员工能调用统一的真实世界工具。

### OHB与现有平台的关系？
OHB是现有商业模拟教育平台的「自然延伸」和「最终出口」。学生完成知识学习和模拟训练后，解锁OHB，将能力转化为真实商业成果。
