# 事件总线协议

> **文档定位**：定义OHB与现有商业模拟教育平台之间的事件通信协议，确保两系统之间的松耦合集成。
>
> **最后更新**：2026-05-17

---

## 一、传输层

```yaml
transport:
  primary: Redis Pub/Sub
  fallback: HTTP Webhook
  serialization: JSON
  
redis_channels:
  - "ohb:events:all"           # 所有OHB事件广播
  - "ohb:events:platform"      # 需要现有平台处理的事件
  - "platform:events:all"      # 现有平台事件广播
  - "platform:events:ohb"      # OHB需要监听的事件
```

---

## 二、事件格式

```json
{
  "specversion": "1.0",

  "source": "ohb/api",

  "time": "2026-05-17T10:30:00Z",
  "datacontenttype": "application/json",
  "data": { },
  "extensions": {
    "ohb_version": "1.0",
    "platform_version": "2.0",
    "trace_id": "trace_xxx"
  }
}
```

## 三、OHB → 现有平台 事件

### 3.1 能力解锁事件

```json
{
  "type": "ohb.capability.unlocked",
  "data": {
    "career_id": "career_xxx",
    "user_id": "user_xxx",

  }
```

## 四、现有平台 → OHB 事件

### 4.1 入口解锁

```json
{
  "type": "platform.ohb.unlocked",
  "data": {
    "career_id": "career_xxx",
    "user_id": "user_xxx",
    "unlocked_at": "2026-05-15",
    "trigger": {
      "type": "ability_threshold",
      "details": {
        "average_score": 72,
        "threshold": 70
      }
    }
  }
}
```

### 4.2 性格/能力数据同步

```json
{
  "type": "platform.persona.updated",
  "data": {
    "career_id": "career_xxx",
    "user_id": "user_xxx",
    "persona_snapshot": {

      "decision_style": "analytical",
      "risk_tolerance": 0.7
    },
    "recommended_directions": ["saas", "content_creation"]

```

## 五、事件订阅注册

```python
# OHB 订阅现有平台事件
subscriptions = {
    "platform.ohb.unlocked": handle_ohb_unlocked,
    "platform.persona.updated": handle_persona_update,
    "platform.ability.updated": handle_ability_update,
}

# 现有平台订阅OHB事件
subscriptions = {
    "ohb.xp.awarded": handle_xp_awarded,
    "ohb.achievement.earned": handle_achievement,
    "ohb.ability.updated": handle_ability_update,
}
```

## 六、错误处理

| 场景 | 处理 |
|------|------|
| 事件格式错误 | 记录错误日志，丢弃事件，告警管理员 |
| 处理超时 | 重试3次，之后放入死信队列 |
| 目标系统不可用 | 指数退避重试，最多10分钟 |
| 重复事件 | 幂等处理，根据event_id去重 |
