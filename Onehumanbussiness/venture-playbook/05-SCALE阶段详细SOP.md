## 二、运营自动化工作流

### 2.1 自动化优先级矩阵

| 任务 | 频率 | 自动化难度 | 优先级 | 工具 |
|------|------|-----------|--------|------|
| 用户欢迎邮件 | 每次注册 | 低 | P0 | Resend自动化 |
| 数据报表 | 每日 | 低 | P0 | DATA-01 + 定时任务 |
| 社媒发布 | 每日 | 中 | P0 | Buffer/n8n |
| 客服回复 | 实时 | 中 | P1 | AI聊天机器人 |
| 用户分群 | 每周 | 中 | P1 | 自建脚本 |
| 账单生成 | 每月 | 低 | P1 | Stripe订阅 |
| A/B测试 | 持续 | 高 | P2 | 自建或第三方 |

### 2.2 n8n 工作流示例

```yaml
workflow: "用户注册自动 nurture"
triggers:
  - type: webhook
    event: "user.registered"

steps:
  - delay: "5 minutes"
  - action: "send_email"
    template: "welcome"
    subject: "欢迎加入！这是你的快速开始指南"
  
  - condition: "user.activated == false"
    true:
      - delay: "24 hours"
      - action: "send_email"
        template: "activation_reminder"
    false:
      - delay: "3 days"
      - action: "send_email"
        template: "tips_and_tricks"
  
  - delay: "7 days"
  - action: "send_email"
    template: "feedback_request"
  
  - condition: "user.paid == false"
    true:
      - delay: "14 days"
      - action: "send_email"
        template: "upgrade_offer"
```
