# IDEATE 阶段详细 SOP

> **文档定位**：创意孵化期（第1-14天）的逐日操作手册、模板和检查清单。
>
> **最后更新**：2026-05-17

---

## 一、阶段目标

在14天内，将模糊想法转化为**结构化的商业创意**，输出：
- ✅ 完整的商业模式画布（BMC）
- ✅ 竞品分析矩阵（Top 5）
- ✅ 3个用户画像
- ✅ 品牌方案（名称+故事+视觉方向）

---

## 二、逐日任务清单

### Week 1: 发现与扫描

#### Day 1: 兴趣审计与方向初选

**上午（学生）**：
- [ ] 查看平台生成的「高匹配度创业方向」推荐（基于Persona+能力雷达）
- [ ] 浏览3个推荐方向的知识图谱节点
- [ ] 选择1个最感兴趣的方向作为起点

**下午（与AI员工协作）**：
- [ ] 雇佣 BA-01（商业分析师）
- [ ] 雇佣 CP-01（创意策划师）
- [ ] 向 BA-01 派发任务：「输出该方向的TAM/SAM/SOM估算」
- [ ] 向 CP-01 派发任务：「生成10个该方向的创意变体」

**交付物**：
- 市场规模估算报告
- 10个创意点子清单

---

#### Day 2: 痛点深度扫描

**上午（学生）**：
- [ ] 查看 Scout（市场探员）的情报报告
- [ ] 阅读目标用户在社交媒体上的真实抱怨

**下午（与AI员工协作）**：
- [ ] 向 Scout 派发任务：「扫描Reddit/知乎/小红书相关讨论，提取高频痛点」
- [ ] 向 BA-01 派发任务：「验证痛点的普遍性和付费意愿」

**交付物**：
- 用户痛点关键词云
- 痛点优先级排序表

---

#### Day 3: 竞品初探

**上午（学生）**：
- [ ] 查看 BA-01 输出的竞品列表
- [ ] 亲自体验2-3个主要竞品

**下午（与AI员工协作）**：
- [ ] 向 BA-01 派发任务：「输出竞品功能矩阵（Top 5）」
- [ ] 标记每个竞品的优势和劣势

**交付物**：
- 竞品分析矩阵

---

#### Day 4: 创意筛选

**上午（学生）**：
- [ ] 与 CP-01 进行头脑风暴回顾
- [ ] 用 BMC 轻量模板快速评估每个创意

**评估标准**：
| 维度 | 权重 | 评分1-5 |
|------|------|---------|
| 我喜欢吗？ | 20% | |
| 市场够大吗？ | 20% | |
| 我能做出来吗？ | 20% | |
| 有差异化空间吗？ | 20% | |
| 能快速验证吗？ | 20% | |

**下午**：
- [ ] 选择评分最高的1-2个创意深入研究

---

#### Day 5-7: 深度研究

**Day 5: 用户画像构建**
- [ ] 向 BA-01 派发任务：「构建3个典型用户画像」
- [ ] 学生补充自己对目标用户的理解

**用户画像模板**：
```markdown
## 用户画像 1: {名称}

**基本信息**
- 年龄: 
- 性别: 
- 职业: 
- 收入: 
- 所在城市: 

**行为特征**
- 日常习惯: 
- 信息获取渠道: 
- 消费决策方式: 

**痛点**
- 当前最困扰的问题: 
- 现有解决方案的不足: 
- 愿意为此付费吗？多少？

**目标**
- 想要达成什么: 
- 成功是什么样: 

**引述**
- 如果 interviewed，TA 可能会说: 
```

**Day 6: 价值主张打磨**
- [ ] 与 CP-01 一起打磨核心价值主张
- [ ] 必须回答：为谁？解决什么？独特在哪？

**价值主张画布**：
```
┌─────────────────────────────────────────┐
│  我们的产品/服务: [名称]                  │
├─────────────────────────────────────────┤
│  帮助 [谁]                                │
│  解决 [什么问题]                           │
│  通过 [什么独特方式]                        │
│  不同于 [现有方案]                         │
│  因为我们 [核心优势]                        │
└─────────────────────────────────────────┘
```

**Day 7: Week 1 复盘**
- [ ] 整理Week 1所有交付物
- [ ] 与 Cortex 复盘："这周的进展如何？下一步建议？"

### Week 2: 定型与输出

#### Day 8-9: BMC 填充

**BMC 9宫格填充（使用平台编辑器）**：

| 格子 | 内容 | 负责 | 检查点 |
|------|------|------|--------|
| 客户细分 | 谁是你的目标用户？ | BA-01+学生 | 有3个具体画像 |
| 价值主张 | 你为他们解决什么？ | CP-01+学生 | 一句话说清楚 |
| 渠道通路 | 如何触达他们？ | BA-01 | 有3个具体渠道 |
| 客户关系 | 如何维护关系？ | CP-01 | 有具体方式 |
| 收入来源 | 如何赚钱？ | BA-01 | 有定价初步想法 |
| 核心资源 | 你需要什么资源？ | BA-01 | 列出关键资源 |
| 关键活动 | 每天必须做什么？ | 学生 | 有3个核心活动 |
| 重要合作 | 需要谁的帮助？ | BA-01 | 列出潜在合作伙伴 |
| 成本结构 | 主要成本是什么？ | BA-01 | 有成本估算 |

**Day 9 下午**：
- [ ] BA-01 审核BMC完整性
- [ ] 标记每个格子的置信度（高/中/低）

---

#### Day 10-11: 品牌方案

**Day 10: 命名**
- [ ] 向 CP-01 派发任务：「生成10个品牌名方案」
- [ ] 每个方案检查：
  - [ ] 域名是否可用（.com/.cn）
  - [ ] 商标风险
  - [ ] 文化敏感性
  - [ ] 发音是否顺口

**Day 11: 品牌故事+视觉方向**
- [ ] 向 CP-01 派发任务：「撰写品牌故事」
- [ ] 向 DES-01（如已雇佣）派发任务：「设计3套视觉方向 mood board」

**品牌故事模板**：
```markdown
# {品牌名} 的品牌故事

## 起源
（为什么创立这个品牌？真实或虚构但可信的故事，1段）

## 使命
（我们存在的目的是什么？1句话）

## 愿景
（3年后，我们希望成为什么？1句话）

## 价值观
（3个核心价值观，每个配1句解释）

## 品牌人格
（如果品牌是一个人，TA是...）
```

## 三、Gateway 1 评审标准

| 评审项 | 权重 | 通过标准 |
|--------|------|----------|
| BMC完整性 | 20% | 9宫格无空白 |
| 市场真实性 | 20% | 有数据来源，非伪需求 |
| 差异化程度 | 20% | 与竞品有明显差异 |
| 用户画像质量 | 15% | 3个画像，基于真实数据 |
| 品牌方案 | 15% | 名称可用，故事可信 |
| 学生投入度 | 10% | 有主动思考和决策 |

**评审结果**：
- 🟢 **通过**（≥75分）：进入VALIDATE阶段
- 🟡 **有条件通过**（60-74分）：修改指定问题后通过
- 🔴 **不通过**（<60分）：返回修改或更换方向

## 四、常见问题与解决

| 问题 | 解决建议 |
|------|----------|
| "我想不出创意" | 从自己的痛点出发；让Scout扫描「大家都在抱怨什么」 |
| "市场看起来很小" | 检查是否只看了直接竞品，忽略了替代方案市场 |
| "这个方向已经有人做了" | 差异化不需要全新品类，更好的体验/更低的成本也是差异化 |
| "我不会写品牌故事" | 用CP-01辅助，但必须基于真实想法，不要完全让AI代写 |
| "BMC填不完" | 某些格子确实信息不足，标注「待验证假设」即可 |
