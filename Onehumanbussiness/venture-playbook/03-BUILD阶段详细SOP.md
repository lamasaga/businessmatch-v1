> **最后更新**：2026-05-17

## 一、阶段目标

在4周内，构建并上线**最小可用产品（MVP）**。

**关键产出**：
- ✅ 可访问的MVP
- ✅ 核心功能可用
- ✅ 基础测试通过
- ✅ 部署到生产环境

```
你的产品是什么类型？
├── 信息展示/博客
```

## 五、开发规范

### 5.1 代码审查Checklist

```markdown
## 代码审查清单

### 功能
- [ ] 功能按需求实现
- [ ] 边界情况已处理
- [ ] 错误有友好提示

### 代码质量
- [ ] 函数/组件有注释
- [ ] 命名清晰有意义
- [ ] 无console.log（生产代码）
- [ ] 无硬编码密钥

### 性能
- [ ] 图片已压缩
- [ ] 大组件使用懒加载
- [ ] API调用有缓存或防抖

### 安全
- [ ] 用户输入已校验
- [ ] SQL注入防护（参数化查询）
- [ ] XSS防护（不直接渲染用户输入）
```

### 5.2 测试策略

| 测试类型 | 工具 | 覆盖范围 | 负责人 |
|----------|------|----------|--------|
| 单元测试 | Jest / Vitest | 工具函数、API | DEV-01 |
| 组件测试 | React Testing Library | UI组件 | DEV-01 |
| 手动测试 | 人工 | 完整用户流程 | 学生 |
| 视觉回归 | 截图对比 | 关键页面 | DES-01 |
