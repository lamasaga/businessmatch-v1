# 大学段（本科+MBA）主题推荐库

> **适用学段**：大学本科、研究生、MBA/EMBA
> **认知特征**：高度复杂、信息不完全、竞争动态变化的决策环境
> **决策复杂度**：数十至数百个决策变量，强调战略思维、系统整合和不确定性下的决策质量
> **目标**：从"理解商业"过渡到"创造商业价值"

## 二、本科阶段主题路径

### 2.1 大一：基础构建

**目标**：建立商业运作的整体认知

```
第一学期：商业基础
  - Cesim Global Challenge 简化版 或 CapsimCore
  - 理解四大职能模块（生产、营销、财务、研发）
  - 学习三大财务报表的勾稽关系
  
第二学期：竞争入门
  - 全国企业竞争模拟大赛（BizWar赛道）
  - 理解寡头竞争和博弈论基础
  - 建立Excel财务模型
```

### 2.2 大二：专业深化

**目标**：在特定领域建立深度能力

```
第一学期：营销/金融方向选择
  - 营销方向：Cesim SimBrand / Markstrat
  - 金融方向：投资人对决模拟 / KWHS指导角色
  
第二学期：综合应用
  - 全国企业竞争模拟大赛（iBizSim赛道，企业决策）
  - 引入多变量决策和优化方法
  - Python/R辅助数据分析
```

### 2.3 大三：战略高度

**目标**：从职能视角提升到战略视角

```
第一学期：战略整合
  - "商道"系统（PREMKING）
  - 体验战略规划到执行的全流程
  - 理解决策的滞后效应和路径依赖
  
第二学期：国际视野
  - Cesim Global Challenge（完整版）
  - 跨国运营、汇率风险、文化差异
  - 全球供应链优化
```

### 2.4 大四：输出与转化

**目标**：将模拟经验转化为实际能力

```
- 尖烽时刻全国赛 / 全球赛
- 毕业论文：基于模拟数据的实证研究
- 实习：将模拟经验迁移到真实企业
```

## 三、MBA/研究生阶段主题路径

### 3.1 核心课程嵌入

| 课程 | 推荐模拟平台 | 教学模块 | 学习目标 |
|------|-------------|----------|----------|
| **战略管理** | Cesim Global Challenge | 全球战略制定、多市场协同 | Think Global, Act Local |
| **市场营销** | Markstrat / SimBrand | 品牌资产建设、营销组合优化 | 长期品牌vs短期销售 |
| **运营管理** | CapsimOps | 供应链优化、库存管理 | 运筹学方法应用 |
| **公司金融** | 投资人对决 | 估值、融资、条款谈判 | 创业者vs投资人双视角 |
| **创业管理** | SimFirm | 从0到1的全生命周期 | 资源约束下的战略选择 |
| **国际商务** | Global Challenge / 跨国贸易博弈 | 汇率风险、跨文化管理 | 全球化运营复杂性 |

### 3.2 EMBA高阶定制

**中欧国际工商学院"三高"设计**：
- **高复杂度**：信息不完全（关键市场数据缺失）
- **高不确定性**：决策时间窗口更短（模拟突发事件）
- **高时间压力**：需平衡股东、员工、政府、社区多方诉求

**人大商学院本土化实践**：
- 欧洲电信市场案例 → 中国移动通信市场
- 奢侈品品牌管理 → 本土快消品牌
- 汽车制造业 → 中国新能源汽车产业

## 四、核心理论框架

### 4.1 经济学理论

| 理论 | 核心内容 | 模拟应用 |
|------|----------|----------|
| **寡头竞争理论** | 古诺模型、伯特兰模型、斯塔克尔伯格模型 | iBizSim市场分配机制 |
| **产业组织理论** | 市场结构-行为-绩效（SCP）框架 | 竞争策略选择 |
| **博弈论** | 纳什均衡、重复博弈、不完全信息 | 多轮决策中的策略互动 |
| **行为经济学** | 前景理论、框架效应、锚定效应 | 案例推演中的决策陷阱 |

### 4.2 战略管理理论

| 理论 | 核心内容 | 模拟应用 |
|------|----------|----------|
| **波特五力** | 行业竞争强度分析 | 市场进入决策 |
| **价值链分析** | 价值创造活动识别 | 产业链角色扮演 |
| **蓝海战略** | 价值创新、ERRC网格 | 蓝海创业大赛 |
| **资源基础观（RBV）** | VRIN框架 | 竞争优势构建 |
| **动态能力** | 感知- seize - 转型 | 危机应对、Pivot决策 |

### 4.3 金融学理论

| 理论 | 核心内容 | 模拟应用 |
|------|----------|----------|
| **投资组合理论** | 均值-方差优化、CAPM | 投资人对决组合管理 |
| **期权定价** | Black-Scholes、实物期权 | 战略投资的灵活性价值 |
| **资本结构理论** | MM定理、权衡理论、优序融资 | 融资决策 |
| **公司治理** | 委托-代理、信息不对称 | Term Sheet条款设计 |

## 六、学术研究与论文方向

### 6.1 基于模拟数据的研究主题

| 研究方向 | 研究问题 | 方法论 |
|----------|----------|--------|
| **决策行为** | 学生在模拟中是否表现出与理论预测一致的行为？ | 实验经济学 |
| **团队动态** | 团队规模、异质性如何影响决策质量？ | 组织行为学 |
| **学习效果** | 商业模拟教学相比传统案例教学的效果如何？ | 教育评估 |
| **算法优化** | 如何用机器学习方法优化模拟决策？ | 强化学习 |
| **跨文化比较** | 不同国家学生的决策风格有何差异？ | 跨文化研究 |

### 6.2 论文写作建议

- **数据来源**：模拟平台的决策日志、排行榜数据、学生问卷
- **理论框架**：结合经济学、管理学、心理学的理论
- **实证方法**：回归分析、实验设计、案例研究
- **发表渠道**：商学教育期刊、教学案例库

## 七、职业发展衔接

### 7.1 模拟经验 → 职业路径

| 模拟能力 | 对应职业 | 关键证书/技能 |
|----------|----------|--------------|
| 战略决策 | 战略咨询（MBB） | Case Interview训练 |
| 财务建模 | 投资银行、PE/VC | CFA、财务建模课程 |
| 投资分析 | 基金经理、分析师 | CFA、量化分析 |
| 运营管理 | 供应链经理、运营总监 | Six Sigma、PMP |
| 创业模拟 | 创业者、产品经理 | 精益创业、产品设计 |
| 国际商务 | 跨国企业管理者 | 语言能力、跨文化培训 |

### 7.2 模拟经验在求职中的应用

- **简历**：量化成果（"在全国企业竞争模拟大赛中，带领团队从200+队伍中获得前10%"）
- **面试**：用模拟经历回答行为面试题（"描述一次你在资源有限下做出艰难决策的经历"）
- **Case Interview**：模拟训练直接提升Case Interview表现
