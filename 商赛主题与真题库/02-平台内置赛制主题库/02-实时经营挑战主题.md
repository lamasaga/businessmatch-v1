## 一、赛制核心参数

### 1.1 公司初始状态

| 指标 | 初始值 | 说明 |
|------|--------|------|
| 现金流 | 100万 | 创业启动资金 |
| 团队规模 | 8人 | 包含创始人、技术、运营、市场 |
| 月收入 | 0 | 产品尚未产生收入 |
| 月支出 | 8.5万 | 人员工资+租金+服务器+推广 |
| 跑道（Runway） | 11.8个月 | 现金流除以月支出 |
| 产品完成度 | 60% | MVP开发中 |

### 1.2 核心指标体系

| 指标类别 | 具体指标 | 正常范围 | 危险阈值 |
|----------|----------|----------|----------|
| **财务健康** | 现金流 | 大于30万 | 小于15万 |
| | 月收入 | 持续增长 | 连续2月下降 |
| | runway | 大于6个月 | 小于3个月 |
| **运营效率** | 产能利用率 | 60-85% | 小于50%或大于95% |
| | 库存周转率 | 每月1-2次 | 小于0.5次 |
| | 客户获取成本（CAC） | 小于200元/人 | 大于500元/人 |
| **客户健康** | 月活跃用户（MAU） | 持续增长 | 流失率大于20% |
| | 客户满意度（NPS） | 大于30 | 小于0 |
| | 复购率 | 大于25% | 小于10% |

|----------|----------|----------|----------|----------|

| **投资人主动接触** | 8% | 融资机会，但可能估值偏低 | 5分钟 | 接受/谈判/拒绝并专注经营 |
| **技术突破** | 7% | 产品性能大幅提升 | 3分钟 | 快速上线/申请专利/市场宣传 |

### 2.3 极端事件（低频，影响巨大）

| 事件名称 | 发生概率 | 影响描述 |
|----------|----------|----------|
| **行业监管风暴** | 3% | 整个业务模式被质疑，需重大调整 |
| **核心竞品被收购** | 2% | 竞争格局剧变，巨头入场 |

## 三、经典决策情境题库

### 3.1 情境A：现金流危机应对

**背景**：
> 你的公司运营到第6个月，突然发生以下情况：
> - 最大客户（占收入40%）通知30天后终止合作
> - 当前现金流：23万
> - 月支出：8.5万
> - 跑道剩余：2.9个月（低于3个月安全线）
> - 产品仍在迭代中，新功能预计2个月后上线

**可选方案**：

**方案A：紧急裁员50%**
- 裁掉6名员工（保留核心技术和销售）
- 支出降至5.5万/月
- 需支付N+1补偿金约6万（一次性）
- 影响：-30%产能，士气受损，产品迭代延迟

**方案B：紧急融资**
- 以极低估值接受30万过桥贷款
- 稀释40%股权
- 影响：创始人控制权大幅下降，但获得10个月 runway

**方案C：全力挽回客户**
- 创始人亲自拜访，承诺降价20%+专属服务
- 50%概率挽回，投入2万差旅和招待成本
- 影响：若挽回成功，利润率下降但维持运营；若失败，浪费宝贵时间和资金

**方案D：Pivot转型**
- 放弃B端业务，All in C端产品
- 3个月开发期，期间零收入
- 影响：高风险豪赌，若成功市场扩大10倍；若失败，公司倒闭

**教学锚点**：
- 现金流管理的"死亡螺旋"概念
- 固定成本的刚性与变动成本的灵活性
- 沉没成本谬误（是否因为已投入很多而不愿止损？）

### 3.2 情境B：增长与质量的权衡

**背景**：
> 第4个月，产品获得市场认可，MAU快速增长：
> - 当前MAU：5,000人
> - 月增长率：40%
> - 客户投诉率：从2%上升到8%
> - 服务器响应时间：从200ms上升到800ms
> - 技术团队请求2周时间重构代码，期间暂停新功能开发

**决策问题**：
1. 是否同意技术团队暂停新功能开发？
2. 是否增加服务器投入以应对增长？
3. 是否降低市场投放以控制投诉增长？
4. 是否紧急招聘更多技术人员？

**分析框架**：
- 技术债务的累积效应（现在不修，以后成本更高）
- 增长与质量的经典权衡
- 网络效应的窗口期（错过增长窗口可能丧失先发优势）

### 3.3 情境C：投资人找上门

**背景**：
> 第8个月，公司月收入达到15万，月支出12万，首次实现盈亏平衡。
> 
> 某知名VC主动联系，提出：
> - 投资200万
> - 投前估值800万
> - 要求25%股权
> - 附加条款：对赌协议（12个月内月收入需达到50万，否则创始人需转让额外5%股权）

**决策问题**：
1. 接受投资？谈判更好条款？还是拒绝？
2. 如果接受，如何分配200万？（市场扩张/团队/技术/储备）
3. 对赌协议的风险评估
4. 如果不接受，如何维持自造血增长？

**教学锚点**：
- 融资估值方法论
- 对赌协议的风险
- 创始人控制权与资金需求的权衡
- 精益创业的"持续经营"原则

## 四、运营优化真题

### 4.1 库存管理

**题目**：
> 你的产品月销量为1,000件，每次订货成本500元，每件每月库存持有成本2元。计算经济订货量（EOQ）。如果供应商要求最低订货量500件，你应该接受吗？

**解答**：
- EOQ = 根号(2乘1000乘500除2) = 根号500,000 约等于 707件
- 最低订货量500件小于EOQ 707件，因此接受500件但订货频率需提高

### 4.2 盈亏平衡分析

**题目**：
> 你的产品售价100元/件，变动成本60元/件，月固定成本30,000元。计算：
> 1. 盈亏平衡销量
> 2. 如果目标月利润20,000元，需要销售多少件？
> 3. 如果降价至90元以刺激销量，新的盈亏平衡销量是多少？

**解答**：
1. 盈亏平衡 = 30,000 除 (100-60) = 750件
2. 目标销量 = (30,000+20,000) 除 40 = 1,250件
3. 新盈亏平衡 = 30,000 除 (90-60) = 1,000件（风险上升）

### 4.3 客户生命周期价值（LTV）

**题目**：
> 你的获客成本（CAC）为150元，客户平均每月消费50元，毛利率40%，平均客户留存周期为12个月。计算LTV和LTV/CAC比率。这个比率健康吗？

**解答**：
- 月毛利贡献 = 50 乘 40% = 20元
- LTV = 20 乘 12 = 240元
- LTV/CAC = 240除150 = 1.6
- 健康标准：LTV/CAC 大于 3，因此当前比率偏低

## 五、系统动力学基模

### 5.1 舍本逐末

```
客户投诉增加 → 增加客服人手（症状解）→ 投诉暂时减少
                      下
               产品问题未解决 → 投诉更多 → 需要更多客服
```

**教学点**：症状解（治标）vs 根本解（治本）

### 5.2 成长上限

```
市场投放增加 → 用户增长 → 服务器压力 → 体验下降 → 口碑恶化 → 增长停滞
```

**教学点**：增长不是无限的，基础设施需要同步升级

### 5.3 死亡螺旋（反向增强回路）

```
现金流紧张 → 削减研发投入 → 产品竞争力下降 → 客户流失 → 收入下降 → 现金流更紧张
```

**教学点**：有时"节流"比"开源"更紧迫，但要避免削减核心能力

## 六、教学使用建议

### 6.1 适合场景

- **创业课程的风险教育**：让学生体验真实创业的现金流压力
- **运营管理课程**：理解产能、库存、供应链的动态平衡
- **危机管理培训**：在信息不完全和时间压力下做出选择

### 6.2 常见学生误区

| 误区 | 表现 | 纠正方法 |
|------|------|----------|
| **过度乐观** | 低估固定支出，高估收入增长 | 强调 runway 概念，强制计算 |
| **忽视 runway** | 不关注"还能活多久" | 将 runway 设为仪表盘核心指标 |
| **反应过度** | 对每个危机都采取最激进措施 | 引导区分"可控危机"和"系统性危机" |
| **沉没成本** | 因为已投入很多，不愿及时止损 | 课后复盘强调"零基决策"思维 |
