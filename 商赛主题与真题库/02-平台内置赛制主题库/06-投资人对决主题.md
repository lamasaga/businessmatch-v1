# 投资人对决 · 主题与真题库

> **赛制编号**：Mode 06
> **核心机制**：双阵营对抗（创业者vs投资人）、路演、估值博弈、Term Sheet谈判
> **适用学段**：大学及以上
> **核心能力**：路演表达、估值分析、条款谈判
> **阵营**：创业者（融资方）vs 投资人（出资方）

---

## 一、双阵营机制

### 1.1 创业者阵营

| 维度 | 详情 |
|------|------|
| **目标** | 获得尽可能高的估值，融到足够资金 |
| **最终排名** | 按公司估值排名 |
| **核心能力** | 路演表达、商业计划、估值谈判、经营兑现 |
| **获胜逻辑** | 讲好故事 → 拿到高估值 → 经营证明估值合理 |

### 1.2 投资人阵营

| 维度 | 详情 |
|------|------|
| **目标** | 用有限虚拟资金投资最有潜力的项目 |
| **最终排名** | 按组合回报率(ROI)排名 |
| **核心能力** | 项目判断、估值分析、风险分散、投后管理 |
| **获胜逻辑** | 发现被低估的项目 → 谈判拿到好条款 → 投后增值 → 退出获利 |

### 1.3 融资路线图

```
种子轮(500万) → 天使轮(2000万) → A轮(1亿) → B轮(5亿) → IPO/并购(30亿+)
   已完成        已完成          当前         待解锁        终局
```

## 二、路演评分维度

创业者路演评分标准：

| 维度 | 权重 | 评审要点 |
|------|------|----------|
| 商业逻辑清晰度 | 25% | 商业模式是否自洽、市场机会是否真实 |
| 数据支撑力度 | 20% | 是否使用财务预测、市场调研数据 |
| 团队说服力 | 20% | 演讲表达、问答应对、团队协作 |
| 创新性与差异化 | 20% | 与竞争对手的差异化优势 |
| 可行性 | 15% | 执行计划是否现实、时间表是否合理 |

## 三、估值方法论题库

### 3.1 估值方法选择

| 方法 | 适用阶段 | 核心公式 | 优点 | 缺点 |
|------|----------|----------|------|------|
| **P/S倍数** | 早期（无利润） | 估值 = 年收入 x 行业P/S | 简单直观 | 忽略成本结构 |
| **P/E倍数** | 成长期（有利润） | 估值 = 净利润 x 行业P/E | 反映盈利能力 | 利润可操纵 |
| **DCF** | 成熟期 | 估值 = 未来现金流现值之和 | 理论基础扎实 | 假设敏感 |
| **可比公司法** | 任何阶段 | 参考同类公司交易估值 | 市场导向 | 可比公司难找 |
| **风险投资法** | 早期 | 考虑目标回报率的逆向推导 | 适合高风险项目 | 主观性强 |

### 3.2 估值计算真题

**题目1：P/S估值**
> 某SaaS公司年收入1,200万，年增长率120%，毛利率65%。行业P/S倍数为8-12x，团队溢价系数1.3x。
> 
> 计算合理估值区间。

**解答**：
- 基础估值 = 1,200 x (8到12) = 9,600万到14,400万
- 团队溢价后 = 9,600x1.3 到 14,400x1.3 = 1.25亿到1.87亿
- 考虑增长率溢价（120%为高增长），可上浮至1.5亿-2.0亿

**题目2：DCF估值**
> 某公司未来5年自由现金流预测：
> - 第1年：200万
> - 第2年：300万
> - 第3年：450万
> - 第4年：600万
> - 第5年：800万
> 
> 永续增长率g=3%，WACC=12%。计算企业价值。

**解答**：
- 前5年现值 = 200/1.12 + 300/1.12^2 + 450/1.12^3 + 600/1.12^4 + 800/1.12^5
- 终端价值 = 800x(1+3%) / (12%-3%) = 9,156万
- 终端价值现值 = 9,156 / 1.12^5
- 企业价值 = 前5年现值 + 终端价值现值（约7,500万）

**题目3：风险投资法**
> 投资人要求5年10倍回报（IRR约58%）。当前投前估值5,000万，预计5年后退出估值5亿。投资人应占多少股权？

**解答**：
- 投资人要求5年后价值 = 投资额 x 10
- 设投资额为X，X x 10 = 退出时价值 x 股权比例
- 若投后估值6,000万（投前5,000万+投资1,000万）
- 5年后公司估值5亿，投资人股权 = 1,000/6,000 = 16.7%
- 投资人5年后价值 = 5亿 x 16.7% = 8,350万
- 倍数 = 8,350/1,000 = 8.35x < 10x，不满足要求
- 需重新调整：设投资额为X，X x 10 = 5亿 x (X/(5,000+X))
- 解得 X 约等于 1,250万，股权比例约20%

## 四、Term Sheet关键条款

### 4.1 核心条款解析

| 条款 | 创业者视角 | 投资人视角 | 谈判要点 |
|------|-----------|-----------|----------|
| **估值** | 越高越好 | 越低越好（但需交易完成） | 市场可比、增长预期、团队溢价 |
| **股权比例** | 稀释越少越好 | 需达到目标回报 | 投资额/投后估值 |
| **反稀释保护** | 限制未来融资的低价发行 | 保护不被后续低价融资稀释 | 广义vs狭义加权平均 |
| **优先清算权** | 限制投资人优先拿走太多 | 确保最坏情况下收回投资 | 1x非参与式 vs 2x参与式 |
| **董事会席位** | 保持控制权 | 参与重大决策 | 创始人+投资人+独立董事 |
| **对赌协议** | 压力巨大，可能丧失控制权 | 激励管理层达成目标 | 业绩指标、时间窗口、补偿方式 |
| **竞业禁止** | 限制创始人离职后创业 | 保护投资不被创始人带走 | 期限、地域、补偿 |
| **回购权** | 可能被要求高价回购 | 提供退出渠道 | 触发条件、回购价格 |

### 4.2 条款博弈真题

**情境**：
> 创业者提出投前估值1.5亿，投资人提出1.2亿。
> 双方差异主要体现在：
> - 创业者认为技术壁垒应给予30%溢价
> - 投资人认为市场尚未验证，应保守估值
> 
> 谈判空间：
> 1. 提高估值但增加对赌条款
> 2. 接受较低估值但减少反稀释保护
> 3. 分期投资（里程碑式），降低单次风险
> 4. 设置棘轮条款，根据业绩调整估值

**分析**：
- 分期投资（里程碑式）是双赢方案：创业者获得较高名义估值，投资人降低风险
- 对赌条款需谨慎：过度激进的对赌可能导致创始人行为扭曲（短期主义）

## 五、投资组合管理

### 5.1 分散化策略

投资人需在多个项目中分散投资：

| 分散维度 | 说明 | 示例 |
|----------|------|------|
| **行业分散** | 不集中在单一行业 | 科技+消费+医疗+教育 |
| **阶段分散** | 种子/天使/A轮混合 | 早期高回报+晚期低风险 |
| **地域分散** | 不同地区项目 | 一线城市+新一线+海外 |
| **时间分散** | 分批投资 | 避免在市场高点全部投入 |

### 5.2 投后管理

| 活动 | 频率 | 目的 |
|------|------|------|
| 董事会会议 | 季度 | 战略监督、资源对接 |
| 财务报告审查 | 月度 | 财务健康监控 |
| 关键里程碑检查 | 按约定 | 对赌条款执行 |
| 增值服务 | 持续 | 介绍客户、招聘、后续融资 |

## 六、经典路演真题

### 6.1 5分钟路演结构

```
0:00-0:30  钩子（Hook）
           "每年有超过100万中小企业因现金流断裂而倒闭。我们解决这个问题。"

0:30-1:30  问题（Problem）
           市场规模、痛点深度、现有解决方案不足

1:30-3:00  解决方案（Solution）
           产品演示、核心功能、技术壁垒

3:00-4:00  商业模式（Business Model）
           收入来源、定价策略、增长飞轮

4:00-4:30  团队与 traction
           核心团队背景、已有成绩、关键指标

4:30-5:00  融资需求（Ask）
           "我们正在寻求500万天使轮融资，用于产品开发和市场验证。"
```

### 6.2 投资人常见提问

| 问题类型 | 示例 | 考察点 |
|----------|------|--------|
| 市场验证 | "你们有多少付费用户？付费转化率多少？" | PMF（产品-市场匹配） |
| 竞争壁垒 | "如果腾讯明天做同样的事，你怎么办？" | 护城河 |
| 财务预测 | "你的财务预测中第二年增长300%，依据是什么？" | 理性程度 |
| 团队风险 | "如果CTO离开，项目还能继续吗？" | 团队稳定性 |
| 退出路径 | "你期望的退出方式是什么？IPO还是并购？" | 战略清晰度 |
| 资金用途 | "这500万你会怎么花？" | 执行力、规划能力 |

## 七、教学锚点

| 学生体验 | 教师锚定问题 | 对应理论 |
|----------|-------------|----------|
| "投资人把我的估值压得很低" | "估值是艺术还是科学？哪些因素让两家公司估值相差10倍？" | 估值方法论 |
| "我答应了太多条款，现在很被动" | "Term Sheet中的哪些条款可能在日后让你失去公司？" | 公司治理、控制权 |
| "我投的项目都失败了" | "投资组合理论告诉我们，即使每个项目都看起来很好，为什么整体仍会亏损？" | 分散化、幸存者偏差 |
| "创业者说的一切都太完美了" | "作为投资人，你如何识别过度包装？尽职调查的关键是什么？" | 信息不对称、信号理论 |
| "我的对赌协议让我不得不做短视决策" | "激励相容为什么重要？错误的激励如何导致错误的行为？" | 委托-代理理论、激励设计 |
