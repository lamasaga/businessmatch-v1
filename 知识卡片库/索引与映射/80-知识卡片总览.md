# 知识卡片总览与索引

> **文档定位**：知识卡片库（Knowledge Card Library）的全局索引，涵盖经济学、商学、管理学三大领域共 **48张核心概念卡片**。每张卡片均可被平台各系统调用：CyberCore（赛制规则）、Persona（性格推荐）、Athena（AI辅导）、Apollo（数据追踪）。
>
> **设计理念**："每一个概念都是一颗种子"——在不同学段以不同深度播种，在赛事体验中发芽，在反思复盘时开花。

## 五、使用指南

### 5.1 教师使用场景

```
场景1：备课时
  输入：今天要上"定价策略"
  查询：KN-BS-MK-005 + 关联赛制（03拍卖/01回合制）
  输出：概念定义 → 生活案例 → 平台赛事配置 → 课后复盘Prompt

场景2：学生提问时
  输入：学生问"什么是机会成本"
  查询：KN-EC-MI-004
  输出：定义 → 类比 → 学生所在学段适配版 → 关联赛事

场景3：AI Tutor 实时辅导
  输入：学生在"拍卖交易大厅"中过度竞价
  查询：KN-EC-BE-002（损失厌恶）+ KN-EC-MI-002（价格弹性）
  输出：AI提示"你似乎不想'错过'这个机会——这是损失厌恶在影响你的判断"
```

### 5.2 内容创作者使用场景

```
场景：设计一个新的"品牌危机管理"赛事
  步骤1：查询 KN-BS-MK-003（品牌资产）+ KN-MG-ET-003（伦理决策）
  步骤2：查看关联赛制 → 05案例推演 + 12品牌造物坊
  步骤3：复制卡片元数据 → 填写赛事配置模板
  步骤4：参考卡片中的"学段适配"设计难度梯度
  步骤5：引用卡片中的"AI辅导话术"设计Athena介入点
```
