## Feature 5：单轮结算

**作为** 参赛队伍
**我希望** 每轮决策后能看到准确的财务结果和市场排名
**从而** 调整下一轮策略

### Background

```gherkin
Given OPS 比赛 "OPS-2026-0610-A1B2" 状态为 "operation_round_1"
And 比赛中有 4 支队伍："创新者联盟"、"极速科技"、"品质生活"、"未来工厂"
And 所有队伍均已提交 R1 决策
```

### Scenario 5.1：R1 结算后生成财务报表

```gherkin
Given 队伍 "创新者联盟" 的 R1 决策为：
  | 生产量 | 单价 | 市场营销 | 研发 | 销售人员 | 城市 |
  | 200    | 180  | 8000     | 5000 | 3        | 杭州 |
And 队伍 "创新者联盟" 的产品品类为 "home"
And 目标客群为 "pragmatic"
When 组织者李老师点击「结算 R1」
Then 比赛状态变为 "settlement_1"
And 队伍 "创新者联盟" 收到 R1 损益表
And 损益表中营业收入 = 实际销量 × 180
And 损益表中营业成本 = 实际销量 × 单位成本
And 损益表中运营利润 = 毛利润 - 营销费用 - 研发费用 - 人力费用 - 管理费用 - 库存持有成本
And 队伍 "创新者联盟" 收到 R1 资产负债表
And 资产负债表中现金大于等于 0
And 比赛状态变为 "operation_round_2"
```

### Scenario 5.2：生产量超过产能上限时按上限生产

```gherkin
Given 队伍 "极速科技" 的 R1 决策中生产量为 800
And 队伍 "极速科技" 的基础产能为 200
And 队伍 "极速科技" 无产能加成
When 组织者李老师点击「结算 R1」
Then 队伍 "极速科技" 的实际产量为 200
And 队伍 "极速科技" 的原材料采购费按 200 计算
And 结算提示中显示 "生产计划受产能限制"
```

### Scenario 5.3：库存结转到下一轮

```gherkin
Given 队伍 "品质生活" 的 R1 决策中生产量为 200
And R1 结算后 "品质生活" 实际销量为 150
When 组织者李老师点击「结算 R1」
Then 队伍 "品质生活" 的库存为 50
And 队伍 "品质生活" 的库存持有成本 = 50 × 2
```

### Scenario 5.4：开启新城市时扣除开城费

```gherkin
Given 队伍 "未来工厂" 的 R1 决策中目标城市包含 "上海"
And 上海为一线城市，开城费为 30000
And 队伍 "未来工厂" 此前未进入过上海
When 组织者李老师点击「结算 R1」
Then 队伍 "未来工厂" 的现金减少 30000
And 队伍 "未来工厂" 的已开拓城市包含 "上海"
And R2 选择上海不再扣除开城费
```

### Scenario 5.5：结算后触发市场事件

```gherkin
Given OPS 比赛当前为 R2 结算
And 系统随机触发 "原材料涨价" 事件
When 组织者李老师点击「结算 R2」
Then 结算结果中显示新闻 "原材料涨价：上游原材料供应紧张，成本上升"
And R3 所有队伍的原材料成本乘以 1.15
```

### Scenario 5.6：结算幂等性

```gherkin
Given 组织者李老师已点击过一次「结算 R1」
And 所有队伍的 R1 状态已更新
When 组织者李老师因误操作再次点击「结算 R1」
```


**我希望** 在比赛结束后看到最终排名和奖励
**从而** 知道比赛结果和获得的成长资源

```gherkin

  | 创新者联盟 | 110000 | 10000 | 80000 |
  | 极速科技 | 105000 | 5000 | 75000 |
And 系统按总得分降序排名
And 比赛状态变为 "finished"
```

### Scenario 9.2：发放 XP 和金币奖励

## Feature 11：异常与边界场景

**作为** 系统运营者
**我希望** 各种异常边界都能被妥善处理
**从而** 保证比赛稳定运行

### Scenario 11.1：队伍在比赛中途退出

```gherkin
Given OPS 比赛 "OPS-2026-0610-A1B2" 处于 R2 开放决策阶段
And 队伍 "极速科技" 有 2 名队员在线
When 这 2 名队员同时断开连接超过 30 秒
Then 系统将该队标记为 "离线"
And 组织者李老师可选择「托管为 AI」
When 李老师点击「托管为 AI」
Then 队伍 "极速科技" 后续轮次由 AI 代理决策
And 该队显示 "AI 托管" 标识
```

### Scenario 11.2：组织者强制推进轮次

```gherkin
Given OPS 比赛 "OPS-2026-0610-A1B2" 处于 R3 开放决策阶段
And 4 支队伍中已有 3 支提交决策
And 倒计时剩余 3 分钟
When 组织者李老师点击「强制截止」
Then 未提交的队伍 "未来工厂" 自动生成默认决策
And 系统立即执行 R3 结算
And 比赛状态变为 "operation_round_4"
```

### Scenario 11.3：空状态排行榜

```gherkin
Given OPS 比赛 "OPS-2026-0610-A1B2" 刚创建
And 比赛状态为 "registration"
When 学生小林尝试查看排行榜
Then 系统提示 "比赛尚未开始，暂无排行数据"
And 不显示空白或崩溃
```

### Scenario 11.4：结算后数据一致性

```gherkin
Given OPS 比赛 "OPS-2026-0610-A1B2" 已完成 R2 结算
When 学生小林同时查看：
  | 页面 |
  | 排行榜 |
  | 财务报表 |
  | 大屏投影 |
Then 三个页面上 "创新者联盟" 的净资产显示一致
And 三个页面上当前轮次均显示 "R3 运营决策"
```
