## 一、概述

### 1.1 设计目标

把教师端从「高级组织者控制台」升级为「课程实施导演台」。在 7 天夏令营场景中，教师的核心诉求是：

| 角色场景 | 教师需要做什么 | 平台应支持 |
|----------|---------------|-----------|
| **导演** | 编排 7 天的教学节奏 | 每日议程 + 任务发布 + 进度监控 |
| **裁判** | 评价学生/团队的产出 | 评分维度配置 + 多评委打分 + 奖项颁发 |
| **银行家** | 运营营币经济系统 | 发放/扣除 + 规则配置 + 商城管理 |
| **策展人** | 收集和展示学生作品 | 任务提交 + 画廊浏览 + 导师点评 |
| **HR** | 组建和管理公司团队 | 角色分配 + 公司主页 + 角色轮换 |

### 1.2 信息架构（Tab 结构）

基于现有 `CampDetailPage` 的 7 个 Tab，扩展为 **7 个主 Tab**，覆盖夏令营全部场景：

```
教师端 :5174 /camps/:id
├── 📊 概览          ← 扩展：看板 + 今日议程 + 快捷操作
├── 📋 任务中心      ← 新增：任务发布 + 进度看板 + 作品画廊 + 导师点评
├── 🏢 公司管理      ← 新增：公司列表 + 角色分配 + 公司主页
├── 🪙 营币经济      ← 新增：发放 + 规则 + 商城 + 排行榜
├── 🏆 评分评奖      ← 新增：评分维度 + 打分 + 奖项 + 颁奖
├── 🎮 营内商赛      ← 已有：发起商赛 + 控场（不变）
└── 👥 成员管理      ← 合并：成员名册 + 学员进度 + 分组管理 + 公告
```

> **设计原则**：Tab 不超过 7 个，避免信息过载。"成员管理"合并原有的 members/progress/groups/announcements 四个子 Tab。

### 2.4 交互细节

**今日议程（TodayAgenda）**
- 数据来源于「任务中心」的当日任务配置
- 当前进行中的环节：绿色高亮 + 倒计时显示
- 已结束的环节：灰色 + 完成标记 ✅
- 点击「编辑今日议程」跳转任务中心 Tab
- 每个环节可展开查看：地点、说明、关联任务

**快捷操作（QuickActions）**
- 5 个按钮点击后跳转对应 Tab 并打开对应弹窗：
  - 「发布任务」→ 任务中心 + 打开新建任务弹窗
  - 「发放营币」→ 营币经济 + 打开发放弹窗
  - 「抽命运卡」→ 营币经济 + 打开命运卡弹窗
  - 「查看画廊」→ 任务中心 + 切换到画廊子视图
  - 「进入控场」→ 营内商赛（如存在进行中商赛）

**任务状态流转**：
```

  ↓ 教师发布
published（已发布）→ 学生可见，可提交
  ↓ 截止
closed（已截止）→ 停止接收提交
  ↓ 教师评分完成
scored（已评分）→ 学生可见分数和点评
  ↓ 教师手动
archived（已归档）
```

## 九、全局交互与状态流转

### 9.1 教师操作状态机

```
营团生命周期：

  创建营团
    ↓
  draft（草稿）→ 配置角色模板、议程、任务
    ↓
  active（招募中）→ 学生入营、分组
    ↓
  running（进行中 Day 1~7）→ 发布任务、发放营币、评分、控场
    ↓
  closing（结营中 Day 7）→ 评分汇总、颁奖、生成档案
    ↓
  closed（已结束）→ 档案只读、历史回顾
```

### 9.2 关键交互流程

**流程 1：教师发布任务**
```
教师: 点击「发布任务」
  → 打开 CreateTaskModal
  → 填写标题、类型、天数、截止时间、提交要求
  → 配置评分维度（可选）
  → 选择提交对象（个人/公司）
  → 点击「创建」
  → 系统创建任务，推送通知给学生
  → 学生端「今日任务中心」显示新任务
```

**流程 2：教师发放营币**
```
教师: 点击「发放营币」
  → 打开发放弹窗
  → 选择对象（全营/公司/个人）
  → 输入金额和理由
  → 预览确认
  → 点击「确认发放」
  → 系统创建 CampCoinTransaction
  → 学生端实时收到余额变动通知
```

**流程 3：教师评分**
```
教师: 进入「评分评奖」→「评分管理」
  → 选择要评分的任务
  → 查看未评分公司列表
  → 点击「去评分」
  → 打开评分弹窗
  → 查看作品 + 各维度打分 + 写点评
  → 点击「保存并下一家」
  → 系统自动计算综合分
  → 学生端可见评分和点评
```

### 9.3 实时通知（WebSocket / SSE）

| 事件 | 推送对象 | 内容 |
|------|---------|------|
| 新任务发布 | 营内全部学生 | 任务标题、截止时间 |
| 营币发放 | 受赠学生 | 金额、理由、新余额 |
| 任务截止提醒 | 未提交学生 | 任务名、剩余时间 |
| 作品被精选 | 提交团队 | 作品名、导师评语 |
| 新公告 | 营内全部学生 | 公告标题 |
| 评分更新 | 被评分学生 | 任务名、综合分 |
| 命运卡触发 | 营内全部学生 | 卡片标题、效果 |
| 颁奖 | 获奖团队 | 奖项名、奖杯动画 |
