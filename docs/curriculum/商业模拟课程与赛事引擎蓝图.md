# 商业模拟课程与赛事引擎蓝图

> **最后更新**：2026-07-05
> **Phase**：A 范围内的课程与产品上游文档，不触代码、不新增路由、不新增数据库表。
> **任务类型**：经济学夏令营课程组织 + 商业模拟赛事引擎设计。
> **核心原则**：不要先问“现有几个引擎怎么排课”，而要先问“学生应该经历哪些商业与经济学问题”。赛事引擎是课程的实验室，不是课程的起点。

---

## 一、总判断

商业模拟教育最有价值的部分，不是让学生背概念，也不是让他们在屏幕上多点几次按钮，而是让他们在有限信息、有限资源和真实竞争压力下做选择，然后用经济学和商学语言解释自己的选择。

因此，课程组织应当遵循这样的顺序：

```
知识目标 → 可体验的问题 → 学生决策 → 系统反馈 → 数据复盘 → 迁移到现实商业
```

引擎设计也应当从这个顺序反推：

```
本节课要讲的概念
  ↓
学生会自然犯什么错
  ↓
用什么比赛机制让这个错误显性化
  ↓
赛后用哪些图表和问题把它讲清楚
```

这意味着，未来的商业模拟引擎不应被简单理解成“贸易、运营、创投、金融”几个产品名字，而应理解成一组“经济学问题实验器”。同一个引擎可以服务多个课程，同一门课程也可以拆成多个轻量实验。

---

## 二、教学目标分层

商业模拟课程可以分成五层目标。越往上越接近真实商业能力，越往下越适合做成概念课和短局练习。

| 层级 | 学生要形成的能力 | 典型课堂问题 | 模拟引擎承担什么 |
|------|------------------|--------------|------------------|
| 1. 概念识别 | 认识成本、价格、利润、风险、现金流等基本词汇 | 为什么收入高不等于赚钱？ | 给出可见数字与即时反馈 |
| 2. 模型思维 | 用供需、边际、弹性、机会成本解释现象 | 为什么降价可能反而少赚钱？ | 让变量之间的关系可观察 |
| 3. 决策训练 | 在预算、产能、时间和不确定性下做取舍 | 钱应该投广告、库存还是研发？ | 提供有限资源和互斥选择 |
| 4. 竞争协作 | 理解市场竞争、谈判、联盟、博弈和规则 | 价格战为什么会伤害所有人？ | 让学生之间互相影响 |
| 5. 复盘迁移 | 用数据讲清楚策略，迁移到真实商业案例 | 这局输了，到底输在判断还是执行？ | 输出可复盘日志、图表和评价 |

一个好的赛事引擎至少要服务第 2～5 层，而不是只停留在“谁的分数更高”。

## 三、课程知识地图

以下知识地图不按现有引擎划分，而按商学与经济学教学逻辑划分。每个模块都可以独立做短课，也可以组合成夏令营主线。

### 3.1 商业语言与财务启蒙

这是所有模拟的共同底座。学生需要先分清收入、成本、利润、现金、资产、负债这些词，否则后续的市场竞争和投融资都会变成“看分数猜输赢”。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 收入、成本、利润 | 利润不是销售额，成本结构决定抗风险能力 | 小店经营、订单选择、成本报价 |
| 现金流 | 账面盈利和现金断裂可以同时发生 | 赊销、库存、租金、工资发放 |
| 固定成本 / 变动成本 | 规模扩大前后，单位成本不同 | 产能扩张、设备购买 |
| 损益表雏形 | 一局比赛结束后如何读经营结果 | 赛后财务报表复盘 |

适合学段：小学高段到初中可做直观体验，高中以上可加入报表和财务比率。

### 3.2 稀缺、选择与机会成本

经济学的第一课不是赚钱，而是选择。每一笔预算、每一次行动点、每一个团队角色，都应让学生感到“选了 A 就不能选 B”。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 稀缺性 | 资源有限，所以必须排序 | 有限预算采购原料、雇人、投广告 |
| 机会成本 | 成本包括放弃的最好选择 | 多项目投资、城市路线选择 |
| 边际收益 / 边际成本 | 多投入一单位是否值得 | 连续加价、扩产、加广告 |
| 沉没成本 | 已经花掉的钱不应决定下一步 | 亏损项目是否继续投入 |

适合学段：初中以上。小学高段可以用“时间、金币、库存格子”做直观版。

### 3.3 市场交换、价格与供需

价格不是老师给的答案，而是市场参与者互相试探后的结果。这个模块是经济学体验感最强的部分，适合做成高互动短局。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 供给与需求 | 买卖双方共同决定成交价和成交量 | 双向拍卖、交易大厅 |
| 价格弹性 | 同样涨价，对不同商品影响不同 | 不同城市、不同消费者群体 |
| 流动性 | 有人愿意交易，价格才有意义 | 稀缺商品、市场深度变化 |
| 套利 | 同一商品在不同市场价格不同会引发搬运 | 城市间贸易、运费和风险 |
| 信息不对称 | 信息优势会改变报价和利润 | 私有情报、质量隐藏、市场传闻 |

适合学段：初中到大学。年龄越高，越可以加入需求曲线、均衡价格、市场失灵。

### 3.4 企业运营、产能与供应链

很多学生会天然以为“卖得越多越好”，运营模块要让他们看到产能、库存、交付、资金周转和质量管理的约束。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 产能约束 | 想卖不等于能生产 | 工厂排产、设备瓶颈 |
| 库存管理 | 缺货损失销售，过量占用现金 | 需求预测、库存周转 |
| 单位经济模型 | 每单赚多少钱比总销量更重要 | 定价、材料、渠道费用 |
| 供应链风险 | 上游价格、运输、延迟会影响利润 | 原料竞价、物流事件 |
| 质量与返工 | 低价低质可能带来后续惩罚 | 质量投入、退货、口碑 |

适合学段：初中以上。高中和大学可加入 EOQ、瓶颈理论、现金转换周期。

### 3.5 市场营销与消费者行为

营销不只是“砸广告”，而是理解谁会买、为什么买、以什么价格买。这个模块可以把抽象的需求曲线变成可观察的人群选择。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 市场细分 | 不同消费者重视不同价值 | 学生、白领、家庭、企业客户 |
| 定位 | 产品不是越全越好，要有清晰选择 | 品牌路线、功能取舍 |
| 渠道 | 同一产品在不同渠道成本和客群不同 | 线上、门店、代理、校园渠道 |
| 广告边际效应 | 广告有递减收益 | 广告预算分配 |
| 口碑与复购 | 短期销量和长期信任可能冲突 | 客诉、满意度、复购率 |

适合学段：初中以上。低龄段可以做“摆摊卖给不同顾客”，高龄段可加入 A/B 测试与 CAC/LTV。

### 3.6 竞争战略与博弈论

商业不是单人解题，而是和其他团队同时行动。战略模块应让学生体验“我的最优选择取决于别人怎么做”。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 价格战 | 个体理性可能导致集体利润下降 | 多队同品类定价 |
| 差异化 | 不一定要在同一维度硬拼 | 产品路线、城市选择、客群定位 |
| 进入壁垒 | 先发优势、规模、品牌会改变竞争格局 | 市场抢占、专利、渠道锁定 |
| 重复博弈 | 长期关系会改变短期背叛收益 | 多轮合作、供货协议 |
| 信号与承诺 | 可置信承诺比口头承诺更重要 | 保证金、合同、公开投资 |

适合学段：高中以上。初中可以用简化的“价格战与差异化”。

### 3.7 投资、金融与风险

金融模块不能只做成“炒价格”，而要讲风险、收益、信息、组合和时间。学生应理解金融的本质是跨时间配置资源、承担风险并要求补偿。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 风险收益权衡 | 高收益通常伴随高不确定性 | 多资产投资组合 |
| 分散化 | 不把所有资源押在一个结果上 | 行业组合、城市组合 |
| 信息与预期 | 价格反映预期，不只反映现在 | 新闻事件、财报、传闻 |
| 杠杆 | 放大收益也放大损失 | 借款投资、保证金 |
| 时间价值 | 今天的钱和未来的钱不同 | 利息、折现、长期项目 |

适合学段：高中到大学。低龄段可做“风险卡牌 + 储蓄投资”的轻量版。

### 3.8 创业、创新与商业模式

创业模块不应只等于“融资比赛”。真正的教学重点是发现问题、验证需求、搭建商业模式、管理有限资源，并在不确定中迭代。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 用户痛点 | 创意必须对应真实需求 | 访谈、需求卡、场景任务 |
| MVP | 用最小成本验证关键假设 | 原型选择、测试预算 |
| 单位经济 | 增长之前先看每单是否成立 | CAC、LTV、毛利 |
| 融资与股权 | 钱不是免费的，会稀释和约束 | 投资人谈判、估值 |
| 团队分工 | 创业是多职能协作 | CEO/CFO/COO/CMO/产品经理 |

适合学段：初中到大学。大学段可加入商业计划书、路演和尽调。

### 3.9 宏观经济、国际贸易与政策

宏观模块适合作为高阶课程或综合营的背景层。它让学生看到企业不是漂浮在真空里，而是受利率、汇率、产业政策、关税和周期影响。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 经济周期 | 需求、融资和就业会随周期变化 | 景气/衰退事件 |
| 汇率 | 跨境交易会受货币变化影响 | 进口原料、出口销售 |
| 关税与贸易壁垒 | 政策改变比较优势 | 国家/城市贸易路线 |
| 利率 | 影响融资成本和投资决策 | 借款、扩张、资产价格 |
| 产业政策 | 补贴和监管会改变企业行为 | 新能源、教育、医疗等行业主题 |

适合学段：高中到大学。低龄段可以只保留“天气、政策、节日需求”等外部冲击。

### 3.10 ESG、伦理与公共价值

商业教育如果只奖励利润，会训练出单薄的商业观。ESG 与伦理模块应让学生看到外部性、信誉、合规和长期价值。

| 知识点 | 讲授重点 | 适合的模拟体验 |
|--------|----------|----------------|
| 外部性 | 企业行为会影响非交易方 | 污染、拥堵、公共资源 |
| 合规 | 违规可能短期获利，长期受罚 | 监管抽查、声誉扣分 |
| 利益相关者 | 股东之外还有员工、客户、社区 | 薪资、质量、安全 |
| 长期主义 | 信任和品牌是慢变量 | 复购、人才吸引、许可证 |
| 社会创新 | 商业也可以解决公共问题 | 公益产品、普惠服务 |

适合学段：初中以上。建议作为综合复盘维度，而不是单独孤立成“道德说教”。

## 四、按学段组织课程

同一知识模块应按年龄降低抽象程度，而不是简单删减。低龄段用故事和可见反馈，高龄段逐渐加入公式、报表和策略分析。

| 学段 | 教学重心 | 推荐课程主题 | 推荐模拟形态 |
|------|----------|--------------|--------------|
| 小学高段 | 财商启蒙、交换、预算、诚信 | 我的第一家小店、集市交易、预算挑战 | 短局、卡牌、直观数值、少变量 |
| 初中 | 企业经营、市场竞争、团队协作 | 开店经营、城市贸易、广告与定价 | 3～5 轮回合制、小队竞争 |
| 高中 | 经济学模型、战略、金融风险、创业 | 供需与价格、产销运营、投资组合、创业路演 | 多轮经营、可视化图表、赛后报告 |
| 大学 / 职校 | 商业分析、产业策略、财务决策、宏观约束 | 商业模式验证、供应链优化、行业竞争、政策推演 | 高参数、多角色、案例化复盘 |

核心不是每个学段换一套完全不同的引擎，而是同一引擎拥有不同的配置包与讲授层次。

## 五、夏令营组织方式

夏令营不应是一串互不相关的比赛，而应是一段从“认识商业语言”到“完成综合经营判断”的学习旅程。建议采用“微型实验 → 小队练习 → 正式对抗 → 复盘产出”的节奏。

### 5.1 单日教学节奏

| 环节 | 建议时长 | 教师任务 | 引擎任务 |
|------|----------|----------|----------|
| 概念导入 | 15～25 分钟 | 讲一个真实问题和 2～3 个核心概念 | 不需要启动复杂比赛 |
| 规则试跑 | 10～15 分钟 | 用样例解释变量和胜负条件 | 提供演示局或沙盒局 |
| 小队决策 | 30～90 分钟 | 观察学生误区，少量干预 | 记录决策、状态和市场结果 |
| 数据复盘 | 20～40 分钟 | 把学生行为映射回知识点 | 输出图表、排行榜、决策日志 |
| 迁移产出 | 15～30 分钟 | 让学生写策略备忘录或展示 | 提供报告素材 |

### 5.2 五天营建议编排

| 天数 | 主题 | 知识目标 | 模拟/比赛 | 学生产出 |
|------|------|----------|-----------|----------|
| Day 1 | 商业语言与市场交换 | 价格、利润、供需、预算 | 集市交易 / 价格发现短局 | 个人交易复盘卡 |
| Day 2 | 企业运营与现金流 | 成本、库存、产能、现金流 | 小队产销经营赛 | 小队经营报表 |
| Day 3 | 竞争战略与营销 | 定价、差异化、广告、客群 | 多队同市场竞争 | 策略备忘录 |
| Day 4 | 创业与投融资 | MVP、单位经济、估值、风险 | 创业项目孵化 + 投资人谈判 | 商业模式画布 / 路演稿 |
| Day 5 | 综合商业挑战 | 资源配置、竞争、风险、社会价值 | 综合赛 / 决赛 | 路演 + 数据复盘报告 |

### 5.3 七天营扩展

七天营可以在五天营基础上加入金融和宏观两天：

| 新增天数 | 主题 | 价值 |
|----------|------|------|
| 金融与风险日 | 投资组合、新闻预期、杠杆、风险控制 | 帮学生理解“收益不是唯一目标” |
| 宏观与贸易日 | 汇率、关税、经济周期、政策冲击 | 帮学生理解企业外部环境 |

### 5.4 角色分工

每个小队建议设置可轮换角色，让学生体验商业组织中的视角差异。

| 角色 | 关注问题 | 适合关联的知识点 |
|------|----------|------------------|
| CEO | 战略方向、资源取舍、团队协调 | 机会成本、竞争战略 |
| CFO | 现金流、利润、融资、风险 | 财务、金融、预算 |
| COO | 产能、库存、交付、质量 | 运营与供应链 |
| CMO | 客群、价格、广告、品牌 | 市场营销、弹性 |
| Analyst | 数据、预测、复盘、竞品观察 | 统计、经济模型、报告表达 |

## 六、从知识反推赛事引擎家族

下面的引擎家族是课程视角下的“未来引擎谱系”。它们不是当前实现承诺，也不要求一次全部开发。每一个家族都应能回答一个清晰的教学问题。

### 6.1 市场价格发现引擎

**教学问题**：价格是怎么形成的，为什么同一种商品在不同市场会有不同价格？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 供需、均衡、弹性、流动性、套利、信息不对称 |
| 学生决策 | 报价、买卖时机、运输路线、库存持有、情报购买 |
| 关键变量 | 商品库存、需求强度、交易深度、运输成本、价格波动 |
| 典型误区 | 只看价差不看运费和时间；盲目囤货；追涨杀跌 |
| 复盘图表 | 价格曲线、成交量、利润来源拆分、库存周转 |
| 适合形态 | 实时交易、限时拍卖、城市贸易、课堂短局 |

### 6.2 产销运营与现金流引擎

**教学问题**：为什么企业卖得多也可能倒闭，为什么运营约束会吞掉好战略？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 固定/变动成本、产能、库存、现金转换周期、质量 |
| 学生决策 | 采购、排产、定价、雇员、设备、渠道、借款 |
| 关键变量 | 产能、原料价格、库存、现金余额、订单、质量分 |
| 典型误区 | 过度扩产；忽视现金；库存过高；低价接亏损订单 |
| 复盘图表 | 损益表、现金流曲线、产能利用率、库存周转 |
| 适合形态 | 回合制经营赛、6～8 轮营内对抗、教师控场正式赛 |

### 6.3 消费者与营销策略引擎

**教学问题**：为什么同样的产品卖给不同人结果完全不同？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 市场细分、定位、广告边际效应、渠道、品牌、复购 |
| 学生决策 | 客群选择、功能组合、广告投放、价格、渠道 |
| 关键变量 | 客群偏好、品牌认知、广告触达、满意度、复购率 |
| 典型误区 | 试图讨好所有客群；广告预算一把梭；只看短期销量 |
| 复盘图表 | 客群转化漏斗、广告 ROI、品牌/口碑曲线 |
| 适合形态 | 面板策略赛、产品发布赛、品牌经营赛 |

### 6.4 竞争战略与博弈引擎

**教学问题**：为什么商业决策不能只看自己，还要预测对手？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 价格战、差异化、进入壁垒、重复博弈、可信承诺 |
| 学生决策 | 定价、市场进入、研发路线、合作/背叛、公开承诺 |
| 关键变量 | 市场份额、利润率、品牌壁垒、合作信誉、对手行为 |
| 典型误区 | 盲目降价；忽略对手反应；短期背叛损害长期信誉 |
| 复盘图表 | 策略矩阵、市场份额变化、行业总利润、背叛收益 |
| 适合形态 | 多队同步回合、盲提交决策、淘汰或联赛制 |

### 6.5 创业创新与投融资引擎

**教学问题**：创业为什么不是“有点子就融资”，而是持续验证关键假设？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 用户痛点、MVP、商业模式、单位经济、估值、股权 |
| 学生决策 | 选赛道、做原型、访谈、招聘、融资、增长投入 |
| 关键变量 | 产品成熟度、用户验证、现金 runway、股权、团队能力 |
| 典型误区 | 过早扩张；只追融资；忽视毛利；产品不对应需求 |
| 复盘图表 | 假设验证表、现金 runway、股权稀释、单位经济 |
| 适合形态 | 多日项目制、路演赛、投资人谈判、营期主线 |

### 6.6 金融投资与风险引擎

**教学问题**：如何在不确定环境中配置资产，为什么高收益并不自动代表好决策？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 风险收益、分散化、预期、杠杆、流动性、行为金融 |
| 学生决策 | 买卖资产、配置组合、使用杠杆、解读新闻、止损 |
| 关键变量 | 资产收益、波动率、相关性、利率、新闻冲击、保证金 |
| 典型误区 | 追涨杀跌；集中押注；过度杠杆；把运气当能力 |
| 复盘图表 | 收益曲线、最大回撤、夏普式风险调整收益、持仓图 |
| 适合形态 | 投资挑战赛、新闻驱动交易、团队投委会 |

### 6.7 宏观贸易与政策沙盘引擎

**教学问题**：企业为什么必须理解城市、产业、政策和全球市场？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 比较优势、汇率、关税、经济周期、产业政策、区域分工 |
| 学生决策 | 选市场、进出口、对冲汇率、迁移产能、响应政策 |
| 关键变量 | 城市需求、汇率、关税、物流、政策补贴、景气指数 |
| 典型误区 | 只看单点利润；忽视政策变化；低估周期和汇率风险 |
| 复盘图表 | 区域利润地图、贸易流向、政策前后对比、风险暴露 |
| 适合形态 | 高中/大学综合赛、多城市地图、长局或营期决赛 |

### 6.8 ESG 与公共价值引擎

**教学问题**：企业如何在利润、合规、社会责任和长期信任之间做取舍？

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 外部性、合规、信誉、利益相关者、长期价值 |
| 学生决策 | 环保投入、薪资、质量、安全、公益、合规披露 |
| 关键变量 | 利润、碳排、员工满意度、客户信任、监管风险 |
| 典型误区 | 只追短期利润；把合规当成本；忽视信任损耗 |
| 复盘图表 | 利润 vs 声誉、风险事件、长期价值曲线、利益相关者评分 |
| 适合形态 | 综合赛附加维度、案例推演、教师主持辩论 |

### 6.9 谈判、合同与组织协作引擎

**教学问题**：商业不是只有市场价格，还有关系、合同、信任和执行。

| 维度 | 设计建议 |
|------|----------|
| 核心知识 | 谈判、契约、委托代理、信任、激励相容 |
| 学生决策 | 报价、合同条款、违约选择、保证金、分润机制 |
| 关键变量 | 合同价格、交付率、信誉、违约惩罚、关系价值 |
| 典型误区 | 只争价格；忽视条款；短期违约破坏长期机会 |
| 复盘图表 | 谈判区间、合同履约率、信誉变化、双方收益 |
| 适合形态 | 角色扮演、供应链谈判、投资人条款谈判 |

## 七、知识点到机制的映射表

这张表用于判断一个引擎是否真的承载了知识目标。若某个概念没有对应机制，学生就只能听懂，不能体验。

| 知识概念 | 应转化成的机制 | 复盘时看什么 |
|----------|----------------|--------------|
| 稀缺性 | 预算、行动点、时间、产能上限 | 学生如何排序资源 |
| 机会成本 | 互斥项目、不可逆选择、路线锁定 | 放弃项的潜在收益 |
| 边际分析 | 递增成本或递减收益曲线 | 最后一单位投入是否划算 |
| 价格弹性 | 不同客群对价格变化反应不同 | 涨价后的销量和总利润 |
| 固定成本 | 扩张前先支付设备/租金 | 规模不足时的亏损压力 |
| 现金流 | 收款延迟、库存占款、固定支出 | 盈利但现金断裂的时点 |
| 风险 | 随机事件、概率分布、波动 | 决策质量与运气分离 |
| 信息不对称 | 私有情报、隐藏质量、延迟公布 | 信息优势如何转化为收益 |
| 外部性 | 污染、拥堵、声誉、监管 | 私利与公共成本的差异 |
| 博弈 | 同步提交、多队互相影响 | 对手反应和均衡结果 |
| 时间价值 | 利息、折现、长期项目 | 短期现金和长期收益取舍 |
| 品牌信任 | 复购、口碑、违规惩罚 | 短期收益对长期变量的影响 |

## 八、评价体系

赛事不能只按最终利润排名。商业教育需要把“过程中的好判断”从“结果中的运气”里拆出来。

### 8.1 学生评价维度

| 维度 | 关注能力 | 可观测证据 |
|------|----------|------------|
| 市场洞察 | 读懂需求、价格、对手和消费者 | 预测、报价、客群选择 |
| 财务纪律 | 控制现金、成本、风险和单位经济 | 现金流、利润率、杠杆、库存 |
| 运营执行 | 把战略落到产能、库存和交付 | 缺货率、产能利用率、质量 |
| 战略协作 | 团队分工、长期策略、对手判断 | 角色贡献、策略一致性 |
| 伦理与长期价值 | 信誉、合规、外部性和社会价值 | 违规、声誉、ESG 指标 |

### 8.2 赛后复盘问题

每局比赛结束后，教师至少应能围绕以下问题组织讨论：

1. 你们最重要的一个假设是什么？最后被验证了吗？
2. 如果只看利润，你们赢在哪里；如果看风险调整后收益，还成立吗？
3. 哪个决策是因为信息不足做错的，哪个是因为模型理解错了？
4. 哪个时刻你们应该停止投入，但没有停？
5. 对手的行为如何改变了你们原本的最优选择？
6. 如果这是一家真实企业，你们会如何向投资人或董事会解释？

### 8.3 教师端需要沉淀的数据

这不是当前实现要求，而是未来设计复盘系统时的课程需求。

| 数据 | 教学用途 |
|------|----------|
| 决策日志 | 还原学生当时的判断，而不是只看结果 |
| 关键变量曲线 | 展示价格、现金、库存、声誉如何变化 |
| 同队角色贡献 | 判断团队协作与职责分工 |
| 误区标签 | 标记过度扩张、价格战、忽视现金流等典型问题 |
| 复盘报告素材 | 自动生成学生可以解释的图表和摘要 |

## 九、把现有引擎放回课程地图中

本文件刻意不以现有引擎为起点，但现有引擎可以被重新解释为课程地图中的若干落点。

| 当前方向 | 更适合归入的课程引擎家族 | 可强化的知识目标 |
|----------|--------------------------|------------------|
| 浮生记 / 贸易交易 | 市场价格发现 + 宏观贸易 | 供需、套利、物流成本、城市差异、信息 |
| OPS 产销运营赛 | 产销运营与现金流 | 成本、库存、产能、现金流、拍卖采购 |
| TechVenture / 创投 | 创业创新与投融资 + 竞争战略 | MVP、研发、城市投资、团队策略、估值 |
| finance-lab 方向 | 金融投资与风险 | 投资组合、新闻预期、风险控制、杠杆 |

下一步若继续扩展，不建议简单补“第五、第六引擎”的名字，而应先确定缺失的课程问题。例如：是否缺少营销消费者行为？是否缺少 ESG 公共价值？是否缺少谈判合同？这些问题比引擎编号更重要。

## 十、推荐的引擎建设优先级

若目标是服务经济学夏令营，建议按“教学闭环完整度”排序，而不是按技术炫技程度排序。

| 优先级 | 引擎方向 | 原因 |
|--------|----------|------|
| P0 | 价格发现 / 市场交易短局 | 最容易把供需、价格、弹性讲活，适合开营破冰 |
| P0 | 产销运营与现金流 | 商业基础最核心，能纠正“销售额等于成功”的误区 |
| P0 | 创业创新与投融资 | 最适合作为营期主线和最终路演 |
| P1 | 竞争战略与营销 | 把单队经营升级为多队博弈和市场定位 |
| P1 | 金融投资与风险 | 适合高中以上，能训练风险意识 |
| P2 | 宏观贸易与政策沙盘 | 适合高阶营或综合决赛，不宜过早复杂化 |
| P2 | ESG 与公共价值 | 应先作为综合指标嵌入，再考虑独立引擎 |
| P2 | 谈判合同引擎 | 适合线下角色扮演与线上记录结合 |

## 十一、未来 PRD 写作模板

当某个课程方向要落成具体引擎 PRD 时，建议先填写这组问题：

| 问题 | PRD 中应给出的答案 |
|------|--------------------|
| 这节课要讲什么？ | 3～5 个核心知识点，不超过一个主题簇 |
| 学生会自然犯什么错？ | 明确列出希望被模拟暴露的典型误区 |
| 玩家每轮能做什么？ | 决策项不宜过多，初级引擎控制在 3～5 类 |
| 系统如何反馈？ | 即时反馈、回合反馈、赛后反馈分别是什么 |
| 胜负是否等于学习？ | 除排名外，还要定义过程性评价 |
| 教师怎么讲？ | 前置讲授、赛中观察点、赛后复盘问题 |
| 如何适配学段？ | 小学/初中/高中/大学各降低或增加哪些变量 |
| 是否可配置？ | 哪些参数进入配置包，哪些是引擎机制 |

## 十二、结论

商识唯智的赛事引擎体系，最稳的组织方式不是“现有引擎排排坐”，而是建立一条课程主线：

```
商业语言 → 市场交换 → 企业运营 → 竞争战略 → 创业金融 → 宏观公共价值
```

每一个引擎都应该是这条主线上的一个实验室。学生在实验室里犯错、竞争、合作、看见数据，然后在教师引导下把经验翻译成经济学和商学概念。这样，平台既能做比赛，也能真正承担课程。
