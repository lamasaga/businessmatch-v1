# OPS 12 岁商业公司管理教学项目

> **最后更新**：2026-07-07
> **Phase**：A 范围内的教研设计文档，不改代码、不新增路由、不新增数据库表。
> **任务类型**：面向 12 岁左右学生的 OPS 课程降阶与比赛承载设计。
> **定位**：本文回答两个问题：面向 12 岁学生，OPS 应该如何组织商业与公司管理教学内容；为了让比赛真正承载这些教学目标，OPS 赛制和复盘还需要细化哪些内容。

---

## 一、结论：原课程对 12 岁学生偏艰深

如果直接把 OPS 讲成“产能、单位经济、Softmax 市场份额、广告存量、资产负债表、价格弹性”，对 12 岁左右学生确实会偏艰深。不是因为这些内容不能教，而是因为这个年龄段更需要先看见具体场景，再慢慢抽象出概念。

12 岁学生更适合这样的学习路径：

```text
我们开了一家小公司
→ 我们要卖什么、卖给谁
→ 我们的钱够不够
→ 我们要做多少货
→ 我们定什么价格
→ 我们怎样让顾客知道
→ 本轮卖得怎么样
→ 下轮我们怎么改
```

也就是说，课程不能从经济学名词出发，而要从“小队经营一家公司的故事”出发。教师心里可以有经济学框架，但学生眼前应看到产品、顾客、钱袋、库存、广告、团队会议和每轮结果。

---

## 二、低龄版 OPS 的课程定位

面向 12 岁学生，OPS 建议包装为：

```text
小小公司经营挑战
```

学生不是在操作一套复杂财务系统，而是在小队中扮演一家公司。每家公司要设计一个产品，选择目标顾客，安排生产，决定价格，做宣传，管理库存，最后用一张简单账本解释自己为什么赚钱或亏钱。

### 2.1 教学目标

| 目标 | 学生应能做到 |
|------|--------------|
| 认识公司 | 知道公司不是一个人赚钱，而是一群人分工合作解决顾客问题 |
| 认识顾客 | 能说出“我的产品卖给谁，他们为什么会买” |
| 认识成本 | 知道做产品、打广告、请人帮忙都要花钱 |
| 认识利润 | 能用“收入 - 花出去的钱 = 本轮赚/亏”解释结果 |
| 认识库存 | 知道做太少会不够卖，做太多会压在仓库里 |
| 认识定价 | 知道价格太高可能没人买，太低可能赚不到钱 |
| 认识团队 | 能在小队里分角色讨论，而不是一个人拍脑袋 |
| 认识复盘 | 能根据本轮结果说出下一轮要改什么 |

### 2.2 不建议直接讲的内容

| 暂不直接讲 | 低龄替代表达 |
|------------|--------------|
| 价格弹性 | 价格变了，顾客还愿不愿意买 |
| Softmax / Logit | 顾客会比较每家公司的吸引力 |
| 单位经济模型 | 每卖出一个产品到底赚不赚钱 |
| 资产负债表 | 公司现在还剩多少钱和多少货 |
| 广告存量 | 广告有些当轮有效，有些会让顾客以后更记得你 |
| 机会成本 | 选了这个，就少了做另一个的机会 |
| 赢家诅咒 | 抢到了资源，但花太多钱也可能亏 |

教师可以在讲义或复盘中使用背后的专业概念，但对学生呈现时，先用生活语言。

## 三、课程主线：从“开公司”到“会复盘”

建议把 12 岁版 OPS 组织成六个主题，而不是十二个进阶经济学模块。

| 主题 | 学生语言 | 教师背后的知识 |
|------|----------|----------------|
| 1. 我们要开一家什么公司 | 我们卖什么？卖给谁？ | 产品定位、市场细分 |
| 2. 钱从哪里来、花到哪里去 | 现在有多少钱？要花在哪？ | 预算、成本、现金流 |
| 3. 做多少货才合适 | 做少了不够卖，做多了占仓库 | 产能、库存、需求预测 |
| 4. 卖多少钱才合适 | 太贵没人买，太便宜赚不到 | 定价、需求、利润 |
| 5. 怎样让顾客喜欢我们 | 做广告、提高质量、选好市场 | 营销、产品力、客群匹配 |
| 6. 公司会议怎么复盘 | 本轮哪里做对了？下轮怎么改？ | 数据复盘、管理决策 |

这个组织方式更像一个项目制学习，而不是一门经济学小课。学生在比赛中经历一家公司从定位到经营再到复盘的完整流程。

## 四、推荐课程结构

### 4.1 90 分钟体验课

| 时间 | 内容 | 教师重点 |
|------|------|----------|
| 0-10 分钟 | 故事导入：班级里要开一家小公司 | 公司是为顾客解决问题的组织 |
| 10-20 分钟 | 分队和角色卡 | CEO、财务、生产、营销、记录员 |
| 20-30 分钟 | 选择产品和目标顾客 | 不要卖给“所有人” |
| 30-60 分钟 | 进行 2 轮简化经营 | 每轮只做生产、价格、广告三个决策 |
| 60-75 分钟 | 看小公司账本 | 收入、花费、库存、赚/亏 |
| 75-90 分钟 | 每队一句话复盘 | 我们下轮会改变什么 |

这个版本适合公开体验、招生课和第一次接触商业模拟的学生。不要引入拍卖和复杂城市市场，先让学生跑通“决策 - 结果 - 复盘”。

### 4.2 半日项目课

| 环节 | 内容 | 对应比赛机制 |
|------|------|--------------|
| 公司成立 | 起公司名、产品名、目标顾客 | 产品定位 |
| 第一轮经营 | 决定做多少、卖多少钱、打多少广告 | R1 运营 |
| 第一次复盘 | 看收入、花费、剩货、顾客反馈 | 简化报表 |
| 资源选择 | 每队用预算购买一个资源卡 | 简化拍卖或固定价格资源商店 |
| 第二轮经营 | 根据资源卡调整策略 | R2 运营 |
| 第三轮经营 | 面对事件卡或顾客偏好变化 | R3 运营 |
| 展示复盘 | 每队展示“我们的公司故事” | 结算与表达 |

半日课可以加入“资源卡”，但建议先不用激烈拍卖。12 岁学生容易在拍卖中被情绪带走，第一次更适合用固定价格资源商店，让他们理解资源要和策略匹配。

### 4.3 一日营课程

| 时段 | 内容 | 学生收获 |
|------|------|----------|
| 上午 1 | 什么是公司：顾客、产品、团队、钱 | 建立公司经营框架 |
| 上午 2 | OPS 练习局：2 轮经营 | 学会提交决策和看账本 |
| 下午 1 | 正式挑战：3 到 4 轮经营 + 资源卡 | 在变化中调整策略 |
| 下午 2 | 公司发布会：展示复盘海报 | 用数据讲清楚自己的公司 |

一日营可以把 OPS 做成完整项目。最终成果不只是排行榜，而是每队提交一张“公司经营海报”：产品、顾客、最重要的决策、赚/亏原因、下一步计划。

### 4.4 六讲课程

| 讲次 | 课程主题 | 比赛/活动 |
|------|----------|-----------|
| 1 | 我们成立一家公司 | 分队、角色卡、产品定位 |
| 2 | 钱袋和成本 | 简化账本、成本小游戏 |
| 3 | 生产和库存 | 做多少货的预测挑战 |
| 4 | 价格和顾客 | 高中低三档价格实验 |
| 5 | 广告和资源卡 | 资源选择、广告投入、顾客反馈 |
| 6 | 公司复盘会 | 完整小赛 + 经营展示 |

这个版本适合校内兴趣课或夏令营前置课。每一讲只抓一个核心概念，最后再合成一场完整经营挑战。

## 五、学生角色设计

12 岁学生需要角色来帮助他们参与团队讨论。建议每队 4 到 5 人：

| 角色 | 学生任务 | 可见工具 |
|------|----------|----------|
| CEO | 主持讨论，确保大家都发言 | 决策确认卡 |
| 财务官 | 看钱够不够，记录收入和花费 | 小公司账本 |
| 生产经理 | 决定做多少货，关注库存 | 生产计划卡 |
| 营销经理 | 决定广告和顾客沟通 | 广告卡/顾客卡 |
| 记录员/发言人 | 记录理由，赛后汇报 | 复盘卡 |

角色不是为了模拟真实公司职位，而是为了防止队伍里只有一个学生做决定。每轮可以轮换角色，让每个学生都体验一次“看钱”“看货”“看顾客”的视角。

## 六、比赛应如何承载低龄教学

### 6.1 决策项要分层

面向 12 岁学生，不建议第一局就开放全部 OPS 决策。可以做三层复杂度。

| 难度 | 决策项 | 适合场景 |
|------|--------|----------|
| 入门版 | 生产数量、价格档位、广告投入 | 90 分钟体验课 |
| 标准版 | 生产数量、价格、广告、质量改进、目标顾客 | 半日课/一日营 |
| 进阶版 | 增加资源卡、城市市场、销售人员、研发 | 多讲课程或第二次参赛 |

第一局最重要的是让学生理解因果，不是让他们拥有所有按钮。按钮越多，学生越容易从“经营思考”退回到“随便试数值”。

### 6.2 专业数字要翻译成可见反馈

| 系统内部可以有 | 学生界面更适合显示 |
|----------------|--------------------|
| market share | 本轮有多少顾客选择了你 |
| price sensitivity | 顾客觉得价格贵不贵 |
| tech / fit / show | 产品质量、适合程度、大家知不知道 |
| net assets | 公司现在还剩多少钱和货 |
| cumulative profit | 到现在一共赚了多少 |
| inventory holding cost | 仓库里剩货太多，会多花保管费 |

低龄版最需要“解释卡”。每轮结算后，系统应该给出 3 到 5 条简单原因，例如：

| 结果解释 | 学生能理解的含义 |
|----------|------------------|
| 价格比同类公司高，顾客少了一些 | 不是越贵越好 |
| 广告投入提高了顾客认识度 | 广告能让更多人知道你 |
| 库存剩得太多，占用了现金 | 做太多货会有压力 |
| 产品质量提高，让目标顾客更喜欢 | 改进产品会影响后续销量 |
| 本轮缺货，错过了一些订单 | 做太少也会损失机会 |

### 6.3 报表要做成“小公司账本”

12 岁学生不需要一开始就看完整损益表。建议低龄版先显示一张小公司账本：

| 项目 | 学生看到的表达 |
|------|----------------|
| 期初现金 | 本轮开始时有多少钱 |
| 生产花费 | 做产品花了多少钱 |
| 广告花费 | 让顾客知道我们花了多少钱 |
| 其他花费 | 请人帮忙、仓库保管等 |
| 销售收入 | 卖产品收回多少钱 |
| 剩余库存 | 仓库里还剩多少产品 |
| 本轮结果 | 这一轮赚了还是亏了 |
| 公司健康 | 钱是否安全、库存是否太多、顾客是否满意 |

这样学生先能读懂。等他们熟悉后，再逐步引入“收入、成本、利润、现金、库存、净资产”等正式词。

### 6.4 胜负不能只看利润

如果只按利润排名，12 岁学生很容易学成“压低质量、疯狂降价、短期冲刺”。建议低龄版评分更像“健康公司”：

| 维度 | 建议权重 | 教学意义 |
|------|----------|----------|
| 公司盈利 | 35% | 公司要能赚钱 |
| 现金安全 | 15% | 不能把钱花光 |
| 库存管理 | 15% | 做货要有计划 |
| 顾客满意 | 15% | 不是只卖出去就好 |
| 团队复盘 | 20% | 能说清楚怎么想、怎么改 |

这样比赛能传达更完整的公司管理观：赚钱很重要，但健康经营、服务顾客和团队学习同样重要。

### 6.5 拍卖要先改成“资源卡商店”

标准 OPS 的拍卖适合高中以上，12 岁学生可以保留资源竞争，但形式要温和一点。

| 原拍卖机制 | 低龄版改法 |
|------------|------------|
| 英式竞价、不断加价 | 固定价格资源卡，先选先得或抽签决定顺序 |
| 生产线、广告位、原料折扣 | 更多故事化命名：更快的机器、便宜的材料、校园海报位 |
| 出价上限、现金约束 | 资源卡价格清楚写在卡面上 |
| 战略资源估值 | 教师提问：这张卡适合你们公司吗？为什么？ |

等学生理解“资源要和策略匹配”后，再升级成真正拍卖。这样不会让第一次课程变成纯抢东西。

### 6.6 城市市场要先变成“顾客群”

OPS 的城市机制对 12 岁学生可能有点远。建议先把城市抽象成三类顾客群：

| 顾客群 | 喜好 |
|--------|------|
| 实用型顾客 | 喜欢价格合理、质量稳定 |
| 潮流型顾客 | 喜欢广告、外观、品牌感 |
| 科技型顾客 | 喜欢功能、创新、质量升级 |

等学生熟悉后，再把顾客群放回城市：比如校园市场、社区市场、商场市场。这样的顺序更自然。

### 6.7 每轮要有“公司会议”

比赛每轮不应只是提交数字。建议固定一个 3 分钟公司会议结构：

```text
1. 上轮哪里做得好？
2. 上轮最大问题是什么？
3. 这轮我们最想改变哪一件事？
4. 财务官确认钱够不够。
5. CEO 点击提交。
```

这个会议结构会把比赛变成管理课。学生会学到：公司决策不是凭感觉，而是先看结果，再讨论，再选择。

## 七、建议的低龄版比赛流程

### 7.1 入门赛：3 轮经营

| 阶段 | 学生动作 | 教师讲授 |
|------|----------|----------|
| 公司成立 | 起名、选产品、选目标顾客 | 公司要服务顾客 |
| R1 | 做多少、卖多少钱、打多少广告 | 钱会流入也会流出 |
| R1 复盘 | 看账本和顾客反馈 | 销量不等于利润 |
| R2 | 根据反馈调整 | 库存和价格 |
| 资源卡 | 买一张资源卡 | 资源要匹配策略 |
| R3 | 最后一轮经营 | 综合取舍 |
| 总复盘 | 经营展示 | 用数据讲故事 |

### 7.2 标准赛：4 轮经营 + 资源卡

| 阶段 | 教学重点 |
|------|----------|
| 产品定位 | 卖给谁 |
| R1 | 第一次试市场 |
| R2 | 调整生产和价格 |
| 资源卡 | 选择公司优势 |
| R3 | 放大优势或修正错误 |
| R4 | 最终经营 |
| 发布会 | 复盘与表达 |

### 7.3 进阶赛：6 轮经营 + 双资源阶段

当学生已经参加过一次入门赛，可以再使用更接近 OPS 目标赛制的结构：

| 阶段 | 低龄解释 |
|------|----------|
| 拍卖 A / 资源商店 A | 先买基础工具 |
| R1-R3 | 看看我们的公司能不能稳定卖货 |
| 拍卖 B / 资源商店 B | 买后半场的特别机会 |
| R4-R6 | 根据竞争情况调整 |
| 总结算 | 谁是最健康、最会学习的公司 |

进阶赛可以逐步引入真正拍卖、城市市场和研发积累，但仍不建议把公式暴露给学生。

## 八、需要细化和完善的比赛内容

下面这些是为了让 OPS 真正承载 12 岁教学项目，需要在课程和产品层继续细化的内容。

### 8.1 低龄版配置包

建议未来设计一个独立配置包，例如：

```text
ops-junior-v1
```

它不一定新增引擎，只是降低参数和界面复杂度。

| 配置项 | 低龄版建议 |
|--------|------------|
| 回合数 | 3 轮入门，4 轮标准，6 轮进阶 |
| 决策项 | 入门只保留生产、价格、广告 |
| 价格 | 可先用低/中/高三档 |
| 顾客 | 3 类顾客群，而不是复杂城市 |
| 报表 | 小公司账本，而不是完整财务报表 |
| 排名 | 健康公司评分，而不是只看净资产 |
| 资源 | 固定价格资源卡优先，拍卖作为进阶 |

### 8.2 产品与顾客卡

需要为学生准备更生活化的产品与顾客：

| 产品主题 | 适合原因 |
|----------|----------|
| 校园文具 | 学生熟悉，容易理解成本和顾客 |
| 饮品小店 | 定价、广告、库存都直观 |
| 智能台灯 | 可以引入质量和研发 |
| 环保水杯 | 可以引入顾客偏好和社会价值 |
| 校园文创 | 适合讲设计、品牌和展示 |

每个主题要配 3 类顾客卡。例如校园文具可以有“省钱型学生”“爱设计的学生”“重视耐用的学生”。顾客卡会让抽象需求变得可见。

### 8.3 资源卡系统

低龄版资源卡要有明确故事、清楚价格和简单效果。

| 资源卡 | 学生语言效果 | 背后机制 |
|--------|--------------|----------|
| 更快的机器 | 每轮可以多做一些产品 | 产能加成 |
| 便宜材料 | 每个产品少花一点钱 | 原料成本下降 |
| 校园海报位 | 更多顾客知道你 | 广告/Show 加成 |
| 质量老师 | 产品更好，目标顾客更喜欢 | Tech/Fit 加成 |
| 仓库整理员 | 剩货保管更便宜 | 库存成本下降 |
| 顾客调查卡 | 下轮更清楚顾客喜欢什么 | 提示需求/偏好 |

资源卡不宜太多。入门版 6 到 8 张就够，避免学生被选项淹没。

### 8.4 每轮解释卡

系统或教师需要给每队生成简短解释：

| 解释维度 | 示例 |
|----------|------|
| 价格 | 你的价格比大多数队伍高，所以顾客少了一些 |
| 广告 | 你打了广告，更多顾客知道了你的产品 |
| 生产 | 你做得太少，卖完后还有顾客想买 |
| 库存 | 你做得太多，仓库里剩了很多货 |
| 质量 | 你投入了质量改进，目标顾客更喜欢你 |
| 现金 | 你花钱太快，下轮选择会变少 |

这是低龄版最重要的产品能力之一。没有解释卡，学生只会看到排名；有了解释卡，学生才知道下一轮为什么要改。

### 8.5 教师控场提示

教师端或教师手册需要按阶段提供提示语：

| 阶段 | 教师提示 |
|------|----------|
| 产品定位 | 请每队说一句：我们的产品卖给谁，为什么他们需要 |
| R1 前 | 先不要追求赢，先看看市场会怎么反应 |
| R1 后 | 请找出你们本轮赚/亏的最大原因 |
| 资源卡前 | 不要买看起来最厉害的卡，要买最适合你们公司的卡 |
| 最后一轮前 | 现在最重要的是冲销量、保现金，还是清库存 |
| 赛后 | 用一个数字证明你们学到了什么 |

12 岁学生需要教师把注意力拉回学习目标。否则比赛很容易变成只看排名的热闹活动。

### 8.6 团队协作与记录工具

建议配套三张纸面或系统内表单：

| 工具 | 内容 |
|------|------|
| 公司设定卡 | 公司名、产品、目标顾客、团队角色 |
| 每轮决策卡 | 本轮目标、生产、价格、广告、理由 |
| 复盘卡 | 结果、原因、下轮改变、一个证据 |

这些表单能帮助学生把讨论留下来。赛后复盘时，教师可以让学生比较“当时的理由”和“实际结果”。

### 8.7 低龄版评价规则

建议低龄版最终奖项不要只有冠军。

| 奖项 | 评价重点 |
|------|----------|
| 最会赚钱公司 | 盈利表现好 |
| 最健康公司 | 现金安全、库存合理 |
| 最懂顾客公司 | 定位清楚、顾客满意 |
| 最会改进公司 | 根据数据及时调整 |
| 最佳团队公司 | 分工清楚、汇报完整 |

多奖项能保护学习动机。12 岁学生尤其需要看到“我没拿第一，但我在某件事上做得很好”。

## 九、一套推荐的最小可行版本

如果近期要快速把 OPS 用在 12 岁学生项目中，建议先做这个版本：

| 模块 | 最小方案 |
|------|----------|
| 主题 | 校园新品公司挑战 |
| 产品 | 文具、饮品、台灯、水杯、文创中选一类 |
| 顾客 | 实用型、潮流型、科技型 |
| 回合 | 3 轮经营 |
| 决策 | 生产数量、价格档位、广告投入 |
| 资源 | 第 2 轮前买一张固定价格资源卡 |
| 报表 | 小公司账本 |
| 反馈 | 每轮 3 条解释卡 |
| 胜负 | 盈利 35% + 现金 15% + 库存 15% + 顾客满意 15% + 复盘 20% |
| 产出 | 一张公司经营海报或 3 分钟复盘汇报 |

这个版本足够承载公司管理入门教学，又不会把学生压进复杂公式。等学生熟悉后，再逐步加入研发、销售人员、城市、拍卖和更完整的财务报表。

## 十、给现有 OPS 文档的关系说明

现有 [OPS 引擎可开展课程内容梳理](./OPS引擎可开展课程内容梳理.md) 更适合高中、大学、职校和商赛训练营，用来说明 OPS 能承载哪些完整经济学和商学内容。

本文则是低龄版教学项目方案。两者不是互相否定，而是同一个引擎的不同讲法：

| 版本 | 面向对象 | 教学语言 |
|------|----------|----------|
| 低龄版 OPS | 12 岁左右学生 | 公司故事、顾客、钱袋、仓库、广告、团队会议 |
| 标准 OPS | 初高中商赛学生 | 定价、成本、库存、营销、研发、竞争、报表 |
| 进阶 OPS | 高中高年级、大学、职校 | 单位经济、价格弹性、市场份额模型、管理会计、战略资源 |

好的课程不是把难知识删掉，而是把难知识藏在合适的体验后面。对 12 岁学生，先让他们把一家公司经营“看懂”，再让他们慢慢学会用更专业的词解释它。
