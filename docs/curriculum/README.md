## 三、使用方式

1. 设计课程时，先读本目录，确定知识模块、学段和营期节奏。
2. 设计新赛事引擎时，先回答“要让学生理解哪一个经济学/商学问题”，再写 `docs/engines/<id>/PRD.md`。
3. 进入开发前，把课程蓝图里的概念转为明确的规则、数据、API 与复盘指标。
