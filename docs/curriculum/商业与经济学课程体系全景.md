## 一、总纲

商业与经济学模拟课程的核心，不是让学生背诵概念，也不是把现实商业压缩成一个排行榜，而是让学生在有限资源、有限信息、竞争压力和不确定环境下做选择，然后用商学和经济学语言解释自己的选择。

一套完整课程应当同时满足三件事：

1. 学生能听懂概念。
2. 学生能在模拟中体验概念。
3. 学生能用数据和语言复盘自己的决策。

因此，课程设计的基本链条是：

```text
现实问题
→ 核心概念
→ 模拟机制
→ 学生决策
→ 系统反馈
→ 数据复盘
→ 现实迁移
```

如果课程只讲理论，学生容易觉得商业知识离自己很远；如果课程只比赛，学生会把胜负误认为学习本身。最好的组织方式，是把赛事引擎当作“经济学实验室”和“商业判断训练场”。

## 二、课程培养目标

### 2.1 总目标

课程最终要培养的是学生的商业判断力。它包括理解市场、配置资源、管理风险、组织协作、表达策略和承担责任的能力。

| 能力 | 具体表现 |
|------|----------|
| 商业语言能力 | 能区分收入、成本、利润、现金、资产、负债、股权、估值等概念 |
| 经济模型能力 | 能用供需、边际、机会成本、弹性、风险收益解释商业现象 |
| 经营决策能力 | 能在预算、产能、库存、时间和竞争约束下做取舍 |
| 市场洞察能力 | 能识别客群、需求、价格信号、渠道差异和竞争格局 |
| 财务纪律能力 | 能理解现金流、成本结构、利润率、杠杆和风险暴露 |
| 战略博弈能力 | 能预测对手反应，理解合作、背叛、差异化和价格战 |
| 创新创业能力 | 能从问题出发验证需求，搭建商业模式并解释融资逻辑 |
| 复盘表达能力 | 能基于数据写出策略备忘录、复盘报告或路演说明 |
| 伦理责任能力 | 能理解合规、信誉、外部性、员工、客户和公共价值 |

### 2.2 五层学习闭环

| 层级 | 学生状态 | 教学任务 | 模拟系统承担什么 |
|------|----------|----------|------------------|
| 概念识别 | 知道一个词 | 给出清晰定义和现实例子 | 呈现可见变量 |
| 机制理解 | 知道变量如何互相影响 | 解释模型和因果关系 | 让变量随决策变化 |
| 决策训练 | 能在约束下选择 | 设计资源冲突和机会成本 | 提供互斥决策 |
| 竞争协作 | 能理解他人行为影响自己 | 组织小队、对抗和谈判 | 多队同场互相影响 |
| 复盘迁移 | 能解释为什么赢或输 | 引导数据分析与现实迁移 | 输出日志、图表和评价 |

## 三、课程主线

建议采用九段式主线：

```text
财商启蒙
→ 市场价格
→ 企业经营
→ 消费者与营销
→ 竞争战略
→ 创业创新
→ 金融投资
→ 宏观贸易
→ ESG 与综合决策
```

这条主线从个人理解金钱开始，逐渐扩展到企业、市场、产业、资本、政策和社会价值。低龄段可以只走前半段，高龄段和营期决赛可以走完整闭环。

## 四、核心课程模块

### 4.1 财商启蒙与商业语言

这是所有商业模拟课程的入口。学生要先学会商业世界最基本的语言，否则后续比赛会变成“看分数猜输赢”。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么收入高不等于赚钱？为什么账面盈利也可能现金断裂？ |
| 核心概念 | 收入、成本、利润、现金流、资产、负债、预算、储蓄、投资 |
| 推荐活动 | 小店经营、家庭预算、班级集市、订单选择 |
| 典型误区 | 只看销售额；忽视固定成本；把现金和利润混为一谈 |
| 模拟机制 | 初始资金、进货成本、租金、工资、售价、库存、结算报表 |
| 复盘问题 | 你们赚的钱来自销量、定价还是成本控制？有没有现金紧张时刻？ |

适合学段：小学高段、初中入门、高中预备课。

### 4.2 稀缺、选择与机会成本

商业和经济学的第一原则是稀缺。课程要让学生体验“选了这个，就必须放弃那个”。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么不是所有看起来好的机会都值得做？ |
| 核心概念 | 稀缺、机会成本、边际收益、边际成本、沉没成本、资源配置 |
| 推荐活动 | 多项目投资、城市路线选择、行动点分配、预算分配 |
| 典型误区 | 已经投钱就继续投；平均分配资源；忽视最好替代方案 |
| 模拟机制 | 互斥项目、行动点、不可逆投资、退出损失、边际递减 |
| 复盘问题 | 你们最大的机会成本是什么？哪一笔投入应该早点停止？ |

适合学段：初中以上；小学段可以用时间、金币和库存格子做直观版。

### 4.3 市场交换、供需与价格

价格不是老师给出的标准答案，而是买卖双方在信息、库存、需求和竞争中形成的结果。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么同一种商品在不同城市、不同时间会有不同价格？ |
| 核心概念 | 需求、供给、均衡价格、成交量、价格弹性、流动性、套利 |
| 推荐活动 | 双向拍卖、交易大厅、城市贸易、限时抢购、供需实验 |
| 典型误区 | 只看价差不看运费；以为降价一定提高利润；盲目囤货 |
| 模拟机制 | 买价/卖价、库存池、交易深度、运输成本、市场新闻 |
| 复盘问题 | 哪些交易是真正套利？哪些只是忽略了时间和风险？ |

适合学段：初中到大学。高中以上可加入需求曲线、弹性计算和市场失灵。

### 4.4 企业运营、产能与供应链

企业经营不是“想卖多少就能卖多少”。运营课程要让学生看见产能、库存、质量、交付和资金周转对战略的约束。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么订单多也可能把企业拖垮？ |
| 核心概念 | 产能、库存、采购、固定成本、变动成本、质量、供应链风险 |
| 推荐活动 | 产销运营赛、工厂排产、采购竞价、库存挑战、交付任务 |
| 典型误区 | 过度扩产；忽视库存占款；低价接亏损订单；不重视质量 |
| 模拟机制 | 设备、产能、原料、订单、库存、缺货、返工、现金流 |
| 复盘问题 | 你们的瓶颈在哪里？哪一次缺货或库存积压最影响利润？ |

适合学段：初中以上。高中/大学可加入库存周转率、现金转换周期和瓶颈理论。

### 4.5 消费者行为与市场营销

营销不是单纯“花钱打广告”，而是理解谁会买、为什么买、在哪买、以什么价格买。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么同样的产品卖给不同人结果完全不同？ |
| 核心概念 | 市场细分、用户画像、定位、渠道、广告 ROI、品牌、复购 |
| 推荐活动 | 产品定位赛、广告预算实验、渠道选择、品牌经营 |
| 典型误区 | 想讨好所有客群；广告预算一把梭；只看短期销量 |
| 模拟机制 | 客群偏好、广告触达、转化率、渠道成本、口碑、复购率 |
| 复盘问题 | 你们选择的客群是谁？广告花费带来了利润还是虚假繁荣？ |

适合学段：初中以上。高龄段可加入 CAC、LTV、漏斗分析和 A/B 测试。

### 4.6 竞争战略与博弈论

商业决策不是孤立计算题。对手会观察、反击、合作、背叛，学生必须理解“我的最优取决于别人怎么做”。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么价格战常常让所有人都变差？ |
| 核心概念 | 价格战、差异化、进入壁垒、先发优势、重复博弈、可信承诺 |
| 推荐活动 | 多队同市场商战、盲提交定价、渠道争夺、联盟谈判 |
| 典型误区 | 盲目降价；忽视对手反应；短期背叛破坏长期信誉 |
| 模拟机制 | 同步决策、市场份额、行业总利润、合作协议、信誉分 |
| 复盘问题 | 哪个对手行为改变了你们的策略？你们有没有陷入囚徒困境？ |

适合学段：高中以上。初中可做简化版价格战和差异化体验。

### 4.7 创业创新与商业模式

创业课程不应只等于“路演比赛”。真正的重点是发现问题、验证假设、控制现金、构建商业模式。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么有创意不等于有商业？ |
| 核心概念 | 用户痛点、MVP、假设验证、商业模式、单位经济、现金 runway |
| 推荐活动 | 创业孵化、用户访谈、MVP 选择、商业模式画布、路演 |
| 典型误区 | 过早扩张；只追融资；产品不对应真实需求；不算单位经济 |
| 模拟机制 | 原型、用户反馈、现金消耗、团队能力、增长投入、融资轮次 |
| 复盘问题 | 你们验证了哪个关键假设？哪一个假设还只是自我想象？ |

适合学段：初中到大学。大学段可加入估值、股权稀释、尽调和投资条款。

### 4.8 投融资、金融市场与风险

金融教育不能只做成“谁买中了上涨资产”。课程应强调风险收益、预期、分散化和行为偏差。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么高收益不一定代表好决策？ |
| 核心概念 | 风险收益、波动、分散化、相关性、预期、杠杆、流动性 |
| 推荐活动 | 投资组合挑战、新闻驱动交易、投委会、融资谈判 |
| 典型误区 | 追涨杀跌；集中押注；过度杠杆；把运气当能力 |
| 模拟机制 | 多资产价格、新闻事件、保证金、止损、最大回撤、资金曲线 |
| 复盘问题 | 你的收益来自判断、风险承担还是运气？最大回撤是否可承受？ |

适合学段：高中到大学。低龄段只保留储蓄、保险、风险卡牌和简单投资组合。

### 4.9 宏观经济、产业与国际贸易

企业不是漂浮在真空里。宏观课程让学生理解周期、政策、利率、汇率、关税和区域分工如何改变企业选择。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么同一家企业在不同政策和周期下会做出不同决策？ |
| 核心概念 | 经济周期、利率、汇率、关税、比较优势、产业政策、区域分工 |
| 推荐活动 | 多城市贸易、跨国供应链、政策冲击、产业选择沙盘 |
| 典型误区 | 只看单笔利润；忽视汇率和政策；低估经济周期 |
| 模拟机制 | 城市需求、汇率、关税、物流成本、补贴、监管、景气指数 |
| 复盘问题 | 你们的利润对哪一个外部变量最敏感？有没有做对冲或备选方案？ |

适合学段：高中到大学。初中可用天气、节日、政策卡做低抽象版。

### 4.10 ESG、商业伦理与公共价值

商业教育如果只奖励利润，会训练出单薄的商业观。ESG 课程要让学生看到外部性、合规、信誉和长期价值。

| 项目 | 内容 |
|------|------|
| 核心问题 | 企业是否只对利润负责？ |
| 核心概念 | 外部性、合规、声誉、员工、客户、社区、长期主义、社会创新 |
| 推荐活动 | ESG 经营挑战、监管事件、公众听证、利益相关者辩论 |
| 典型误区 | 把合规当纯成本；只追短期利润；忽视信任损耗 |
| 模拟机制 | 碳排、客户信任、员工满意度、监管罚款、品牌价值 |
| 复盘问题 | 哪些短期利润牺牲了长期信任？如果你是客户还会买吗？ |

适合学段：初中以上。建议作为综合评价维度嵌入所有高阶比赛。

### 4.11 谈判、合同与组织协作

真实商业中，很多价值不是在公开市场中自动产生的，而是在合同、谈判、团队和长期关系中形成的。

| 项目 | 内容 |
|------|------|
| 核心问题 | 为什么同一笔交易，不同合同条款会产生完全不同结果？ |
| 核心概念 | 谈判区间、合同、违约、保证金、委托代理、激励相容、信任 |
| 推荐活动 | 供应链谈判、投资条款谈判、渠道合同、团队分工挑战 |
| 典型误区 | 只谈价格不谈条款；低估违约成本；忽视长期关系 |
| 模拟机制 | 合同价格、履约率、违约惩罚、信誉、分润、保证金 |
| 复盘问题 | 这份合同对双方都可持续吗？有没有激励一方违约？ |

适合学段：高中以上；初中可用角色扮演和简单合同卡。

## 五、按学段的课程进阶

### 5.1 小学高段：财商与交换启蒙

| 维度 | 设计 |
|------|------|
| 核心目标 | 认识钱、预算、交换、成本、利润、诚信 |
| 教学语言 | 少公式，多故事，多实物比喻 |
| 推荐主题 | 我的第一家小店、班级集市、预算大挑战、诚信商人 |
| 模拟强度 | 10～30 分钟短局，变量不超过 3～5 个 |
| 评价方式 | 是否能说清楚“我为什么这样花钱/定价/交易” |

推荐模块：

1. 钱从哪里来，到哪里去。
2. 收入和利润为什么不一样。
3. 买卖双方都满意才有交易。
4. 预算有限，所以要排序。
5. 诚信会影响下一次交易。

### 5.2 初中：企业经营与市场竞争入门

| 维度 | 设计 |
|------|------|
| 核心目标 | 认识企业、市场、团队、竞争和基本财务 |
| 教学语言 | 概念 + 例子 + 小队决策 |
| 推荐主题 | 小队开店、城市贸易、广告与定价、供应链小工厂 |
| 模拟强度 | 3～5 轮回合制，变量 5～8 个 |
| 评价方式 | 策略选择、团队协作、基础数据复盘 |

推荐模块：

1. 成本、定价与利润。
2. 库存和现金流。
3. 供需与价格变化。
4. 广告、客群和渠道。
5. 价格战与差异化。

### 5.3 高中：经济学模型与商业策略

| 维度 | 设计 |
|------|------|
| 核心目标 | 用经济学模型解释商业决策 |
| 教学语言 | 模型、图表、数据、案例结合 |
| 推荐主题 | 供需价格实验、产销运营赛、创业融资、投资组合 |
| 模拟强度 | 5～8 轮，多队竞争，可加入随机事件 |
| 评价方式 | 数据分析、策略备忘录、赛后报告 |

推荐模块：

1. 供需、弹性和市场均衡。
2. 边际分析和机会成本。
3. 企业成本结构和规模经济。
4. 博弈论与竞争战略。
5. 金融风险和投资组合。
6. 创业商业模式与融资逻辑。

### 5.4 大学 / 职校：专业化商业能力训练

| 维度 | 设计 |
|------|------|
| 核心目标 | 面向专业、职业和产业场景的综合商业判断 |
| 教学语言 | 案例、报表、模型、行业数据 |
| 推荐主题 | 供应链优化、产业竞争、跨境贸易、投资决策、创业孵化 |
| 模拟强度 | 高参数、多角色、长局或项目制 |
| 评价方式 | 商业报告、财务分析、路演、董事会答辩 |

推荐模块：

1. 财务报表和经营分析。
2. 供应链与运营优化。
3. 战略定位和行业结构。
4. 投融资、估值和资本结构。
5. 宏观政策、汇率和国际贸易。
6. ESG、治理和商业伦理。

### 5.5 MBA / 成人：高阶决策与组织管理

| 维度 | 设计 |
|------|------|
| 核心目标 | 在复杂约束下做战略、资本和组织决策 |

## 七、赛事引擎与课程映射

课程设计应先问“要讲什么知识”，再问“用什么引擎”。引擎是教学问题的实验器。

| 课程模块 | 适合的引擎类型 | 学生主要决策 | 复盘重点 |
|----------|----------------|--------------|----------|
| 商业语言 | 小店经营 / 订单选择 | 采购、定价、预算 | 收入、成本、利润、现金 |
| 机会成本 | 多项目投资 | 资源分配、项目取舍 | 放弃项和边际收益 |
| 市场价格 | 交易大厅 / 拍卖 / 城市贸易 | 报价、买卖时机、库存 | 供需、弹性、套利 |
| 企业运营 | 产销经营引擎 | 采购、排产、库存、质量 | 现金流、产能、库存周转 |
| 市场营销 | 消费者与品牌引擎 | 客群、渠道、广告、定位 | 转化率、广告 ROI、复购 |
| 竞争战略 | 多队同步商战 | 定价、差异化、合作/背叛 | 对手反应、行业总利润 |
| 创业创新 | 创业孵化引擎 | MVP、招聘、融资、增长 | 假设验证、单位经济 |
| 金融风险 | 投资组合引擎 | 买卖资产、仓位、杠杆 | 收益、回撤、波动 |
| 宏观贸易 | 多区域政策沙盘 | 市场进入、进出口、对冲 | 汇率、政策、贸易流 |
| ESG 伦理 | 公共价值经营引擎 | 环保、薪酬、质量、合规 | 长短期价值、外部性 |
| 谈判合同 | 角色扮演/合同引擎 | 价格、条款、保证金、履约 | 双方收益、违约激励 |

### 7.1 现有引擎的课程定位

| 当前引擎方向 | 课程定位 | 可承担的知识点 |
|--------------|----------|----------------|
| 浮生记 / 贸易交易 | 市场价格、城市贸易、套利与物流 | 供需、价差、运输成本、库存、信息 |
| OPS 产销运营赛 | 企业经营、现金流、供应链和拍卖 | 产能、库存、采购、现金流、质量 |
| TechVenture / 创投 | 创业创新、研发投资、团队战略 | MVP、研发路线、城市投资、增长策略 |
| finance-lab 方向 | 金融投资与风险控制 | 组合、波动、新闻预期、杠杆 |

## 八、课堂与赛后复盘体系

### 8.1 每局比赛的复盘结构

| 复盘层 | 问题 |
|--------|------|
| 结果 | 你们最终排名、利润、现金、资产如何？ |
| 策略 | 你们原本的核心策略是什么？有没有坚持？ |
| 假设 | 你们押注了哪个市场、客群、价格或事件？ |
| 证据 | 哪些数据证明这个假设成立或不成立？ |
| 错误 | 哪个错误最贵？是信息错、模型错还是执行错？ |
| 对手 | 对手的哪个行为改变了你们的选择？ |
| 迁移 | 如果这是现实公司，下一步会怎么做？ |

### 8.2 学生复盘模板

| 项目 | 学生填写 |
|------|----------|
| 我们的目标 | 本局最想达成什么 |
| 我们的策略 | 为什么这么定价/采购/投资 |
| 最关键决策 | 哪一轮最重要，为什么 |
| 数据证据 | 用一个数字证明策略效果 |
| 最大失误 | 如果重来，会改哪一步 |
| 学到的概念 | 本局对应哪个经济学或商学概念 |
| 现实迁移 | 现实中哪个商业案例类似 |

### 8.3 教师复盘话术

教师复盘应尽量避免只说“第一名做得好”。更好的方式是把学生行为翻译成概念。

| 学生行为 | 教师可引导的概念 |
|----------|------------------|
| 盲目降价抢市场 | 价格战、利润率、囚徒困境 |
| 订单很多但现金不够 | 现金流、库存占款、账期 |
| 只押一个资产或市场 | 分散化、风险暴露 |
| 投入广告但利润没涨 | 边际收益、广告 ROI |
| 扩产后产能闲置 | 固定成本、规模经济门槛 |
| 违约后短期获利 | 信誉、重复博弈、长期价值 |
| 抢到低价原料但卖不出 | 供应链和需求预测脱节 |

## 九、评价体系

### 9.1 不只按利润排名

商业模拟课程如果只按利润排名，会鼓励学生只追短期结果。建议采用“结果 + 过程 + 表达 + 伦理”的综合评价。

| 维度 | 权重建议 | 评价内容 |
|------|----------|----------|
| 经营结果 | 30% | 利润、现金、资产、排名、风险控制 |
| 决策质量 | 25% | 策略一致性、资源配置、时机判断 |
| 数据复盘 | 20% | 能否用图表和数字解释结果 |
| 团队协作 | 15% | 分工、沟通、角色履责 |
| 商业伦理 | 10% | 合规、信誉、外部性和长期价值 |

### 9.2 五维能力雷达

| 维度 | 初级表现 | 高级表现 |
|------|----------|----------|
| 市场洞察 | 能发现价格变化 | 能解释需求、弹性和竞争因素 |
| 财务纪律 | 能算利润 | 能管理现金、风险和资本结构 |
| 运营执行 | 能完成生产销售 | 能优化产能、库存和交付 |
| 战略协作 | 能完成小队任务 | 能形成一致战略并预测对手 |
| 社会价值 | 知道不能违规 | 能权衡利润、信任和公共影响 |

### 9.3 学习证据

| 证据 | 用途 |
|------|------|
| 决策日志 | 看学生当时如何判断 |
| 交易记录 | 看市场行为和报价逻辑 |
| 财务报表 | 看收入、成本、利润和现金 |
| 排名曲线 | 看策略变化和拐点 |
| 复盘报告 | 看概念掌握与表达能力 |
| 路演展示 | 看商业表达和团队协作 |

## 十、教师实施指南

### 10.1 课前准备

| 准备项 | 内容 |
|--------|------|
| 明确目标 | 本节课只抓 2～3 个核心概念 |
| 选择引擎 | 选择能暴露这些概念的模拟机制 |
| 设置参数 | 控制变量数量，避免学生被复杂度淹没 |
| 准备案例 | 找一个现实商业案例作为导入或迁移 |
| 准备复盘表 | 提前确定要看的数据和讨论问题 |

### 10.2 课中观察

教师在学生比赛时不应频繁告诉学生正确答案，而要观察典型误区。

| 观察点 | 说明 |
|--------|------|
| 是否理解目标 | 学生是否知道自己要优化什么 |
| 是否看关键数据 | 是否只看排行榜，不看现金、库存、利润率 |
| 是否有团队分工 | 是否有人负责财务、运营、市场和分析 |
| 是否能调整策略 | 是否根据反馈改变决策 |
| 是否陷入常见误区 | 价格战、过度扩张、追涨杀跌、沉没成本 |

### 10.3 课后沉淀

| 产出 | 说明 |
|------|------|
| 个人复盘卡 | 每个学生写出一条概念理解 |
| 小队经营报告 | 小队解释策略和数据证据 |
| 教师点评 | 指出共性误区和优秀策略 |
| 班级榜单 | 榜单只作为入口，不作为唯一评价 |
| 学习档案 | 汇入 Career / 成长档案 |

## 十四、结论

这套商业与经济学课程体系的重点，不是把所有商业知识一次讲完，而是让学生在反复模拟中逐渐形成一套判断框架：

```text
看懂钱
→ 看懂市场
→ 看懂企业
→ 看懂竞争
→ 看懂风险
→ 看懂社会价值
→ 能用数据解释自己的商业选择
```

赛事引擎的价值，是把抽象概念变成可体验、可犯错、可复盘的决策现场。课程的价值，是把这些现场经验重新翻译成经济学、商学和现实世界的理解。
