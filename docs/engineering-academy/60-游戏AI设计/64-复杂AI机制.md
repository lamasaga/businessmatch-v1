# 复杂 AI 机制

> 当游戏世界需要涌现性行为、动态难度、社会互动时，就需要更复杂的 AI 机制。本章讲几类常见的复杂机制。

## 1. 经济模拟 AI

### 原理

AI 不仅是玩家对手，还是经济系统的一部分。AI 商人根据市场信号自主决策，形成供需、价格、就业的循环。

### 关键要素

| 要素 | 说明 |
|------|------|
| 生产者 | 决定生产什么、生产多少 |
| 消费者 | 有偏好和预算约束 |
| 价格形成 | 供需决定价格 |
| 库存与物流 | 商品需要运输和存储 |

### 项目中例子

浮生记 RTS 的城市池量和价格系统就是简化版经济模拟：

- 城市有生产量和消费量
- 玩家和 AI 的交易影响池量
- 池量影响价格

### 扩展方向

- AI 生产者根据价格调整生产
- AI 消费者有季节性偏好
- 宏观经济事件冲击供需

## 2. 社会模拟 AI

### 原理

模拟群体中的关系、声望、合作、背叛。

### 关键概念

| 概念 | 说明 |
|------|------|
| 关系网络 | AI 之间的好感度 |
| 声望 | 历史行为记录 |
| 派系 | AI 根据利益结盟 |
| 谣言 | 信息传播 |

### 适用场景

- 政治模拟
- 谈判游戏
- 多势力策略游戏

### 与本项目的关系

当前商业模拟还没涉及社会网络，但未来营团模式、联盟对抗可以考虑。

---

## 3. 叙事 AI

### 原理

根据玩家行为和游戏状态生成故事事件。

### 实现方式

| 方式 | 说明 |
|------|------|
| 触发器脚本 | 条件满足时触发固定事件 |
| 分支剧情树 | 玩家选择导致不同剧情 |
| 动态叙事 | 根据玩家行为组合生成事件 |
| LLM 生成 | 用大模型生成对话和事件 |

### 适用场景

- RPG 剧情
- 商业模拟中的新闻、市场波动事件
- NPC 对话

### 项目中例子

OPS 的随机事件（消费降级、原材料涨价、政策补贴）就是简单的叙事 AI。

---

## 4. 动态难度调整（Dynamic Difficulty Adjustment, DDA）

### 原理

根据玩家表现实时调整游戏难度。

### 常见策略

| 策略 | 说明 |
|------|------|
| 参数调整 | 降低 AI 反应速度、减少资源 |
| 资源倾斜 | 给落后玩家额外资源 |
| 事件触发 | 玩家连胜时触发不利事件 |
| 匹配调整 | 给高手匹配更强对手 |

### 注意事项

- 玩家应感觉不到被操纵
- 调整幅度要小
- 保留挑战性，不要变成「保姆」

### 例子

如果玩家连续三局排名第一，下次比赛的 AI 可以：

- 更激进地抢市场份额
- 更少犯随机错误
- 更早开拓高价值城市

## 5. 涌现性行为

### 原理

简单规则的组合产生复杂、不可预测但整体有序的群体行为。

### 经典例子

- 鸟群（Boids）：每只鸟遵循分离、对齐、聚合三条简单规则
- 蚁群：单个蚂蚁简单，群体能找到最优路径
- 市场经济：个体追求利益，整体形成价格

### 设计中如何制造涌现

1. 定义简单个体规则
2. 让个体之间能交互
3. 引入资源、空间或信息约束
4. 观察并调整参数

---

## 6. 与 AI 沟通示例

```
我要为 TechVenture 增加动态难度。
规则：
- 若玩家连续两回合排名第一，AI 下回合增加 15% 投入
- 若玩家连续两回合排名垫底，AI 下回合减少 10% 投入并更保守
- 调整只在 AI 规则层，不改变结算公式
- 组织者端可开关此功能
```
