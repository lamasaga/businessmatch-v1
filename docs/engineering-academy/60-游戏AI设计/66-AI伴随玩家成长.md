# AI 伴随玩家成长

> 最好的 AI 不是一直赢玩家，而是让玩家在对战中学习、进步、获得成就感。本章讲 AI 如何适应玩家水平并陪伴成长。

## 1. 什么是 AI 伴随成长

AI 伴随成长 = AI 能：

- 感知玩家当前水平
- 调整自身难度
- 提供适时指导
- 让玩家感觉「有挑战但能赢」

理想状态：玩家每次都能学到一点新东西，但不至于被碾压。

## 2. 玩家建模（Player Modeling）

### 需要收集什么

| 维度 | 例子 |
|------|------|
| 技能水平 | 胜率、排名、决策质量 |
| 偏好 | 喜欢冒险还是稳健 |
| 学习曲线 | 进步速度 |
| 错误模式 | 重复犯的错误 |
| 投入度 | 在线时长、完成任务数 |
| 情绪状态 | 挫败感、兴奋感（通过行为推断） |

### 建模方法

| 方法 | 说明 |
|------|------|
| 规则分段 | 按胜率/等级把玩家分到不同段位 |
| 聚类 | 用 K-Means 等算法发现玩家类型 |
| 贝叶斯网络 | 推断玩家隐藏属性 |
| 深度学习 | 从大量行为数据中预测 |

### 隐私与伦理

- 只收集游戏内行为数据
- 不收集敏感个人信息
- 数据用于改善体验，不泄露

## 3. 动态难度调整（DDA）进阶

### 不只是「调参数」

好的 DDA 应该：

- 根据玩家表现微调 AI 行为
- 提供教学性挑战（让玩家练习特定技能）
- 避免玩家发现「系统在帮我」

### 策略库方法

```
为 AI 准备多个策略模板：
- beginner：保守、少犯错、给玩家机会
- intermediate：平衡、偶尔犯错
- advanced：激进、善于抓住机会
- adaptive：根据玩家表现动态切换
```

### 例子：浮生记 RTS

| 玩家状态 | AI 调整 |
|---------|---------|
| 新手，连续亏损 | AI 少做跨城套利，给玩家利润空间 |
| 中级，能稳定盈利 | AI 正常套利，偶尔竞争热门路线 |
| 高级，经常垄断 | AI 联合抢货、提前布局 |

## 4. 导师 AI（Mentor AI）

### 作用

- 在关键时刻给建议
- 解释复杂机制
- 指出玩家决策中的问题
- 鼓励玩家尝试新策略

### 实现方式

| 方式 | 说明 |
|------|------|
| 规则触发 | 检测到玩家错误时弹出提示 |
| LLM 生成 | 根据玩家行为生成个性化建议 |
| 回放分析 | 赛后分析关键决策点 |

### 例子

玩家在三回合内都过度生产导致库存积压：

```
导师 AI："你的库存已经连续三回合超过 80%，
          持有成本正在侵蚀利润。
          建议下一回合降低产量或降价促销。"
```

## 5. 适应性对手（Adaptive Opponent）

### 原理

AI 根据玩家历史行为调整自己的策略。

### 例子

如果玩家总是：

- 高价卖出 → AI 增加竞争，压低 bid
- 低价买入 → AI 提前抢购
- 固定路线 → AI 堵截关键城市

### 实现注意

- 不要让 AI 显得「专门针对玩家」
- 保持一定随机性
- 给玩家反制手段

## 6. 情感计算（Affective Computing）

### 原理

通过玩家行为推断情绪状态。

### 间接信号

| 行为 | 可能情绪 |
|------|---------|
| 频繁失败仍继续 | 坚持 |
| 失败后立即退出 | 挫败 |
| 快速连续操作 | 兴奋或焦虑 |
| 长时间不操作 | 困惑或无聊 |

### 应用

- 挫败时降低难度
- 无聊时增加挑战
- 兴奋时引入转折事件

## 7. 长期成长路径

### 设计一个成长弧线

```
新手期：AI 宽容，重点教规则
  ↓
成长期：AI 逐步增加挑战，引入新机制
  ↓
熟练期：AI 使用高级策略，玩家需要创新
  ↓
精通期：AI 作为强力对手，玩家追求极限
```

### 成就与里程碑

- 「第一次盈利」
- 「完成一次跨城套利」
- 「连续三回合排名第一」
- 「用最低成本获胜」

## 8. 与本项目 Phase 门控的结合

| Phase | 可实现的陪伴机制 |
|------|----------------|
| **A（当前）** | 多档难度 AI、基础赛后点评 |
| **B1/B2** | 玩家分段匹配、动态难度开关 |
| **B3** | LLM 生成个性化复盘和建议 |
| **C/D** | 长期玩家建模、自适应导师 AI |
| **E** | OPC LangGraph + MCP 深度陪伴 |

## 9. 与 AI 沟通示例

```
我要为浮生记 RTS 增加一个导师 AI。
需求：
- 玩家连续 3 回合总资产下降时触发
- 分析玩家最近行为（买入/卖出/移动记录）
- 给出一条具体建议，例如：
  "你在南京高价买入大米，但上海 bid 更高，
   下次可以考虑直接运输到上海出售。"
- 建议通过后端接口异步生成，不阻塞游戏
- 使用规则 + LLM 结合：规则提取事实，LLM 润色语言
```
