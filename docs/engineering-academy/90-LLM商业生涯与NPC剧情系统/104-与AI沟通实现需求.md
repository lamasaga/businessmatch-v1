# 与 AI 沟通实现需求

> 本章提供向 AI 描述 LLM 商业生涯系统实现需求时的模板和关键词。

## 1. 描述 LLM 商业生涯系统需求的结构

```
【目标】这个系统要实现什么教学/娱乐体验
【参考】借鉴了哪些游戏（CK3、太吾、RimWorld 等）
【核心机制】状态机、LLM、关系网、记忆、商业模拟
【玩家角色】实习生、职场人、创业者、投资人等
【NPC 设计】性格、目标、关系、记忆、自主行为
【商业内容】公司、项目、财务、市场、竞争
【LLM 边界】做什么、不做什么、如何约束
【技术约束】NPC 数量、LLM 成本、响应时间、Phase 门控
【验收标准】可运行的 MVP 标准
```

## 3. 提示词模板

### 模板一：设计 LLM 商业生涯系统 MVP

```
我要在商识唯智平台新增一个 LLM 商业生涯引擎。

目标：
让玩家体验从职场新人到企业家的成长，与有记忆的 NPC 建立关系，经历商业竞争和道德抉择。

参考：
- CK3 的角色特质、压力、关系网
- 太吾绘卷的 NPC 自主生态和奇遇
- RimWorld 的故事生成

核心机制：
1. 异步状态机驱动 NPC 行为
2. LLM 负责对话和叙事包装
3. NPC 有性格、目标、记忆、关系网
4. 玩家可以创建和经营公司
5. 公司与 NPC 公司竞争

玩家角色：
- 职场新人 → 专业人士 → 管理者 → 创业者/高管 → 企业家/投资人

NPC 设计：
- 类型：导师、同事、合伙人、竞争对手、投资人
- 属性：性格特质、技能、目标、情绪、声望
- 行为：自主求职、创业、挖角、联盟、报复

商业内容：
- 公司：创建、部门、项目、财务
- 人才：招聘、培训、满意度、离职
- 市场：产品、定价、营销、竞争
- 融资：天使、VC、IPO

LLM 边界：
- LLM 不修改核心数值
- LLM 输出结构化 JSON
- LLM 只生成自然语言和辅助推理
- 有硬回退机制

技术约束：
- Phase A，单场比赛，不跨比赛持久化
- 50-200 活跃 NPC
- 10-50 公司
- 每回合 NPC 更新 < 5 秒
- 对话延迟 < 1 秒

请给出：
1. 目录结构
2. 数据库模型
3. 状态机和 LLM 结合架构
4. Prompt 模板
5. 与 Arena 的集成方案
```

### 模板二：实现 NPC 记忆系统

```
我要实现 NPC 记忆系统。

需求：
- 短期记忆：最近事件
- 长期记忆：压缩后的洞察
- 向量检索：按语义检索相关记忆
- 上下文管理：控制 LLM prompt 长度
- 遗忘机制：低重要性记忆衰减

输入：
- NPC ID
- 事件数据

输出：
- 记忆条目
- 检索结果
- LLM 可用的上下文

请给出：
- 记忆数据模型
- 记忆生成流程
- 压缩算法
- 检索策略
- 遗忘公式
```

[如何用 LLM 包装成故事]

## 4. 常见错误

| 错误 | 后果 | 改进 |
|------|------|------|
| "让 LLM 做所有决策" | 不可控、成本高、不一致 | LLM 只负责叙事和辅助 |
| "NPC 完全自由" | 行为离谱、难以调试 | 用状态机约束行为空间 |
| "一期做完整系统" | 无法落地 | 分 Phase，先做对话包装 |
| "忽略数值模拟" | 缺乏真实商业感 | 商业规则引擎必须扎实 |
| "记忆无限增长" | 性能和成本爆炸 | 聚合、压缩、遗忘 |
| "只关注娱乐不要教学" | 失去教育价值 | 明确学习目标 |
| "只关注教学不要娱乐" | 玩家没动力 | 加入故事和情感 |

## 5. 验收清单

### MVP 验收

- [ ] 能创建生涯比赛
- [ ] 有至少 5 个可交互 NPC
- [ ] NPC 能进行有记忆的多轮对话
- [ ] 玩家能创建公司
- [ ] 公司能完成项目
- [ ] 能计算基础财务指标
- [ ] 能触发至少 3 种竞争事件
- [ ] 有硬回退机制

### 完整版验收

- [ ] 50+ NPC 自主运行
- [ ] 完整的生涯阶段和技能树
- [ ] 完整的公司经营系统
- [ ] 多样的竞争和联盟机制
- [ ] 长期记忆和关系演化
- [ ] 丰富的 LLM 叙事
- [ ] 教学案例可运行
- [ ] 性能满足目标
