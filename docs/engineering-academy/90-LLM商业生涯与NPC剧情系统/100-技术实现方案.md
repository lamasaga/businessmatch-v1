## 3. LLM 调用策略

### 3.1 模型选择

| 任务 | 推荐模型 | 原因 |
|------|---------|------|
| 对话生成 | Claude Haiku / GPT-3.5 | 成本低、速度快 |
| 复杂叙事 | Claude Sonnet / GPT-4 | 质量高 |
| 意图解析 | Claude Haiku / 本地小模型 | 结构化输出 |
| 记忆压缩 | Claude Haiku | 摘要任务 |
| 世界知识 | 视需求 | RAG 提供 |

### 3.2 调用方式

```python
class LLMClient:
    async def generate(self, prompt, schema=None):
        # 1. 检查缓存
        if cached := self.cache.get(prompt):
            return cached
        
        # 2. 调用 API
        response = await anthropic.messages.create(...)
        
        # 3. 解析和校验
        parsed = self.parser.parse(response.content, schema)
        if not self.validator.validate(parsed):
            return self.fallback.generate(prompt)
        
        # 4. 缓存
        self.cache.set(prompt, parsed)
        return parsed
```

### 3.3 成本控制

- 缓存高频 prompt。
- 简单任务用小模型。
- 批量生成而非单次调用。
- 限制对话轮数和长度。
- 预生成固定模板。

## 4. 异步调度

### 4.1 调度器

```python
class WorldScheduler:
    def __init__(self):
        self.running = False
        self.interval = 300  # 5 分钟推进一次（可配置）
    
    async def start(self, event_id):
        self.running = True
        while self.running:
            await self.tick(event_id)
            await asyncio.sleep(self.interval)
    
    async def tick(self, event_id):
        # 1. 加载世界状态
        world = load_world_state(event_id)
        
        # 2. 更新所有 NPC（并行）
        tasks = [npc.update(world) for npc in world.active_npcs]
        await asyncio.gather(*tasks)
        
        # 3. 处理公司运营
        for company in world.companies:
            company.operate(world)
        
        # 4. 市场竞争
        world.market.clear()
        
        # 5. 检测事件
        events = world.event_detector.check()
        
        # 6. 生成叙事（异步，不阻塞）
        for event in events:
            asyncio.create_task(generate_narrative_async(event))
        
        # 7. 保存状态
        save_world_state(world)
```

## 6. 安全与可控性

### 6.1 内容安全

- 输入过滤：防止 prompt injection。
- 输出过滤：防止不当内容。
- 主题约束：限制在商业价值体系内。

### 6.2 数值安全

- LLM 不直接修改数值。
- 所有数值变化由状态机和模拟层执行。
- 有最大值和最小值限制。

### 6.3 可复现性

- 种子固定时，非 LLM 部分可复现。
- LLM 部分因温度参数可能有差异，但核心状态由规则决定。
