# 商业生涯系统设计

> 本章设计玩家的商业生涯：从职场新人到企业家/投资人的成长路径，以及职业生涯中的关键节点和故事。

## 1. 生涯阶段

```
[学生/实习生]
    ↓
[职场新人]
    ↓
[专业人士]
    ↓
[管理者 / 技术专家]
    ↓
[创业者 / 高管]
    ↓
[企业家 / 投资人]
    ↓
[行业领袖 / 退休]
```

每个阶段有不同的决策空间、关系网络和故事主题。

## 2. 职业路径

### 2.1 销售路径

```
销售代表 → 销售经理 → 销售总监 → VP of Sales → CCO / 创始人
```

核心能力：客户关系、谈判、市场洞察。

### 2.2 技术路径

```
工程师 → 高级工程师 → 技术主管 → CTO → 技术型创始人
```

核心能力：技术深度、产品创新、团队管理。

### 2.3 管理路径

```
专员 → 主管 → 经理 → 总监 → VP → CEO
```

核心能力：组织协调、战略决策、领导力。

### 2.4 财务路径

```
分析师 → 投资经理 → 投资总监 → 合伙人 → 投资人 / CFO
```

核心能力：财务分析、投资判断、风险控制。

### 2.5 创业路径

```
有想法 → 找合伙人 → 融资 → 产品开发 → 市场推广 → 扩张 / 退出
```

核心能力：综合能力、风险承受、资源整合。

## 3. 技能系统

### 3.1 技能分类

| 类别 | 技能 |
|------|------|
| 商业 | 销售、营销、谈判、战略 |
| 技术 | 编程、产品、数据分析 |
| 管理 | 领导力、团队建设、项目管理 |
| 财务 | 会计、投资、融资、风控 |
| 社交 | 人脉、影响力、演讲 |
| 个人 | 抗压、学习、决策 |

### 3.2 技能成长

```python
def skill_growth(npc, activity, practice_time):
    base_growth = practice_time * learning_rate
    
    # 天赋影响
    if has_aptitude(npc, activity.skill):
        base_growth *= 1.5
    
    # 导师加成
    if has_mentor(npc, activity.skill):
        base_growth *= 1.3
    
    # 挑战度
    if activity.difficulty > current_skill:
        base_growth *= 1.2
    
    npc.skills[activity.skill] += base_growth
```

### 3.3 技能瓶颈

某些高级能力需要特定经历：

- 领导力：需要带团队经验。
- 战略：需要参与高层决策。
- 投资：需要成功和失败的项目经验。

## 4. 关键生涯事件

### 4.1 正面事件

| 事件 | 影响 |
|------|------|
| 成功完成重大项目 | 技能提升、声望增加、晋升机会 |
| 获得导师赏识 | 获得指导、机会推荐 |
| 创业成功 | 财富自由、行业地位 |
| 关键人脉建立 | 未来合作机会 |
| 适时跳槽 | 薪资大幅提升 |

### 4.2 负面事件

| 事件 | 影响 |
|------|------|
| 项目失败 | 声望下降、压力增加 |
| 被裁员 | 收入中断、需要重新求职 |
| 合伙人背叛 | 公司分裂、信任危机 |
| 投资失败 | 财富损失、压力增加 |
| 职场冲突 | 关系恶化、晋升受阻 |

### 4.3 转折事件

| 事件 | 影响 |
|------|------|
| 遇到贵人 | 职业加速 |
| 行业变革 | 需要转型 |
| 公司并购 | 地位变化 |
| 经济危机 | 逆境考验 |
| 家庭变故 | 影响工作投入 |

### 5.2 不同角色的追求

| 角色 | 主要追求 |
|------|---------|
| 职场人 | 稳定收入、晋升、工作生活平衡 |
| 创业者 | 成就、影响力、财富 |
| 投资人 | 回报、行业洞察、风险可控 |
| 高管 | 权力、 legacy、行业地位 |

## 6. 传承与继任

### 6.1 代际传承

参考 CK3 的王朝机制：

- 玩家可以培养继任者。
- 继任者继承公司、人脉、声望。
- 继任者有自己的性格，可能改变公司方向。

### 6.2 退休生活

- 玩家退休后可以成为：
  - 天使投资人
  - 行业顾问
  - 慈善家
  - 幕后操盘手
