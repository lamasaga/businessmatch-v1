# 与现有平台的集成

> 本章说明如何把 LLM 商业生涯系统接入商识唯智现有平台，与 Arena、Career、现有引擎协同。

## 1. 集成原则

- **新引擎独立**：作为 `games/career_sim/` 新引擎。
- **复用 Arena**：比赛生命周期由 Arena 管理。
- **Career 联动**：生涯成就可转化为 XP/徽章。
- **渐进引入**：Phase A 先做轻量叙事包装，后续逐步加深。

## 2. 后端集成

### 2.1 路由挂载

在 `webapp/backend/app/main.py` 增加：

```python
app.include_router(career_sim_api.router, prefix="/api/v1")
app.include_router(career_sim_admin.router, prefix="/api/v1")
```

### 2.2 API 设计

#### 参赛端

| 接口 | 方法 | 说明 |
|------|------|------|
| `/career-sim/{event_id}/state` | GET | 获取当前世界状态 |
| `/career-sim/{event_id}/npc/{npc_id}/talk` | POST | 与 NPC 对话 |
| `/career-sim/{event_id}/decisions` | POST | 提交商业决策 |
| `/career-sim/{event_id}/company` | GET/POST | 管理公司 |
| `/career-sim/{event_id}/reports` | GET | 获取回合报告 |
| `/career-sim/{event_id}/pending-events` | GET | 离线期间事件 |

#### 组织端

| 接口 | 方法 | 说明 |
|------|------|------|
| `/career-sim/admin/{event_id}/start` | POST | 开始 |
| `/career-sim/admin/{event_id}/advance` | POST | 推进回合 |
| `/career-sim/admin/{event_id}/events` | POST | 触发事件 |
| `/career-sim/admin/{event_id}/leaderboard` | GET | 排行榜 |

### 2.3 与 Arena 的交互

```python
# Arena 创建比赛
event = create_match(game_config_id="career-sim-v1", match_kind="practice")

# Arena 开赛时初始化世界
career_sim_init(db, event)

# 每回合推进
career_sim_advance_turn(db, event)

# 比赛结束
career_sim_finish(db, event)
settle_match_rewards(event)  # Career 域
```

### 2.4 与 Career 域的交互

生涯成就可映射为 Career XP：

| 成就 | XP 奖励 |
|------|--------|
| 成功创业 | 1000 |
| 完成第一轮融资 | 500 |
| 公司上市 | 2000 |
| 建立重要人脉 | 200 |
| 化解重大危机 | 800 |

## 3. 前端集成

### 3.1 学生端页面

- `/career-sim/{event_id}`：生涯主页
- `/career-sim/{event_id}/world`：世界地图/关系网
- `/career-sim/{event_id}/npc/{npc_id}`：NPC 详情与对话
- `/career-sim/{event_id}/company`：公司管理
- `/career-sim/{event_id}/career`：职业生涯树
- `/career-sim/{event_id}/reports`：事件与报告

### 3.2 组织者端页面

- 世界控制台
- 回合推进
- 事件管理
- 玩家状态监控

### 3.3 可视化需求

| 可视化 | 用途 |
|--------|------|
| 关系网络图 | 显示 NPC 之间的关系 |
| 时间线 | 玩家生涯关键事件 |
| 公司仪表盘 | 财务、项目、人才 |
| 对话界面 | 与 NPC 聊天 |
| 事件卡片 | 重要事件展示 |

## 4. 与现有引擎的关系

| 现有引擎 | 关系 |
|----------|------|
| trading | 可以作为生涯系统中的一个「商业技能挑战」 |
| techventure | 可以作为「创业公司模拟」的简化版前置 |
| ops_sim | 可以作为「公司运营」的子模块 |
| city_sim | 可以作为更宏观城市的商业子系统 |

未来可以让生涯系统「调用」其他引擎作为具体商业场景的模拟。

## 5. 配置示例

```yaml
engine: career_sim
name: LLM商业生涯模拟
rounds: 20
offline_tick_minutes: 30

world:
  initial_npcs: 50
  initial_companies: 15
  
player:
  starting_stage: professional
  starting_cash: 100000
  
llm:
  dialogue_model: claude-haiku
  narrative_model: claude-sonnet
  max_context_tokens: 3000
  enable_free_input: true
  
economy:
  industries: [tech, retail, manufacturing, services, finance]
  market_volatility: 0.2
```
