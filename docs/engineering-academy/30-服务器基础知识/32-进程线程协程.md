# 进程、线程、协程

> 后端程序要同时服务很多用户，这就需要「并发」。本文用通俗语言解释三个关键概念。

## 1. 进程（Process）

一个运行中的程序就是一个进程。

- 每个进程有独立的内存空间
- 一个程序崩溃通常不影响其他进程
- 启动新进程开销较大

例如：同时运行后端、学生端、组织者端，就是三个进程。

## 2. 线程（Thread）

进程内部可以有多条执行线，叫线程。

- 同一进程内的线程共享内存
- 线程切换比进程快
- 多个线程可以并行工作

例如：一个玩家请求对应一个线程处理。

## 3. 协程（Coroutine）

协程是更轻量的并发单位。

- 由程序自己调度，而不是操作系统
- 可以挂起和恢复
- 适合大量 IO 操作（如等数据库返回、等网络请求）

Python 中协程用 `async` / `await` 关键字。

## 4. 为什么本项目用协程

FastAPI 原生支持异步协程。当后端等待数据库或网络时，协程可以挂起去处理其他请求，从而提高并发能力。

本项目是单进程单数据库，但用协程可以服务更多同时在线的玩家。

## 5. 类比

- 进程：一家餐厅
- 线程：餐厅里的服务员
- 协程：一个服务员同时服务多桌，遇到等菜时间先去招呼其他桌

## 6. 与 AI 沟通关键词

| 你想说的 | 关键词 |
|---------|--------|
| 同时处理多个请求 | "concurrency, async/await" |

| 后台定时任务 | "background task, scheduler" |
| 多进程扩展 | "multi-process deployment" |
