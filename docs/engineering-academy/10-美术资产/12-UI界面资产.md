# UI 界面资产

> UI 是用户与系统交互的界面。本文讲 UI 资产的分类、设计系统、切图规范，以及如何让前端「拼」出界面。

## 1. UI 资产的分类

| 类型 | 例子 | 特点 |
|------|------|------|
| 图标（Icon） | 首页、设置、返回、金币 | 小、清晰、可缩放 |
| 按钮（Button） | 主按钮、次按钮、危险按钮 | 多种状态 |
| 面板（Panel） | 弹窗、侧边栏、卡片 | 可容纳内容 |
| 输入框（Input） | 文本框、下拉框、选择器 | 有焦点/禁用状态 |
| 进度条（Progress） | 血条、时间条、经验条 | 需要可裁剪填充 |
| 列表/表格 | 排行榜、库存列表 | 通常由程序动态生成 |
| 背景/装饰 | 纹理、边框、角标 | 可重复平铺 |

## 2. 按钮的状态

一个按钮通常需要 4 种图：

- **default**：正常状态
- **hover**：鼠标悬停
- **active / pressed**：按下
- **disabled**：禁用

如果只有一张图，前端也能用 CSS 滤镜模拟 hover，但效果不如原画。

## 3. 可拉伸图片：9-patch / Slice

面板和按钮通常中间要放文字，但文字长度不固定。于是需要「九宫格切图」：

```
┌───┬───────┬───┐
│ 1 │   2   │ 3 │  ← 四角不变形
├───┼───────┼───┤
│ 4 │   5   │ 6 │  ← 上下/左右边框拉伸
├───┼───────┼───┤
│ 7 │   8   │ 9 │  ← 中间放内容
└───┴───────┴───┘
```

前端按 9 宫格拉伸，角不变形，中间区域可任意缩放。

CSS 中对应属性：

```css
border-image-slice: 20 20 20 20 fill;
```

## 4. 矢量图标：SVG

SVG 是矢量格式，放大不会模糊，非常适合图标。本项目已经使用 Tabler 图标库：

- 仓库：`art-assets/tabler/`
- 使用方式：前端通过 `@tabler/icons-react` 引入
- 优点：一套风格统一、可直接改颜色

如果自定义图标，也建议导出 SVG。

## 5. 颜色与主题

UI 需要与平台主题一致。建议维护一个 `theme.json` 或 `tokens.css`：

```json
{
  "colors": {
    "primary": "#3B82F6",
    "danger": "#EF4444",
    "success": "#10B981",
    "bg": "#F8FAFC",
    "text": "#1E293B"
  }
}
```

前端用变量而不是硬编码颜色，后续换皮肤方便。

## 6. 组件库

本项目已有一个组件库文档 `docs/bizsim-component-library.md`。新增 UI 时应先看这里是否已有类似组件，避免重复造轮子。

常用前端组件库：

- `shadcn/ui`：本项目基础
- `Tailwind CSS`：样式原子类
- `Radix UI`：无样式可访问组件

