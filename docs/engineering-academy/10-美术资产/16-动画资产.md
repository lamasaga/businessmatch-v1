# 动画资产

> 动画让角色和界面活起来。本文讲常见动画格式、骨骼动画、以及程序如何调用动画。

## 1. 动画类型

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| 帧动画 | 一张张图片连续播放 | 简单循环动作 |
| 补间动画 | 定义起点终点，中间由程序计算 | UI 位移、缩放、旋转 |
| 骨骼动画 | 角色由骨骼驱动，可换皮 | 复杂角色、剧情 |
| Lottie | 矢量动画 JSON | UI 动画、引导 |
| 视频 | MP4/WebM | 高质量过场 |
| 程序动画 | 代码生成 | 数据可视化、实时反馈 |

## 2. 帧动画

最基础的动画方式。把动作拆成若干帧，按顺序播放。

参数：

- **帧率（fps）**：每秒播放多少帧。常见 12、24、30、60。
- **循环（loop）**：是否反复播放。
- **混合模式**：是否与上一帧叠加。

适合：小图标动画、简单角色动作、粒子。

## 3. 骨骼动画（Spine / Live2D）

把角色拆成多个「骨骼」或「变形网格」，通过移动骨骼来驱动画面。

优点：

- 动作平滑
- 可换服装、表情、发型
- 文件相对小

缺点：

- 需要专门工具和学习成本
- 与前端集成需要运行时库

Spine 导出 `.json` + `.atlas` + `.png` 组合；Live2D 导出 `.moc3` + 贴图。

## 4. UI 动画

界面动画通常不需要美术导出，而是由前端用 CSS / JS 实现：

- 进入动画：fade-in、slide-up
- 离开动画：fade-out、scale-down
- 状态切换：颜色过渡、宽度变化
- 微交互：按钮按下、开关切换

这些动画应该统一时长（如 200ms、300ms、500ms），保持平台手感一致。

## 5. 动画状态机

角色动画通常用状态机管理：

```
idle（待机）
  ↓
walk（行走）
  ↓
talk（说话）
  ↓
win（胜利）
```

程序根据游戏状态切换动画。美术需要提供每个状态的动画资源，以及过渡规则。

## 6. 推荐规格

| 类型 | 工具 | 导出格式 | 备注 |
|------|------|---------|------|
| 帧动画 | Aseprite / Photoshop | PNG 序列 / Sprite Sheet | 小尺寸 |
| 骨骼动画 | Spine | JSON + atlas + PNG | 角色 |
| 矢量 UI 动画 | After Effects | Lottie JSON | 轻量 |
| 视频过场 | Premiere / AE | MP4 / WebM | 大文件 |

## 7. 命名示例

```
anim_character_merchant_idle.json
anim_character_merchant_walk.json
anim_character_merchant_talk.json
anim_ui_toast_slide_in.json
anim_ui_modal_fade_in.json
anim_victory_chest_open.json
cutscene_intro.mp4
```

## 8. 与 AI 沟通示例

```
我要为 NPC 商人增加一组动画。
需求：
- 工具：Spine
- 动作：idle、talk、gesture、happy
- 每个动作循环播放
- 导出 Spine 标准格式（json + atlas + png）
- 提供每个动作的名称和时长
```
