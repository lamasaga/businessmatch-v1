# 美术资产导论

> 游戏里的「图」不只是图，而是程序能识别、能加载、能正确显示的数据。本章讲美术资产的分类、规格、命名和交付流程。

## 1. 美术资产 ≠ 随便一张图

程序加载图片时，需要知道：

- 格式（PNG / JPG / SVG / WebP）
- 尺寸（宽度 x 高度，像素）
- 透明背景还是实底
- 是否是一组动画帧
- 是否是矢量可缩放

如果美术给的是 PSD 或者尺寸不统一的 PNG，前端就很难用。所以每一类资产都要有**规格约定**。

## 2. 本项目资产分类

| 类别 | 用途 | 常见格式 | 存放位置 |
|------|------|---------|---------|
| 人物 | 玩家形象、NPC、角色立绘 | PNG、SVG、Lottie | `art-assets/fushengji/characters/` |
| UI | 按钮、面板、图标、血条、弹窗 | SVG、PNG | `art-assets/tabler/`（图标）、`frontend/public/ui/` |
| 场景 | 城市背景、地图、大厅 | PNG、WebP、SVG | `art-assets/fushengji/scenes/` |
| 物品 | 商品图标、道具、资源 | PNG、SVG | `art-assets/fushengji/items/` |
| 特效 | 闪光、粒子、提示光环 | PNG 序列、Lottie、CSS | `frontend/public/effects/` |
| 动画 | 角色动作、过场动画 | Lottie、GIF、APNG、骨骼动画 | `frontend/public/animations/` |

## 3. 像素尺寸与缩放

Web 前端通常用 CSS 控制显示大小，但原始图片尺寸影响：

- **清晰度**：原始太小，放大后模糊。
- **加载速度**：原始太大，浪费流量。
- **对齐**：UI 元素尺寸不统一，布局会乱。

常见做法：

- 图标：24x24、32x32、48x48、64x64（以 1x 为基准，再出 2x 高清版）
- 人物立绘：512x1024 或 1024x2048
- 场景背景：1920x1080 或按 16:9 比例
- 商品图标：128x128

## 4. 透明背景

- **PNG**：支持透明，适合图标、人物、物品。
- **JPG**：不支持透明，适合照片类背景。
- **SVG**：矢量，支持透明，适合 UI 图标。
- **WebP**：现代格式，体积小，支持透明和动画。

## 5. 命名规范

好的命名让程序能自动找到资源。建议：

```
{category}_{name}_{state}.{ext}
```

例如：

```
character_merchant_idle.png
character_merchant_talk.png
ui_button_primary_default.svg
ui_button_primary_hover.svg
item_rice_128.png
scene_city_nanjing_day.jpg
effect_coin_sparkle_01.png
effect_coin_sparkle_02.png
```

避免：

- 中文文件名
- 空格（用下划线）
- `1.png`、`2.png` 这种无意义名字
- `final.png`、`final_final.png`、`final_v2.png`

## 6. 导出清单

美术交付时，最好附带一个 `assets-manifest.json`：

```json
{
  "version": "1.0.0",
  "assets": [
    {
      "id": "character_merchant",
      "type": "character",
      "files": {
        "idle": "character_merchant_idle.png",
        "talk": "character_merchant_talk.png"
      },
      "size": [512, 1024]
    }
  ]
}
```

这样程序可以按 ID 读取，而不是硬编码文件名。

## 7. 与 AI 沟通的关键词

| 你想说的 | 关键词 |
|---------|--------|
| 我要换一套皮肤 | "reskin, replace asset references" |
| 图标要高清 | "provide 1x and 2x PNG/SVG" |
| 人物要动 | "sprite sheet / Lottie animation" |
| 背景要适配手机 | "responsive background, 16:9 safe area" |
| 加载慢 | "compress to WebP, lazy load" |
