# 物品图标资产

> 商业模拟中，商品、道具、资源都需要图标。本文讲物品图标的设计规范和程序对接。

## 1. 物品图标的用途

- 库存列表中的商品
- 交易界面的买入/卖出
- 市场价格面板
- 任务奖励
- 背包/道具栏

## 2. 风格统一

同一套图标应该：

- 视角一致（全部正视 / 全部等角）
- 光影一致（光源方向相同）
- 尺寸一致（同一列表中的图标尺寸相同）
- 描边粗细一致

如果混用不同风格，界面会显得很乱。

## 3. 推荐规格

| 用途 | 尺寸 | 格式 | 背景 |
|------|------|------|------|
| 列表小图标 | 32x32 或 48x48 | PNG / SVG | 透明 |
| 交易面板图标 | 64x64 或 96x96 | PNG / SVG | 透明 |
| 详情页大图标 | 128x128 或 256x256 | PNG | 透明或带底板 |
| 地图标记 | 32x32 或 48x48 | PNG / SVG | 透明 |

## 4. 状态变化

物品图标可能需要表达状态：

- 普通
- 选中 / 高亮
- 禁用（灰色）
- 稀有度（铜 / 银 / 金边框）
- 数量角标（99+）

处理方式：

- 图标本身保持统一
- 边框/角标由程序叠加
- 禁用状态用 CSS 灰度滤镜

## 5. 数据绑定

每个物品图标应有一个唯一 ID，程序通过 ID 读取：

```yaml
products:
  - id: rice
    name: 大米
    icon: item_rice_64.png
```

不要在前端写死 `rice.png`，而是读取配置。

## 6. 命名示例

```
item_rice_32.png
item_rice_64.png
item_rice_128.png
item_silk_64.png
item_gold_64.png
item_border_common.svg
item_border_rare.svg
item_border_legendary.svg
```

## 7. 与 AI 沟通示例

```
我要为 TechVenture 增加一组科技产品图标，共 8 个。
需求：
- 风格：扁平化、2.5D 等角
- 尺寸：64x64 PNG 透明，同时出 128x128 高清版
- 每个产品有普通 / 稀有 / 史诗三种稀有度边框
- 边框单独导出 SVG
请给出 assets-manifest.json 和命名规范。
```
