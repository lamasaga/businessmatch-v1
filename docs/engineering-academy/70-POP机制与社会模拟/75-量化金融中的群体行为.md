# 量化金融中的群体行为与市场微观结构

> 如果把 POP 看作「市场中的参与者群体」，那么量化金融研究的就是真实市场中这些群体的行为。本章讲如何把 POP 思维迁移到金融市场设计。

## 1. 市场微观结构（Market Microstructure）

### 1.1 什么是市场微观结构

研究交易所、交易机制和市场参与者如何共同决定价格和成交量的学科。

核心问题：

- 价格是怎么形成的？
- 买卖价差（bid-ask spread）为什么存在？
- 大额交易如何影响价格？
- 信息如何融入价格？

### 1.2 限价订单簿（LOB）

现代交易所的核心数据结构：

```
买单（Bids）          卖单（Asks）
价格  数量            价格  数量
100    5             101    3
99    10             102    7
98    20             103    12
```

市场价格由买卖单匹配决定。

### 1.3 关键参与者类型

| 参与者 | 特点 |
|--------|------|
| 做市商 | 提供流动性，赚取买卖价差 |
| 知情交易者 | 拥有私有信息，主动交易 |
| 噪声交易者 | 随机或情绪化交易 |
| 套利者 | 捕捉价格偏离 |
| 算法交易者 | 按程序自动交易 |

这些类型可以直接对应到 POP 机制中的不同人群组。

## 2. 订单流与市场影响

### 2.1 订单流持久性

研究发现，订单流具有长期记忆性：

- 如果一段时间内买单多，接下来继续买单多的概率更高。
- 这说明交易决策不是独立的，而是相互影响的。

### 2.2 市场影响

大额交易会影响价格：

- **暂时性影响**：交易完成后价格部分恢复。
- **永久性影响**：信息被永久融入价格。

公式（简化）：

```
价格影响 = λ × 订单规模
```

其中 λ 是市场冲击系数，反映市场深度。

### 2.3 与 POP 的对应

| 金融市场概念 | POP 机制对应 |
|-------------|-------------|
| 订单流 | POP 的买卖行为 |
| 市场深度 | POP 数量和财富规模 |
| 买卖价差 | 交易成本 |
| 价格冲击 | 大 POP 群体交易对价格的影响 |
| 信息融入 | POP 对新信息的反应 |

## 3. 行为金融学

### 3.1 经典偏差

| 偏差 | 说明 | 游戏中的表现 |
|------|------|-------------|
| 羊群效应（Herding） | 跟随他人行动 | 玩家跟风买入某商品 |
| 过度自信 | 高估自己判断 | 玩家过度杠杆 |
| 损失厌恶 | 亏比赚更痛苦 | 玩家不愿止损 |
| 锚定效应 | 依赖历史价格 | 玩家在固定价格附近挂单 |
| FOMO | 害怕错过 | 玩家追高 |

### 3.2 为什么需要行为金融学

传统金融假设人是完全理性的，但现实中：

- 人会恐慌
- 人会贪婪
- 人会跟风
- 人会犯错

这些非理性行为正是泡沫、崩盘、踩踏的来源。

## 4. 量化模型：Hawkes 过程

### 4.1 什么是 Hawkes 过程

一种「自激发」的点过程：一个事件会增加未来事件发生的概率。

在金融中：

- 一次买单可能激发更多买单。
- 一次卖单可能激发更多卖单。

### 4.2 公式（简化）

```
λ(t) = μ + Σ κ × exp(-β × (t - t_i))
```

- μ：基础到达率
- κ：事件激发强度
- β：衰减速度
- t_i：历史事件发生时间

### 4.3 在游戏中的应用

可以用 Hawkes 过程模拟 POP 的群体行为：

```
若某个城市大米价格上涨 → 其他 POP 跟风买入的概率增加
若某个城市出现失业 → 迁移潮概率增加
```

## 5. 泡沫与崩盘

### 5.1 正反馈循环

```
价格上涨 → 更多人买入 → 价格进一步上涨 → 更多人买入
              ↓
        泡沫形成
              ↓
        某个触发事件 → 恐慌性卖出 → 价格暴跌 → 崩盘
```

### 5.2 如何在游戏中设计

- 让 POP 有「趋势跟随」倾向。
- 设置信息传播延迟。
- 设置杠杆和恐慌阈值。
- 引入随机冲击事件。

## 6. 与 POP 机制的结合

### 6.1 把金融参与者设计成 POP

| POP 类型 | 行为模式 | 市场影响 |
|----------|---------|---------|
| 散户 | 追涨杀跌、信息滞后 | 放大波动 |
| 机构投资者 | 基于基本面、信息优势 | 价格发现 |
| 做市商 | 提供流动性 | 缩小价差 |
| 投机者 | 短期套利 | 增加成交量 |

### 6.2 微观到宏观的链路

```
单个 POP 决策
    ↓
订单流聚合
    ↓
限价订单簿变化
    ↓
价格形成
    ↓
POP 财富变化
    ↓
下一轮决策
```

## 7. 与 AI 沟通示例

```
我要为一个金融市场模拟引擎设计基于 POP 的订单流模型。

POP 类型：
- 散户：追涨杀跌，对信息反应慢
- 机构：基于基本面交易
- 做市商：提供流动性

机制：
- 每个 POP 根据当前价格趋势和自身策略提交买卖订单
- 订单进入限价订单簿
- 价格由订单簿匹配决定
- 散户行为用 Hawkes 过程建模趋势跟随
- 机构行为基于基本面估值

输出：
- 订单簿快照
- 价格序列
- 成交量
- 波动率

请给出 POP 规则、订单簿实现和示例代码结构。
```
