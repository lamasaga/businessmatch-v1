# 涌现事件与叙事

> 涌现事件让城市模拟更有故事性和不可预测性。本章设计如何从历史事件、经济危机、社会运动中提炼机制。

## 1. 为什么要涌现事件

纯粹的机械模拟可能显得枯燥。事件可以：

- 创造转折点
- 测试玩家应变能力
- 让宏观规律更直观
- 提供教学讨论素材

## 2. 事件分类

### 2.1 经济事件

| 事件 | 触发条件 | 影响 |
|------|---------|------|
| 原材料涨价 | 外部市场冲击 | 制造业成本上升，通胀 |
| 技术突破 | 研发积累 | 某产业生产率大幅提升 |
| 金融危机 | 信贷过度扩张 | 企业破产，失业激增 |
| 产业外迁 | 成本过高 | 工厂关闭，工人失业 |
| 出口机遇 | 外部需求增加 | 相关产业繁荣 |

### 2.2 社会事件

| 事件 | 触发条件 | 影响 |
|------|---------|------|
| 罢工 | 工人满意度低、工会强 | 生产中断，工资谈判 |
| 迁移潮 | 区域差距大 | 人口快速变化 |
| 社区抗议 | 污染或绅士化 | 政策压力 |
| 教育运动 | 教育投入增加 | 技能提升 |

### 2.3 环境事件

| 事件 | 触发条件 | 影响 |
|------|---------|------|
| 自然灾害 | 随机/气候变化 | 基础设施损毁，重建需求 |
| 污染危机 | 工业过度集中 | 健康成本，居民迁移 |
| 能源危机 | 能源依赖 | 生产成本上升 |

### 2.4 政策事件

| 事件 | 触发条件 | 影响 |
|------|---------|------|
| 中央政策变化 | 外部政治 | 税收、补贴变化 |
| 选举 | 任期结束 | 政策方向变化 |
| 国际协议 | 外部事件 | 贸易条件变化 |

## 3. 事件触发机制

### 3.1 基于阈值触发

```python
if unemployment_rate > 0.15 and avg_satisfaction < 4:
    trigger_event('mass_protest')
```

### 3.2 基于概率触发

```python
if random() < base_probability * risk_factor:
    trigger_event('financial_crisis')
```

### 3.3 基于累积压力触发

```python
housing_pressure += population_growth - housing_supply_growth
if housing_pressure > threshold:
    trigger_event('housing_crisis')
```

## 4. 事件影响模型

### 4.1 直接影响

事件立即改变某些变量：

```python
event_effects = {
    'financial_crisis': {
        'credit_multiplier': 0.5,
        'investment_multiplier': 0.3,
        'consumer_confidence': -0.4
    }
}
```

### 4.2 间接影响

通过 POP 行为传导：

```
金融危机 → 企业裁员 → 失业增加 → 消费下降 → 更多企业倒闭
```

### 4.3 反馈放大

某些事件会自我强化：

```
房价下跌 → 购房者观望 → 房价进一步下跌
```

## 5. 叙事生成

### 5.1 事件叙事

用 LLM 或模板生成事件描述：

```
模板：「由于 [原因]，城市遭遇了 [事件]。[群体] 受到严重影响，
      [指标] 在 [时间] 内 [变化]。政府可以考虑 [可选政策]。」

例子：「由于过度信贷扩张，城市遭遇了金融危机。制造业工人大量失业，
      失业率在两年内从 5% 上升到 18%。政府可以考虑增加公共就业项目。」
```

### 5.2 回合报告

每回合生成城市简报：

```
第 5 年城市简报
- GDP 增长 3.2%，主要由科技业带动
- 失业率下降至 6%
- 房价持续上涨，低收入群体开始迁往郊区
- 地铁 2 号线开通，沿线商业繁荣
- 警告：制造业岗位持续流失
```

### 5.3 个人故事

为高代表性 POP 生成故事：

```
「张先生，35 岁，制造业工人。由于工厂外迁，他失去了工作。
 目前依靠储蓄生活，正在考虑学习新技能或搬到另一个城市。」
```

## 6. 教学中的事件设计

### 6.1 设计原则

- 事件应与核心教学内容相关。
- 事件应有多重解决方案。
- 事件后果应可追溯。

### 6.2 案例：金融危机

**教学目标**：理解货币政策和财政政策。

**事件**：银行信贷紧缩，企业投资下降，失业率上升。

**可选政策**：

- 降息（刺激投资）
- 增加政府支出（基建、公共服务）
- 减税（刺激消费）
- 救助银行（恢复信贷）

**讨论**：

- 每种政策的受益者是谁？
- 长期后果是什么？
- 现实中有哪些类似案例？

## 7. 与 AI 沟通示例

```
我要为 POP-拟真城市设计涌现事件系统。

事件类型：
- 经济：原材料涨价、技术突破、金融危机、产业外迁
- 社会：罢工、迁移潮、社区抗议
- 环境：自然灾害、污染危机
- 政策：中央政策变化、选举

触发机制：
- 阈值触发（如失业率 > 15%）
- 概率触发
- 累积压力触发

叙事：
- 每回合生成城市简报
- 重大事件生成详细描述
- 可选 LLM 增强

请给出事件数据结构、触发条件示例和城市简报模板。
```
