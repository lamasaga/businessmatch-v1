# 城市空间与土地利用

> 本章设计 POP-拟真城市的空间系统：地块、区位、地价、土地利用类型，以及城市扩张机制。

## 1. 空间层级

### 1.1 地块（Parcel）

最小空间单位，属性包括：

```python
class Parcel:
    id: str
    district_id: str           # 所属区域
    land_use: str              # 土地利用类型
    owner: str                 # 所有者（政府/企业/个人）
    building_density: float    # 建筑密度 0-1
    land_value: float          # 地价
    rent: float                # 租金
    accessibility: float       # 可达性
    pollution: float           # 污染程度
    amenities: dict            # 配套设施
    zoning: str                # 规划用途限制
```

### 1.2 区域（District）

由多个地块组成，代表城市功能区：

| 区域类型 | 特点 |
|----------|------|
| CBD | 商业办公集中，地价最高 |
| 工业区 | 工厂集中，污染较高，地价较低 |
| 住宅区 | 居民居住，分高档、中档、低档 |
| 港口/物流区 | 贸易、运输、仓储 |
| 科教区 | 学校、研究机构 |
| 生态区 | 公园、绿地 |

## 2. 土地利用类型

| 类型 | 产出 | 主要使用者 |
|------|------|-----------|
| 住宅 | 住房服务 | 家庭 |
| 商业办公 | 办公服务 | 企业总部、服务业 |
| 零售 | 商品销售 | 零售商 |
| 工业 | 制造业产出 | 工厂 |
| 农业 | 农产品 | 农场 |
| 公共设施 | 公共服务 | 政府 |
| 绿地 | 环境效益 | 全体市民 |

## 3. 竞租理论与 Alonso-Mills-Muth 模型

### 3.1 核心思想

Alonso-Mills-Muth（AMM）模型是城市经济学的核心理论：

- 城市有一个中心商务区（CBD）。
- 不同土地利用类型愿意为不同位置支付不同租金。
- 土地归最高出价者使用。

### 3.2 竞租曲线

```
租金
 ↑
 │   商业  \   住宅   \   农业
 │       \        \      \
 │        \        \      \
 └────────────────────────────→ 距 CBD 距离
```

- 商业：市中心租金最高，随距离快速下降。
- 住宅：愿意牺牲可达性换取更大空间。
- 工业：需要大量土地和交通，位于边缘。

### 3.3 游戏中实现

每个地块的用途由竞租决定：

```python
def calculate_bid_rent(parcel, land_use_type, economic_context):
    if land_use_type == 'commercial':
        bid = accessibility_premium * parcel.accessibility
        bid -= distance_penalty * parcel.distance_to_cbd
        bid += agglomeration_bonus * nearby_business_count
    elif land_use_type == 'residential':
        bid = income_weight * avg_income
        bid -= commute_cost * parcel.avg_commute_time
        bid += amenity_value * parcel.amenities_score
    elif land_use_type == 'industrial':
        bid = transport_access * parcel.highway_access
        bid -= land_area_cost * parcel.area
        bid -= regulation_cost * zoning_restrictions
    
    return bid
```

每回合，系统根据各用途的出价更新土地利用。

## 4. 可达性计算

可达性是决定地价和居民选择的关键因素。

### 4.1 就业可达性

```python
employment_accessibility(parcel) = Σ (jobs_in_zone_j / travel_time_ij^β)
```

### 4.2 服务可达性

```python
service_accessibility(parcel) = Σ (service_quality_k / travel_time_ik^β)
```

### 4.3 综合可达性

```python
accessibility = w1 * employment_access + w2 * service_access + w3 * leisure_access
```

## 5. 地价与租金

### 5.1 地价形成

```python
land_value(parcel) = base_value
                     * accessibility_factor
                     * land_use_premium
                     * (1 - pollution_penalty)
                     * (1 + amenity_premium)
                     * policy_factor
```

### 5.2 租金

```python
rent = land_value * capitalization_rate
```

## 6. 城市扩张

### 6.1 扩张条件

当城市人口增长、现有地块无法满足需求时，城市向外扩张。

### 6.2 扩张成本

- 农地转换成本
- 基础设施成本（道路、水电、学校）
- 生态成本

### 6.3 扩张边界

```python
expansion_cost(parcel) = agricultural_rent
                        + infrastructure_cost
                        + environmental_cost
                        - expected_development_value
```

当预期开发价值 > 扩张成本时，地块被开发。

## 7. 城市结构模型

### 7.1 同心圆模型

传统城市结构：

```
中心：CBD
 ↓
内环：商业和高档住宅
 ↓
中环：工业和中档住宅
 ↓
外环：郊区和农业
```

### 7.2 多中心模型

现代城市往往有多个中心：

```
主 CBD
  ├── 副中心 A（科技园）
  ├── 副中心 B（大学城）
  └── 副中心 C（港口物流）
```

游戏中可以通过交通投资和产业集聚自然形成副中心。

## 8. 规划工具（玩家可用）

| 工具 | 效果 |
|------|------|
| Zoning（区划） | 限制某地块用途 |
| 土地拍卖 | 出售国有土地给开发商 |
| 基础设施投资 | 提高特定区域可达性 |
| 绿化/治污 | 改善环境质量 |
| 历史保护 | 限制开发，保留特色 |
