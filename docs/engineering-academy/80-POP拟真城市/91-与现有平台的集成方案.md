# 与现有平台的集成方案

> 本章说明如何把 POP-拟真城市引擎接入商识唯智现有平台，复用 Arena 生命周期和前端架构。

## 1. 集成原则

- **硬域边界**：新引擎只操作自己的表，不写 Arena 表。
- **复用 Arena**：比赛创建、报名、回合推进、结算、奖励由 Arena 管理。
- **独立配置**：使用 `content/game-configs/city-sim-v1.yaml`。
- **双前端**：学生端参与决策，组织者端控制流程。

## 2. 后端集成

### 2.1 路由挂载

在 `webapp/backend/app/main.py` 增加：

```python
app.include_router(city_sim_api.router, prefix="/api/v1")
app.include_router(city_sim_admin.router, prefix="/api/v1")
```

### 2.2 API 设计

#### 参赛端

| 接口 | 方法 | 说明 |
|------|------|------|
| `/city-sim/{event_id}/state` | GET | 获取当前城市状态 |
| `/city-sim/{event_id}/decisions` | POST | 提交玩家决策 |
| `/city-sim/{event_id}/firms` | GET/POST | 管理自己的企业 |
| `/city-sim/{event_id}/reports` | GET | 获取历史报告 |

#### 组织端

| 接口 | 方法 | 说明 |
|------|------|------|
| `/city-sim/admin/{event_id}/start` | POST | 开始比赛 |
| `/city-sim/admin/{event_id}/advance` | POST | 推进回合 |
| `/city-sim/admin/{event_id}/events` | POST | 手动触发事件 |
| `/city-sim/admin/{event_id}/leaderboard` | GET | 排行榜 |

### 2.3 与 Arena 的交互

```python
# Arena 创建比赛
event = create_match(game_config_id="city-sim-v1", ...)

# Arena 开赛时调用引擎初始化
city_sim_init(db, event)

# 每回合组织者推进
city_sim_settle_round(db, event, player_decisions)

# 比赛结束
city_sim_finish(db, event)
settle_match_rewards(event)  # Career 域发放奖励
```

### 2.4 与 Career 域的交互

比赛结束后，根据玩家表现调用 `domains/career/services/rewards.py` 发放奖励。

## 3. 前端集成

### 3.1 学生端

新增页面：

- `/city-sim/{event_id}`：城市概览
- `/city-sim/{event_id}/firms`：企业管理
- `/city-sim/{event_id}/policy`：政策投票/建议
- `/city-sim/{event_id}/reports`：回合报告

### 3.2 组织者端

新增页面：

- `/city-sim/admin/{event_id}`：控制台
- 回合推进按钮
- 宏观指标面板
- 事件管理

### 3.3 可视化需求

| 可视化 | 用途 |
|--------|------|
| 城市地图 | 显示土地利用、地价、人口分布 |
| 时间序列图 | GDP、失业率、房价等趋势 |
| 人口金字塔 | 收入、职业、年龄结构 |
| 交通流量图 | 拥堵、通勤模式 |
| 政策影响图 | 政策前后对比 |

## 4. 配置与 YAML

```yaml
# content/game-configs/city-sim-v1.yaml
engine: city_sim
name: POP-拟真城市基础版
rounds: 10
players:
  roles: [government, entrepreneur, investor, labor_leader]
  
map:
  size_x: 10
  size_y: 10
  initial_parcels:
    - id: cbd_core
      district: cbd
      land_use: commercial
      land_value: 10000
    - id: industrial_zone_1
      district: industrial_north
      land_use: industrial
      land_value: 2000

pop:
  initial_total: 5000
  distribution:
    low_skill_worker: 0.4
    high_skill_worker: 0.3
    professional: 0.2
    capitalist: 0.1

firms:
  initial:
    - industry: manufacturing
      count: 10
    - industry: services
      count: 15
    - industry: tech
      count: 5
```
