## 4. 性能策略

### 4.1 POP 聚合

同属性 POP 合并，减少计算量。

### 4.2 可达性缓存

交通网络不变时，复用上轮可达性结果。

### 4.3 分区更新

不同区域独立计算，可并行。

### 4.4 事件驱动重算

只有相关变量变化时才重算子系统。

### 4.5 异步处理

结算可以放入后台任务，不阻塞 HTTP 请求。

## 6. 关键算法

### 6.1 市场清算

```python
def market_clear(demand, supply, price, elasticity):
    excess_demand = demand - supply
    price_change = excess_demand / max(demand, supply) * elasticity
    new_price = price * (1 + price_change)
    return clamp(new_price, price * 0.5, price * 2)
```

### 6.3 可达性计算

```python
def dijkstra_accessibility(graph, origin, destinations):
    distances = dijkstra(graph, origin)
    accessibility = sum(
        dest.value / (distances[dest.node] ** beta)
        for dest in destinations
    )
    return accessibility
```
