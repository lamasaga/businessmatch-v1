# 世界观与核心概念

> 本章定义 POP-拟真城市的世界观、时间尺度、玩家角色和核心循环。

## 1. 城市规模与时间尺度

### 1.1 城市规模

- **抽象城市**：不是真实 3D 城市，而是基于地块（parcel）的抽象地图。
- **空间单元**：
  - 地块（Parcel）：最小空间单位，约 1 km²。
  - 街区（Block）：4-9 个地块组成。
  - 区域（District）：若干街区组成，如 CBD、工业区、住宅区、港口区。
- **POP 规模**：单场比赛 5000-10000 个聚合 POP。

### 1.2 时间尺度

- 一场比赛代表 10-20 年的城市发展。
- 每回合代表 1 年或 1 个季度。
- 每个回合内：
  - 玩家做政策/投资决策。
  - 系统结算 POP 行为和城市状态。
  - 展示结果和新事件。

## 2. 玩家角色

本方案支持多种玩家角色，每种角色有不同的决策权和胜利条件：

| 角色 | 决策内容 | 胜利条件 |
|------|---------|---------|
| **市政府** | 税收、补贴、基础设施、 zoning、公共服务 | 城市 GDP、居民满意度、财政收入平衡 |
| **企业家** | 建厂、定价、工资、投资、扩张 | 利润、市场份额、企业价值 |
| **投资者/开发商** | 买地、开发房地产、收租 | 资产增值、租金收入 |
| **劳工领袖** | 组织工会、罢工、争取权益 | 工人平均工资、就业率、工作条件 |
| **市民代表** | 倡导政策、组织社区 | 特定群体满意度、政治影响力 |

在教学中，可以让学生分组扮演不同角色。

## 3. 核心循环

```
回合开始
    ↓
观察城市状态（GDP、失业率、房价、交通、满意度）
    ↓
各玩家做出决策
    ↓
系统执行 POP 行为更新
    ↓
市场清算（劳动力、商品、土地、金融）
    ↓
宏观指标计算
    ↓
事件触发（经济危机、社会运动、技术突破）
    ↓
结果展示与反思
    ↓
下一回合
```

## 4. 核心概念

### 4.1 POP（人群组）

城市的基本经济单元。每个 POP 代表一群具有相似属性的人。

### 4.2 可达性（Accessibility）

一个地点到达就业、服务、休闲机会的能力。是城市经济学的核心概念。

```
可达性 = f(距离, 交通方式, 交通成本, 目的地机会)
```

### 4.3 集聚经济（Agglomeration Economies）

企业和人口集中带来的效率提升：

- 知识溢出
- 劳动力池
- 中间投入共享

游戏中表现为：企业靠近其他企业时生产率提升。

### 4.4 竞租（Bid Rent）

不同土地利用类型愿意为地块支付不同租金。

- CBD 附近：商业/办公愿意付最高租金。
- 边缘地区：工业和住宅为主。

### 4.5 循环流动（Circular Flow）

家庭提供劳动力，获得工资；企业雇佣劳动力，生产商品；家庭消费商品，企业获得收入。政府和银行调节资金流动。

## 5. 可教学的核心理念

| 概念 | 通过游戏理解 |
|------|-------------|
| 供需关系 | POP 需求和商品供给决定价格 |
| 价格信号 | 地价和工资引导土地利用和居住选择 |
| 外部性 | 工厂污染降低周边住宅地价 |
| 公共品 | 地铁投资提高沿线可达性和地价 |
| 市场失灵 | 垄断、信息不对称、贫富差距 |
| 政策效果 | 税收、补贴、最低工资的传导 |
| 经济周期 | 投资、就业、消费的波动 |
| 城市结构 | 同心圆、扇形、多中心模型 |

## 6. 与 AI 沟通示例

```
我要设计一个 POP-拟真城市游戏。

世界观：
- 抽象城市，约 100 个地块
- 一场比赛 10 回合，每回合代表 1 年
- 玩家扮演市政府、企业家、投资者、劳工领袖

核心体验：
- 玩家决策影响 POP 行为
- POP 行为涌现出 GDP、失业率、房价、交通等指标
- 可教学经济学和城市规划概念

请帮我设计核心循环和玩家角色。
```
