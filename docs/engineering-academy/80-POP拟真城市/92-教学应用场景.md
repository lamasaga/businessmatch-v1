# 教学应用场景

> 本章给出 POP-拟真城市在教学中的具体应用场景、课程设计和实验案例。

## 1. 适用学段

| 学段 | 适用内容 | 复杂度 |
|------|---------|--------|
| 初中 | 基础供需、城市功能分区 | 低 |
| 高中 | 市场经济、政府调控、城市问题 | 中 |
| 大学 | 微观经济学、宏观经济学、城市经济学、公共政策 | 高 |
| MBA/企业培训 | 战略决策、政策影响、利益相关者分析 | 高 |

## 2. 课程模块设计

### 模块一：城市是如何长大的（初中/高中）

**目标**：理解人口、产业、交通如何共同塑造城市。

**活动**：

1. 学生分组扮演市政府、企业家、居民。
2. 每回合做简单决策（建什么、在哪里建）。
3. 观察城市从单中心到多中心的演变。

**讨论问题**：

- 为什么市中心地价最高？
- 工厂为什么通常在郊区？
- 交通如何改变城市结构？

### 模块二：最低工资的争议（高中/大学）

**目标**：理解政策的多重效应和利益冲突。

**设置**：

- 市政府决定最低工资。
- 企业家决定工资和雇佣。
- 劳工领袖争取更高工资。

**实验**：

1. 第一轮：最低工资较低，观察就业和贫困。
2. 第二轮：提高最低工资，观察就业和通胀变化。
3. 第三轮：结合培训补贴，观察长期效果。

**讨论问题**：

- 最低工资提高后谁受益？谁受损？
- 为什么有时提高最低工资会导致失业？
- 如何设计政策减少负面影响？

### 模块三：房地产泡沫与调控（大学/MBA）

**目标**：理解资产泡沫、信贷、调控。

**设置**：

- 投资者可以购买和开发房地产。
- 银行提供贷款。
- 市政府可以出台限购、房产税、土地供应政策。

**实验**：

1. 宽松信贷 → 房价上涨 → 投机增加 → 泡沫。
2. 收紧信贷或加税 → 房价回落 → 部分投资者破产。

**讨论问题**：

- 泡沫是如何形成的？
- 政策工具各有什么效果？
- 现实中 2008 年金融危机有何相似之处？

### 模块四：产业升级与劳动力转型（大学）

**目标**：理解技术进步、产业结构调整、劳动力再培训。

**设置**：

- 城市有制造业和服务业。
- 科技业可以逐步发展。
- 低技能工人需要培训才能进入高技能岗位。

**实验**：

1. 投资教育，观察低技能工人向高技能岗位转移。
2. 不投资教育，直接引进科技企业，观察人才短缺。
3. 比较两种路径的长期 GDP 和失业率。

**讨论问题**：

- 为什么产业升级需要教育配合？
- 被替代的产业工人怎么办？
- 政府应该扮演什么角色？

### 模块五：气候变化与城市韧性（跨学科）

**目标**：理解环境约束、长期规划、风险。

**设置**：

- 城市面临洪水、污染、能源危机等风险。
- 工业发展带来污染，但创造就业。
- 绿色投资成本高，但长期有益。

**实验**：

1. 追求短期 GDP → 高污染 → 居民满意度下降 → 健康成本。
2. 绿色转型 → 短期阵痛 → 长期可持续发展。

## 3. 课堂组织形式

### 3.1 角色扮演

- 4-5 人一组，每组扮演一个角色。
- 每回合小组讨论后提交决策。
- 系统结算后展示结果。

### 3.2 数据分析

- 学生记录每回合关键指标。
- 课后绘制趋势图。
- 写反思报告。

### 3.3 对比实验

- 相同初始条件，不同组采取不同策略。
- 比较结果差异。
- 分析原因。

## 4. 评估方式

| 评估维度 | 方式 |
|----------|------|
| 概念理解 | 课堂提问、测验 |
| 决策能力 | 模拟中的排名和指标 |
| 团队协作 | 小组讨论质量 |
| 批判思维 | 反思报告、辩论 |
| 现实联系 | 案例分析 |

## 5. 与现实课程标准的对应

| 课程标准 | 对应模块 |
|----------|---------|
| 经济学基础 | 供需、价格、市场 |
| 城市地理 | 城市结构、土地利用 |
| 公共管理 | 政策制定、公共财政 |
| 可持续发展 | 环境与经济平衡 |
| 劳动教育 | 职业选择、技能发展 |

## 6. 与 AI 沟通示例

```
我要为高中经济课设计一个 POP-拟真城市教学模块。

主题：最低工资政策

学生角色：
- 市政府：设定最低工资和税收政策
- 企业家：决定工资和雇佣
- 劳工领袖：争取权益

课程流程：
1. 15 分钟讲解最低工资理论
2. 30 分钟模拟（3 回合）
3. 15 分钟讨论结果

希望学生理解：
- 最低工资提高后谁受益谁受损
- 为什么可能产生失业
- 政策如何平衡多方利益

请给出教学设计、学生任务卡和讨论问题。
```
