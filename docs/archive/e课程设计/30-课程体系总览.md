# College —— 商业模拟平台配套课程体系

> "College" 取"学院、课程体系"之意。这里存放的是与商业模拟教学平台配套的全套课程教学内容、教师指导资源和课程-平台对接方案。

---

## 课程设计理念

### 核心主张

**不是"平台是工具，课程是内容"，而是"平台即课程，课程即体验"。**

传统教学是"先讲概念，再做练习"。我们的设计是"先体验，再命名，再深化"。

```
传统模式：讲授 → 记忆 → 练习 → 考试
         （概念先行）

我们的模式：体验 → 反思 → 概念锚定 → 迁移应用
           （体验先行）
```

### 课程与平台的关系

| 课程环节 | 平台对应 | 学生体验 |
|----------|----------|----------|
| **情境导入** | 剧情模式 / 新手引导 | "我成为了一家公司的CEO" |
| **概念探索** | 单人闯关 / 课程单元 | "我在模拟中发现了某种规律" |
| **协作决策** | 班级对局 | "我和队友讨论后做出了选择" |
| **即时反馈** | 结算引擎 + 可视化 | "我看到了决策的结果" |
| **概念命名** | AI导师 / 教师讲解 | "原来这就是'边际效用递减'" |
| **迁移应用** | 挑战模式 / 变式情境 | "我在新场景中应用了这个原理" |
| **社会分享** | 成绩卡片 / 排行榜 | "我获得了'市场洞察者'徽章" |

### 每阶课程的通用结构

```
单元名称
├── 课前准备（教师端 5分钟）
│   ├── 学习目标设定
│   ├── 分组安排
│   └── 平台房间创建
│
├── 情境导入（5-8分钟）
│   ├── 生活案例 / 视频 / 故事
│   └── 激发问题
│
├── 概念探索（15-20分钟）
│   ├── 微课（3-5分钟视频）
│   ├── 平台模拟体验（1-2轮简化对局）
│   └── 即时反馈与讨论
│
├── 深化理解（15-20分钟）
│   ├── 概念讲解与命名
│   ├── 真实商业案例连接
│   └── 小组讨论
│
├── 应用迁移（15-20分钟）
│   ├── 平台挑战模式（变式情境）
│   ├── 决策理由撰写
│   └── 同伴互评
│
├── 复盘总结（10-15分钟）
│   ├── 系统生成个人报告
│   ├── 概念测验
│   └── 教师点评
│
└── 课后延伸（可选）
    ├── 延伸阅读 / 视频
    ├── 家庭讨论任务
    └── 下次课预告
```

## 核心素养模型

```
商业素养（Business Literacy）
├── 财务素养（Financial Literacy）
│   └── 理解成本、收入、利润、现金流、投资回报率
│
├── 市场素养（Market Literacy）
│   └── 理解供需、消费者、竞争、差异化、定价
│
├── 战略素养（Strategic Literacy）
│   └── 理解目标设定、资源配置、风险管理、长期规划
│
├── 协作素养（Collaborative Literacy）
│   └── 理解团队分工、沟通协商、冲突解决、共同决策
│
└── 伦理素养（Ethical Literacy）
    └── 理解公平竞争、社会责任、可持续经营、利益相关者
```

## 与平台功能的联动设计

| 平台功能 | 课程应用 |
|----------|----------|
| **课程单元模式** | 每个单元对应一个预设规则模板，教师一键发起 |
| **剧情模式** | 第一阶主要使用，用故事降低认知门槛 |
| **标准对局** | 第二阶以上使用，完整4轮竞技 |
| **挑战模式** | 每单元课后作业，特殊约束条件下的胜利 |
| **AI导师** | 第三阶以上启用，提供策略分析和概念解释 |
| **局外成长** | 跨单元、跨课程积累经验值和徽章 |
| **班级公会** | 同班学生自动加入，累积班级总分 |
| **排行榜** | 单元内可见，支持进步排名和多维评价 |
| **复盘报告** | 每单元结束自动生成，支持教师点评 |

## 使用方式

### 对于教师

1. 查阅 **01-课程框架**，了解整体结构
2. 根据学段选择对应模块文档（02-05）
3. 查阅 **07-映射表**，了解如何在平台上发起对应活动
4. 参考 **06-教师手册**，掌握课堂组织和控场技巧

### 对于课程开发者

1. 以 **01-课程框架** 为指导，确保新增内容符合素养模型
2. 参考 **07-映射表**，确保每个单元都有对应的平台规则模板
3. 遵循"体验先行"原则，每个概念都必须先有模拟体验

---

> **说明**：这套课程体系是活的。随着平台功能迭代、教学实践反馈、不同地区课标变化，应持续更新。建议每学期末进行一次课程复盘，收集教师和学生的反馈，优化单元设计。
