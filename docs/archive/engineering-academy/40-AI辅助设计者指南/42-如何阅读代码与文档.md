# 如何阅读代码与文档

> 作为设计者，你不需要读懂每一行代码，但需要快速定位「这个功能在哪里实现」。

## 1. 先读文档，再读代码

| 文档 | 用途 |
|------|------|
| `CLAUDE.md` | 项目规则、Phase、域边界 |
| `03-ENGINEERING.md` | 当前实现状态、API 表 |
| `02-ARCHITECTURE.md` | 高层架构 |
| `domains/arena/ARCHITECTURE.md` | Arena 详细设计 |
| `docs/decisions/*.md` | 为什么这样设计 |

## 2. 代码搜索技巧

### 按功能搜

用关键词搜索：

- 路由名：`/leaderboard`
- 函数名：`advance_round`
- 表名：`trading_rounds`
- YAML 字段：`demand_curve`

### 按文件层级定位

```
webapp/backend/app/
├── api/           # 路由入口
├── domains/       # 业务域
│   ├── arena/     # 比赛生命周期
│   └── career/    # 奖励结算
├── games/         # 游戏引擎
│   ├── trading/   # 浮生记 RTS
│   └── techventure/ # TechVenture
├── models/        # 数据库模型
├── schemas/       # 数据校验
└── core/          # 配置、工具
```

## 3. 读一个 API 的流程

```
1. 从 main.py 找到路由挂载
2. 进入 api/xxx.py 看处理函数
3. 跟踪调用的 service 函数
4. 看 models.py 了解表结构
5. 看 YAML 配置了解规则参数
```

## 4. 问 AI 的高效方式

不要问：

❌ "这个项目怎么工作的？"

要问：

✅ "`POST /api/v1/competitions` 创建比赛时，调用了哪些函数？最终写入了哪些表？请按调用顺序列出。"

✅ "浮生记 RTS 的 `rts_scheduler.py` 中，`maybe_advance_rts` 做了哪几步？哪些步骤涉及数据库写入？"

## 5. 做笔记

看到关键映射关系时记下来：

| 功能 | 文件 | 函数 |
|------|------|------|
| 创建比赛 | api/competitions.py | create_competition |
| 推进回合 | games/techventure/engine.py | advance_round |
| 发奖励 | domains/career/services/rewards.py | settle_match_rewards |

这些笔记未来会成为你的「代码地图」。
