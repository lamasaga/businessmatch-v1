# 维多利亚 1~3 代 POP 机制演进

> 维多利亚系列是 POP 机制的集大成者。理解它从 1 代到 3 代的演进，可以帮助我们把握「微观人群组驱动宏观经济」这一设计思路的发展脉络。

## 1. Victoria 1（2003）

### 1.1 基本设计

Victoria 1 首次把人口按 **POP** 拆分，每个 POP 是一定数量的人口单位。

### 1.2 POP 分类

- **按阶级**：贵族、资本家、中产阶级、工人、农民、奴隶等
- **按职业**：农民、劳工、工匠、职员、士兵等
- **按文化/宗教**：不同文化组和宗教组

### 1.3 核心机制

| 机制 | 说明 |
|------|------|
| 生活需求 | POP 需要满足基本生活品，否则死亡率上升 |
| 日用品需求 | 满足后可提高生活质量 |
| 奢侈品需求 | 满足后提高忠诚度和税收 |
| 迁移 | POP 会从生活成本低、工资低的地方迁往机会多的地方 |
| 升级/降级 | 农民可成为工人，工人可成为职员（需满足条件） |
| 政治意识 | 未满足需求会提高政治意识和激进程度 |

### 1.4 历史意义

Victoria 1 奠定了「把国家拆成人群组」的思路，但系统相对粗糙，很多计算是隐式的。

## 2. Victoria 2（2010）

### 2.1 核心改进

Victoria 2 把 POP 机制做得更深入、更可观察。

### 2.2 POP 类型

| 类型 | 特点 |
|------|------|
| Aristocrats | 贵族，从土地和工厂分红 |
| Capitalists | 资本家，投资工厂 |
| Artisans | 手工业者，小规模生产商品 |
| Clergymen | 神职人员，提高识字率 |
| Clerks | 职员，工厂管理和研发 |
| Craftsmen | 工人，工厂主要生产力量 |
| Farmers | 农民，农业生产 |
| Labourers | 劳工，低技能工作 |
| Slaves | 奴隶，无工资 |
| Soldiers | 士兵 |
| Bureaucrats | 官僚，提高行政效率 |
| Officers | 军官 |

### 2.3 需求系统

每个 POP 有三级需求：

| 需求层级 | 例子 | 未满足后果 |
|----------|------|-----------|
| Life Needs | 粮食、茶叶 | 死亡率上升、迁移 |
| Everyday Needs | 衣服、家具 |  Consciousness（意识）上升 |
| Luxury Needs | 汽车、收音机 | Militancy（战斗性）下降 |

### 2.4 Consciousness（意识）与 Militancy（战斗性）

这是 Victoria 2 最重要的政治反馈机制：

| 指标 | 含义 | 影响因素 |
|------|------|---------|
| Consciousness | POP 对国家事务的关注程度 | 教育、未满足需求、事件 |
| Militancy | POP 愿意采取暴力行动的程度 | 贫困、战争失败、未满足需求 |

- 高 Consciousness + 高 Militancy → 革命、叛乱
- 高 Consciousness + 低 Militancy → 支持改革党派

### 2.5 迁移与同化

- POP 会迁往工资高、失业率低、生活成本合理的地区。
- 移民会优先考虑新世界国家（美洲）。
- 不同文化的 POP 可以被同化成本地文化。

### 2.6 经济与政治的闭环

```
工厂利润高 → 资本家收入高 → 资本家投资更多工厂
              ↓
        招募更多工人 → 工资上升
              ↓
        工人 Everyday Needs 满足 → Consciousness 上升
              ↓
        工人要求改革（投票权、工会）
              ↓
        政府通过/拒绝改革 → Militancy 变化
              ↓
        社会稳定或革命
```

## 3. Victoria 3（2022）

### 3.1 设计哲学的转变

Victoria 3 对 POP 机制做了**大幅简化但更深层的重构**：

- 不再追踪每个具体 POP 的 Consciousness/Militancy。
- 引入 **Standard of Living（生活水平）** 作为核心指标。
- 用 **Interest Groups（利益集团）** 和 **Political Movements（政治运动）** 代替直接的民兵/叛乱。

### 3.2 Standard of Living（SoL）

SoL 是 Victoria 3 最重要的 POP 指标：

| SoL 等级 | 状态 |
|----------|------|
| 1-5 | 赤贫，容易死亡和迁移 |
| 5-10 | 贫困 |
| 10-15 | 温饱 |
| 15-20 | 小康 |
| 20+ | 富裕 |

SoL 受以下因素影响：

- 收入（工资、分红、养老金）
- 生活成本（受商品价格影响）
- 税收
- 政府补贴

### 3.3 POP 类型（Vic3）

| 类型 | 收入来源 | 特点 |
|------|---------|------|
| Peasants | 自给农业、微薄工资 | 效率低，容易迁移 |
| Laborers | 工资 | 工厂、矿场、建筑主要劳动力 |
| Machinists | 工资 | 高技能工人 |
| Farmers | 工资 | 商业化农场工人 |
| Shopkeepers | 小生意利润 | 小资产阶级 |
| Clerks | 工资 | 办公室职员 |
| Engineers | 高工资 | 高科技产业 |
| Capitalists | 分红 | 投资工厂、获得利润 |
| Aristocrats | 土地分红 | 保守势力 |
| Bureaucrats | 工资 | 政府雇员 |
| Officers | 工资 | 军队 |
| Soldiers | 工资 | 军队 |
| Slaves | 无 | 被强制劳动 |

### 3.4 Goods（商品）与 Needs

Victoria 3 把需求从「按 POP 类型固定」改为**按生活水平和财富等级动态计算**。

每个 POP 会消费：

- 基本食物
- 衣物
- 家具
- 电器
- 汽车
- 奢侈品

商品在世界市场上买卖，价格由全球供需决定。

### 3.5 政治系统

| 概念 | 说明 |
|------|------|
| Interest Groups | 由相同利益的 POP 组成（如工业家、农民、知识分子） |
| Political Movements | 由事件或改革诉求触发 |
| Radicals | 对现状不满的 POP |
| Loyalists | 支持政府的 POP |

SoL 下降 → Radicals 增加 → 政治不稳定
SoL 上升 → Loyalists 增加 → 政府更稳定

### 3.6 经济闭环

```
玩家建造工厂 → 需要劳动力和原料
              ↓
        劳动力需求上升 → 工资上升
              ↓
        工人 SoL 上升 → 消费更多商品
              ↓
        商品需求上升 → 价格上涨
              ↓
        工厂利润变化 → 投资变化
              ↓
        经济结构转型
```

## 4. 三代对比总结

| 维度 | Victoria 1 | Victoria 2 | Victoria 3 |
|------|-----------|-----------|-----------|
| POP 粒度 | 粗 | 细 | 中等（按职业/财富） |
| 核心指标 | 需求满足 | Consciousness/Militancy | Standard of Living |
| 政治表达 | 简单 | 党派/叛乱 | 利益集团/政治运动 |
| 经济模拟 | 简单供需 | 全球市场经济 | 更抽象但动态的市场 |
| 可观察性 | 低 | 中 | 高（生活水平、激进派/忠诚派） |
| 设计复杂度 | 中 | 高 | 中高 |

## 5. 给设计者的启示

### 5.1 不是越复杂越好

Victoria 3 简化了 Consciousness/Militancy，但用 SoL + Radicals/Loyalists 实现了更强的可观察性。

### 5.2 核心指标要可见

玩家需要能直观看到：我的决策如何影响了人群的生活状态。

### 5.3 反馈要有延迟

POP 不会立即反应，而是经过一段时间才升级/迁移/激进化。这种延迟创造了策略深度。

### 5.4 宏观是涌现的，不是预设的

经济周期、社会动荡应该从 POP 互动中产生，而不是脚本触发。

## 6. 与 AI 沟通示例

```
我要设计一个类似 Victoria 3 的 POP 系统，但用于商业模拟教育。
需求：
- POP 按职业分层：工人、职员、工程师、资本家
- 每个 POP 有收入、生活成本、政治倾向
- 玩家建造工厂会影响劳动力需求和工资
- 工资变化影响消费，消费影响市场价格
- 最终要能看到「生活水平」「激进派/忠诚派」指标
- 计算复杂度可控，单场比赛 1000 个 POP 以内

请给出数据结构和更新流程。
```
