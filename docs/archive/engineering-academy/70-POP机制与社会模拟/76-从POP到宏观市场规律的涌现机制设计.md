# 从 POP 到宏观市场规律的涌现机制设计

> 本章是核心设计方法论。我们不只是学习 POP，而是要设计出让「玩家行动 → POP 反馈 → 宏观规律」闭环运行的机制。

## 1. 设计目标

我们要实现：

```
玩家行动
    ↓
影响 POP 的收入、需求、位置、职业、政治倾向
    ↓
大量 POP 的个体行为聚合
    ↓
涌现出宏观市场规律
    ↓
宏观规律反馈给玩家决策
```

## 2. 设计原则

### 2.1 微观规则简单

每个 POP 只遵循少数几条规则。复杂来自数量，而不是单个个体的规则。

### 2.2 反馈闭环

玩家的每个重要行动都要能找到对应的 POP 反馈路径。

### 2.3 延迟与惯性

POP 不会立即反应。收入变化影响消费习惯需要时间，迁移需要更长时间，政治激进化需要更长时间。

### 2.4 可观察的宏观指标

必须让玩家看到：

- 价格指数
- 失业率
- 平均工资
- 消费者结构
- 社会满意度
- 政治稳定性

### 2.5 非线性

线性系统不会涌现。需要设计：

- 阈值效应（SoL 低于某值会触发迁移潮）
- 正反馈（涨价 → 囤货 → 更涨价）
- 负反馈（高工资 → 企业外迁 → 失业）

## 3. 核心机制设计

### 3.1 需求-供给-价格闭环

```
POP 收入上升 → 日常需求增加 → 商品价格上涨
                              ↓
                    企业利润增加 → 扩大生产 → 雇佣更多工人
                              ↓
                    工资上升 → POP 收入上升
```

设计要点：

- 每个 POP 有需求函数（受收入和价格影响）。
- 每个商品有供给函数（受生产成本和价格影响）。
- 市场按供需清算价格。

### 3.2 劳动力市场闭环

```
企业扩张 → 劳动力需求增加 → 工资上升
                              ↓
                    更多人进入该行业（升级/迁移）
                              ↓
                    劳动力供给增加 → 工资增速放缓
```

设计要点：

- POP 会迁移到高工资地区。
- POP 会升级到低失业率职业。
- 工资调整有粘性（不会瞬间变化）。

### 3.3 投资-产能闭环

```
资本家利润高 → 投资新工厂 → 产能增加
                              ↓
                    商品价格下降 → 利润下降
                              ↓
                    投资减少 → 产能增速放缓
```

### 3.4 政治反馈闭环

```
生活成本上升 → SoL 下降 → 激进派增加
                              ↓
                    要求提高工资/补贴
                              ↓
                    政府/玩家决策
                              ↓
                    满足 → 稳定；拒绝 → 动荡加剧
```

## 4. 涌现现象的设计

### 4.1 通货膨胀

触发条件：

- 货币供给增加（玩家印钱或大量投资）
- 供给瓶颈（某商品短缺）
- 需求过热（收入普遍上升）

表现：

- 多数商品价格持续上涨
- 储蓄贬值
- 固定收入 POP 受损

### 4.2 失业

触发条件：

- 技术替代（机器取代工人）
- 产业外迁
- 经济衰退

表现：

- 劳动力供给 > 需求
- 工资下降
- 消费萎缩

### 4.3 泡沫与崩盘

触发条件：

- POP 趋势跟随行为
- 信贷扩张
- 信息传播

表现：

- 某商品价格远超基本面
- 突然逆转，价格暴跌
- 大量 POP 财富蒸发

### 4.4 产业升级

触发条件：

- 高收入 POP 增加
- 教育和技能提升
- 高附加值产业利润更高

表现：

- 低技能 POP 减少
- 高技能 POP 增加
- 消费结构从基础商品转向服务和奢侈品

## 5. 玩家行动如何影响 POP

| 玩家行动 | 对 POP 的直接影响 | 宏观涌现 |
|----------|------------------|---------|
| 投资建设工厂 | 创造就业、提高工资 | GDP 增长、产业升级 |
| 提高产品价格 | 消费者购买力下降 | 通胀、消费结构变化 |
| 压低工人工资 | 工人 SoL 下降 | 消费萎缩、激进派增加 |
| 开拓新市场 | 需求增加 | 价格上涨、利润增加 |
| 投资教育 | POP 升级速度加快 | 高技能劳动力增加 |
| 补贴特定商品 | 该商品需求增加 | 相关行业扩张 |

## 6. 计算流程示例

每轮/每 tick 更新：

```python
# 1. 生产
for firm in firms:
    firm.produce()

# 2. 收入分配
for pop in pops:
    pop.earn_income()

# 3. 市场清算
for good in goods:
    total_demand = sum(pop.demand_for(good) for pop in pops)
    total_supply = sum(firm.supply_of(good) for firm in firms)
    price = market_clear(total_demand, total_supply)

# 4. POP 消费与满意度
for pop in pops:
    pop.consume(goods, prices)
    pop.update_sol()

# 5. 迁移与升级
for pop in pops:
    if pop.want_to_migrate():
        pop.migrate()
    if pop.want_to_promote():
        pop.promote()

# 6. 政治反馈
for pop in pops:
    pop.update_political_stance()

# 7. 投资
for capitalist in capitalists:
    capitalist.decide_investment()

# 8. 宏观指标更新
update_gdp()
update_unemployment()
update_cpi()
update_inequality()
```

## 7. 性能优化

| 技术 | 说明 |
|------|------|
| 聚合相同 POP | 同类型同地区 POP 合并为一个对象，内部用数量表示 |
| 事件驱动 | 只有状态变化显著时才更新 |
| 分区并行 | 不同地区独立计算 |
| 缓存需求 | 价格未变时复用上轮需求 |
| 降采样 | 不需要每 tick 都更新政治倾向 |
