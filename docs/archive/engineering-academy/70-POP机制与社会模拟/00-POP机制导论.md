# POP 机制与社会模拟导论

> 本文档面向：希望设计「微观个体行动涌现出宏观经济规律」机制的设计者 / 策划者。
> 目标：理解 POP（人群组）机制的设计逻辑，掌握从个体行为到宏观规律涌现的方法论。

## 1. 什么是 POP 机制

POP 是 Paradox 游戏《维多利亚》（Victoria）系列中的核心概念，全称 **Population**（人口），但游戏中被设计为**按职业、文化、宗教、财富等因素划分的离散人群组**。

每个 POP 不是抽象的「人口数字」，而是：

- 有职业（农民、工匠、资本家、职员等）
- 有收入水平
- 有物质和精神需求
- 有政治倾向（保守、自由、激进、社会主义等）
- 会迁移、升级、死亡、生育
- 会对政策、战争、经济波动做出反应

## 2. 为什么 POP 机制重要

传统策略游戏通常用「国家」作为单一决策单位：

```
国家 A 决定生产 100 门大炮 → 国家 A 获得 100 门大炮
```

POP 机制把国家拆成无数个小群体：

```
资本家获得利润 → 投资工厂 → 招募职员和工人
工人获得工资 → 购买食物和衣服 → 刺激农业和纺织业
农民破产 → 迁移到城市成为工人 → 改变政治倾向
```

结果是：**宏观历史不是被写好的，而是从无数微观互动中涌现出来的**。

## 4. 核心问题

本模块要回答一个核心问题：

> **玩家的行动如何动态影响 POP，大量 POP 的反馈如何涌现出宏观市场规律？**

这个问题可以拆成四个子问题：

1. **POP 如何被玩家行动影响？**
   - 玩家改变价格 → POP 收入变化 → POP 消费变化
   - 玩家投资工厂 → POP 就业结构变化
   - 玩家政策 → POP 政治倾向变化

2. **POP 如何反馈？**
   - POP 需求变化 → 市场价格变化
   - POP 迁移 → 地区劳动力变化
   - POP 政治激进化 → 政策阻力或革命

3. **如何涌现出宏观规律？**
   - 个体 POP 的简单规则叠加 → 供需曲线、通胀、失业、经济周期
   - 非线性反馈 → 泡沫、崩溃、繁荣

4. **这个机制能教真实世界吗？**
   - 可以教：供需关系、价格信号、市场失灵、政策效果
   - 不能教：精确预测现实经济

## 5. 与当前项目的关系

本项目的赛事引擎目前使用「聚合变量」而非 POP：

- 浮生记 RTS：城市池量、价格、总消费/生产
- TechVenture：市场份额、消费者结构
- OPS：总需求、总供给、市场份额

如果引入 POP 机制，可以：

- 把「城市消费者」拆成不同收入层和偏好群体
- 让玩家的营销/定价决策影响具体人群
- 让城市经济从人群互动中涌现

但这会显著增加复杂度，需要在合适的 Phase 和引擎中引入。

## 6. 关键原则

1. **微观规则要简单**：单个 POP 的决策规则越简单，宏观涌现越可控。
2. **反馈要闭环**：玩家的行动要能影响 POP，POP 的变化要能回到玩家决策中。
3. **可观察性**：宏观规律必须能被玩家感知和理解，否则只是后台黑盒。
4. **可教学性**：机制应与现实经济学概念对应，避免反直觉的虚假规律。
5. **性能可控**：大量 POP 模拟需要 careful 设计，避免服务器压力过大。
