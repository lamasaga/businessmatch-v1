# 商业竞争与博弈

> 本章设计公司之间的竞争机制：价格战、人才战、营销战、并购、联盟、信息战，以及这些如何与 NPC 关系网交织。

## 1. 竞争维度

### 1.1 产品竞争

| 策略 | 说明 |
|------|------|
| 价格战 | 降低价格抢市场份额 |
| 差异化 | 提高质量或特色，避免价格战 |
| 创新竞赛 | 更快推出新技术/产品 |
| 细分市场 | 专注特定客户群 |

### 1.2 人才竞争

| 策略 | 说明 |
|------|------|
| 高薪挖角 | 直接挖竞争对手核心员工 |
| 培养体系 | 建立内部培训和晋升 |
| 股权激励 | 用股权绑定核心人才 |
| 文化吸引 | 打造有吸引力的企业文化 |

### 1.3 市场竞争

| 策略 | 说明 |
|------|------|
| 广告轰炸 | 提高品牌知名度 |
| 渠道控制 | 独占销售渠道 |
| 客户锁定 | 会员、长期合同 |
| 地理扩张 | 进入新城市/市场 |

### 1.4 资本竞争

| 策略 | 说明 |
|------|------|
| 融资竞赛 | 比对手更快拿到资金 |
| 并购 | 收购竞争对手或互补企业 |
| 价格战补贴 | 用资本换市场份额 |
| 上市 | 获取公开资本 |

## 2. 竞争与 NPC 关系

### 2.1 个人恩怨变成商业战争

```
玩家与 NPC 张伟曾是合伙人
    ↓
因经营理念分歧分道扬镳
    ↓
张伟创办竞争公司
    ↓
张伟利用旧人脉挖角玩家员工
    ↓
玩家反击，降低价格
    ↓
两败俱伤，第三方趁机崛起
```

### 2.2 联盟与背叛

```
玩家与李四结盟对抗张伟
    ↓
联盟成功压制张伟
    ↓
李四趁玩家虚弱时背叛
    ↓
玩家陷入更大危机
```

### 2.3 信息战

```
NPC 散布关于玩家的负面消息
    ↓
玩家声誉下降
    ↓
投资者犹豫
    ↓
玩家需要公关或反击
```

## 3. 博弈机制

### 3.1 囚徒困境

两家公司可以选择：

- 合作：共同维持高价，都获中等利润。
- 背叛：一方降价，获得高利润，另一方受损。
- 都背叛：都降价，都获低利润。

### 3.2 纳什均衡

在竞争稳定状态下，任何一方单方面改变策略都不会更好。

### 3.3 重复博弈

商业竞争通常是长期的重复博弈：

- 今天背叛可能带来明天的报复。
- 建立声誉很重要。
- 合作可以形成默契。

## 4. 竞争事件

### 4.1 挖角事件

```python
event = {
    'type': 'poaching_attempt',
    'from_company': 'player_co',
    'to_company': 'rival_co',
    'target_employee': 'employee_id',
    'offer': {'salary': 1.5, 'title': 'Director'}
}
```

玩家/员工反应：

- 匹配 offer。
- 提供更好的发展机会。
- 接受离职，但要求竞业限制。
- 员工决定留下或离开。

### 4.2 价格战事件

```python
event = {
    'type': 'price_war',
    'initiator': 'rival_co',
    'product': 'product_id',
    'new_price': old_price * 0.8
}
```

玩家选择：

- 跟进降价。
- 维持价格，强调质量。
- 推出差异化产品。
- 寻找成本优势。

### 4.3 并购邀约

```python
event = {
    'type': 'acquisition_offer',
    'from_company': 'big_co',
    'to_company': 'player_co',
    'offer_price': valuation * 1.5,
    'terms': 'cash + stock'
}
```

玩家选择：

- 接受，退休或继续在大公司任职。
- 拒绝，继续独立发展。
- 谈判，争取更好条件。

### 4.4 联盟邀约

```python
event = {
    'type': 'alliance_proposal',
    'from_company': 'peer_co',
    'goal': 'jointly_defeat_rival',
    'terms': 'share_rnd_costs'
}
```

## 5. 竞争优势来源

| 来源 | 说明 |
|------|------|
| 成本优势 | 规模经济、效率、低成本供应链 |
| 差异化 | 品牌、技术、服务 |
| 网络效应 | 用户越多，价值越大 |
| 转换成本 | 客户难以离开 |
| 政策保护 | 专利、牌照、补贴 |
| 人才优势 | 核心团队不可复制 |
