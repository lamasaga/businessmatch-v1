# 公司经营模拟

> 本章设计公司经营的核心机制：创建、部门、项目、财务、人才、产品、市场。

## 1. 公司创建

### 1.1 创建条件

- 玩家达到创业阶段。
- 有初始资金或投资人。
- 有合伙人或核心团队。
- 有商业想法/技术/市场机会。

### 1.2 公司类型

| 类型 | 特点 |
|------|------|
| 科技型 | 高研发投入、高风险高回报 |
| 贸易型 | 资金周转快、利润率低 |
| 服务型 | 人力密集、客户关系重要 |
| 制造型 | 资产重、规模效应 |
| 平台型 | 网络效应、赢家通吃 |

### 1.3 股权结构

```python
class Company:
    shares: list              # 股权结构
    valuation: float          # 估值
    
class Share:
    owner_id: str
    share_type: str           # 普通股/优先股
    percentage: float
    voting_power: float
```

## 2. 组织架构

### 2.1 部门设计

| 部门 | 职责 |
|------|------|
| 研发 | 产品开发、技术创新 |
| 销售 | 客户获取、收入 |
| 市场 | 品牌建设、推广 |
| 运营 | 日常运营、客户服务 |
| 财务 | 资金管理、融资、报表 |
| 人力资源 | 招聘、培训、文化 |
| 法务/合规 | 合同、知识产权、合规 |

### 2.2 岗位

每个部门有：

- 部门负责人
- 普通员工
- 实习生

## 3. 项目系统

### 3.1 项目类型

| 类型 | 例子 |
|------|------|
| 产品开发 | 开发新功能、新产品 |
| 市场活动 | 品牌推广、营销活动 |
| 客户项目 | 为特定客户交付 |
| 内部优化 | 流程改进、系统升级 |
| 并购整合 | 收购后整合 |

### 3.2 项目属性

```python
class Project:
    id: str
    name: str
    type: str
    status: str                    # planning, executing, completed, failed
    
    required_skills: dict          # 需要的技能
    team: list                     # 参与人员
    
    total_work: float              # 总工作量
    completed_work: float          # 已完成
    quality: float                 # 质量
    risk: float                    # 风险
    
    budget: float
    spent: float
    
    deadline: int                  # 回合数
```

def project_progress(project):

## 4. 财务系统

### 4.1 财务报表

| 报表 | 内容 |
|------|------|
| 利润表 | 收入、成本、费用、利润 |
| 资产负债表 | 资产、负债、所有者权益 |
| 现金流量表 | 经营、投资、融资现金流 |

### 4.2 关键指标

| 指标 | 公式 |
|------|------|
| 毛利率 | (收入 - 成本) / 收入 |
| 净利率 | 净利润 / 收入 |
| 现金流 | 现金流入 - 现金流出 |
|  burn rate | 每月现金消耗 |
| runway | 现金 / burn rate |
| ROE | 净利润 / 所有者权益 |

### 4.3 融资

| 融资方式 | 特点 |
|----------|------|
| 天使投资 | 早期、金额小、估值低 |
| VC | 成长期、金额大、有对赌 |
| 银行贷款 | 需要抵押、有利息 |
| 债券 | 稳定企业适用 |
| IPO | 公开上市、融资规模大 |

satisfaction = f(

### 5.3 离职与挖角

员工会离职如果：

- 薪资不满意。
- 没有成长空间。
- 与上司关系差。
- 收到更好的 offer。
- 公司前景不明。
