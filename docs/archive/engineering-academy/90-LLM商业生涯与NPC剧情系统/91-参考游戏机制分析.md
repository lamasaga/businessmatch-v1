# 参考游戏机制分析

> 本章分析 CK3、太吾绘卷、RimWorld、Dwarf Fortress 和部分商业模拟游戏的核心机制，提取可借鉴的设计元素。

## 1. 十字军之王 3（Crusader Kings 3）

### 1.1 核心机制

#### 角色特质系统

CK3 的角色有丰富特质：

| 类型 | 例子 |
|------|------|
| 性格特质 | 勇敢/怯懦、贪婪/慷慨、野心勃勃/知足常乐 |
| 生活方式特质 | 外交家、军事家、管理家、密谋家、学者 |
| 身体特质 | 貌美/丑陋、巨人/侏儒 |
| 健康/精神特质 | 压力、抑郁、疯狂 |
| 信仰/文化特质 | 朝圣者、神圣者 |

**借鉴点**：

- 用少量关键特质定义角色性格。
- 特质之间有相容和冲突。
- 特质影响可选择的行动和事件分支。

#### 压力系统

角色做与性格不符的事会积累压力：

```
公正角色 + 施行暴政 = 压力增加
暴虐角色 + 施行暴政 = 压力减少
```

**借鉴点**：

- 玩家决策有心理成本。
- 性格约束增加角色扮演感。
- 压力过高触发精神危机事件。

#### 关系与秘密

- **好感度（Opinion）**：受特质、行动、家族、信仰影响。
- **秘密（Secrets）**：婚外情、谋杀、私生子等。
- **把柄（Hooks）**：掌握秘密后可胁迫他人。

**借鉴点**：

- 关系不是静态的，由事件塑造。
- 秘密和把柄创造非对称权力。
- NPC 会主动利用关系网。

#### 生活方式焦点树

玩家选择发展路径：

- 外交：联盟、威望、封臣管理
- 军事：战争、骑士、指挥官
- 管理：经济、发展、领地
- 密谋：阴谋、谋杀、勾引、绑架
- 学识：科技、信仰、文化、健康

**借鉴点**：

- 职业发展有明确路径和事件。
- 不同路径有不同的事件库和能力。

#### 王朝与传承

- Dynasty（王朝）> House（家族分支）> Character（个人）。
- 王朝声望解锁跨代遗产。
- 继承人会继承领地，但性格不同。

**借鉴点**：

- 长期目标超越单个人物。
- 传承机制创造代际故事。

### 1.2 对商业生涯系统的启示

| CK3 机制 | 商业系统对应 |
|----------|-------------|
| 角色特质 | 企业家性格（激进/保守、诚信/投机） |
| 压力系统 | 商业伦理压力、决策焦虑 |
| 关系/秘密 | 商业伙伴关系、内幕信息、把柄 |
| 生活方式树 | 职业路径（销售/技术/管理/投资） |
| 王朝传承 | 企业传承、家族企业 |

## 2. 太吾绘卷

### 2.1 核心机制

#### 自由 NPC 生态

- NPC 有自己的目标和人生轨迹。
- NPC 会拜师、结婚、复仇、远走高飞。
- 点开履历可阅读「江湖微小说」。

**借鉴点**：

- NPC 不是围绕玩家转，而是自主生活。
- 履历系统让玩家看到 NPC 的故事。
- 奇遇从人物关系中生长。

#### 好感度与互动

- 对话、送礼提升好感。
- 偷窃等行为降低好感。
- 特殊 NPC 可触发「远走高飞」等奇遇。

**借鉴点**：

- 互动有长期后果。
- 关系深度影响可触发的剧情。

#### 奇遇系统

- 事件以「奇遇」形式出现。
- 不同立场 NPC 以不同方式应对。
- 选择影响结果。

**借鉴点**：

- 用奇遇包装随机事件。
- 事件结果与 NPC 性格和关系相关。

### 2.2 对商业生涯系统的启示

| 太吾机制 | 商业系统对应 |
|----------|-------------|
| NPC 自主生态 | 商业人物自主求职、创业、跳槽 |
| 人物履历 | 商业人物职业履历 |
| 奇遇 | 商业机会、危机、合作邀约 |
| 远走高飞 | 合伙人离职创业、核心员工跳槽 |

## 3. RimWorld

### 3.1 核心机制

#### 故事生成器

RimWorld 自称「故事生成器」，目标是生成有趣的故事，而不是让玩家「赢」。

#### 角色系统

- 每个殖民者有背景故事、特质、技能。
- 社交关系：熟人、朋友、恋人、对手。
- 特质影响行为：善良、粗鲁、烦人声音、变态呼吸等。

**借鉴点**：

- 小团队中的关系冲突很有戏剧性。
- 角色特质要能产生有趣互动。

#### 事件系统

- 随机事件（袭击、疾病、商人来访）。
- 事件根据殖民地状态和角色关系触发。
- 连锁反应：一个角色死亡 → 其他人悲伤 → 精神崩溃 → 更多问题。

**借鉴点**：

- 事件不是孤立惩罚，而是故事的催化剂。
- 关注连锁反应设计。

### 3.2 对商业生涯系统的启示

| RimWorld 机制 | 商业系统对应 |
|---------------|-------------|
| 故事生成器 | 商业故事生成器 |
| 殖民者关系 | 创业团队关系 |
| 精神崩溃 | 创业压力、 burnout |
| 随机事件 | 市场变化、客户流失、竞争对手动作 |

## 4. Dwarf Fortress

### 4.1 核心机制

#### 深度模拟

- 每个矮人有 500+ 互锁的需求、技能、记忆。
- 持久的喜好/厌恶驱动行为。
- 家庭关系、伤口、历史事件都被记录。

**借鉴点**：

- 机械相关的描述比纯文本更有叙事力。
- 长期记忆让世界有历史感。

####  engraving 与神器

- 矮人会在墙上雕刻历史事件。
- 神器会记录创造过程和意义。

**借鉴点**：

- 用游戏内物品/记录承载叙事。
- 历史可视化增强沉浸感。

### 4.2 对商业生涯系统的启示

| Dwarf Fortress 机制 | 商业系统对应 |
|---------------------|-------------|
| 深度角色模拟 | 商业人物详细履历和状态 |
| 历史记录 | 公司年鉴、行业历史 |
| 家庭关系 | 商业家族、师徒传承 |
|  engraving | 商业案例库、里程碑 |

## 5. 商业模拟游戏

### 5.1 Capitalism II

- 供应链、生产、市场竞争。
- AI 对手会与你打价格战。
- 工厂专业化、物流优化。

### 5.2 Game Dev Tycoon

- 技术研究竞赛。
- 员工技能组合。
- 跟随市场趋势。

### 5.3 Hollywood Animal / City Game Studio

- 竞争对手挖角、并购。
- 人才竞争。
- 奖项竞争。

### 5.4 对商业生涯系统的启示

| 商业游戏机制 | 本系统应用 |
|--------------|-----------|
| 供应链 | 公司生产、采购、库存 |
| 人才管理 | 员工招聘、培训、离职 |
| 市场竞争 | 价格战、广告、产品差异化 |
| 并购 | 公司收购、合并 |
| 技术竞赛 | 研发投入、专利 |

## 6. 可借鉴的设计元素总结

| 元素 | 来源 | 商业系统应用 |
|------|------|-------------|
| 性格特质 | CK3 | 企业家/员工性格 |
| 压力/精神状态 | CK3, RimWorld | 决策压力、 burnout |
| 关系网 | CK3, 太吾 | 商业关系网 |
| 秘密/把柄 | CK3 | 内幕信息、谈判筹码 |
| NPC 自主生态 | 太吾 | 商业人物自主演化 |
| 奇遇/事件 | 太吾, RimWorld | 商业机会和危机 |
| 故事生成器 | RimWorld | 商业故事生成 |
| 深度记忆 | Dwarf Fortress | 人物和公司历史 |
| 供应链/竞争 | 商业游戏 | 公司经营核心 |

## 7. 与 AI 沟通示例

```
我要设计一个商业生涯系统，参考 CK3 和太吾绘卷。

核心体验：
- 玩家扮演一个商业人物，有性格特质
- NPC 有自己的目标和人生轨迹
- 关系网驱动剧情
- 异步演化，玩家离线时 NPC 也在行动

需要学习的机制：
- CK3 的角色特质、压力、关系、生活方式树
- 太吾绘卷的 NPC 自主生态、奇遇、履历
- RimWorld 的故事生成和角色关系

请帮我分析这些机制哪些适合借鉴，哪些不适合，
并给出商业系统对应表。
```
