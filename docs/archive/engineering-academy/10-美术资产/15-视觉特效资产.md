# 视觉特效资产

> 特效让状态变化可视化：交易成功、价格波动、任务完成、比赛结束。本文讲特效的分类和实现方式。

## 1. 特效的类别

| 类型 | 说明 | 例子 |
|------|------|------|
| 粒子特效 | 大量小图运动 | 金币飞溅、烟花、雪花 |
| 闪光/光环 | 单一光源或扩散效果 | 选中高亮、升级光环 |
| UI 转场 | 界面切换动画 | 弹窗打开、页面切换 |
| 数字跳动 | 分数/金币变化 | +100、价格跳动 |
| 环境效果 | 营造氛围 | 下雨、雾气、烛光摇曳 |

## 2. 实现方式对比

| 方式 | 优点 | 缺点 | 适用 |
|------|------|------|------|
| CSS 动画 | 轻量、易修改 | 复杂效果难做 | 按钮 hover、数字跳动 |
| PNG 序列帧 | 效果丰富 | 文件大、加载多 | 短暂爆发特效 |
| Lottie (JSON) | 矢量、小、可交互 | 复杂粒子受限 | UI 动画、引导动画 |
| WebGL/Canvas | 性能高、效果强 | 开发复杂 | 大量粒子、3D 效果 |
| SVG 动画 | 矢量、可缩放 | 浏览器兼容性需注意 | 简单图标动效 |

## 3. 序列帧规格

如果导出 PNG 序列：

- 每帧尺寸一致
- 帧数不宜过多（通常 8~30 帧）
- 提供帧率（fps）
- 可拼成 Sprite Sheet 减少加载请求

示例：

```
effect_coin_burst_01.png
effect_coin_burst_02.png
...
effect_coin_burst_12.png
```

或合并为：

```
effect_coin_burst_sheet.png  // 12 帧横向排列
```

## 4. Lottie 动画

Lottie 是 Adobe After Effects 导出的 JSON 动画，前端用 `lottie-react` 等库播放。

优点：

- 矢量，任意缩放
- 文件小
- 可暂停、跳转、循环
- 可动态改颜色

适合做：加载动画、成功提示、空状态插画。

## 5. 特效触发的时机

特效不是随便放的，通常绑定事件：

| 事件 | 特效 |
|------|------|
| 交易成功 | 金币 +1 动画 |
| 价格上涨 | 向上箭头 + 红色高亮 |
| 获得奖励 | 宝箱打开 + 粒子 |
| 回合结束 | 全屏淡入结算面板 |
| 比赛结束 | 奖杯升起 + 烟花 |

这些事件由后端推送到前端，前端再触发特效。

## 6. 命名示例

```
effect_coin_burst.json          # Lottie
effect_coin_burst_sheet.png     # 序列帧精灵图
effect_level_up_ring.svg        # SVG 光环
effect_success_check.json       # Lottie 成功勾选
effect_rain_loop.png            # 循环背景特效
effect_toast_bg.9.png           # 提示条背景
```

## 7. 与 AI 沟通示例

```
我要在交易成功时加一个反馈特效。
需求：
- 金币从交易按钮飞向余额区域
- 持续 0.6 秒
- 使用 Lottie 导出，文件小于 50KB
- 提供触发方式：前端监听 trade_success 事件后播放
请提供 AE 源文件和 Lottie JSON。
```
