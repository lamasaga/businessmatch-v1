# 人物角色资产

> 人物是商业模拟中最重要的情感锚点。本文讲人物资产的类型、规格、与程序对接方式。

## 1. 人物在游戏中承担什么

- **玩家化身**：代表用户自己。
- **NPC**：商人、导师、对手、新闻播报员。
- **AI 玩家**：在比赛中自动决策的对手。

不同类型的人物，需要的资源精细度不同。

## 2. 人物资产类型

| 类型 | 说明 | 使用场景 |
|------|------|---------|
| 头像（Avatar） | 小尺寸，正方形 | 排行榜、聊天、个人资料 |
| 半身像（Bust） | 肩部以上 | 对话框、剧情 |
| 立绘（Full Body） | 全身 | 角色详情、加载页、过场 |
| 行走图 / 精灵图（Sprite） | 多帧小图拼成 | 2D 地图、RTS 场景 |
| 骨骼动画（Spine/Live2D） | 可换表情、动作 | 高品质角色、剧情演出 |
| Lottie | 矢量动画 | UI 内小动画 |

## 3. 推荐规格

| 用途 | 尺寸 | 格式 | 背景 |
|------|------|------|------|
| 头像 | 128x128, 256x256 | PNG / WebP | 透明或圆形遮罩 |
| 半身像 | 512x512 | PNG / WebP | 透明 |
| 立绘 | 1024x2048 | PNG / WebP | 透明 |
| 精灵图 | 单帧 64x128 或 128x256 | PNG 序列 / Sprite Sheet | 透明 |
| 骨骼动画 | 按工具导出 | Spine JSON / Live2D | 透明 |

## 4. 精灵图（Sprite Sheet）

如果人物要在地图上移动，通常把多帧动作拼在一张大图里：

```
+---+---+---+---+
| 走1 | 走2 | 走3 | 走4 |
+---+---+---+---+
| 站1 | 站2 | 站3 | 站4 |
+---+---+---+---+
```

程序通过「帧索引」读取：第 0 帧、第 1 帧……

需要约定：

- 每帧宽度/高度是否一致
- 行对应什么动作（行走、站立、说话）
- 列对应动画帧序号
- 每秒播放几帧

## 5. 表情与换装

如果人物需要多表情或多服装，建议：

- **拆分图层**：身体、脸、眼睛、嘴、衣服分开画。
- **程序组合**：运行时把图层拼起来显示。
- **避免爆炸组合**：如果衣服 10 套 × 表情 10 个，全部导出就是 100 张图；拆分后只需要 20 个图层。

## 6. AI 玩家形象

在浮生记 RTS 中，AI 玩家通常用：

- 固定头像 + 名称标签
- 地图上的 icon（小头像或代表色块）
- 不需要复杂动画

## 7. 命名示例

```
avatar_player_default.png
avatar_ai_merchant_01.png
bust_mentor_wang.png
fullbody_npc_banker.png
sprite_merchant_walk_64x128.png
spine_character_student.json
```

## 8. 与 AI 沟通示例

```
我要给 TechVenture 引擎增加一个 NPC 导师角色。
需要：
- 头像 256x256 PNG 透明
- 半身像 512x512 PNG 透明
- 3 个表情：微笑、严肃、惊讶
请按命名规范导出，并提供 assets-manifest.json。
```
