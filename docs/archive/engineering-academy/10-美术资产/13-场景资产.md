# 场景资产

> 场景是游戏的舞台。本文讲场景背景、地图、城市等资产的规格和注意事项。

## 1. 场景的类型

| 类型 | 说明 | 例子 |
|------|------|------|
| 静态背景 | 一张大图作为底图 | 城市夜景、商业街 |
| 视差背景 | 多层以不同速度滚动 | 远山、近处建筑、前景 |
| 地图 | 可交互的抽象地图 | 城市网络、贸易路线 |
| 房间/大厅 | 玩家聚集的空间 | 交易大厅、会议室 |
| 过场场景 | 剧情演出用 | 谈判桌、新闻发布会 |

## 2. 屏幕适配

不同设备屏幕比例不同：

- PC：16:9、16:10
- 平板：4:3
- 手机：9:16、19.5:9

处理方式：

- **覆盖（cover）**：图片等比放大，直到填满整个屏幕，可能裁切边缘。
- **包含（contain）**：图片等比缩放，完整显示，可能留黑边。
- **安全区（safe area）**：把重要内容放在中间区域，边缘允许被裁切。

建议美术在 16:9 基础上设计，但四周留 10% 出血区。

## 3. 分层与视差

如果场景要有深度感，可以分成多层：

```
前景层（移动最快）
中景层
背景层（移动最慢）
天空/远景层（几乎不动）
```

每层单独一张透明 PNG，程序按滚动速度分别移动。

## 4. 地图资产

商业模拟中的地图通常不是真实地理地图，而是抽象网络：

- 节点：城市、市场、工厂
- 边：路线、运输通道
- 状态：拥堵、价格高低、控制权

地图可以用 SVG 绘制，因为：

- 节点和边是矢量，可缩放
- 可以绑定数据（价格、库存）动态变色
- 可以点击交互

## 5. 推荐规格

| 类型 | 尺寸 | 格式 | 备注 |
|------|------|------|------|
| 全屏背景 | 1920x1080 或 2560x1440 | JPG / WebP | 无透明 |
| 视差层 | 1920x1080 左右 | PNG | 有透明 |
| 地图 | 矢量或 2048x2048 | SVG / PNG | 可缩放 |
| 房间/大厅 | 1920x1080 | JPG / PNG | 视需要透明 |
