# 机器学习 AI

> 机器学习让 AI 从数据中学习，而不是完全靠人写规则。本章讲游戏中最常见的 ML 方法及其边界。

## 1. 监督学习（Supervised Learning）

### 原理

用大量「输入 → 正确答案」的数据训练模型。

```
输入：当前市场状态
输出：应该买入还是卖出
```

### 常见模型

| 模型 | 适用 |
|------|------|
| 决策树 / 随机森林 | 可解释决策 |
| 神经网络 | 复杂模式识别 |
| 逻辑回归 | 二分类问题 |

### 在游戏中的应用

- 预测玩家是否会流失
- 预测玩家下一局可能选择的策略
- 自动标记异常行为

### 缺点

- 需要大量标注数据
- 模型只是模仿，不会超越训练数据
- 在商业模拟中，可解释性可能不足

## 2. 强化学习（Reinforcement Learning, RL）

### 原理

AI 通过试错学习。做对了得奖励，做错了受惩罚。

```
状态 State → 动作 Action → 奖励 Reward → 下一状态 Next State
```

### 关键概念

| 概念 | 说明 |
|------|------|
| 智能体（Agent） | 做决策的 AI |
| 环境（Environment） | 游戏规则 |
| 策略（Policy） | 状态到动作的映射 |
| 奖励函数（Reward） | 告诉 AI 什么行为是好的 |
| 探索（Explore） | 尝试新动作 |
| 利用（Exploit） | 使用已知最优动作 |

### 常见算法

| 算法 | 特点 |
|------|------|
| Q-Learning | 学习状态-动作价值表 |
| DQN | 用神经网络近似 Q 函数 |
| PPO | 策略梯度，稳定易用 |
| AlphaZero | 自对弈 + MCTS |

### 在游戏中的应用

- 训练围棋、星际争霸 AI
- 自动调整 NPC 难度
- 学习最优经济策略

### 缺点

- 训练时间长
- 奖励函数设计困难
- 可能学到奇怪策略
- 商业模拟中可复现性差

## 3. 遗传算法（Genetic Algorithm）

### 原理

模拟生物进化：

1. 生成一群候选策略
2. 评估它们的表现
3. 表现好的保留、交叉、变异
4. 重复多代

### 适用场景

- 策略参数优化
- 平衡性调整
- 自动发现新奇策略

### 例子

优化 TechVenture AI 的投入比例参数：

```
个体 = [tech_pct, fit_pct, show_pct, route_switch_prob]
适应度 = 该策略在 100 场模拟中的平均排名
```

## 4. 机器学习在游戏中的适用边界

| 适合 ML | 不适合 ML |
|---------|-----------|
| 大量对局数据 | 规则必须严格可解释 |
| 需要发现人类想不到的策略 | 奖励函数难以定义 |
| 离线训练后部署 | 实时训练成本高 |
| 玩家行为预测 | 每次决策都要完全一样（可复现） |

## 5. 与规则 AI 的结合

最实用的方式通常是：

- **规则层**：保证基本行为合理、可解释。
- **ML 层**：优化参数、选择策略模板、预测玩家行为。

例如：

```
AI 先按规则生成 3 个候选决策
ML 模型预测哪个决策在当前对局中最可能获胜
选择得分最高的候选
```

## 6. 与 AI 沟通示例

```
我要为浮生记 RTS 训练一个 AI 交易 agent。
约束：
- 使用强化学习离线训练
- 状态包括：当前城市、库存、现金、各城市价格
- 动作包括：买、卖、移动、买车辆、hold
- 奖励 = 总资产增长 - 行动成本
- 训练完成后导出为策略模型，后端加载使用
- 训练过程不要影响线上环境
```
