# 后端服务是什么

> 很多设计者把后端想成「看不见的东西」。其实后端就是一台电脑上的程序，专门处理数据、规则和权限。

## 1. 前端与后端的分工

| 前端 | 后端 |
|------|------|
| 展示界面 | 存储数据 |
| 收集用户输入 | 校验权限 |
| 播放动画 | 执行业务规则 |
| 本地临时状态 | 持久化保存 |

用户看到的所有界面都是前端，但分数、库存、比赛结果都存在后端。

## 2. 后端由什么组成

| 组件 | 作用 |
|------|------|
| Web 框架 | 处理 HTTP 请求，如 FastAPI |
| 路由 | 把不同 URL 指向不同处理函数 |
| 业务逻辑 | 实现规则，如结算、匹配 |
| 数据库 | 长期保存数据 |
| 认证 | 确认用户身份 |
| 任务调度 | 定时执行，如 RTS tick |

## 3. 请求的一生

```
用户在浏览器点击按钮
  ↓
前端发送 HTTP 请求到后端
  ↓
后端路由匹配到处理函数
  ↓
校验身份和参数
  ↓
调用业务逻辑
  ↓
读写数据库
  ↓
返回结果给前端
  ↓
前端更新界面
```

## 4. 本项目后端

- **框架**：FastAPI（Python）
- **数据库**：SQLite
- **进程**：单进程运行
- **部署**：Docker

## 5. 与 AI 沟通示例

```
需求：
- 前端：学生端个人中心显示历史比赛列表
- 后端：提供 GET /api/v1/competitions/history 接口

- 按时间倒序分页
请写在 arena 域内，不要跨域查表。
```
