# 产业与企业

> 本章设计 POP-拟真城市的产业系统：企业如何创建、生产、雇佣、投资，以及不同产业如何互动形成城市经济。

## 1. 企业的角色

企业是连接 POP 和市场的重要节点：

- 雇佣 POP，支付工资。
- 购买原材料和资本。
- 生产商品和服务。
- 销售给家庭、政府、外部市场。
- 创造利润，进行投资或分红。

## 2. 企业分类

### 2.1 按产业

| 产业 | 产出 | 主要投入 | 区位偏好 |
|------|------|---------|---------|
| 农业 | 农产品 | 土地、劳动力 | 城市边缘 |
| 制造业 | 工业品 | 原材料、劳动力、资本 | 工业区/港口 |
| 零售业 | 商品分销 | 商品、劳动力、店面 | 商业区/住宅区 |
| 服务业 | 服务 | 劳动力、办公空间 | CBD/副中心 |
| 科技业 | 高技术产品/服务 | 高技能劳动力、研发 | 科教区/CBD |
| 金融业 | 金融服务 | 资本、高技能劳动力 | CBD |
| 建筑业 | 房屋/基础设施 | 材料、劳动力 | 城市各处 |

### 2.2 按规模

| 规模 | 员工数 | 特点 |
|------|--------|------|
| 微型 | 1-10 | 灵活、脆弱 |
| 小型 | 10-50 | 本地化 |
| 中型 | 50-200 | 区域化 |
| 大型 | 200+ | 全国/全球化 |

## 4. 生产函数

### 4.1 Cobb-Douglas 生产函数

```
Y = A × K^α × L^β × T^γ

Y = 产出
A = 全要素生产率（技术、集聚经济）
K = 资本
L = 劳动力
T = 土地
α, β, γ = 产出弹性
```

### 4.2 产业特异性

不同产业的要素比例不同：

| 产业 | 资本密集度 | 劳动力密集度 | 土地密集度 |
|------|-----------|-------------|-----------|
| 农业 | 低 | 中 | 高 |
| 制造业 | 中 | 中 | 中 |
| 服务业 | 低 | 高 | 低 |
| 科技业 | 高 | 高（高技能） | 低 |
| 金融业 | 高 | 中 | 低 |

## 5. 企业行为规则

### 5.1 雇佣决策

```python
def hiring_decision(firm, labor_market):
    # 预期需求
    expected_demand = forecast_demand(firm.output_good)
    
    # 需要的劳动力
    needed_labor = production_function_inverse(expected_demand, firm.capital, firm.technology)
    
    # 当前员工
    current_labor = sum(firm.employees.values())
    
    if needed_labor > current_labor:
        firm.job_openings = needed_labor - current_labor
        firm.wage_by_profession = adjust_wage_up(firm, labor_market)
    elif needed_labor < current_labor:
        firm.layoff(current_labor - needed_labor)
        firm.wage_by_profession = adjust_wage_down(firm, labor_market)
```

### 5.2 定价决策

```python
def pricing_decision(firm, market):
    # 成本加成定价
    unit_cost = firm.costs / firm.output
    
    # 根据市场竞争调整
    markup = base_markup * (1 + market_power)
    
    # 考虑需求弹性
    if market.elasticity > 1:
        markup *= 0.9  # 需求弹性大，降价
    
    firm.price = unit_cost * (1 + markup)
```

### 5.3 投资决策

```python
def investment_decision(firm, financial_market):
    # 预期利润率
    expected_roi = (firm.profit / firm.capital) * capacity_utilization
    
    # 资金成本
    cost_of_capital = financial_market.interest_rate + risk_premium
    
    if expected_roi > cost_of_capital:
        firm.investment_plan = reinvestment_rate * firm.profit
```

### 5.4 区位决策

```python
def location_decision(firm, parcels):
    best_parcel = None
    best_score = -inf
    
    for parcel in parcels:
        score = (
            labor_access_weight * parcel.labor_accessibility
            + market_access_weight * parcel.market_accessibility
            + transport_weight * parcel.transport_accessibility
            - land_cost_weight * parcel.rent
            - pollution_cost_weight * parcel.pollution
            + agglomeration_weight * nearby_same_industry_count
            - tax_weight * parcel.effective_tax_rate
        )
        
        if score > best_score:
            best_score = score
            best_parcel = parcel
    
    return best_parcel
```

## 6. 产业互动

### 6.1 产业链

```
农业 → 食品加工业 → 零售业 → 家庭
矿业 → 制造业 → 建筑业/零售业
科技业 → 服务业/金融业 → 所有产业
```

### 6.2 集聚经济

当同一产业的企业集中时：

- 知识溢出：技术水平提升更快。
- 劳动力池：更容易招聘专业人才。
- 中间投入共享：降低采购成本。

```python
agglomeration_bonus(firm) = Σ (nearby_same_industry_firms × spillover_coefficient)
```

### 6.3 竞争与垄断

- 企业数量少 → 垄断定价 → 高利润 → 高价格 → 消费者受损。
- 企业数量多 → 完全竞争 → 价格接近成本 → 利润低。

## 7. 企业创建与破产

### 7.1 企业创建

创建条件：

- 有企业家 POP（资本家）
- 有初始资本（自有资金或贷款）
- 有市场需求
- 有合适的土地

### 7.2 企业破产

破产条件：

- 连续多期亏损
- 现金流断裂
- 资不抵债

破产影响：

- 员工失业
- 供应商欠款
- 银行坏账
- 市场集中度变化
