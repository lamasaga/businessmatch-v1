# 交通与物流

> 交通是城市的血液循环。本章设计 POP-拟真城市的交通系统：通勤、货运、拥堵、可达性，以及交通投资如何影响城市结构。

## 1. 交通网络

### 1.1 网络层级

| 层级 | 功能 | 速度 | 成本 |
|------|------|------|------|
| 高速公路 | 城市间/城郊快速通道 | 快 | 高（建设和收费） |
| 城市快速路 | 城市内部长距离 | 较快 | 中 |
| 主干道 | 区域连接 | 中等 | 中 |
| 次干道 | 街区连接 | 较慢 | 低 |
| 公共交通 | 地铁、公交、轻轨 | 中等 | 低（乘客） |
| 步行/自行车 | 短距离 | 慢 | 极低 |

### 1.2 网络表示

交通网络用图表示：

```python
class TransportNetwork:
    nodes: dict              # 节点（地块、站点）
    edges: dict              # 边（路段）
    
class Edge:
    from_node: str
    to_node: str
    capacity: float          # 通行能力
    length: float            # 长度
    base_speed: float        # 基础速度
    current_speed: float     # 当前速度（受拥堵影响）
    toll: float              # 通行费
    transport_mode: str      # 道路/轨道/步行
```

## 2. 通勤行为

### 2.1 通勤需求

每个就业的 POP 需要从居住地到工作地：

```python
commute_demand = Σ (employed_pop.residence → employed_pop.workplace)
```

### 2.2 交通方式选择

POP 根据以下因素选择交通方式：

```python
utility(mode) = w1 × (-cost) + w2 × (-time) + w3 × comfort + w4 × reliability
```

| 因素 | 权重说明 |
|------|---------|
| 成本 | 低收入 POP 更看重 |
| 时间 | 高收入 POP 更看重 |
| 舒适度 | 富裕 POP 更看重 |
| 可靠性 | 所有 POP 都看重 |

### 2.3 拥堵形成

当路段流量超过容量时，速度下降：

```python
def congestion_speed(flow, capacity, base_speed):
    ratio = flow / capacity
    if ratio <= 0.7:
        return base_speed
    elif ratio < 1.0:
        return base_speed * (1 - 0.3 * (ratio - 0.7) / 0.3)
    else:
        return base_speed * max(0.1, 1 / (ratio ** 2))
```

## 4. 可达性更新

### 4.1 计算可达性

使用图算法（如 Dijkstra）计算每个地块到其他地块的最短路径：

```python
def calculate_accessibility(parcel, all_destinations, travel_mode):
    accessibility = 0
    for dest in all_destinations:
        travel_time = shortest_path_time(parcel, dest, travel_mode)
        opportunity = dest.opportunity_value  # 就业机会、服务品质等
        accessibility += opportunity / (travel_time ** beta)
    return accessibility
```

### 4.2 交通投资的影响

修建新路或地铁会改变可达性分布：

```
修建地铁线 → 沿线地块可达性提高 → 地价上涨 → 住宅和商业集聚
```

## 6. 交通与环境的权衡

### 6.1 私家车 vs 公共交通

| 方面 | 私家车 | 公共交通 |
|------|--------|---------|
| 便利性 | 高 | 中 |
| 成本（个人） | 高 | 低 |
| 拥堵贡献 | 高 | 低 |
| 污染 | 高 | 低 |
| 土地占用 | 高（停车） | 低 |

### 6.2 政策工具

| 工具 | 效果 |
|------|------|
| 地铁建设 | 提高公共交通分担率，提高沿线地价 |
| 拥堵费 | 减少高峰拥堵 |
| 停车限制 | 抑制私家车使用 |
| 公交补贴 | 提高低收入 POP 通勤能力 |
| 自行车道 | 短距离出行替代 |
