# 经济循环设计

> 本章设计 POP-拟真城市的经济循环系统：家庭、企业、政府、银行之间的资金流动，以及注入（Injections）与漏出（Leakages）如何影响城市经济。

## 1. 核心经济主体

```
        家庭（POP）
       /    ↑    \
      ↓     |     ↑
   企业 ←→ 政府 ←→ 银行
      ↑     |     ↓
       \    ↓    /
        外部市场
```

### 1.1 家庭（POP）

- **提供**：劳动力、资本（储蓄）
- **获得**：工资、利息、转移支付
- **支出**：消费、税收、储蓄

### 1.2 企业

- **购买**：劳动力、原材料、土地、资本
- **生产**：商品和服务
- **销售**：给家庭、政府、外部市场
- **分配**：工资、利润、税收、再投资

### 1.3 政府

- **收入**：税收（所得税、企业税、增值税、房产税）
- **支出**：公共服务、基础设施、转移支付、补贴
- **调节**：通过财政政策和货币政策影响经济

### 1.4 银行/金融系统

- **吸收储蓄**：家庭存款
- **发放贷款**：企业投资、房贷
- **创造信贷**：放大投资和消费能力

### 1.5 外部市场

- **进口**：城市从外部购买商品和原材料。
- **出口**：城市向外部销售商品和服务。

## 2. 循环流动的四个阶段

### 第一阶段：生产

企业使用劳动力和资本生产商品。

```
企业产出 = f(劳动力投入, 资本投入, 技术水平, 土地, 集聚经济)
```

### 第二阶段：收入分配

企业收入分配为：

```
企业收入 = 工资 + 原材料成本 + 利润 + 税收
```

### 第三阶段：消费与储蓄

家庭可支配收入：

```
可支配收入 = 工资 + 转移支付 + 财产收入 - 所得税
```

家庭支出：

```
可支配收入 = 消费 + 储蓄 + 其他税收
```

### 第四阶段：投资与再生产

企业利润和银行储蓄转化为投资：

```
总投资 = 企业留存利润 + 银行贷款 + 政府投资 + 外资
```

## 3. 注入（Injections）与漏出（Leakages）

### 3.1 漏出（资金流出循环）

| 类型 | 说明 | 影响 |
|------|------|------|
| 储蓄（S） | 家庭收入未消费部分 | 减少当前需求 |
| 税收（T） | 交给政府 | 减少私人可支配收入 |
| 进口（M） | 购买外部商品 | 资金流出本地 |

### 3.2 注入（资金流入循环）

| 类型 | 说明 | 影响 |
|------|------|------|
| 投资（I） | 企业购买资本品 | 增加需求和产能 |
| 政府支出（G） | 公共服务和基建 | 增加需求 |
| 出口（X） | 外部购买本地商品 | 资金流入本地 |

### 3.3 均衡条件

```
S + T + M = I + G + X
```

- 注入 > 漏出：经济扩张
- 注入 < 漏出：经济收缩

## 4. 价格形成机制

### 4.1 劳动力市场

```
工资 = f(劳动力供给, 劳动力需求, 最低工资, 工会力量)

劳动力需求 = 企业总用工需求
劳动力供给 = 可工作 POP 数量
```

### 4.2 商品市场

```
商品价格 = f(总需求, 总供给, 运输成本, 税收, 补贴)

总需求 = 家庭消费 + 企业投资 + 政府购买 + 出口
总供给 = 本地生产 + 进口
```

### 4.3 土地市场

```
地价/租金 = f(可达性, 周边经济活动, 土地用途, 政策限制)
```

### 4.4 金融市场

```
利率 = f(储蓄供给, 贷款需求, 央行政策)
```

## 5. 宏观经济指标

### 5.1 GDP

```
GDP = C + I + G + (X - M)

C = 家庭消费
I = 企业投资
G = 政府支出
X - M = 净出口
```

### 5.2 失业率

```
失业率 = 失业人口 / 劳动力总人口
```

### 5.3 通胀率

```
通胀率 = (本期价格指数 - 上期价格指数) / 上期价格指数
```

### 5.4 基尼系数

```
基尼系数 = 衡量收入或财富不平等程度
```

### 5.5 居民满意度指数

```
满意度 = f(收入, 住房, 通勤, 消费满足, 环境, 安全)
```

## 6. 反馈循环示例

### 正反馈：投资繁荣

```
企业利润高 → 投资增加 → 就业增加 → 工资上升 → 消费增加 → 企业收入增加 → 利润更高
```

### 负反馈：经济衰退

```
企业利润下降 → 裁员 → 失业增加 → 消费下降 → 企业收入进一步下降 → 更多裁员
```

### 正反馈：房地产泡沫

```
房价上涨 → 投资者买入 → 需求增加 → 房价继续上涨 → 更多人投机 → 泡沫
```

```
注入与漏出：
- 漏出：储蓄、税收、进口
- 注入：投资、政府支出、出口

- 失业率
- 通胀率

```
