# 政策与制度

> 政策是玩家影响 POP 和城市的主要杠杆。本章设计税收政策、社会福利、劳动法规、 zoning 等制度，以及它们的传导机制。

## 1. 财政政策

### 1.1 税收类型

| 税种 | 征收对象 | 经济影响 |
|------|---------|---------|
| 个人所得税 | 家庭收入 | 影响可支配收入和消费 |
| 企业所得税 | 企业利润 | 影响投资和雇佣 |
| 增值税/消费税 | 商品交易 | 影响商品价格和需求 |
| 房产税 | 房产价值 | 影响住房成本和土地开发 |
| 土地增值税 | 土地增值 | 影响投机和开发时机 |
| 工资税 | 雇主支付 | 影响用工成本 |
| 污染税 | 污染排放 | 影响企业环保投入 |

### 1.2 税率设计

```python
class TaxPolicy:
    income_tax_brackets: list      # 累进税率
    corporate_tax_rate: float
    vat_rate: float
    property_tax_rate: float
    land_value_tax_rate: float
    payroll_tax_rate: float
    pollution_tax_per_unit: float
```

### 1.3 政府支出

| 支出类型 | 效果 |
|----------|------|
| 基础设施 | 提高可达性，刺激经济 |
| 教育 | 提高 POP 技能，促进产业升级 |
| 医疗 | 提高满意度，降低死亡率 |
| 社会福利 | 保障低收入 POP，减少贫困 |
| 科研补贴 | 提高企业技术水平 |
| 产业补贴 | 扶持特定产业 |

## 2. 劳动制度

### 2.1 最低工资

```python
effective_wage = max(market_wage, minimum_wage)
```

影响：

- 提高低收入 POP 收入。
- 可能减少低技能岗位。
- 可能推动企业自动化或外迁。

### 2.2 工会力量

工会力量影响工资谈判：

```python
wage = market_wage × (1 + union_power × negotiation_factor)
```

### 2.3 工作时间与福利

- 最长工作时间
- 带薪假期
- 产假/育儿假
- 失业保险

## 5. 制度的传导机制

### 5.1 提高最低工资

```
最低工资提高
    ↓
低技能工人收入增加
    ↓
低收入 POP 消费增加
    ↓
零售和餐饮需求增加
    ↓
但企业用工成本增加
    ↓
部分企业裁员或涨价
    ↓
失业可能上升，通胀可能上升
```

### 5.2 建设地铁

```
地铁建设
    ↓
沿线可达性提高
    ↓
沿线地价上涨
    ↓
开发商在沿线建住宅和商业
    ↓
人口向沿线集聚
    ↓
沿线商业繁荣，税收增加
    ↓
但原住民可能因房租上涨而迁出（绅士化）
```

### 5.3 减税刺激企业

```
企业所得税降低
    ↓
企业利润增加
    ↓
投资增加
    ↓
就业增加
    ↓
消费增加
    ↓
但政府收入减少，可能影响公共服务
```

## 6. 制度成本与收益

每个政策都有受益者和受损者：

| 政策 | 受益者 | 受损者 |
|------|--------|--------|
| 最低工资 | 低技能工人 | 雇佣低技能工人的企业 |
| 地铁建设 | 沿线居民、通勤者 | 原租户（房租上涨） |
| 企业所得税减免 | 企业、股东 | 政府公共服务 |
| 污染税 | 环境、居民 | 污染企业 |
| 房产税 | 政府 | 房产所有者 |

## 7. 政治约束

### 7.1 政策阻力

激进政策可能遭遇阻力：

```python
policy_resistance = Σ (affected_pop.size × stance_against_policy × political_mobilization)
```

### 7.2 选举与连任

如果市政府由选举产生，政策会影响支持率：

```python
approval_rating = f(average_satisfaction, economic_growth, specific_policy_effects)
```
