# 09-ESG可持续经营 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
ESG可持续经营是商业模拟平台的**社会责任与长期价值训练模块**。引入环保、社会、治理三维指标，企业价值不再只看利润。面向大学及以上学段，训练长期主义思维，理解可持续发展与商业成功的共生关系。

### 1.2 设计目标
- **理解三重底线**：利润(People)、地球(Planet)、繁荣(Profit)的平衡
- **体验伦理困境**：利润与责任之间的艰难选择
- **量化社会价值**：将"做好事"转化为可衡量的指标
- **训练长期思维**：短期成本vs长期收益的权衡

### 1.3 教学哲学
传统商业教育强调"股东利益最大化"，此模式引入"利益相关者理论"的视角。学生发现：ESG不是成本，而是投资——对品牌、人才、风险管理的长期投资。

### 3.4 可持续伦理困境

**困境卡片**：
- 类型标签："环境伦理"
- 编号："决策 3 / 8"

**情境**：
> "你的工厂每天排放500吨工业废水。当前处理系统只能达到国家最低标准。环保组织正在调查你所在的行业，如果被发现'仅达标'，可能引发公关危机。升级处理系统需要一次性投入¥200万，但可将排放降至行业领先水平。"

**当前财务状况**：
- 现金：¥450万
- 月利润：¥80万
- 环境评分：72分

**四选项网格**（2×2）：

**选项1 · 维持现状** 💰
- "我们已经在合法范围内，不需要额外投入。"
- **影响**：利润+¥200万 / 环境-15分 / 50%概率公关危机

**选项2 · 全面升级** 🌍
- "投资未来，成为行业环保标杆。"
- **影响**：利润-¥200万 / 环境+25分 / 获得绿色认证

**选项3 · 渐进升级** ⚖️
- "分阶段投入，平衡财务与环保。"
- **影响**：利润-¥80万/季度 / 环境+10分/季度 / 6个月完成

**选项4 · 联合行动** 🤝
- "联合同行共建处理中心，分摊成本。"
- **影响**：利润-¥60万 / 环境+20分 / 依赖合作伙伴

**设计意图**：
- 四选项覆盖从"无视"到"激进"的完整光谱
- 每个选项明确列出财务、环境、声誉三个维度的影响
- 概率事件（50%公关危机）引入不确定性

## 六、使用建议

### 6.1 适合场景
- 商业伦理、企业社会责任课程
- 需要理解"可持续发展与商业成功的关系"
- 训练长期主义和伦理判断

### 6.2 教师操作要点
1. **赛前**：介绍ESG基本概念和SDGs框架
2. **赛中**：引导学生关注"短期成本vs长期收益"的权衡
3. **赛后**：对比不同学生的ESG评分，讨论"好企业"的定义

### 6.3 常见学生误区
- **道德绝对主义**：认为环保总是对的，忽视财务现实
- **绿色洗白**：只做表面功夫，不真正改变
- **忽视权衡**：不理解"所有选择都有代价"
