## 一、三种测试方式速览

| 方式 | 场景 | 引擎 | 平台 | 复杂度 |
|------|------|------|------|--------|
| **A. 本地双服务** | 日常开发、联调 | `python run.py` :9001 | `python run.py` :8000 | 低 |
| **B. Docker Compose** | 集成测试、演示 | `docker run` :9001 | `docker compose` :8000 | 中 |
| **C. Mock 引擎** | 单元测试、CI | `unittest.mock` | 正常启动 | 最低 |

**推荐日常开发流**：方式 A（双服务）+ 方式 C（Mock 跑 CI）。

## 二、方式 A：本地双服务（推荐日常开发）

### 2.1 架构

```
终端 1: 平台后端          终端 2: 引擎匣子           终端 3: 前端
  │                         │                         │
  ▼                         ▼                         ▼
FastAPI :8000  ←────HTTP──→  FastAPI :9001         Vite :5173
  │                            │                      │
  SQLite                       内存/引擎SQLite         │
```

### 2.2 启动步骤

**Step 1：启动引擎匣子**

```powershell
# 终端 1
Set-Location "D:\1XFAwork\bizsim-engine-box"
.\venv\Scripts\python run.py
# 或
.\venv\Scripts\uvicorn src.api.server:app --host 0.0.0.0 --port 9001 --reload
```

验证引擎健康：
```bash
curl http://localhost:9001/health
curl http://localhost:9001/engine/info
```

**Step 2：启动平台后端**

```powershell
# 终端 2
Set-Location "D:\1XFAwork\businessmatch-v1\webapp\backend"
$env:ENGINE_FUSHENGJI_ENDPOINT="http://localhost:9001"
$env:ENGINE_TEMPLATE_ENDPOINT="http://localhost:9001"
.\venv\Scripts\python run.py
```

**Step 3：启动前端**

```powershell
# 终端 3
Set-Location "D:\1XFAwork\businessmatch-v1\webapp\frontend"
npm run dev
```

### 2.3 环境变量配置

平台侧通过环境变量告诉引擎客户端去哪里找引擎：

```powershell
# PowerShell
$env:ENGINE_FUSHENGJI_ENDPOINT="http://localhost:9001"
$env:ENGINE_TECHVENTURE_ENDPOINT="http://localhost:9002"
$env:ENGINE_OPS_SIM_ENDPOINT="http://localhost:9003"
$env:ENGINE_FINANCE_LAB_ENDPOINT="http://localhost:9004"

# 或写入 webapp/backend/.env
ENGINE_FUSHENGJI_ENDPOINT=http://localhost:9001
ENGINE_TECHVENTURE_ENDPOINT=http://localhost:9002
```

### 2.4 手动测试流程

```bash
# 1. 平台创建比赛（内部调用引擎 /match/create）
curl -X POST http://localhost:8000/api/v1/competitions \
  -H "Content-Type: application/json" \
  -d '{"title":"测试赛","game_config_id":"template-v1","max_players":10}'

# 2. 学生加入（平台内部调用引擎 /match/{id}/join）
curl -X POST http://localhost:8000/api/v1/competitions/join \
  -H "Content-Type: application/json" \
  -d '{"room_code":"1234"}'

# 3. 组织者开始（平台调用引擎 /match/{id}/start）
curl -X POST http://localhost:8000/api/v1/competitions/1/start

# 4. 学生提交决策（平台透传引擎 /match/{id}/decision）
curl -X POST http://localhost:8000/api/v1/match/decision \
  -H "Content-Type: application/json" \
  -d '{"event_id":1,"decision":{"choice":"A"}}'

# 5. 组织者推进（平台调用引擎 /match/{id}/advance）
curl -X POST http://localhost:8000/api/v1/competitions/1/advance

# 6. 查看引擎状态（直连引擎，验证平台与引擎数据一致）
curl http://localhost:9001/match/{match_id}/state
```

## 三、方式 B：Docker Compose（推荐集成测试）

### 3.1 编排文件

在 `webapp/docker-compose.yml` 中增加引擎服务：

```yaml
services:
  backend:
    # ... 原有配置
    environment:
      - ENGINE_FUSHENGJI_ENDPOINT=http://engine-fushengji:9001
      - ENGINE_TEMPLATE_ENDPOINT=http://engine-template:9001

  engine-template:
    build:
      context: ../../bizsim-engine-box
      dockerfile: Dockerfile
    container_name: bizsim-engine-template
    ports:
      - "9001:9001"
    environment:
      - PORT=9001
      - PLATFORM_CALLBACK_URL=http://backend:8000/api/v1/engine/callbacks
    networks:
      - bizsim

  # 未来可添加更多引擎
  # engine-techventure:
  #   build:
  #     context: ../../bizsim-engine-box-techventure
  #   ...
```

### 3.2 引擎 Dockerfile

在 `bizsim-engine-box/Dockerfile`：

```dockerfile
FROM python:3.13-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY src/ ./src/
COPY content/ ./content/

EXPOSE 9001
CMD ["python", "-m", "uvicorn", "src.api.server:app", "--host", "0.0.0.0", "--port", "9001"]
```

### 3.3 启动

```powershell
Set-Location "D:\1XFAwork\businessmatch-v1\webapp"
docker compose up -d --build
```

## 四、方式 C：Mock 引擎（推荐单元测试）

### 4.1 为什么需要 Mock

- 跑平台单元测试时**不需要真的启动引擎**
- CI 流水线中**快速验证平台逻辑**
- 模拟引擎故障场景（超时、500 错误）

### 4.2 Mock 实现

```python
# webapp/backend/tests/mock_engine.py
from unittest.mock import AsyncMock

class MockEngineClient:
    """Mock engine for unit testing."""

    def __init__(self):
        self.matches = {}
        self.create_match = AsyncMock(return_value={
            "code": "OK",
            "data": {"match_id": "mock_001", "status": "created"}
        })
        self.join_match = AsyncMock(return_value={
            "code": "OK",
            "data": {"participant_id": "part_001", "status": "joined"}
        })
        self.start_match = AsyncMock(return_value={
            "code": "OK",
            "data": {"status": "playing", "current_round": 1}
        })
        self.submit_decision = AsyncMock(return_value={
            "code": "OK",
            "data": {"decision_id": "dec_001", "status": "accepted"}
        })
        self.advance_match = AsyncMock(return_value={
            "code": "OK",
            "data": {"current_round": 2, "is_final": False}
        })
        self.finish_match = AsyncMock(return_value={
            "code": "OK",
            "data": {
                "status": "finished",
                "final_standings": [{"rank": 1, "player_id": "p1", "final_score": 100}],
                "xp_payload": {"total_xp": 50, "idempotency_key": "xp_mock_001"}
            }
        })
        self.get_state = AsyncMock(return_value={
            "code": "OK",
            "data": {"status": "playing", "current_round": 1}
        })
```

## 七、常见问题

### Q1: 平台报错 "Engine unavailable"

检查：
1. 引擎服务是否已启动（`curl http://localhost:9001/health`）
2. 环境变量 `ENGINE_XXX_ENDPOINT` 是否设置正确
3. 防火墙是否放行端口

### Q2: 引擎回调平台失败

检查：
1. 平台回调端点是否已注册（`POST /api/v1/engine/callbacks`）
2. 引擎的 `PLATFORM_CALLBACK_URL` 环境变量是否正确
3. 如果是在 Docker 中，使用服务名而非 localhost

### Q3: 练习模式不自动推进

检查引擎的 `config.yaml` 中 `round_based` 是否为 `true`，以及 `ai_opponents` 是否 > 0。

### Q4: 平台需要支持多个引擎怎么办？

在 `config.py` 中配置多个 endpoint，在 `engine_client.py` 中根据 `game_config_id` 的 `engine` 字段路由到对应引擎。
