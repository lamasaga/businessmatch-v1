### 三层架构说明

| 层级 | 定位 | 知识特征 | 对应能力 | 典型卡片 |
|------|------|----------|----------|----------|
| **L1 基础原理层** | 经济学直觉与商业常识 | 单点概念、生活化类比、可感知 | 理解&记忆 | 供需、成本、利润、机会成本、边际效用 |
| **L2 核心概念层** | 学科主干分析框架 | 结构化模型、多变量分析、可应用 | 分析&应用 | SWOT、五力、博弈论、4P、三张表、供应链 |
| **L3 前沿整合层** | 跨学科综合决策 | 系统性思维、伦理权衡、创新设计 | 评价&创造 | 蓝海战略、ESG、精益创业、宏观政策、估值 |

**关键设计原则**：
- 下层是上层的基础，上层是下层的综合
- 同一层内存在横向关联（如博弈论↔竞争战略）
- 跨学科存在斜向连接（如行为经济学→定价策略→品牌资产）

- **主线1（价格机制）**：供需关系 → 价格弹性 → 市场结构 → 定价策略

### 4.2 横向关联路径（概念之间的依赖链）

```
【路径A：从供需到品牌】
供需关系 → 价格弹性 → 定价策略 → 品牌资产 → 市场定位
  (L1)      (L2)       (L2)       (L2)       (L3)
  
【路径B：从成本到战略】
固定/变动成本 → 盈亏平衡 → 现金流 → 竞争优势 → 蓝海战略
```

## 八、附录：图谱技术规格

### 8.1 推荐的图谱数据库模型

```yaml
# 节点（概念）Schema
Node:
  id: string           # 如 "KN-EC-MI-001"
  label: string        # 如 "供需关系"
  category: enum       # economics | business | management
  subcategory: string  # 如 "micro_economics"
  level: int           # 1-3（基础/核心/前沿）
  difficulty: int      # 1-5
  competencies: [string]  # 如 ["ML-1", "FL-1"]
  bloom_level: enum    # remember/understand/apply/analyze/evaluate/create

# 边（关系）Schema
Edge:
  source: string       # 源节点ID
  target: string       # 目标节点ID
  relation_type: enum  # prerequisite | extension | cross_discipline | game_mode_link
  strength: float      # 0-1（关联强度）
  bidirectional: bool  # 是否双向

# 属性标签Schema
Tag:
  node_id: string
  tag_type: enum       # personality | level | game_mode | topic
  tag_value: string    # 如 "INTJ" 或 "turn_based_strategy_v2"
  weight: float        # 匹配权重
```

### 8.2 可视化建议

```
推荐的前端可视化方案：

1. 全局视图：力导向图（Force-directed Graph）
   - 节点大小 = 枢纽度（连接数）
   - 节点颜色 = 学科（经济学=蓝，商学=绿，管理学=橙）
   - 边粗细 = 关联强度
   - 层级 = 同心圆（L1内圈，L2中圈，L3外圈）

2. 个人视图：径向树图（Radial Tree）
   - 中心 = 学生当前位置
   - 分支 = 已掌握（绿）、学习中（黄）、待解锁（灰）
   - 路径高亮 = 推荐学习路径

3. 教学视图：矩阵热力图（Matrix Heatmap）
   - X轴 = 知识卡片
   - Y轴 = 学生/班级
   - 颜色深浅 = 掌握度
```
