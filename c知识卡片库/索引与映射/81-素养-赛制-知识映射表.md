> - 教师备课：查询目标素养 → 获取关联赛制和知识卡片 → 设计教学单元

### 6.2 快速查询命令（假设数据库化后）

```sql
-- 查询某素养关联的所有知识卡片
SELECT * FROM knowledge_cards 
WHERE competencies CONTAINS 'FL-3' 
ORDER BY difficulty;

-- 查询某赛制的前置知识卡片
SELECT * FROM knowledge_cards 
WHERE content_id IN (
  SELECT prerequisite_knowledge FROM game_mode_mapping 
  WHERE mode_id = 'turn_based_strategy_v2'
);

-- 查询适合某性格类型的知识卡片
SELECT * FROM knowledge_cards 
WHERE personality_mapping.recommended.mbti CONTAINS 'INTJ' 
  OR personality_mapping.challenge_for.mbti CONTAINS 'INTJ';

-- 查询某学段应学习的知识卡片路径
SELECT * FROM knowledge_cards 
WHERE level_adaptations.middle IS NOT NULL 
  AND content_id IN (
    SELECT knowledge_id FROM learning_path 
    WHERE level = 'middle_school' AND module = 1
  )
ORDER BY sequence;
```
