## 二、AI Agent 框架对比

### 2.1 多智能体框架（2026）

| 框架 | 开发者 | 核心模式 | 学习曲线 | 生产可靠性 | 适用场景 | OPC定位 |
|------|--------|----------|----------|------------|----------|---------|
| **LangGraph** | LangChain | 图状态机、显式节点边 | 陡峭 | ⭐⭐⭐⭐⭐ 9/10 | 复杂工作流、企业级 | Cortex核心编排 |
| **CrewAI** | CrewAI Inc | 角色驱动、团队协作 | 平缓 | ⭐⭐⭐⭐ 7/10 | 快速原型、业务自动化 | AI员工团队原型 |
| **AutoGen** | Microsoft | 对话式协作 | 中等 | ⭐⭐⭐⭐ 8/10 | 研究环境、人机协同 | 谈判/对话场景 |
| **OpenAI Agents SDK** | OpenAI | 轻量可组合 | 平缓 | ⭐⭐⭐⭐ 8/10 | 快速验证、简单Agent | 单Agent快速测试 |
| **Agno** | Agno | 极简代码 | 最平缓 | ⭐⭐⭐ 6/10 | 原型验证 | 教学示例 |
| **MetaGPT** | DeepWisdom | 软件工程化 | 陡峭 | ⭐⭐⭐⭐ 7/10 | 软件开发任务 | DEV-01代码生成 |

### 2.2 框架选择决策树

```
需要复杂状态管理 + 生产级部署？
  ├─ 是 → LangGraph
  └─ 否 → 需要快速原型验证？
      ├─ 是 → 已有OpenAI模型？
      │   ├─ 是 → OpenAI Agents SDK
      │   └─ 否 → CrewAI
      └─ 否 → 需要极简代码？
          ├─ 是 → Agno
          └─ 否 → 特定场景专用框架
```

| AI员工 | AI Employee / Agent | 在OPC中可执行任务的数字协作者，有角色、KPI和交付物 |

| 冒烟测试 | Smoke Test | 不开发产品即验证需求的低成本测试方法 |
| 假门测试 | Fake Door Test | 在产品不存在时放置购买按钮，测试真实付费意愿 |
| POP | Population-Oriented Participant | 需求侧虚拟群体，模拟市场人群反应（继承自现有平台） |
