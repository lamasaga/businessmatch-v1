# 伦理与合规框架

> **文档定位**：定义OPC平台在AI使用、青少年保护、数据隐私和商业伦理方面的规则与保障机制。
>
> **最后更新**：2026-05-17

---

## 一、AI使用伦理

### 1.1 核心原则

| 原则 | 说明 | 平台实现 |
|------|------|----------|
| **透明性** | 学生知道哪些内容是AI生成的 | 所有AI输出标注来源 |
| **可解释性** | AI决策可被理解和质疑 | 展示AI的思考过程 |
| **人类主导** | 最终决策权始终在学生 | 禁止AI自动执行不可逆操作 |
| **教育目的** | AI辅助学习，不替代思考 | AI不直接给答案，只给框架 |
| **公平性** | AI建议不受偏见影响 | 定期审计AI输出 |

### 1.2 AI员工行为边界

**禁止行为**：
- 直接替学生完成考试/评估类任务
- 生成用于学术作弊的内容
- 提供可能伤害用户或他人的商业建议
- 在没有免责声明的情况下提供法律/医疗/财务建议
- 生成虚假数据或伪造用户证言

**必须行为**：
- 所有建议标注置信度
- 高风险的商业决策必须附带风险提示
- 涉及真实资金的操作必须二次确认
- 每次任务完成后附带学习要点

## 二、青少年保护

### 2.1 年龄分级策略

| 年龄段 | OPC模式 | 功能限制 |
|--------|---------|----------|
| <14岁 | 仅模拟模式 | 禁止真实支付、禁止真实社媒账号 |
| 14-17岁 | 模拟模式+有条件真实 | 真实支付需家长确认，社媒使用教育账号 |
| ≥18岁 | 完整功能 | 无额外限制（仍需伦理审计） |

### 2.2 内容过滤

```yaml
content_filtering:
  automatic_block:
    - 赌博相关商业
    - 色情/成人内容
    - 毒品/非法药物
    - 武器/暴力服务
    - 虚拟货币投机
    -  pyramid scheme（传销）
  
  flag_for_review:
    - 高额借贷/放贷
    - 医疗/健康建议类产品
    - 教育辅导/代写服务
    - 涉及个人隐私收集的产品
  
  require_parental_consent:
    - 任何真实资金交易
    - 使用真实身份信息的注册
    - 对外公开的学生个人信息
```

### 2.3 家长知情权

```yaml
parental_notification:
  triggers:
    - "学生创建公司"
    - "学生开启真实货币模式"
    - "学生进行任何真实支付"
    - "学生累计消费超过50元"
    - "学生公司产生第一笔收入"
  
  notification_method:
    - 微信小程序推送
    - 短信（如绑定手机号）
    - 邮件（如绑定邮箱）
  
  content:
    - 学生做了什么
    - 涉及金额（如适用）
    - 家长可采取的行动
    - 联系客服方式
```

## 三、数据隐私合规

### 3.1 数据收集最小化

```yaml
data_minimization:
  collected:
    - 账号信息（昵称、头像）
    - 学习行为数据（任务完成、评分）
    - 商业创意数据（BMC、品牌方案）
    - 模拟财务数据（教学用途）
  
  not_collected:
    - 真实身份证号
    - 真实家庭住址
    - 真实银行账户（除Stripe必要信息外）
    - 生物识别信息
  
  optional:
    - 真实姓名（用于证书，可选）
    - 手机号（用于通知，可选）
    - 学校信息（用于认证，可选）
```

### 3.2 数据隔离

```
数据隔离架构

┌─────────────────────────────────────────┐
│           平台层（共享基础设施）           │
├─────────────────────────────────────────┤
│  学校A租户  │  学校B租户  │  学校C租户  │
├─────────────────────────────────────────┤
│ 学生1 │ 学生2 │ 学生3 │ 学生4 │ ...   │
├─────────────────────────────────────────┤
│ 公司数据隔离：                            │
│ 学生1的公司数据对学生2不可见               │
│ 除非学生1主动分享                         │
└─────────────────────────────────────────┘
```

### 3.3 隐私政策要求

所有在OPC创建的公司必须包含隐私政策：

```markdown
# 隐私政策（模板）

## 我们收集什么信息
- [列出具体收集的数据类型]

## 我们如何使用信息
- [列出具体用途]

## 我们如何保护信息
- [描述安全措施]

## 用户权利
- 查看、修改、删除个人数据的权利
- 撤回同意的权利

## 联系我们
- [联系方式]

## 更新日期
- [日期]
```

## 四、商业伦理教育

### 4.1 学生创业伦理准则

```yaml
student_entrepreneur_ethics:
  honesty:
    - 不伪造用户评价
    - 不夸大产品功能
    - 不隐瞒已知缺陷
  
  fairness:
    - 不抄袭他人创意
    - 尊重知识产权
    - 公平竞争
  
  responsibility:
    - 保护用户数据安全
    - 提供明确的退款政策
    - 对用户反馈及时响应
  
  transparency:
    - 明确的定价，无隐藏费用
    - 清晰的取消/退款流程
    - 真实的公司信息
```

### 4.2 伦理违规处理

| 违规级别 | 示例 | 处理 |
|----------|------|------|
| 轻微 | 文案中使用了极限词 | 警告，要求修改 |
| 中等 | 伪造少量用户评价 | 暂停相关功能，要求整改 |
| 严重 | 抄袭他人产品/品牌 | 暂停公司运营，导师介入 |
| 极严重 | 涉及非法活动 | 永久封号，报告相关部门 |
