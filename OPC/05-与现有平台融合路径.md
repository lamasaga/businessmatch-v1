# OPC · 与现有平台融合路径

> **文档定位**：OPC 不是孤立系统，而是现有商业模拟教育平台的「自然延伸」。本文档定义从现有平台到OPC的无缝过渡机制，确保学生、教师、运营方的平滑迁移。
>
> **关联文档**：`../商业模拟教育平台/01-一体化平台总体规划.md`、`../03-生涯模式与激励闭环.md`
>
> **最后更新**：2026-05-17

## 一、融合原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **数据不孤岛** | OPC与现有平台共享同一用户ID、CareerProfile、能力评估体系 |
| **入口自然** | OPC不是独立应用，而是生涯模式达到特定条件后的「解锁区域」 |
| **能力可回溯** | 在OPC中积累的能力和经验反哺现有平台的成就/认证体系 |
| **教师不增负** | OPC的导师角色主要由AI承担，真人教师可选择性参与终审 |
| **渐进可选** | 学生可自主选择是否开启OPC，不强制 |

## 二、入口与解锁机制

### 2.1 触发条件（多路径）

学生可通过以下任一条件解锁OPC入口：

| 路径 | 条件 | 说明 |
|------|------|------|
| **能力路径** | 五维能力平均分 > 70 | 确保学生具备基础商业素养 |
| **课程路径** | 完成「创业入门」课程单元 | 理论知识准备就绪 |
| **商赛路径** | 在「创业生存战」或「投资人对决」中排名前30% | 实战能力得到验证 |
| **成就路径** | 获得「战略思维大师」+「财务洞察Lv.3」徽章 | 关键能力组合达标 |
| **主动申请** | 提交创业意向书 + Athena推荐信 | 特殊通道，降低门槛 |

### 2.2 解锁仪式

当学生满足条件时，触发「创业启航」仪式：

1. **Athena 专属对话**：回顾学生在平台的学习历程，提炼「你可能适合创业的信号」
2. **能力匹配报告**：基于Persona测评，推荐3个高匹配度创业方向
3. **Legacy继承**：商赛中获得的称号、技能、成就可以转化为OPC的「初始资源包」
   - 例：「TECH路线大师」→ OPC中DEV-01初始等级+1
   - 例：「谈判专家」→ OPC中Rival经验可迁移至Advisor能力
4. **选择创业模式**：
   - 🟢 **实战模式**：真实公司，真实收入（推荐18岁+）
   - 🟡 **模拟模式**：全程虚拟币，但流程完整（适合低龄段）
   - 🔵 **竞赛模式**：限时创业挑战赛，与同龄人PK

## 三、数据融合

### 3.1 单向流入（现有 → OPC）

| 数据源 | 数据项 | OPC用途 |
|--------|--------|---------|
| Persona 性格引擎 | MBTI/大五人格/决策风格 | 创业方向推荐、AI员工性格匹配 |
| Athena 学习记录 | 课程完成轨迹、薄弱知识点 | Advisor针对性补强 |
| Arena 商赛记录 | 决策日志、排名历史、策略风格 | 评估学生商业实战能力 |
| Atlas 知识图谱 | 概念掌握度 | 解锁AI员工技能的知识前提 |
| Credenti 认证 | 已获徽章/证书 | 初始资源包计算依据 |
| Quest 日常活动 | streak、协作记录 | 创业毅力和社交能力参考 |

### 3.2 双向流动（OPC ↔ 现有）

| 数据项 | 方向 | 说明 |
|--------|------|------|
| OPC公司运营数据 | OPC → 现有 | 作为新的「能力维度」计入五维雷达（新增「创业力」维度） |
| OPC毕业认证 | OPC → 现有 | 「一人公司创始人」徽章写入Credenti |
| OPC收入数据 | OPC → 现有 | 可选公开，作为「成就墙」展示 |
| 知识图谱更新 | 双向 | OPC中发现的新概念/工具反哺Atlas节点 |
| AI员工使用数据 | OPC → 现有 | 用于优化Athena的个性化建议 |

### 3.3 统一事件总线扩展

在现有 CloudEvents 事件体系上，新增OPC相关事件：

| 事件类型 | 发布域 | 订阅方 | 影响 |
|----------|--------|--------|------|
| `OPC.company.created` | OPC | Career, Credenti | +XP，解锁成就 |
| `OPC.stage.completed` | OPC | Career, Athena | +XP，更新能力雷达 |
| `OPC.gateway.passed` | OPC | Credenti, Social | 徽章发放，社区展示 |
| `OPC.revenue.first` | OPC | Career, Athena, Apollo | 里程碑记录，叙事更新 |
| `OPC.employee.leveled_up` | OPC | Career | AI员工管理技能成长 |
| `OPC.company.graduated` | OPC | Credenti, Career | 最高级认证，Legacy归档 |
| `career.OPC.unlocked` | Career | OPC | 学生满足条件，OPC入口开放 |

### 4.2 教师参与深度（可选）

| 参与级别 | 教师动作 | 时间投入 |
|----------|----------|----------|
| **L0 旁观者** | 仅查看数据看板，不干预 | ~0分钟/周 |

## 五、赛事体系融合

### 5.1 新增赛制：一人公司挑战赛

将OPC流程包装为一种新商赛模式，融入现有Arena体系：

```yaml
game_mode:
  id: one_human_business_challenge
  name: 一人公司挑战赛
  duration: 12周
  team_size: 1  # 强制单人
  
  phases:
    - name: "创意 sprint"
      duration: 2周
      deliverable: "BMC + 品牌方案"
      judging: [ai_panel, mentor_review]
      
    - name: "验证 sprint"
      duration: 2周
      deliverable: "着陆页 + 用户反馈报告"
      judging: [conversion_rate, feedback_quality]
      
    - name: "构建 sprint"
      duration: 4周
      deliverable: "可访问的MVP"
      judging: [functionality, ux_score, code_quality]
      
    - name: "发射 sprint"
      duration: 4周
      deliverable: "市场数据 + 收入证明"
      judging: [user_growth, revenue, innovation]
      
  scoring:
    - metric: 商业可行性
      weight: 0.25
    - metric: 产品完成度
      weight: 0.25
    - metric: 市场验证度
      weight: 0.25
    - metric: 真实收入
      weight: 0.15
    - metric: AI协作效率
      weight: 0.10  # 评估学生管理AI员工的能力
      
  special_rules:
    - "必须使用至少3个AI员工"
    - "禁止学生直接编写超过20%的代码（强制使用AI员工）"
    - "收入必须使用真实支付渠道（测试模式可豁免）"
    - "允许使用外部工具和服务（需申报）"
```

### 5.2 赛季制融合

OPC的「一人公司挑战赛」可作为现有赛季制的「终极赛季」：

```
常规赛季（1-16周）：
  → 知识学习 + 模拟商赛 + 日常Quest
  → 能力积累 + 性格发展
  
终极赛季（17-28周）：
  → 一人公司挑战赛
  → 真实创业实践
  → 毕业认证
```

## 六、商业化与可持续性

### 6.1 OPC对现有商业模式的增强

| 现有收入 | OPC增强 |
|----------|---------|
| B2B学校订阅 | 旗舰版新增OPC模块，支持学生真实创业追踪 |
| B2C学生增值 | OPC「创业工具包」增值服务（高级AI员工、额外MCP工具） |
| 企业合作 | 企业可发布「真实需求」作为OPC挑战题目，获取创意方案 |
| 人才输送 | OPC毕业学生直接向合作企业推荐 |

### 6.2 成本结构

| 成本项 | 预估（元/学生/学期） | 优化策略 |
|--------|---------------------|----------|
| LLM API调用 | 50-200 | 模型路由+缓存+学校批量采购 |
| 外部服务（部署/支付等） | 0-100（按实际使用） | 教育优惠+免费 tier |
| 平台运维 | 10-30 | 与现有平台共享基础设施 |
| **总计** | **60-330** | 通过增值服务覆盖 |
