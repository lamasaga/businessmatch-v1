# 07 - 课程-平台功能映射表

> 一份操作级对照文档。教师可以直接查询："我要上第X单元，需要在平台上做什么设置？"

---

## 使用说明

本表按学段-单元-平台操作三层组织。每行包含：
- **单元**：课程名称
- **核心素养**：对应5维素养模型
- **平台规则模板**：需要加载的规则配置
- **平台功能**：需要开启/关闭的功能开关
- **教师操作步骤**：发起活动的具体流程
- **特殊设置**：该单元独有的参数调整

### 5.2 快速发起流程

```
标准发起流程（5步）：
1. 登录教师端 → 进入"课程中心"
2. 选择学段 → 选择单元 → 加载对应模板
3. 设置班级参数（人数、组队方式、时长）
4. 生成班级码 → 分享给学生
5. 监控面板 → 开始活动

高级发起流程（8步）：
1-4. 同上
5. 调整规则参数（可选）
6. 设置事件池（可选）
7. 开启/关闭特定功能
8. 预览模拟 → 确认 → 开始活动
```

## 六、故障速查

| 问题现象 | 可能原因 | 快速解决 |
|----------|----------|----------|
| 学生看不到排行榜 | 该学段默认关闭 | 教师端"设置"→"排行榜"→开启 |
| 事件没有触发 | 事件池为空 | 检查模板事件配置，手动添加 |
| 角色分工不生效 | 未开启强制角色 | 设置"强制角色=ON" |
| 融资选项不出现 | 融资系统关闭 | 检查功能开关 |
| 数据导出为空 | 对局未结算 | 确保至少完成1轮结算 |
| 自定义规则报错 | JSON格式错误 | 使用平台内置验证工具 |
