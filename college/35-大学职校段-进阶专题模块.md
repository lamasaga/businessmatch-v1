# 05 - 大学/职校段（18岁+）：进阶专题模块

> 大学生和职校生即将或已经步入职场，需要理解真实商业世界的复杂性。本模块不再使用简化规则，而是直面多变量交互、信息不对称、长期战略、伦理困境等真实商业挑战。标准对局只是起点，产业链模拟、跨文化经营、ESG决策等进阶玩法成为主流。

---

## 一、模块总览

| 项目 | 内容 |
|------|------|
| **目标学段** | 大学本科（非商科/商科）/ 职业院校 |
| **总课时** | 32-48课时（每课时45分钟） |
| **单元数** | 8个专题 |
| **核心理念** | "商业是复杂系统中的决策艺术" |
| **教学风格** | 案例研讨、数据分析、角色扮演、真实项目 |
| **平台模式** | 全功能开放 / 自定义规则 / 真实数据注入 |
| **数学工具** | 微积分、线性代数、概率统计、优化理论、博弈论 |

## 二、8个专题设计

### 专题1：创业模拟营

**主题**：从0到1的完整创业体验

**课程设计**：
- 时长：8课时（2周）
- 形式：学生组成创业团队，完成完整的商业模拟周期

**流程**：
```
第1-2课时：团队组建 + 创意路演
  └── 每队提出产品概念，班级投票选出 Top 8

第3-4课时：市场验证 + 首轮决策（R1）
  └── 使用真实城市数据设定市场参数
  └── 完成首轮投资分配

第5-6课时：竞争加剧 + 迭代决策（R2-R3）
  └── 引入真实行业事件（如政策变化、技术突破）
  └── 允许团队间交易、联盟、并购

第7-8课时：最终结算 + 投资人路演
  └── 向"投资人 panel"（教师/嘉宾）路演
  └── 评选：最佳商业价值 / 最佳创新 / 最佳韧性
```

**平台功能**：
- 使用完整 TechVenture v6 规则
- 开启"并购""联盟""间谍"等进阶功能
- 允许自定义部分参数

---

### 专题2：产业链博弈

**主题**：上下游关系与价值分配

**课程设计**：
- 时长：4课时
- 形式：产业链角色扮演

**角色分配**：
| 角色 | 数量 | 目标 | 约束 |
|------|------|------|------|
| 原材料供应商 | 3-4队 | 最大化原料利润 | 产能有限 |
| 制造商 | 3-4队 | 最大化产品利润 | 依赖供应商 |
| 分销商 | 2-3队 | 最大化渠道利润 | 依赖制造商 |
| 零售商 | 3-4队 | 最大化销售利润 | 依赖分销商 |

**核心机制**：
- 每轮必须进行跨组交易（合同系统）
- 价格由谈判决定，平台记录合同
- 如果供应商集体提价，制造商利润被挤压
- 如果制造商整合（并购），对供应商议价力增强

**教学点**：
- 波特五力模型中的"买方议价力"和"供应商议价力"
- 垂直整合 vs 外包的决策逻辑
- 供应链风险与韧性

---

### 专题3：金融与投资

**主题**：资本市场与估值逻辑

**课程设计**：
- 时长：6课时
- 形式：一半是模拟投资，一半是案例分析

**模拟投资环节**：
- 学生获得虚拟资金 100 万
- 平台提供多个"虚拟公司"的历史财报和经营数据
- 学生决定投资组合
- 平台根据各公司的模拟经营结果，计算投资收益

**教学点**：
- 基本面分析：如何从财报判断公司质量
- 组合理论：分散投资降低风险
- 市场有效性：能否持续跑赢市场？
- 行为金融：过度自信、羊群效应、损失厌恶

---

### 专题4：全球化经营

**主题**：跨文化商业决策

**课程设计**：
- 时长：4课时
- 形式：使用平台"区域模板系统"（参见 inspire/13-全球化文档）

**情境**：
- 学生团队经营一家中国企业，计划进入东南亚市场
- 可选择进入新加坡（高消费、高竞争）或越南（高增长、政策风险）
- 每个国家有不同的消费者偏好、法规环境、汇率波动

**教学点**：
- Hofstede 文化维度在商业中的体现
- 汇率风险对冲
- 本地化 vs 标准化的战略选择
- 地缘政治风险

---

### 专题5：商业伦理与ESG

**主题**：利益相关者与可持续经营

**课程设计**：
- 时长：4课时
- 形式：伦理困境模拟 + 案例法庭

**伦理困境模拟**：
- 平台引入"ESG 评分"维度（环境/社会/治理）
- 每个决策不仅影响财务，还影响 ESG 评分
- 高 ESG 评分：长期获得消费者信任、政策优惠
- 低 ESG 评分：短期成本低，但面临声誉风险和监管处罚

**困境案例**：
- "发现供应商使用童工，切换供应商成本增加 30%，你怎么选？"
- "竞争对手在数据隐私上打擦边球，获得成本优势，你跟不跟？"
- "新产品 profitable 但可能加剧环境污染，上不上？"

**案例法庭**：
- 学生分组扮演"企业""NGO""政府""消费者"
- 就某个真实商业伦理事件进行模拟听证

---

### 专题6：数据驱动决策

**主题**：商业分析工具

**课程设计**：
- 时长：6课时
- 形式：数据分析工作坊

**内容**：
1. **描述性分析**：平台数据的可视化（Tableau/Power BI 风格）
2. **诊断性分析**："为什么销量下降？"——因果推断入门
3. **预测性分析**：用历史数据预测下轮市场趋势
4. **处方性分析**：优化模型——给定约束，求最优解

**实操**：
- 学生导出平台模拟数据
- 使用 Excel/Python 进行分析和建模
- 将分析结果转化为下轮决策

---

### 专题7：宏观经济周期

**主题**：宏观环境对企业的影响

**课程设计**：
- 时长：4课时
- 形式：宏观经济模拟器

**平台扩展**：
- 引入"宏观经济状态"变量（繁荣/衰退/滞胀/复苏）
- 宏观状态影响所有企业的成本和需求
- 学生可以观察：同样的策略，在不同宏观环境下的不同结果

**教学点**：
- 顺周期 vs 逆周期行业
- 财政政策与货币政策对企业的影响
- 库存周期、资本支出周期
- 黑天鹅事件与风险管理

---

### 专题8：商业模拟设计工作坊

**主题**：从玩家到设计者

**课程设计**：
- 时长：8课时（期末项目）
- 形式：学生设计自己的商业模拟规则

**流程**：
```
第1-2课时：解构现有规则
  └── 分析 TechVenture v6 的 config.ts
  └── 理解每个参数的商业含义

第3-4课时：设计新规则
  └── 选择一个真实行业（咖啡、新能源、AI...）
  └── 设计该行业的核心变量和交互规则
  └── 用 JSON/表格定义参数

第5-6课时：原型测试
  └── 在平台上加载自定义规则
  └── 自己试玩，发现问题
  └── 邀请其他同学测试

第7-8课时：展示与评选
  └── 演示设计理念
  └── 展示试玩录像
  └── 评选：最真实 / 最有趣 / 最有教学价值
```

## 三、评估方式

大学/职校段的评估更强调**输出质量**而非**排名**：

| 评估项 | 形式 | 权重 |
|--------|------|------|
| **商业分析报告** | 基于模拟数据的分析文档 | 25% |
| **团队路演** | 模拟投资人/董事会汇报 | 20% |
| **规则设计项目** | 专题8的设计产出 | 20% |
| **课堂参与** | 讨论质量、同伴反馈 | 15% |
| **反思论文** | 个人学习总结（1500字） | 20% |

## 四、与职业发展的连接

| 职业方向 | 对应专题 | 能力证明 |
|----------|----------|----------|
| 创业/管理 | 专题1、2 | 完整经营周期经验 |
| 金融/投资 | 专题3 | 模拟投资业绩记录 |
| 咨询/战略 | 专题4、6、7 | 分析报告和路演录像 |
| 产品经理 | 专题1、6 | 数据驱动决策经验 |
| 可持续发展/ESG | 专题5 | ESG决策案例分析 |
| 游戏/教育设计 | 专题8 | 原创规则设计文档 |

---

> **核心目标**：让大学生和职校生将商业模拟作为"职业实验室"——在安全环境中体验不同职业路径的决策逻辑，带着真实的商业直觉进入职场或创业。
