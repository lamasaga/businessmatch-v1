## 01 · 回合制策略商赛

### 框架映射

| 维度 | 映射结果 |
|------|----------|
| **mode_id** | `turn_based_strategy` |
| **引擎特性** | 非实时、回合制、顺序决策 |
| **核心原子** | `budget_allocate` + `route_select` + `city_occupy` + `softmax_share` + `linear_scoring` + `spy_reveal` + `alliance_form` |
| **布局** | `three_column`（左-状态 / 中-决策 / 右-情报） |
| **回合数** | 4 |
| **阶段** | select_route → select_cities → allocate_budget |

### 决策配置

```yaml
# 决策阶段声明
phases:
  - id: select_route
    duration: 120
    atoms: [route_select]
    ui_component: route_card_grid    # 2×2 路线卡片
    
  - id: select_cities
    duration: 120
    atoms: [city_occupy]
    ui_component: city_grid          # 3×2 城市网格
    
  - id: allocate_budget
    duration: 300
    atoms: [budget_allocate]
    ui_component: slider_group       # 5个滑块联动
```

### 界面组件映射

| 界面元素 | 组件类型 | data_source |
|----------|----------|-------------|
| 路线卡片 | `info_card` | `teams[my_team].route` |
| 城市列表 | `city_list` | `teams[my_team].cities` |
| 资金显示 | `currency_display` | `teams[my_team].budget.remaining` |
| 排名徽章 | `rank_badge` | `teams[my_team].rank` |
| 回合指示器 | `round_indicator` | `lifecycle.round` |
| 投资滑块组 | `slider_group` | `teams[my_team].investments` |
| 预算进度条 | `budget_progress` | `teams[my_team].budget` |
| 间谍面板 | `spy_panel` | `social.spy_logs`（conditional: round >= 3） |
| 市场动态 | `market_feed` | `market.cities` |
| 排名预测 | `rank_prediction` | `computed.predictions` |

### 特殊规则

```yaml
special_rules:
  - rule: "PATHFINDER独占红利"
    condition: "route == PATHFINDER AND city_count == 1"
    effect: "market_share_bonus: 0.15"
    
  - rule: "联盟背叛"
    condition: "alliance.exists AND decision.indicates_betrayal"
    effect: "betrayal_penalty: 0.2"
    
  - rule: "间谍反侦测"
    condition: "spy_used"
    probability: "counter_spy_probability: 0.1"
    effect: "spy_failed AND cost_consumed"
```

## 02 · 实时经营挑战

### 框架映射

| 维度 | 映射结果 |
|------|----------|
| **mode_id** | `realtime_management` |
| **引擎特性** | 实时、tick驱动、自动推进 |
| **核心原子** | `budget_allocate` + `timed_pressure` + `random_crisis` + `linear_scoring` |
| **布局** | `two_column`（主操作区 / 侧边监控面板） |
| **回合数** | `dynamic`（按时间窗口） |
| **阶段** | continuous（无明确阶段，持续决策） |

### 实时配置

```yaml
realtime:
  enabled: true
  tick_interval: 1000           # 1秒1tick
  decision_window: 300          # 5分钟总时长
  auto_advance: true            # 不等待提交
  
  # 前端推送
  push:
    channels:
      - game_state: "throttle_1000ms"
      - events: "realtime"
      - leaderboard: "throttle_5000ms"
```

### 事件流配置

```yaml
event_stream:
  - id: customer_rush
    trigger: "tick == 120"      # 第120秒触发
    effect: {demand_multiplier: 2.0}
    ui_effect: "screen_flash + notification"
    
  - id: supply_shortage
    trigger: "random"
    probability: 0.01            # 每tick 1%
    effect: {supply_cost: +20%}
    
  - id: equipment_failure
    trigger: "random"
    probability: 0.005
    effect: {production_capacity: -50%}
    duration: 30                 # 持续30秒
```

### 界面组件映射

| 界面元素 | 组件类型 | data_source | 特殊配置 |
|----------|----------|-------------|----------|
| 实时时钟 | `timer_countdown` | `lifecycle.decision_window` | 精确到0.1秒 |
| 经营仪表盘 | `data_table` | `teams[my_team].metrics` | 实时刷新 |
| 危机预警 | `info_card` | `events.pending` | 红色渐变背景 |
| 应急操作 | `action_group` | - | 快捷按钮组 |
| 实时排行 | `data_table` | `computed.rankings` | 每5秒更新 |
| 趋势图表 | `chart_line` | `market.trends` | 近60秒走势 |

          text: "立即公开披露，召回相关产品"
          ethical_axis: {transparency: +2, responsibility: +1}
          
        - id: containment
          text: "内部修复，限制信息传播"
          ethical_axis: {transparency: -1, pragmatism: +2}
          
        - id: deflection
          text: "对外否认，准备法律应对"

scoring:

    - id: stakeholder_balance
      name: "利益相关者平衡"
