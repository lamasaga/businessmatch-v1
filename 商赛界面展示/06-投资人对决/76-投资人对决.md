# 06-投资人对决 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
投资人对决是商业模拟平台的**双阵营对抗模式**。学生分为"创业者"和"投资人"两派：创业者需要路演、融资、经营；投资人用虚拟资金投资，按回报率排名。面向大学及以上学段，体验投融资、估值谈判、尽职调查与退出机制。

### 1.2 设计目标
- **体验双向博弈**：创业者想高估，投资人想低估——同一标的的两种视角
- **训练路演表达**：5分钟限时路演，用故事和数据打动投资人
- **理解估值逻辑**：从P/S倍数到团队溢价，估值不是数字游戏
- **感受Term Sheet博弈**：投资条款背后的权力分配

### 1.3 教学哲学
此模式将商业模拟从"经营视角"扩展到"资本视角"。学生发现：创业不仅是"做出好产品"，更是"讲好故事、找对钱、签对条款"。这是真实创业生态的核心认知。

## 三、各模块详细说明

### 3.1 Hero区域

**视觉特征**：
- 主题色：紫色系（`#8b5cf6`），传递"资本、高端、博弈"的心理暗示
- 徽章标签："创业者 vs 投资人 · 双阵营对抗"
- 图标使用钱袋（💰），强化投融资意象

**核心数据展示**：
| 数据项 | 值 | 教学意义 |
|--------|-----|----------|
| 对抗模式 | 双阵营 | 同一市场，两种视角 |
| 路演时限 | 5分钟 | 训练精炼表达能力 |
| 投资额度 | 虚拟资金 | 无真实风险，大胆决策 |
| 适合学段 | 大学+ | 需要一定的商业认知基础 |

---

### 3.2 双阵营机制

**左右对比卡片**：

**创业者阵营** 🚀（紫色边框）
- **目标**：获得尽可能高的估值，融到足够资金
- **最终排名**：按公司估值排名
- **核心能力**：路演表达、商业计划、估值谈判、经营兑现
- **获胜逻辑**：讲好故事→拿到高估值→经营证明估值合理

**投资人阵营** 💼（橙色边框）
- **目标**：用有限虚拟资金投资最有潜力的项目
- **最终排名**：按组合回报率(ROI)排名
- **核心能力**：项目判断、估值分析、风险分散、投后管理
- **获胜逻辑**：发现被低估的项目→谈判拿到好条款→投后增值→退出获利

**融资路线图**（下方时间线）：
```
种子轮(¥500万) → 天使轮(¥2000万) → A轮(¥1亿) → B轮(¥5亿) → IPO/并购(¥30亿+)
   ✅已完成        ✅已完成          🔥当前         ⏳待解锁        ⏳终局
```

**设计意图**：
- 左右对比强化"两种视角"的核心差异
- 融资路线图展示创业公司的成长阶梯
- 不同轮次的估值目标形成递进感

## 五、教学锚点与能力映射

### 5.1 直接训练能力
| 能力维度 | 界面元素 | 训练机制 |
|----------|----------|----------|
| 路演表达 | 路演舞台+评分 | 限时表达+多维度反馈 |
| 估值分析 | 估值计算器 | 理解估值方法论 |
| 条款谈判 | Term Sheet对比 | 高估值vs好条款的权衡 |
| 投资组合 | 组合看板 | 分散投资+动态调整 |

### 5.2 赛后可引出的理论概念
- **公司金融**：估值方法（DCF、可比公司法、风险投资法）
- **博弈论**：双边议价、信息不对称下的信号传递
- **投资组合理论**：马科维茨均值-方差模型、分散化
- **创业融资**：融资轮次、股权稀释、清算优先权

## 六、使用建议

### 6.1 适合场景
- 创业课程、投融资课程的情境化教学
- 需要同时训练"表达"和"分析"两种能力
- 理解"创业者vs投资人"的双向博弈

### 6.2 教师操作要点
1. **赛前**：确保学生理解"估值"和"股权"的基本概念
2. **赛中**：观察路演质量，记录典型问题
3. **赛后**：对比同一项目创业者和投资人的不同评价

### 6.3 常见学生误区
- **创业者**：过度追求高估值，忽视条款质量
- **投资人**：过度分散，没有深度了解任何项目
- **双方**：忽视"投后管理"的重要性
