# 04-产业链角色扮演 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
产业链角色扮演是商业模拟平台的**协作与谈判训练模块**。16人分为供应商、制造商、分销商、零售商四组，每组内部竞争，组间必须交易。平台提供"合同系统"，双方确认条款后系统执行。面向高中及以上学段，每轮协商20-40分钟。

### 1.2 设计目标
- **体验信息不对称**：每个角色掌握不同的成本/价格信息
- **训练谈判技巧**：锚定效应、BATNA、利益而非立场
- **理解产业链利润分配**：从原材料到终端，价值如何分配
- **感受信任与背叛**：合同谈判中的承诺与执行

### 1.3 教学哲学
此模式将商业模拟从"对抗竞争"扩展到"合作竞争"（Coopetition）。学生发现：有时候与"对手"合作比与"队友"竞争更重要。这正是真实商业世界的核心特征。

### 3.2 产业链利润分配

**水平流程图**：
```
🌾 原材料供应商 → 🏭 制造商 → 🚚 分销商 → 🛒 零售商
   成本:¥10/单位    加工:¥15    物流:¥8      售价:¥50
   利润:+¥50万      +¥80万      +¥60万       +¥100万
```

**终端售价分解**：
> 终端售价 ¥50 = 原材料 ¥10 + 加工 ¥15 + 物流 ¥8 + 零售利润 ¥17

**设计意图**：
- 可视化展示产业链各环节的价值贡献
- 利润数字暗示"谁掌握了最大议价权"
- 为后续谈判建立"公平分配"的心理基准

### 3.3 四大角色 · 角色卡片

采用2×2大卡片布局，每个角色有独立颜色编码：

**原材料供应商** 🌾（蓝色系）
- **信息优势**：知道原材料的真实成本
- **信息劣势**：不知道下游能卖出什么价格
- **目标**：以尽可能高的价格卖出原材料
- **核心能力**：成本控制、批量谈判

**制造商** 🏭（绿色系）
- **信息优势**：同时面对上下游
- **信息劣势**：采购成本和销售价格之间的利润空间不确定
- **目标**：管理产能利用率，找到利润空间
- **核心能力**：产能管理、双边谈判

**分销商** 🚚（黄色系）
- **信息优势**：掌握各区域市场的渠道信息
- **信息劣势**：不知道制造商的真实成本
- **目标**：以最优物流方案连接制造与零售
- **核心能力**：渠道信息、物流优化

**零售商** 🛒（粉色系）
- **信息优势**：掌握终端市场需求数据
- **信息劣势**：利润取决于上游给什么价格
- **目标**：在售价和进货价之间博弈
- **核心能力**：市场洞察、定价权

**设计细节**：
- 每个卡片有角色图标（64px大图标）
- 角色徽章标签（带颜色背景）
- 核心能力标签（两个主题色标签）
- hover时卡片上浮+阴影

### 3.5 谈判协商室

**双栏布局**：

**左侧 · 聊天面板**：
- 聊天头部：对方头像+名称+合同编号
- 消息气泡：左右区分（对方左，自己右）
- 消息内容示例：
  - 供应商："我们原材料成本最近上涨了，¥18/件是最低价格了。"
  - 制造商："理解，但如果我一次性订购2000件，能否降到¥16？"
  - 供应商："2000件的话... ¥17吧，但需预付30%定金。"
  - 制造商："¥16.5，预付20%，这是我能接受的上限。"
  - 供应商："让我考虑一下..."

**右侧 · 辅助信息**：

**谈判技巧提示**：
- **锚定效应**：先出价的一方往往掌握主动权
- **BATNA**：始终清楚自己的最佳替代方案
- **利益而非立场**：关注双方真正的利益点
- **创造选项**：用非货币条件增加谈判空间

**市场参考价格表**：
| 交易类型 | 市场均价 | 浮动区间 |
|----------|----------|----------|
| 原材料采购 | ¥17/件 | ¥15-¥20 |
| 加工服务 | ¥14/件 | ¥12-¥18 |
| 物流配送 | ¥8/件 | ¥6-¥12 |
| 零售代理 | ¥34/件 | ¥30-¥40 |

**设计意图**：
- 聊天界面模拟真实商务沟通场景
- 技巧提示提供即时学习支架
- 市场参考价作为谈判的"客观基准"

## 五、教学锚点与能力映射

### 5.1 直接训练能力
| 能力维度 | 界面元素 | 训练机制 |
|----------|----------|----------|
| 谈判技巧 | 聊天室+技巧提示 | 在真实对话中运用策略 |
| 信息利用 | 角色信息差异 | 利用信息优势获取更好条款 |
| 合同理解 | 智能合同系统 | 量化条款，明确权利义务 |
| 协作竞争 | 组内竞争+组间合作 | 同时处理多重关系 |

### 5.2 赛后可引出的理论概念
- **博弈论**：议价博弈（Nash Bargaining Solution）、不完全信息博弈
- **经济学**：纵向一体化vs市场采购（Make or Buy）
- **组织行为学**：信任建立、关系契约、交易成本
- **供应链管理**：牛鞭效应、JIT、供应商关系管理

## 六、使用建议

### 6.1 适合场景
- 需要强调"协作"而非"对抗"的教学目标
- 沟通与谈判技巧训练
- 理解产业链运作机制

### 6.2 教师操作要点
1. **赛前**：确保每组学生理解自己的信息优势和劣势
2. **赛中**：巡视各组谈判，适时提供提示（如"你的BATNA是什么？"）
3. **赛后**：公布"真实成本"数据，让学生看到信息不对称的影响

### 6.3 常见学生误区
- **过早暴露底线**：在谈判初期就亮出自己的最低接受价
- **忽视BATNA**：没有考虑如果谈判失败怎么办
- **零和思维**：认为一方所得必是另一方所失
- **情绪化决策**：因对方态度而做出非理性让步
