MODE 01

回合制策略商赛

四轮回合制竞技，队伍选择路线并投资技术/用户匹配/品牌展示。包含间谍、联盟、暗标拍卖等特色机制。

策略博弈 4轮竞技 高中+
⚡
MODE 02

实时经营挑战

持续运转的经营模拟，24小时为一个游戏年。随机事件不断发生，需在5分钟内做出应急决策。

实时决策 应急响应 初中+
🔨
MODE 03

拍卖交易大厅

快节奏竞价交易，包含城市广告位拍卖、技术专利交易、供应链竞标。体验价格发现与风险博弈。

金融模拟 竞价交易 高中+
🎭
MODE 04

产业链角色扮演

分为供应商、制造商、分销商、零售商四组。组间必须交易，平台提供智能合同系统。训练谈判与协作。

角色扮演 谈判协商 高中+
🎓 进阶决策类
📖
MODE 05

案例推演决策

以真实企业改编的互动案例，学生扮演CEO面对10个关键决策点。每个决策影响后续剧情分支。

叙事沉浸 伦理思辨 大学+
💰
MODE 06

投资人对决

双阵营对抗：创业者路演融资 vs 投资人组合管理。体验投融资、估值谈判、尽职调查与退出机制。

投融资 估值博弈 大学+
🔥
MODE 07

创业生存战

模拟真实创业的残酷法则：现金流断裂即出局。没有排名，只有生与死。训练风险意识与危机决策。

生存制 现金流 高中+
🌊
MODE 08

宏观经济沙盘

引入通胀、紧缩、政策调控等宏观变量，所有队伍在同一经济周期中经营。理解宏观对微观的影响。

宏观周期 政策调控 大学+
🌍 高阶专题类
🌱
MODE 09

ESG可持续经营

引入环保、社会、治理三维指标，企业价值不再只看利润。训练长期主义思维与社会责任。

ESG评分 可持续 大学+
🌐
MODE 10

跨国贸易博弈

在多国家市场中经营，面对汇率波动、关税壁垒、文化差异与地缘政治风险。训练全球化视野。

全球化 汇率风险 大学+

Design System

统一设计系统

十种商赛共享同一套设计语言，通过主题色区分特色

🎨

主题色彩

每种商赛有独特的主题色：回合制(蓝)、实时(绿)、拍卖(金)、角色扮演(粉)、案例(青)、投资(紫)、生存(橙)、宏观(青蓝)、ESG(翠绿)、跨国(靛蓝)。统一在深色背景上呈现。

📐

组件复用

卡片、按钮、时间线、进度条、表格等组件全部共享同一套CSS变量系统，确保视觉一致性。新增模式只需覆盖主题色变量。

📱

响应式适配

从PC大屏到平板再到手机，所有界面自动适配。决策界面在手机上简化，复杂操作引导到PC端。
