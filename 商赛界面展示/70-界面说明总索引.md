## 按学段推荐路径

### 初中段（12-15岁）
**推荐模式**：02 实时经营挑战
- 个人挑战形式，无需复杂团队协作
- 多线程操作训练注意力分配
- 5分钟应急决策培养快速反应能力

### 高中段（15-18岁）
**推荐路径**：01 → 03 → 04 → 07
1. **01 回合制策略商赛**：入门经典，理解基本商业逻辑
2. **03 拍卖交易大厅**：理解价格发现和市场机制
3. **04 产业链角色扮演**：体验协作与谈判
4. **07 创业生存战**：感受创业的真实压力

### 大学/职校段（18岁+）
**推荐路径**：05 → 06 → 08 → 09 → 10
1. **05 案例推演决策**：深度伦理思考
2. **06 投资人对决**：理解资本视角
3. **08 宏观经济沙盘**：建立系统思维
4. **09 ESG可持续经营**：社会责任与长期价值
5. **10 跨国贸易博弈**：全球化视野

## 界面设计统一规范

### 视觉系统
- **背景**：深色主题（`#0f172a`），减少视觉疲劳
- **卡片**：玻璃拟态效果（半透明+模糊背景）
- **字体**：系统字体栈，等宽字体用于数据展示
- **动画**：CSS transform/opacity，GPU加速

### 导航结构
每个界面采用统一的单页长滚动布局：
```
导航栏 → Hero区域 → 概览 → 核心机制 → 交互界面 → 特色功能 → 页脚
```

### 响应式断点
- 桌面端（>1024px）：完整多栏布局
- 平板端（768-1024px）：双栏或堆叠
- 移动端（<768px）：单栏全宽

## 教学使用指南

### 课前准备
1. 根据教学目标选择1-3种竞赛模式
2. 确保学生理解基本规则（5-10分钟讲解）
3. 分组（如需团队协作模式）

### 课中操作
1. 启动界面，让学生熟悉操作（5分钟）
2. 进行模拟竞赛（根据模式，20-60分钟）
3. 观察学生行为，记录典型决策

### 课后复盘
1. 公布结果，展示排名/结局
2. 引导学生反思关键决策点
3. 引出对应的商业理论概念
4. 布置延伸阅读或下次模拟
