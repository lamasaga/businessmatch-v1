# 07-创业生存战 · 界面说明

## 一、界面定位与设计理念

### 1.1 核心定位
创业生存战是商业模拟平台的**极限压力测试模块**。模拟真实创业的残酷法则：现金流断裂即出局，没有排名，只有生与死。面向高中及以上学段，训练风险意识、成本控制与危机决策能力。

### 1.2 设计目标
- **体验生存压力**：不是比谁赚得多，而是比谁活得久
- **理解现金流为王**：所有指标最终都指向一个数字
- **感受随机灾难**：没有安全区，危机随时可能降临
- **训练危机决策**：在信息不完全和时间压力下做出选择

### 1.3 与回合制/实时模式的区别
| 维度 | 回合制策略商赛 | 实时经营挑战 | 创业生存战 |
|------|---------------|-------------|-----------|
| 胜负标准 | 排名 | 持续经营 | 存活/出局 |
| 失败后果 | 落后 | 困难 | 淘汰 |
| 压力来源 | 对手 | 时间+事件 | 生存 |
| 核心指标 | 综合得分 | 多指标平衡 | 现金流 |
| 心理体验 | 竞争 | 忙碌 | 恐惧 |

### 3.2 生存法则 · 三卡片概览

**出局机制** 💀
- 现金流归零即出局，没有复活机会
- 就像真实创业，资金链断裂公司就倒闭
- 最后存活者胜

**时间压力** ⏰
- 每轮代表一个月，固定支出自动扣除
- 收入不确定，支出是确定的
- 必须在钱用完之前找到盈利模式

**随机灾难** 🎲
- 客户流失、核心员工离职、设备故障、疫情冲击
- 随机事件不断考验韧性
- 没有安全区

### 3.4 危机决策

**危机横幅**（红色渐变+脉冲动画）：
- 标题："🚨 重大危机：最大客户流失"
- 描述：占收入40%的核心客户终止合作，月收入将从¥8万骤降至¥4.8万
- 决策倒计时："03:00"（大字号红色）
- 警告："若不行动，跑道将缩短至 1.2个月"

**四选项网格**（2×2）：

**方案A · 紧急裁员50%** ✂️
- 裁掉6名员工，支出从¥8.5万降至¥5.5万
- 需支付N+1补偿金约¥6万
- **影响**：-6人 / +1.1月跑道 / -¥6万一次性 / -30%产能

**方案B · 紧急融资** 💰
- 以极低估值（稀释40%股权）借款¥30万
- **影响**：+¥30万现金 / +10月跑道 / -40%股权 / 高风险

**方案C · 全力挽回客户** 🎯
- 创始人亲自拜访，承诺降价20%
- 50%概率挽回
- **影响**：50%挽回率 / -20%利润率 / -¥2万成本 / 不确定

**方案D · Pivot转型** 🚀
- 放弃B端业务，All in C端产品
- 3个月开发期，期间零收入
- **影响**：3月零收 / 10x潜在市场 / 70%失败率 / 豪赌

**设计意图**：
- 危机横幅使用脉冲动画，制造紧迫感
- 每个方案明确列出四个维度的影响
- 没有完美选项，每个都有重大代价
- 真实创业中的典型困境：裁员、融资、挽回、转型

## 六、使用建议

### 6.1 适合场景
- 创业课程的风险教育
- 需要体验"失败"的学习目标
- 理解"现金流为王"的财务管理核心

### 6.2 教师操作要点
1. **赛前**：强调"出局"是正常结果，不是失败
2. **赛中**：观察学生的情绪反应——焦虑、恐慌、冷静
3. **赛后**：重点复盘"哪个预警信号被忽视了？"

### 6.3 常见学生误区
- **过度乐观**：低估固定支出，高估收入增长
- **忽视 runway**：不关注"还能活多久"
- **反应过度**：对每个危机都采取最激进措施
- **沉没成本**：因为已经投入很多，不愿及时止损
